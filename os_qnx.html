1. 一般                                                 qnx-general

QNX 上の Vim は、他の unix 版とほとんど同じように動作する。os_unix.txt


2. Vim のコンパイル                                     qnx-compiling

Vim は標準の configure/make の方法でコンパイルできる。X11 向けにコンパイルした
い場合は、configure に --with-x オプションを渡す。そうでない場合、./configure
を引数なしで実行するか、または --enable-gui=photon を渡すと、Photon gui サポー
ト付きの vim がコンパイルされる。有効/無効にできる他の機能を調べるには、
./configure --help , を実行すること。


3. 端末サポート                                         qnx-terminal

Vim は、それらのオプションがコンパイルで組み込まれていれば、pterm でのマウスお
よびクリップボードをサポートしている。通常は組み込まれている。

マウスサポートに影響するオプションは 'mouse' および 'ttymouse' である。マウス
を使うとき、単純な左および右のマウスクリック/ドラッグだけがサポートされる。マ
ウスを使っている間に shift、ctrl、または alt を押していると、pterm がマウスを
自分で扱う。vim がしていることとは別に、選択を行う。

マウスを使用中は、Alt-RightMouse を押すと pterm のメニューを開ける。vim でマウ
スを無効にするには、mouse オプションを空に設定する、set mouse=


4. Photon GUI                                           photon-gui

vim の gui を起動するには、gvim または vim -g のどちらかを実行する必要がある。
そうしないと端末版が起動する。詳しい情報は - gui-x11-start

サポートされている機能:
        :browse コマンド                                :browse
        :confirm コマンド                               :confirm
        カーソル点滅                                    'guicursor'
        メニュー、ポップアップメニュー、およびメニュー優先順位  :menu
                                                        popup-menu
                                                        menu-priority
        ツールバー                                      gui-toolbar
                                                        'toolbar'
        フォントセレクタ (:set guifont=*)               photon-fonts
        マウスフォーカス                                'mousefocus'
        マウスを隠す                                    'mousehide'
        マウスカーソルの形状                            'mouseshape'
        クリップボード                                  gui-clipboard

未完成の機能:
        ペルシア語およびヘブライ語のサポートなどのさまざまな国際化サポート、
        異なるエンコーディング、など。

        このヘルプファイル

サポートされていない機能:
        検索および置換のウィンドウ                      :promptfind
        ティアオフメニュー

        思いつかないのでリストに書けない、その他のこと


5. フォント                                             photon-fonts

gui のフォントは guifont オプションで設定する
        :set guifont=Lucida\ Terminal

フォントは等幅フォントでなければならず、フォント名の中の空白はすべて '\' でエ
スケープしなければならない。デフォルトで使われるフォントは PC Terminal、サイズ
8 である。フォント名として'*' を使うと、標準の Photon のフォントセレクタが開
き、そこでフォントを選択できる。

名前の後に、フォントのサイズおよびスタイルを制御する任意の設定を含めることがで
きる。各設定は ':' で区切る。すべてのフォントがさまざまなスタイルをサポートし
ているわけではない。

オプションは、
    s{size}     フォントのサイズを {size} に設定する
    b           太字スタイル
    a           アンチエイリアスを使う
    i           イタリックスタイル

例:

フォントを monospace のサイズ 10、アンチエイリアス付きに設定する
        :set guifont=monospace:s10:a

フォントを Courier のサイズ 12、太字およびイタリック付きに設定する
        :set guifont=Courier:s12:b:i

リクエスタでフォントを選択する
        :set guifont=*



6. バグとやるべきこと

既知の問題:
        - 外部プログラムを実行するときに、Vim が時々固まる。回避策: この行を
          vimrc ファイルに入れる:
                set noguipty

バグ:
        - メニューハイライトにまだ少し問題がある。
        - phditto/phinows などを使っているときに、太字属性をサポートしていない
          フォントを使っていると、vim が太字のテキストを描こうとしたときに、す
          べてめちゃくちゃになる。
        - カーソルが時々見えにくいことがある。
        - 修正できる多数の小さな問題。:)
