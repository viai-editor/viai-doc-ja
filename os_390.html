1. ASCII/EBCDIC に依存するスクリプト    OS390-has-ebcdic zOS-has-ebcdic

内部スクリプト言語に "ebcdic" 機能が追加された。これを使って、ASCII に依存する
スクリプトをこのように修正できる:

    if has("ebcdic")
        let space = 64
    else
        let space = 32
    endif


==============================================================================
2. PuTTY と色                           OS390-PuTTY zOS-PuTTY

Putty を使って z/OS に接続したときに、構文ハイライトの問題やスクリーンの崩れが
見られる場合は、以下を試すこと:

- Putty を "vt220" 端末として設定する (Connection->Data)
- 以下の 3 行を vimrc に追加する:


    set t_AB=^[[4%p1%dm
    set t_AF=^[[3%p1%dm
    set t_CO=8


Note: ^[ は 1 文字であり、入力するには <C-V><Esc> を使う。

3. Motif の問題                         OS390-Motif zOS-Motif

Note: Vim 6.* で見られた。それ以降はテストされていない。

Motif ライブラリを z/OS に移植する際に、プルダウンメニューのアクセラレータ文字
の EBCDIC から ASCII への変換が忘れられたようである。私がメニューを手で変換し
ようとした後でも、アクセラレータキーはメニューを開くこと (ファイルメニューを開
く <Alt-F> など) にしか機能しないままだった。メニュー項目自体 (ファイルブラウ
ザーを開く <Alt-F>O など) にはまだ機能しない。

これにはまだ解決策がない。

4. バグ                                 OS390-bugs zOS-Bugs

- ビジュアルブロックモードで大量のテキストが選択されると、Vim は決まってハング
  する。これはメモリ破壊の問題によるものかもしれない。Note これは端末版と GUI
  版の両方で起こることに注意。

5. 制限事項                             OS390-limitations zOS-limitations

- タグファイル内で二分探索をしない。
  /bin/sort プログラムはデフォルトで ASCII 値でソートする。このプログラムは通
  常、ctags がタグをソートするのに使われる。それを正しく行う ctags のバージョ
  ンがどこかにあるかもしれないが、確かではない。そのため、これは恒久的な制限で
  あるように思われる。

- cscope インターフェイス (cscope) は、我々のメインフレームで使っている
  cscope のバージョンでは動作しない。我々はバージョン 15.0b12 のコピーを持って
  いるが、"cscope add" コマンドを使うと Vim がハングする。cscope データベース
  のバイナリ形式が、Vim が期待しているものとは少し違うのだろうと推測している。
  cscope の現在のバージョン (15.3) を z/OS に移植しようとしたが、あまりうまく
  いかなかった。試すことに興味がある人は、何か進展があれば私に連絡してほしい。

- glib/gtk のサポートはない。私は z/OS UNIX で glib をうまくコンパイルできてい
  ない。つまり、きれいな gtk ツールバーなしで暮らさなければならないということ
  である。

コンパイル時に無効にされているもの:
    - マルチバイトサポート      (multibyte)
    - 右から左モード            (rileft)
    - ペルシア語キーマップ      (Farsi)
    - アラビア語サポート        (Arabic)
    - スペルチェック            (spell)

テストされていないもの:
    - Perl インターフェイス     (perl)
    - ハングル入力              (hangul)
    - 暗号化サポート            (encryption)
    - Langmap                   ('langmap')
    - Python サポート           (Python)
    - 右から左モード            ('rightleft')
    - TCL インターフェイス      (tcl)
    ...
