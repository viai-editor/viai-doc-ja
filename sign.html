==============================================================================
1. 導入                                         sign-intro signs

デバッガまたはその他の IDE ツールがエディタを操作している場合、ファイルについ
ての有用な情報をユーザーに素早く伝える特定のハイライトを与えることができる必要
がある。その一例は、左端のカラムにブレークポイントを示すアイコンを持つデバッガ
であろう。別の例は、プログラムカウンタ (PC) を表す矢印かもしれない。目印機能
は、ウィンドウの左側への目印、またはアイコンの設置、およびその行に適用されるハ
イライトの定義の両方を可能にする。目印を画像として表示するのは、おそらく gvim
でのみ実現可能である (Sun Microsystem の dtterm はこれをサポートしているが、そ
れは私が知る限りこれをサポートする唯一の端末エミュレータである)。テキスト目印
およびハイライトは、どのカラー端末エミュレータでも実現可能なはずである。

目印およびハイライトはデバッガにとってだけ有用なわけではない。Sun の Visual
WorkShop は、ビルドエラーおよび SourceBrowser のヒットに印を付けるために目印お
よびハイライトを使用する。さらに、デバッガは 8 から 10 種類の異なる目印および
ハイライト色をサポートしている。NetBeans を参照。

目印の使用には 2 つの段階がある:

1. 目印を定義する。これは画像、テキスト、およびハイライトを指定する。例えば、
   一時停止の道路標識の画像およびテキスト "!!" を持つ "break" 目印を定義でき
   る。

2. 目印を設置する。これは目印が表示されるファイルおよび行番号を指定する。定義
   された目印は、異なる行およびファイルに複数回設置できる。

                                                        sign-column
ファイルに対して目印が定義された場合、Vim はそれらを表示するための 2 文字幅の
カラムを自動的に追加する。最後の目印の設置が解除された場合、カラムは再び消え
る。この動作は 'signcolumn' オプションで変更できる。

カラムの色は SignColumn ハイライトグループ hl-SignColumn で設定される。色を
設定する例:

        :highlight SignColumn guibg=darkgrey

'cursorline' が有効な場合、CursorLineSign ハイライトグループ
hl-CursorLineSign が使用される。
                                                        sign-identifier
設置された各目印は、目印識別子と呼ばれる数値で識別される。この識別子は、目印へ
ジャンプするか、または目印を除去するために使用される。識別子は、:sign-place
コマンドまたは sign_place() 関数を使用して目印を設置するときに割り当てられ
る。各目印識別子は一意な数値であるべきである。設置された複数の目印が同じ識別子
を使用している場合、目印へのジャンプまたは目印の除去は予測不能になる。識別子の
重複を避けるために、目印グループを使用できる。sign_place() 関数を目印識別子
0 で呼び出して、次の使用可能な識別子を割り当てることができる。

                                                        sign-group
設置された各目印は、グローバルグループまたは名前付きグループのどちらかに割り当
てることができる。目印を設置するとき、グループ名が指定されていない場合、または
空文字列が使用された場合、目印はグローバルグループに設置される。そうでない場
合、目印は名前付きグループに設置される。目印識別子はグループ内で一意である。目
印グループにより、Vim プラグインは、目印を使用する他のプラグインに干渉すること
なく、一意な目印を使用できる。

ポップアップウィンドウに目印を設置するには、グループ名は "PopUp" で始まらなけ
ればならない。その他の目印はポップアップウィンドウには表示されない。グループ名
"PopUpMenu" は、'cursorline' が設定されたポップアップウィンドウで使用される。

                                                        sign-priority
設置された各目印には優先度の値が割り当てられる。同じ行に複数の目印が設置された
場合、目印グループに関係なく、最も高い優先度を持つ目印の属性が使用される。目印
のデフォルトの優先度は 10 であり、この値は、定義時に異なる値を指定することで、
異なる目印に対して変更できる。優先度は目印を設置する時点で割り当てられる。

同じ優先度を持つ 2 つの目印が存在し、一方が目印カラムにアイコンまたはテキスト
を持ち、もう一方が行ハイライトを持つ場合、両方が表示される。

目印が設置されている行が削除された場合、目印は次の行 (次の行が無い場合はバッ
ファの最終行) に移動される。削除が undo された場合、目印は元に戻らない。

行ハイライトを持つ目印および 'cursorline' ハイライトが両方存在する場合、優先度
が 100 以上の場合は目印ハイライトが優先され、そうでない場合は 'cursorline' ハ
イライト。

2. コマンド                                     sign-commands :sig :sign

以下は、テキスト ">>" で表示される目印 "piet" を、カレントファイルの 23 行目に
設置する例である:
        :sign define piet text=>> texthl=Search
        :exe ":sign place 2 line=23 name=piet file=" .. expand("%:p")

そして、以下はそれを再び削除するコマンドである:
        :sign unplace 2

Note ":sign" コマンドの後に別のコマンドまたはコメントを続けることはできないこ
とに注意。それが必要な場合は、:execute コマンドを使用すること。


目印の定義。                           :sign-define E255 E160 E612

同等の Vim script 関数については sign_define() を参照。

:sig[n] define {name} {argument}...
                新しい目印を定義するか、または既存の目印の属性を設定する。
                {name} は数値 (全て数字) または数字以外で始まる名前のどちらか
                にできる。先頭の 0 は無視されるので、"0012"、"012"、および
                "12" は同じ名前と見なされる。
                約 120 個の異なる目印を定義できる。

                受け付けられる引数:

        icon={bitmap}
                ビットマップが見つかるファイル名を定義する。フルパスであるべき
                である。ビットマップは 2 文字分の場所に収まるべきである。これ
                はチェックされない。ビットマップが大きすぎる場合、再描画の問題
                を引き起こす。GTK 2 だけが、ビットマップを使用可能なスペースに
                合わせて拡大縮小できる。
                        ツールキット    サポート
                        GTK 1           pixmap (.xpm)
                        GTK 2           多数
                        Motif           pixmap (.xpm)
                        Win32           .bmp, .ico, .cur
                                        pixmap (.xpm) +xpm_w32
        priority={prio}
                目印のデフォルトの優先度。sign-priority を参照。

        linehl={group}
                目印が設置されている行全体に使用されるハイライトグループ。背景
                色を定義するのが最も有用である。

        numhl={group}
                目印が設置されている行の行番号に使用されるハイライトグループ。
                hl-LineNr、hl-LineNrAbove、hl-LineNrBelow、および
                hl-CursorLineNr を上書きする。

        text={text}                                             E239
                アイコンが無いとき、または GUI が使用されていないときに表示さ
                れるテキストを定義する。印字可能文字のみが許可され、それらは 1
                つまたは 2 つの表示セルを占めなければならない。

        texthl={group}
                テキスト項目に使用されるハイライトグループ。

        culhl={group}
                カーソルが目印と同じ行にあり、'cursorline' が有効なときに、テ
                キスト項目に使用されるハイライトグループ。

        例:
                :sign define MySign text=>> texthl=Search linehl=DiffText


目印の削除                                             :sign-undefine E155

同等の Vim script 関数については sign_undefine() を参照。

:sig[n] undefine {name}
                以前に定義された目印を削除する。この {name} を持つ目印がまだ設
                置されている場合、問題が発生する。

                例:
                        :sign undefine MySign


目印の一覧表示                                 :sign-list E156

同等の Vim script 関数については sign_getdefined() を参照。

:sig[n] list    定義されている全ての目印およびそれらの属性を一覧表示する。

:sig[n] list {name}
                定義されている 1 つの目印およびその属性を一覧表示する。


目印の設置                                             :sign-place E158

同等の Vim script 関数については sign_place() を参照。

:sig[n] place {id} line={lnum} name={name} file={fname}
                {name} として定義された目印を、ファイル {fname} の {lnum} 行目
                に設置する。
                                                        :sign-fname
                ファイル {fname} は既にバッファに読み込まれていなければならな
                い。正確なファイル名を使用しなければならず、ワイルドカード、
                $ENV、および ~ は展開されず、空白はエスケープしてはならない。
                末尾の空白は無視される。

                目印は {id} で記憶され、これはその後の操作に使用できる。{id}
                は数値でなければならない。
                {id} が各ファイルで 1 回だけ使用されるようにするのはユーザーの
                責任である (複数回使用された場合、設置の解除も複数回行わなけれ
                ばならず、変更が期待どおりに動作しないかもしれない)。

                以下の省略可能な目印属性を "file=" の前に指定できる:
                        group={group}   目印を目印グループ {group} に設置する
                        priority={prio} 目印に優先度 {prio} を割り当てる

                デフォルトでは、目印はグローバル目印グループに設置される。

                デフォルトでは、目印の定義で別に指定されていない限り、目印には
                デフォルトの優先度 10 が割り当てられる。異なる優先度の値を割り
                当てるには、"priority={prio}" を使用して値を指定する。優先度
                は、同じ行に複数の目印が設置されたときに表示される目印を決定す
                るために使用される。

                例:
                        :sign place 5 line=3 name=sign1 file=a.py
                        :sign place 6 group=g2 line=2 name=sign2 file=x.py
                        :sign place 9 group=g2 priority=50 line=5
                                                        \ name=sign1 file=a.py

:sig[n] place {id} line={lnum} name={name} [buffer={nr}]
                同上、ただしバッファ {nr} を使用する。buffer 引数が指定されて
                いない場合、目印をカレントバッファに設置する。

                例:
                        :sign place 10 line=99 name=sign3
                        :sign place 10 line=99 name=sign3 buffer=3

                                                        E885
:sig[n] place {id} name={name} file={fname}
                ファイル {fname} 内の設置された目印 {id} を、定義された目印
                {name} を使用するように変更する。{fname} については上記の注意
                :sign-fname を参照。これは、表示される目印を移動せずに変更す
                るために使用できる (例えば、デバッガがブレークポイントで停止し
                たとき)。

                省略可能な "group={group}" 属性を "file=" の前に使用して、特定
                のグループ内の目印を選択できる。省略可能な "priority={prio}"
                属性を使用して、既存の目印の優先度を変更できる。

                例:
                        :sign place 23 name=sign1 file=/path/to/edit.py

:sig[n] place {id} name={name} [buffer={nr}]
                同上、ただしバッファ {nr} を使用する。buffer 引数が指定されて
                いない場合、カレントバッファを使用する。

                例:
                        :sign place 23 name=sign1
                        :sign place 23 name=sign1 buffer=7


目印の除去                                             :sign-unplace E159

同等の Vim script 関数については sign_unplace() を参照。

:sig[n] unplace {id} file={fname}
                以前に設置された目印 {id} をファイル {fname} から除去する。
                {fname} については上記の注意 :sign-fname を参照。

:sig[n] unplace {id} group={group} file={fname}
                同上、ただし目印グループ {group} 内の目印 {id} を除去する。

:sig[n] unplace {id} group=* file={fname}
                同上、ただし全ての目印グループから目印 {id} を除去する。

:sig[n] unplace * file={fname}
                ファイル {fname} 内の全ての設置された目印を除去する。

:sig[n] unplace * group={group} file={fname}
                グループ {group} 内の全ての設置された目印をファイル {fname} か
                ら除去する。

:sig[n] unplace * group=* file={fname}
                全てのグループ内の全ての設置された目印をファイル {fname} から
                除去する。

:sig[n] unplace {id} buffer={nr}
                以前に設置された目印 {id} をバッファ {nr} から除去する。

:sig[n] unplace {id} group={group} buffer={nr}
                グループ {group} 内の以前に設置された目印 {id} をバッファ {nr}
                から除去する。

:sig[n] unplace {id} group=* buffer={nr}
                全てのグループ内の以前に設置された目印 {id} をバッファ {nr} か
                ら除去する。

:sig[n] unplace * buffer={nr}
                バッファ {nr} 内の全ての設置された目印を除去する。

:sig[n] unplace * group={group} buffer={nr}
                グループ {group} 内の全ての設置された目印をバッファ {nr} から
                除去する。

:sig[n] unplace * group=* buffer={nr}
                全てのグループ内の全ての設置された目印をバッファ {nr} から除去
                する。

:sig[n] unplace {id}
                以前に設置された目印 {id} を、それが現れる全てのファイルから除
                去する。

:sig[n] unplace {id} group={group}
                グループ {group} 内の以前に設置された目印 {id} を、それが現れ
                る全てのファイルから除去する。

:sig[n] unplace {id} group=*
                全てのグループ内の以前に設置された目印 {id} を、それが現れる全
                てのファイルから除去する。

:sig[n] unplace *
                グローバルグループ内の全ての設置された目印を全てのファイルから
                除去する。

:sig[n] unplace * group={group}
                グループ {group} 内の全ての設置された目印を全てのファイルから
                除去する。

:sig[n] unplace * group=*
                全てのグループ内の全ての設置された目印を全てのファイルから除去
                する。

:sig[n] unplace
                カーソル位置の設置された目印を除去する。その行に複数の目印が設
                置されている場合、1 つだけが除去される。

:sig[n] unplace group={group}
                カーソル位置のグループ {group} 内の設置された目印を除去する。

:sig[n] unplace group=*
                カーソル位置の任意のグループ内の設置された目印を除去する。

目印へのジャンプ                                       :sign-jump E157

同等の Vim script 関数については sign_jump() を参照。

:sig[n] jump {id} file={fname}
                ファイル {fname} を開くか、または {fname} を含むウィンドウへ
                ジャンプし、カーソルを目印 {id} に置く。
                {fname} については上記の注意 :sign-fname を参照。
                ファイルがウィンドウに表示されておらず、カレントファイルを
                abandon できない場合、これは失敗する。

:sig[n] jump {id} group={group} file={fname}
                同上、ただしグループ {group} 内の目印へジャンプする

                同上、ただしバッファ {nr} を使用する。バッファ {nr} が名前を持
                たない場合、これは失敗する。buffer 引数が指定されていない場合、
                カレントバッファを使用する。

:sig[n] jump {id} group={group} [buffer={nr}]
                同上、ただしグループ {group} 内の目印へジャンプする

3. 関数                                         sign-functions-details

sign_define({name} [, {dict}])                          sign_define()
sign_define({list})
                {name} という名前の新しい目印を定義するか、または既存の目印の
                属性を変更する。これは :sign-define コマンドに似ている。

                名前の衝突を避けるために、{name} の前に一意なテキストを付ける
                こと。目印を設置する場合のような {group} は無い。

                {name} は文字列または数値にできる。省略可能な {dict} 引数は目
                印の属性を指定する。以下の値がサポートされている:
                   icon         目印のビットマップファイルへのフルパス。
                   linehl       目印が設置されている行全体に使用されるハイライ
                                トグループ。
                   priority     目印のデフォルトの優先度の値
                   numhl        目印が設置されている行番号に使用されるハイライ
                                トグループ。
                   text         アイコンが無いとき、または GUI が使用されてい
                                ないときに表示されるテキスト。
                   texthl       テキスト項目に使用されるハイライトグループ
                   culhl        カーソルが目印と同じ行にあり、'cursorline' が
                                有効なときに、テキスト項目に使用されるハイライ
                                トグループ。

                {name} という名前の目印が既に存在する場合、目印の属性が更新さ
                れる。

                1 つの引数 {list} を使用して、目印のリストを定義できる。各リス
                ト項目は、{dict} 内の上記の項目および目印名の "name" 項目を持
                つ辞書である。

                成功時は 0 を、失敗時は -1 を返す。1 つの引数 {list} が使用さ
                れた場合、定義された目印ごとに 1 つずつの値のリストを返す。

                                \ "text" : "=>",
                                \ "texthl" : "Error",
                                \ "linehl" : "Search"})
                        call sign_define([
                                \ {'name' : 'sign1',
                                \  'text' : '=>'},
                                \ {'name' : 'sign2',
                                \  'text' : '!!'}
                                \ ])

                method としても使用できる:
                        GetSignList()->sign_define()

sign_getdefined([{name}])                               sign_getdefined()
                定義された目印およびそれらの属性のリストを取得する。
                これは :sign-list コマンドに似ている。

                {name} が指定されていない場合、定義された全ての目印のリストが
                返される。そうでない場合、指定された目印の属性が返される。

                   icon         目印のビットマップファイルへのフルパス
                   linehl       目印が設置されている行全体に使用されるハイライ
                                トグループ。設定されていない場合は存在しない
                   name         目印の名前
                   priority     目印のデフォルトの優先度の値
                   numhl        目印が設置されている行番号に使用されるハイライ
                                トグループ。設定されていない場合は存在しない
                   text         アイコンが無いとき、または GUI が使用されてい
                                ないときに表示されるテキスト。
                   texthl       テキスト項目に使用されるハイライトグループ。設
                                定されていない場合は存在しない
                   culhl        カーソルが目印と同じ行にあり、'cursorline' が
                                有効なときに、テキスト項目に使用されるハイライ
                                トグループ。設定されていない場合は存在しない

                目印が無い場合、および {name} が見つからない場合、空のリストを
                返す。

                例:
                        " 定義された全ての目印のリストを取得する
                        echo sign_getdefined()

                        " mySign という名前の目印の属性を取得する
                        echo sign_getdefined("mySign")

                        GetSignList()->sign_getdefined()

                戻り値の型: list<dict<string>> または list<any>


sign_getplaced([{buf} [, {dict}]])                      sign_getplaced()
                バッファ内または全てのバッファ内に設置された目印のリストを返
                す。これは :sign-place-list コマンドに似ている。

                省略可能なバッファ名 {buf} が指定された場合、そのバッファに設
                置された目印のリストだけが返される。{buf} の使い方については
                bufname() を参照。省略可能な {dict} は以下のエントリを含むこ
                とができる:
                   group        このグループ内の目印のみを選択する
                   id           この識別子を持つ目印を選択する
                   lnum         この行に設置された目印を選択する。{lnum} の使
                                い方については line() を参照。
                {group} が '*' の場合、グローバルグループを含む全てのグループ
                内の目印が返される。{group} が指定されていないか、または空文字
                列の場合、グローバルグループ内の目印のみが返される。引数が指定
                されていない場合、全てのバッファに設置されたグローバルグループ
                内の目印が返される。
                sign-group を参照。

                戻り値の各リスト項目は、以下のエントリを持つ辞書である:
                        bufnr   目印を持つバッファの番号
                        signs   {bufnr} に設置された目印のリスト。各リスト項目
                                は、以下に挙げるエントリを持つ辞書である

                各目印の辞書は以下のエントリを含む:
                        group    目印グループ。グローバルグループの場合は ''
                                 に設定される。
                        id       目印の識別子
                        lnum     目印が設置されている行番号
                        name     定義された目印の名前
                        priority 目印の優先度

                バッファ内の返される目印は、行番号および優先度の順に並べられ
                る。

                失敗した場合、または設置された目印が無い場合、空のリストを返
                す。

                例:
                        " eval.c に設置されたグローバルグループ内の
                        " 目印のリストを取得する
                        echo sign_getplaced("eval.c")

                        " eval.c に設置されたグループ 'g1' 内の目印のリストを取得する
                        echo sign_getplaced("eval.c", {'group' : 'g1'})

                        " eval.c の 10 行目に設置された目印のリストを取得する
                        echo sign_getplaced("eval.c", {'lnum' : 10})

                        " a.py に設置された識別子 10 の目印を取得する
                        echo sign_getplaced("a.py", {'id' : 10})

                        " a.py に設置されたグループ 'g1' 内の id 20 の目印を取得する
                        echo sign_getplaced("a.py", {'group' : 'g1',
                                                        \  'id' : 20})

                        " 設置された全ての目印のリストを取得する
                        echo sign_getplaced()

                method としても使用できる:
                        GetBufname()->sign_getplaced()

                戻り値の型: list<dict<any>>


sign_jump({id}, {group}, {buf})                         sign_jump()

                :sign-jump コマンドに似ている。

                {group} が空文字列の場合、グローバルグループが使用される。{buf}

                目印の行番号を返す。引数が無効な場合は -1 を返す。

                例:
                        " カレントバッファ内の目印 10 へジャンプする
                        call sign_jump(10, '', '')

                method としても使用できる:

                戻り値の型: Number


                                                        sign_place()
sign_place({id}, {group}, {name}, {buf} [, {dict}])
                {name} として定義された目印を、ファイルまたはバッファ {buf} の
                {lnum} 行目に設置し、目印に {id} および {group} を割り当てる。
                これは :sign-place コマンドに似ている。

                目印識別子 {id} が 0 の場合、新しい識別子が割り当てられる。そ
                うでない場合、指定された数値が使用される。{group} は目印グルー
                プ名である。グローバル目印グループを使用するには、空文字列を使
                用する。{group} は {id} の名前空間として機能するので、2 つのグ
                ループが同じ ID を使用できる。詳細については sign-identifier
                および sign-group を参照。

                {name} は定義された目印を参照する。
                {buf} はバッファ名または番号を参照する。受け付けられる値につい
                ては bufname() を参照。

                省略可能な {dict} 引数は以下のエントリをサポートする:
                        lnum            目印が設置されるファイルまたはバッファ
                                        {buf} 内の行番号。受け付けられる値につ
                                        いては line() を参照。
                        priority        目印の優先度。詳細については
                                        sign-priority を参照。

                省略可能な {dict} が指定されていない場合、グループ {group} 内
                の設置された目印 {id} を、定義された目印 {name} を使用するよう
                に変更する。

                成功時は目印識別子を、失敗時は -1 を返す。

                例:
                        " sign1 という名前の目印を id 5 で、バッファ json.c の
                        " 20 行目に設置する
                        call sign_place(5, '', 'sign1', 'json.c',
                                                        \ {'lnum' : 20})

                        " バッファ json.c 内の目印 5 を sign2 を使用するように更新する
                        call sign_place(5, '', 'sign2', 'json.c')

                        " sign3 という名前の目印を、新しい識別子で、
                        " バッファ json.c の 30 行目に設置する
                        let id = sign_place(0, '', 'sign3', 'json.c',
                                                        \ {'lnum' : 30})

                        " sign4 という名前の目印を id 10 でグループ 'g3' 内に、
                        " バッファ json.c の 40 行目に優先度 90 で設置する
                        call sign_place(10, 'g3', 'sign4', 'json.c',
                                        \ {'lnum' : 40, 'priority' : 90})

                method としても使用できる:
                        GetSignid()->sign_place(group, name, expr)

                戻り値の型: Number


sign_placelist({list})                          sign_placelist()
                1 つ以上の目印を設置する。これは sign_place() 関数に似てい
                る。{list} 引数は設置する目印のリストを指定する。各リスト項目
                は、以下の目印属性を持つ辞書である:
                    buffer      バッファ名または番号。受け付けられる値について
                                は bufname() を参照。
                    group       目印グループ。{group} は {id} の名前空間として
                                機能するので、2 つのグループが同じ ID を使用で
                                きる。指定されていないか、または空文字列に設定
                                された場合、グローバルグループが使用される。詳
                                細については sign-group を参照。
                    id          目印識別子。指定されていないか、または 0 の場
                                合、新しい一意な識別子が割り当てられる。そうで
                                ない場合、指定された数値が使用される。詳細につ
                                いては sign-identifier を参照。
                    lnum        目印が設置されるバッファ内の行番号。受け付けら
                                れる値については line() を参照。
                    name        設置する目印の名前。詳細については
                                sign_define() を参照。
                    priority    目印の優先度。1 行に複数の目印が設置された場
                                合、最も高い優先度を持つ目印が使用される。指定
                                されていない場合、目印の定義で別に指定されてい
                                ない限り、デフォルト値の 10 が使用される。詳細
                                については sign-priority を参照。

                {id} が既存の目印を参照する場合、既存の目印は指定された {name}
                および/または {priority} を使用するように変更される。

                目印識別子のリストを返す。目印の設置に失敗した場合、対応するリ
                スト項目は -1 に設定される。

                例:
                        " バッファ a.c の 20 行目に id 5 で、30 行目に id 10 で
                        " 目印 s1 を設置する
                        let [n1, n2] = sign_placelist([
                                \ {'id' : 5,
                                \  'name' : 's1',
                                \  'buffer' : 'a.c',
                                \  'lnum' : 20},
                                \ {'id' : 10,
                                \  'name' : 's1',
                                \  'buffer' : 'a.c',
                                \  'lnum' : 30}
                                \ ])

                        " 自動生成された識別子で、バッファ a.c の 40 行目および
                        " 50 行目に目印 s1 を設置する
                        let [n1, n2] = sign_placelist([
                                \ {'name' : 's1',
                                \  'buffer' : 'a.c',
                                \  'lnum' : 40},
                                \ {'name' : 's1',
                                \  'buffer' : 'a.c',
                                \  'lnum' : 50}
                                \ ])

                method としても使用できる:
                        GetSignlist()->sign_placelist()

                戻り値の型: list<number> または list<any>

sign_unplace({group} [, {dict}])                        sign_unplace()
                1 つ以上のバッファ内の以前に設置された目印を除去する。これは
                :sign-unplace コマンドに似ている。

                {group} は目印グループ名である。グローバル目印グループを使用す
                るには、空文字列を使用する。{group} が '*' に設定された場合、
                グローバルグループを含む全てのグループが使用される。
                {group} 内の目印は、{dict} 内のエントリに基づいて選択される。

                        buffer  バッファ名または番号。bufname() を参照。
                        id      目印識別子
                {dict} が指定されていない場合、{group} 内の全ての目印が除去さ
                れる。

                成功時は 0 を、失敗時は -1 を返す。

                例:
                        " バッファ a.vim から目印 10 を除去する
                        call sign_unplace('', {'buffer' : "a.vim", 'id' : 10})

                        " バッファ 3 からグループ 'g1' 内の目印 20 を除去する
                        call sign_unplace('g1', {'buffer' : 3, 'id' : 20})

                        " バッファ 10 からグループ 'g2' 内の全ての目印を除去する
                        call sign_unplace('g2', {'buffer' : 10})

                        " 全てのバッファからグループ 'g3' 内の目印 30 を除去する
                        call sign_unplace('g3', {'id' : 30})

                        call sign_unplace('*', {'buffer' : 5})

                        call sign_unplace('g4')

                        " 全てのバッファから目印 40 を除去する
                        call sign_unplace('*', {'id' : 40})

                        call sign_unplace('*')

                        GetSigngroup()->sign_unplace()
