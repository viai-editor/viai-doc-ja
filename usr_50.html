50.1  例外

例から始めましょう:

        try
           read ~/templates/pascal.tmpl
        catch /E484:/
           echo "Sorry, the Pascal template file cannot be found."
        endtry

ファイルが存在しない場合、read コマンドは失敗します。このコードは、エラーメッ
セージを生成する代わりに、エラーを捕捉して、より多くの情報を含むメッセージを
ユーザーに表示します。

try と endtry の間のコマンドでは、エラーは例外に変わります。例外は文字列で
す。エラーの場合、その文字列にはエラーメッセージが入っています。そして、すべて
のエラーメッセージには番号があります。この場合、捕捉するエラーには "E484:" が
含まれています。この番号は同じままであることが保証されています (テキストは変わ
るかもしれません。例えば、翻訳されるかもしれません)。

良いエラーメッセージを表示できることに加えて、Vim は :endtry の後のコマンド
の実行も続けます。そうでなければ、捕捉されないエラーに遭遇すると、スクリプト/
関数/マッピングの実行は中断されます。

read コマンドが別のエラーを起こした場合、パターン "E484:" はそれにマッチしま
せん。そのため、この例外は捕捉されず、通常のエラーメッセージになり、実行は中断
されます。

こうしたくなるかもしれません:

        try
           read ~/templates/pascal.tmpl
        catch
           echo "Sorry, the Pascal template file cannot be found."
        endtry

これは、すべてのエラーが捕捉されることを意味します。しかしそうすると、
"E21: Cannot make changes, 'modifiable' is off" のような、まったく別の問題を示
すエラーが見えなくなります。どんなエラーでも捕捉する前に、よく考えてください!

もう 1 つの便利な仕組みは finally コマンドです:

        var tmp = tempname()
        try
           exe ":.,$write " .. tmp
           exe "!filter " .. tmp
           :.,$delete
           exe ":$read " .. tmp
        finally
           delete(tmp)
        endtry

これは、カーソルからファイルの末尾までの行を、ファイル名の引数を取る "filter"
コマンドでフィルタします。フィルタが動作するかどうかにかかわらず、try と
finally の間で何かがおかしくなるか、またはユーザーが CTRL-C を押してフィルタ
をキャンセルしても、delete(tmp) の呼び出しは常に実行されます。これにより、一
時ファイルを残さないようにできます。

finally は例外を捕捉しません。エラーはやはり以降の実行を中断します。

例外処理についての詳しい情報は、リファレンスマニュアルにあります:
exception-handling。

50.2  可変長引数の関数

Vim では、引数の数が可変の関数を定義できます。例えば以下のコマンドは、1 個の引
数 (start) が必須で、最大 20 個の追加の引数を持てる関数を定義します:

        def Show(start: string, ...items: list<string>)

変数 "items" は、関数内で追加の引数を含むリストになります。他のリストと同じよ
うに使えます。例:

        def Show(start: string, ...items: list<string>)
          echohl Title
          echo "start is " .. start
          echohl None
          for index in range(len(items))
            echon $"  Arg {index} is {items[index]}"
          endfor
          echo
        enddef

このように呼び出せます:

        Show('Title', 'one', 'two', 'three')
        start is Title  Arg 0 is one  Arg 1 is two  Arg 2 is three

これは echohl コマンドを使って、以下の echo コマンドで使われるハイライトを
指定しています。echohl None はそれを再び止めます。echon コマンドは echo
と同じように動作しますが、改行を出力しません。

引数を 1 つで呼び出した場合、"items" リストは空になります。range(len(items))
はインデックスのリストを返し、それを for がループします。それについては後で
さらに説明します。

50.3  ビューの復元

移動して変更を加え、それから同じ位置およびビューに戻りたいことがあります。例え
ば、ファイルヘッダーの何かを変更するためです。これは 2 つの関数でできます:

        var view = winsaveview()
        # 移動して、変更を加える
        winrestview(view)
