                              素早く挿入する


テキストを入力するとき、Vim はキー入力の回数を減らし、タイプミスを避けるさまざ
まな方法を提供します。以前にタイプした単語を繰り返すには、挿入モード補完を使い
ます。長い単語を短い単語に短縮します。あなたのキーボードにない文字をタイプしま
す。

24.1  訂正する

<BS> キーについてはすでに述べました。これはカーソルの直前の文字を削除します。
<Del> キーは、カーソルの下 (後) の文字に対して同じことをします。
   単語全体を間違えてタイプしたときは、CTRL-W を使います:

        The horse had fallen to the sky
                                       CTRL-W
        The horse had fallen to the

行を本当にめちゃくちゃにしてしまい、最初からやり直したい場合、CTRL-U を使って
それを削除します。これはカーソルの後のテキストおよびインデントを保持します。最
初の空白以外の文字からカーソルまでのテキストだけが削除されます。次の行の
"fallen" の "f" にカーソルがある状態で CTRL-U を押すと、こうなります:

        The horse had fallen to the
                      CTRL-U
        fallen to the

数語前に間違いを見つけたときは、それを訂正するためにカーソルをそこに移動する必
要があります。例えば、こうタイプしたとします:

        The horse had follen to the ground

"follen" を "fallen" に変更する必要があります。カーソルが末尾にある状態で、こ
れを訂正するにはこうタイプします:

                                        <Esc>4blraA

        挿入モードを抜ける              <Esc>
        4 単語戻る                           4b
        "o" の上に移動する                     l
        "a" で置き換える                        ra
        挿入モードを再開する                      A

これを行う別の方法:

                <C-Left><C-Left><C-Left><C-Left><Right><Del>a<End>

        4 単語戻る                   <C-Left><C-Left><C-Left><C-Left>
        "o" の上に移動する                      <Right>
        "o" を削除する                                 <Del>
        "a" を挿入する                                      a
        行末に移動する                               <End>

これは、挿入モードのままで、特殊キーを使って移動します。これはモードのないエ
ディタで行うことに似ています。覚えやすいですが、より時間がかかります (あなたの
手を文字からカーソルキーへ移動する必要があり、<End> キーはキーボードを見ずに押
すのが難しいです)。
   これらの特殊キーは、挿入モードを抜けないマッピングを書くときに最も役に立ち
ます。そのときは余分なタイプは問題になりません。
   挿入モードで使用できるキーの概要:

        <C-Home>        ファイルの先頭へ
        <PageUp>        まるごと 1 画面分上へ
        <Home>          行頭へ
        <S-Left>        1 単語左へ
        <C-Left>        1 単語左へ
        <S-Right>       1 単語右へ
        <C-Right>       1 単語右へ
        <End>           行末へ
        <PageDown>      まるごと 1 画面分下へ
        <C-End>         ファイルの末尾へ

他にもいくつかあります。ins-special-special を参照してください。

24.2  マッチを表示する

) をタイプするとき、それがどの ( とマッチするかが見えると良いでしょう。Vim に
そうさせるには、このコマンドを使います:

        :set showmatch

ここで "(example)" のようなテキストをタイプすると、) をタイプするとすぐに、Vim
はカーソルをマッチする ( に短時間移動し、そこに 0.5 秒間とどめ、タイプしていた
場所に戻ります。
   マッチする ( がない場合、Vim はビープ音を鳴らします。それで、どこかで ( を
忘れたか、または ) を 1 つ多くタイプしたかもしれないことがわかります。
   マッチは [] および {} の組に対しても表示されます。次の文字をタイプするのを
待つ必要はありません。Vim がそれを認識するとすぐにカーソルが戻り、以前と同じよ
うに挿入が続きます。
   'matchtime' オプションで Vim が待つ時間を変更できます。例えば、Vim を 1 秒
半待たせるには:

        :set matchtime=15

時間は 10 分の 1 秒単位で指定します。

24.3  補完

Vim は挿入時に単語を自動的に補完できます。単語の最初の部分をタイプし、CTRL-P
を押すと、Vim が残りを推測します。
   例えば、C プログラムを作成していて、以下をタイプしたいとします:

        total = ch_array[0] + ch_array[1] + ch_array[2];

以下を入力することから始めます:

        total = ch_array[0] + ch_

この時点で、CTRL-P コマンドを使って単語を補完するように Vim に指示します。Vim
はカーソルの前にあるもので始まる単語を検索します。この場合、それは "ch_" で、
単語 ch_array にマッチします。したがって、CTRL-P をタイプすると以下のようにな
ります:

        total = ch_array[0] + ch_array

もう少しタイプすると、こうなります (空白で終わっています):

        total = ch_array[0] + ch_array[1] + 

ここで CTRL-P をタイプした場合、Vim はカーソルの前の単語を補完する単語を再び検
索します。カーソルの前には何もないので、後方に向かって最初の単語を見つけます。
それは "ch_array" です。もう一度 CTRL-P をタイプすると、マッチする次の単語、こ
の場合は "total" が得られます。3 回目の CTRL-P はさらに後方を検索します。他に
何もない場合、エディタは単語を使い果たすので、元のテキストに戻ります。それは何
もないテキストです。4 回目の CTRL-P で、エディタは再び "ch_array" から始めま
す。

前方に検索するには、CTRL-N を使います。検索はファイルの末尾で折り返すので、
CTRL-N および CTRL-P は同じマッチを見つけますが、順序が異なります。ヒント:
CTRL-N は Next-match で、CTRL-P は Previous-match です。

Vim エディタは、補完する単語を見つけるために多くの労力を費やします。既定では、
以下の場所を検索します:

        1. カレントファイル
        2. 他のウィンドウのファイル
        3. 他の読み込まれたファイル (隠しバッファ)
        4. 読み込まれていないファイル (非アクティブなバッファ)
        5. タグファイル
        6. カレントファイルによって #include されたすべてのファイル


オプション

'complete' オプションで検索順序をカスタマイズできます。

'ignorecase' オプションが使われます。これが設定されているとき、マッチを検索す
る際に大文字小文字の違いは無視されます。

補完のための特別なオプションは 'infercase' です。これは、大文字小文字を無視し
てマッチを見つけ ('ignorecase' が設定されていなければなりません)、それでもそれ
までにタイプした単語の大文字小文字を使うのに便利です。したがって、"For" とタイ
プして Vim がマッチ "fortunately" を見つけた場合、結果は "Fortunately" になり
ます。


特定のアイテムを補完する

何を探しているかがわかっている場合、これらのコマンドを使って、特定の種類のアイ
テムで補完できます:

        CTRL-X CTRL-F           ファイル名
        CTRL-X CTRL-L           行全体
        CTRL-X CTRL-D           マクロ定義 (インクルードされたファイル内も)
        CTRL-X CTRL-I           カレントファイルおよびインクルードされたファイル
        CTRL-X CTRL-K           辞書からの単語
        CTRL-X CTRL-R           レジスタからの内容
        CTRL-X CTRL-T           類語辞典からの単語
        CTRL-X CTRL-]           タグ
        CTRL-X CTRL-V           Vim コマンドライン

それぞれの後で、CTRL-N を使って次のマッチを、CTRL-P を使って前のマッチを見つけ
ることができます。
   これらの各コマンドについてのさらなる情報はこちら: ins-completion。


ファイル名を補完する

CTRL-X CTRL-F を例に取りましょう。これはファイル名を見つけます。カレントディレ
クトリのファイルを走査し、カーソルの前の単語にマッチするものをそれぞれ表示しま
す。
   例えば、カレントディレクトリに以下のファイルがあるとします:

        main.c  sub_count.c  sub_done.c  sub_exit.c

では、挿入モードに入ってタイプを始めます:

        The exit code is in the file sub

この時点で、CTRL-X CTRL-F コマンドを入力します。Vim はここで、カレントディレク
トリのファイルを見て、現在の単語 "sub" を補完します。最初のマッチは
sub_count.c です。これは望むものではないので、CTRL-N をタイプして次のファイル
にマッチさせます。このマッチは sub_done.c です。もう一度 CTRL-N をタイプすると
sub_exit.c になります。結果:

        The exit code is in the file sub_exit.c

ファイル名が / (Unix) または C:\ (MS-Windows) で始まる場合、ファイルシステム内
のすべてのファイルを見つけることができます。例えば、"/u" とタイプして CTRL-X
CTRL-F をタイプします。これは "/usr" にマッチします (これは Unix 上です):

        the file is found in /usr/

ここで CTRL-N を押した場合、"/u" に戻ります。代わりに、"/usr/" を受け入れて 1
つ深いディレクトリ階層に進むには、もう一度 CTRL-X CTRL-F を使います:

        the file is found in /usr/X11R6/

もちろん、結果はあなたのファイルシステムで何が見つかるかによります。マッチはア
ルファベット順にソートされます。


ソースコード内で補完する

ソースコードファイルはよく構造化されています。そのため、知的な方法で補完を行う
ことが可能です。Vim では、これはオムニ補完と呼ばれます。他のいくつかのエディタ
では intellisense と呼ばれていますが、それは商標です。

オムニ補完のキーは CTRL-X CTRL-O です。言うまでもなく、ここで O は Omni を表し
ているので、より簡単に覚えられます。C ソースを編集する例を使いましょう:

        {
            struct foo *p;
            p->

カーソルは "p->" の後にあります。ここで CTRL-X CTRL-O をタイプします。Vim は候
補のリストを提示します。それは "struct foo" が含むアイテムです。これは CTRL-P
を使うのとはかなり異なります。CTRL-P は任意の単語を補完しますが、ここでは
"struct foo" のメンバーだけが有効です。

オムニ補完が機能するには、何らかのセットアップが必要な場合があります。少なくと
も、ファイルタイププラグインが有効になっていることを確認してください。あなたの
vimrc ファイルにはこのような行が含まれているべきです:
        filetype plugin on
または:
        filetype plugin indent on

C コードの場合、タグファイルを作成し、'tags' オプションを設定する必要がありま
す。それは ft-c-omni で説明されています。他のファイルタイプの場合、同様のこ
とをする必要があるかもしれません。以下の compl-omni-filetypes を見てくださ
い。これは特定のファイルタイプでのみ機能します。機能するかどうかを調べるには、
'omnifunc' オプションの値を確認してください。

24.4  挿入を繰り返す

CTRL-A を押した場合、エディタは最後に挿入モードにいたときにタイプしたテキスト
を挿入します。
   例えば、以下で始まるファイルがあるとします:

        "file.h"
        /* Main program begins */

このファイルを、最初の行の先頭に "#include " を挿入して編集します:

        #include "file.h"
        /* Main program begins */

"j^" コマンドを使って次の行の先頭に移動します。ここで新しい "#include" 行の挿
入を始めます。そこでこうタイプします:

        i CTRL-A

結果は以下のとおりです:

        #include "file.h"
        #include /* Main program begins */

"#include " が挿入されたのは、CTRL-A が前回の挿入のテキストを挿入するためです。
ここで、行を終えるために  "main.h"<Enter>  とタイプします:


        #include "file.h"
        #include "main.h"
        /* Main program begins */

CTRL-@ コマンドは CTRL-A を行い、それから挿入モードを抜けます。これはまったく
同じ挿入を再び行う素早い方法です。

24.5  別の行からコピーする

CTRL-Y コマンドはカーソルの上の文字を挿入します。これは前の行を複製していると
きに便利です。例えば、この C コードの行があるとします:

        b_array[i]->s_next = a_array[i]->s_next;

ここで、同じ行を、ただし "s_next" の代わりに "s_prev" でタイプする必要がありま
す。新しい行を始め、"next" の "n" に来るまで CTRL-Y を 14 回押します:

        b_array[i]->s_next = a_array[i]->s_next;
        b_array[i]->s_

ここで "prev" とタイプします:

        b_array[i]->s_next = a_array[i]->s_next;
        b_array[i]->s_prev

続く "next" まで CTRL-Y を押し続けます:

        b_array[i]->s_next = a_array[i]->s_next;
        b_array[i]->s_prev = a_array[i]->s_

ここで "prev;" とタイプして仕上げます。

CTRL-E コマンドは CTRL-Y と同じように動作しますが、カーソルの下の文字を挿入し
ます。

24.6  レジスタを挿入する

CTRL-R {register} コマンドはレジスタの内容を挿入します。これは長い単語をタイプ
しなければならないのを避けるのに便利です。例えば、こうタイプする必要があるとし
ます:

        r = VeryLongFunction(a) + VeryLongFunction(b) + VeryLongFunction(c)

関数名は別のファイルで定義されています。そのファイルを編集して、そこで関数名の
上にカーソルを移動し、それをレジスタ v にヤンクします:

        "vyiw

"v はレジスタの指定で、"yiw" は yank-inner-word です。ここで新しい行を挿入する
ファイルを編集し、最初の何文字かをタイプします:

        r =

ここで CTRL-R v を使って関数名を挿入します:

        r = VeryLongFunction

関数名の間の文字をタイプし続け、CTRL-R v をさらに 2 回使います。
   同じことを補完でもできたでしょう。レジスタを使うのは、同じ文字で始まる単語
がたくさんあるときに便利です。

レジスタに <BS> またはその他の特殊文字のような文字が含まれている場合、それらは
キーボードからタイプされたかのように解釈されます。これを起こしたくない場合 (本
当に <BS> をテキストに挿入したい場合)、CTRL-R CTRL-R {register} コマンドを使い
ます。

24.7  短縮入力

短縮入力は、長い単語の代わりになる短い単語です。例えば、"ad" は
"advertisement" を表します。Vim では、短縮入力をタイプすることができ、それから
Vim が自動的にそれを展開します。
   それを挿入するたびに "ad" を "advertisement" に展開するように Vim に指示す
るには、以下のコマンドを使います:

        :iabbrev ad advertisement

これで、"ad" とタイプすると、単語全体 "advertisement" がテキストに挿入されま
す。これは、単語の一部になり得ない文字、例えば空白をタイプすることで引き起こさ
れます:

        入力したもの            表示されるもの
        I saw the a             I saw the a
        I saw the ad            I saw the ad
        I saw the ad<Space>     I saw the advertisement<Space>

"ad" とタイプしただけでは展開は起こりません。これにより "add" のような単語をタ
イプでき、それは展開されません。短縮入力として調べられるのは単語全体だけです。


複数の単語を短縮する

複数の単語になる短縮入力を定義することもできます。例えば、"JB" を "Jack Benny"
として定義するには、以下のコマンドを使います:

        :iabbrev JB Jack Benny

プログラマとして、私は 2 つのかなり変わった短縮入力を使っています:

        :iabbrev #b /****************************************
        :iabbrev #e <Space>****************************************/

これらは箱で囲んだコメントを作るのに使います。コメントは #b で始まり、これは上
の線を描きます。それから私はコメントのテキストをタイプし、#e を使って下の線を
描きます。
   #e 短縮入力が空白で始まっていることに注意してください。言い換えると、最初の
2 文字は空白-スターです。通常、Vim は短縮入力と展開の間の空白を無視します。そ
の問題を避けるために、私は空白を 7 文字で綴ります: <、S、p、a、c、e、>。

        Note:
        ":iabbrev" はタイプするには長い単語です。":iab" でも同じように機能しま
        す。
        これは abbreviate コマンドの短縮です!


タイプミスを修正する

毎回同じタイプミスをするのはとてもよくあることです。例えば、"the" の代わりに
"teh" とタイプします。これは短縮入力で修正できます:

        :abbreviate teh the

このようなものをリスト丸ごと追加できます。よくある間違いを見つけるたびに 1 つ
追加します。


短縮入力を一覧表示する

":abbreviate" コマンドは短縮入力を一覧表示します:

        :abbreviate
        i  #e             ****************************************/
        i  #b            /****************************************
        i  JB            Jack Benny
        i  ad            advertisement
        !  teh           the

1 列目の "i" は挿入モードを示します。これらの短縮入力は挿入モードでのみ有効で
す。他に可能な文字は以下です:

        c       コマンドラインモード                    :cabbrev
        !       挿入およびコマンドラインモードの両方    :abbreviate

短縮入力はコマンドラインモードではあまり役に立たないので、たいていは
":iabbrev" コマンドを使うでしょう。これにより、例えば、以下のようなコマンドを
タイプするときに "ad" が展開されるのを避けられます:

        :edit ad


短縮入力を削除する

短縮入力を取り除くには、":unabbreviate" コマンドを使います。以下の短縮入力があ
るとします:

        :abbreviate @f fresh

これはこのコマンドで削除できます:

        :unabbreviate @f

これをタイプしている間に、@f が "fresh" に展開されることに気付くでしょう。これ
については心配いりません。Vim はとにかくそれを理解します ("fresh" に対する短縮
入力がある場合を除きますが、それはほとんどありそうにありません)。
   すべての短縮入力を削除するには:

        :abclear

":unabbreviate" および ":abclear" には、挿入モード用 (":iunabbreviate および
":iabclear") およびコマンドラインモード用 (":cunabbreviate" および ":cabclear")
の変種もあります。


短縮入力をリマップする

短縮入力を定義するときに注意すべきことが 1 つあります: 結果の文字列はマップさ
れるべきではありません。例えば:

        :abbreviate @a adder
        :imap dd disk-door

ここで @a とタイプすると、"adisk-doorer" になります。これは望むものではありま
せん。これを避けるには、":noreabbrev" コマンドを使います。これは ":abbreviate"
と同じことをしますが、結果の文字列がマッピングに使われるのを避けます:

        :noreabbrev @a adder

幸い、短縮入力の結果がマップされることはほとんどありません。

24.8  特殊文字を入力する

CTRL-V コマンドは、次の文字をそのまま挿入するのに使われます。言い換えると、そ
の文字が持つ特別な意味は何であれ、無視されます。例えば:

        CTRL-V <Esc>

エスケープ文字を挿入します。したがって、挿入モードを抜けません。(CTRL-V の後の
空白はタイプしないでください。これは読みやすくするためだけのものです)。

        Note:
        MS-Windows では CTRL-V はテキストを貼り付けるのに使われます。CTRL-V の
        代わりに CTRL-Q を使ってください。一方、Unix では、CTRL-Q は特別な意味
        を持つため、一部の端末では機能しません。

CTRL-V {digits} コマンドを使って、10 進数 {digits} の文字を挿入することもでき
ます。例えば、文字番号 127 は <Del> 文字です (ただし、必ずしも <Del> キーでは
ありません!)。<Del> を挿入するにはこうタイプします:

        CTRL-V 127

この方法で 255 までの文字を入力できます。2 桁未満をタイプするときは、数字以外
の文字でコマンドが終了します。数字以外の文字をタイプする必要を避けるには、1 つ
または 2 つのゼロを前に付けて 3 桁にします。
   次のコマンドはすべて、<Tab> を挿入し、それからドットを挿入します:

        CTRL-V 9.
        CTRL-V 09.
        CTRL-V 009.

16 進数で文字を入力するには、CTRL-V の後に "x" を使います:

        CTRL-V x7f

これも文字 255 (CTRL-V xff) までです。"o" を使って文字を 8 進数としてタイプで
き、さらに 2 つの方法で 16 ビットおよび 32 ビットの数値 (例えば、Unicode 文字
用) までタイプできます:

        CTRL-V o123
        CTRL-V u1234
        CTRL-V U12345678

24.9  ダイグラフ

キーボードにない文字もあります。例えば、著作権文字 (©) です。Vim でこれらの文
字をタイプするには、ダイグラフを使います。ダイグラフでは 2 つの文字が 1 つを表
します。例えば、© を入力するには、3 つのキーを押します:

        CTRL-K Co

どのようなダイグラフが使用可能かを調べるには、以下のコマンドを使います:

        :digraphs

Vim はダイグラフの表を表示します。以下はその 3 行です:

  AC ~_ 159  NS |  160  !I ¡  161  Ct ¢  162  Pd £  163  Cu ¤  164  Ye ¥  165
  BB ¦  166  SE §  167  ': ¨  168  Co ©  169  -a ª  170  << «  171  NO ¬  172
  -- ­  173  Rg ®  174  'm ¯  175  DG °  176  +- ±  177  2S ²  178  3S ³  179

これは、例えば、CTRL-K Pd とタイプして得られるダイグラフが文字 (£) であること
を示しています。これは文字番号 163 (10 進数) です。
   Pd は Pound の略です。ほとんどのダイグラフは、生成される文字についてのヒン
トを与えるように選ばれています。リストに目を通した場合、その論理がわかるでしょ
う。
   その組み合わせのダイグラフがない場合、1 文字目と 2 文字目を入れ替えることが
できます。したがって、CTRL-K dP も機能します。"dP" のダイグラフはないので、Vim
は "Pd" のダイグラフも検索します。

        Note:
        ダイグラフは、あなたが使用していると Vim が仮定する文字セットに依存し
        ます。現在どのダイグラフが使用可能かを調べるには、常に ":digraphs" を
        使ってください。

10 進数で対象の文字を指定して、独自のダイグラフを定義できます。例:

        :digraph a\" 228

これは CTRL-K a" が ä 文字を挿入することを定義します。Note: そうしないとコメン
ト文字として働いてしまうので、" 文字をエスケープする必要がありました。

ダイグラフについてのさらなる情報はこちら: digraphs
   特殊文字を挿入する別の方法は、キーマップを使うことです。それについてのさら
なる情報はこちら: 45.5

24.10 ノーマルモードコマンド

挿入モードが提供するコマンドの数は限られています。ノーマルモードではもっとたく
さんあります。それを使いたいときは、たいてい <Esc> で挿入モードを抜け、ノーマ
ルモードコマンドを実行し、"i" または "a" で挿入モードに再び入ります。
   もっと素早い方法があります。CTRL-O {command} で、挿入モードから任意のノーマ
ルモードコマンドを実行できます。例えば、カーソルから行末まで削除するには:

        CTRL-O D

この方法で実行できるのは 1 つのノーマルモードコマンドだけです。しかし、レジス
タまたはカウントを指定できます。もっと複雑な例:

        CTRL-O "g3dw

これは 3 番目の単語までをレジスタ g に削除します。
