ここに、私がニュースおよびメールから集めた、Vim についてのすてきな引用がある。


vim (vim) 名詞 - あふれんばかりの活力およびエネルギー。[ラテン語、vis の対格、
力] (辞書)

Vim は vi よりもはるかに優れているので、私の古い vi の :map の非常に多くがすぐ
に時代遅れになった! (Tony Nugent、オーストラリア)

Windows からとても GUI 的な考え方でやってきた私は、Vi を使う人々のことを、人間
の服を着た宇宙人の一種のようにいつも思っていた。一度試してみると、そのパワーに
本当にはまってしまい、今では最も奇妙な場所で Vim のキー操作をタイプしている自
分に気付く! それが、テキスト編集を扱うすべてのアプリケーションに Vim が組み込
まれているのを見たい理由だ。(José Fonseca)

私は 12 年間 emacs のユーザーだったが、複数の互換性のないバージョン、不安定な
寄贈パッケージ、まとまりのないキー操作などについに見切りをつけて、約 1 年前に
Vim に乗り換えた。そしてそれは、私がこれまでにした最良の選択の 1 つだった。
(Joel Burton)

新規および改訂された資料の準備中にはすべてのプログラムが使われたが、編集のほと
んどは GNU-Linux (Redhat 4.2) 上の Vim バージョン 4.5 および 5.0 で行われた。
(Arnold Robbins、イスラエル、"Learning the Vi editor" の著者)

私がこれまでに見て使ったすべてのオープンソフトウェアの中で、そして私はたくさん
見てきたが、Vim は最高で、最も便利で、扱うのに最も品質が高く、linux カーネルそ
のものに次ぐものだ。(Peter Jay Salzman)

SourceForge の _全体_ が Vim およびその気の利いた PHP 構文ハイライトを使って書
かれたことは、特筆に値する。SF.net の技術スタッフ全員が Vim を使っていると思う
し、私たちはみな、あなたを迎えられることに興奮している! (Tim Perdue)

Vim は、私にとって代わりのない選ばれたひと握りのツールの 1 つだ。それは見事な
作品だ! (Biju Chacko)

私の以前のガールフレンドは emacs に乗り換えた。言うまでもなく、その関係はうま
くいかなかった。(Geoffrey Mann)

たぶん魚が水についてめったに考えないのと同じように、私は Vim についてめったに
考えない。それは、他のすべてが起こる環境なのだ。私は多くの異なるプラットフォー
ムで働く、かなり忙しいシステム管理者だ。Vim は私のすべてのシステムにわたって一
貫している唯一のものであり、ときどき壊れることがないほぼ唯一のものだ。Vim のな
い新しいシステムがやってくると、私はすぐにそれをインストールする。どこでも同じ
で、完全に信頼でき、そのためそれを無視して他のことを考えられるツールがあるのは
すばらしい。(Pete Schaeffer)

最近、Nokia Communicator を通して telnet 経由で Vim を動かすことに成功したの
で、それが Palm Pilot でもうまく動くことを今や報告できる。(Allan Kelly、スコッ
トランド)

'VIM' ですばらしい仕事をしたね、Bram! 使えば使うほど感心する (私は昔からの頑固
な 'vi' 派で、1970 年代後半に初期のバージョンの 'emacs' から始め、1983 年に初
めて出会った UNIX で 'vi' を見つけてほっとした)。私の意見では、そろそろ 'VIM'
が 'emacs' に取って代わって、トップエディタの標準になる頃だ。(Bo Thide'、ス
ウェーデン)

私も Vim を愛し、たくさん使っている。(Larry Wall)

Vi はフェラーリのようなものだ。初心者の場合、その操縦性はビッチのようだが、いっ

このガイドは gvim の Windows 9.x 用配布物を使って書かれた。それは、神が裸の少

DiBernardo)

Vim の法則:
プログラム P の可能な振る舞い空間 B の各要素 b に対して、ある有限の時間 t が存
在し、その時間より前に、プログラム P の全ユーザー空間 U の少なくとも 1 人のユー
ザー u が、b が許可された振る舞い空間 B' (B' <= B) の要素になることを要求する。
言い換えると: 遅かれ早かれ、誰もがすべてをオプションとして欲しがる。(Negri)

新しいコンピューティングプラットフォームに移るたびに、私が最初にすることは Vim

だ驚いている。(A.M. Sabuncu、トルコ)
