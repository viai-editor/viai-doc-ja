複数のタブページ内のウィンドウで編集する。              tab-page tabpage

複数のタブページを使用するために追加されたコマンドをここで説明する。さらに、2
つ以上のタブページと組み合わせて使用したときに異なる動作をするコマンドについて
の説明もある。

==============================================================================
1. はじめに                                             tab-page-intro

タブページは 1 つ以上のウィンドウを保持する。タブページの間を簡単に切り替える
ことができるので、異なるものを扱うためのいくつかのウィンドウの集まりを持つこと
ができる。

通常、Vim ウィンドウの上部に、タブページごとに 1 つずつ、ラベルのリストが表示
される。マウスでラベルをクリックすると、そのタブページにジャンプできる。タブ
ページの間を移動する方法は他にもある。以下を参照。

ほとんどのコマンドはカレントタブページでのみ動作する。これには CTRL-W コマン
ド、:windo、:all、および :ball (:tab 修飾子を使用していない場合) が含
まれる。カレントタブページ以外のタブページを認識するコマンドについては、以下で
述べる。

タブページは、現在のウィンドウレイアウトを変更せずに、一時的にバッファを編集す
るためのよい方法でもある。新しいタブページを開き、やりたいことを何でも行い、そ
のタブページを閉じる。

==============================================================================
2. コマンド                                             tab-page-commands

新しいタブページを開く:

Vim を起動するとき、"vim -p filename ..." はそれぞれのファイル引数を別々のタブ
ページで開く ('tabpagemax' まで)。-p を参照

GUI でないタブページ行でマウスをダブルクリックすると、新しい空のタブページが開
く。それはクリックした位置の左に置かれる。最初のクリックで先に別のタブページが
選択され、余分な画面更新が発生することがある。

これは、いくつかの GUI バージョン、特に Win32 および Motif でも動作する。ただ
し、ラベルの右をクリックした場合のみである。

GUI のタブページ行では、マウスの右ボタンを使用してメニューを開くことができる。
tabline-menu。

関連する自動コマンドについては tabnew-autocmd を参照。

                ジ [count] の後ろに現れ、そうでない場合、新しいタブページはカ
                レントタブページの後ろに現れる。

タブページを閉じる:

タブページが 1 つしかない場合を除き、タブページの最後のウィンドウを閉じると、
そのタブページも閉じる。

マウスを使う: タブページ行が表示されている場合、右上の "X" をクリックしてカレ
ントタブページを閉じることができる。カスタムの 'tabline' は何か別のものを表示
するかもしれない。

                                                        :tabc :tabclose
:tabc[lose][!]  カレントタブページを閉じる。
                このコマンドは次の場合に失敗する:
                - 画面上にタブページが 1 つしかない。                   E784
                - 'hidden' が設定されておらず、[!] が使用されておらず、バッファ
                  に変更があり、このバッファに他のウィンドウがない場合。
                バッファへの変更は書き込まれず、失われることもないので、これは
                "安全な" コマンドである。
                    :tabclose       " カレントタブページを閉じる

:{count}tabc[lose][!]
:tabc[lose][!] {count}
                タブページ {count} を閉じる。上記の :tabclose と同じように失
                敗する。
                    :-tabclose      " 前のタブページを閉じる
                    :+tabclose      " 次のタブページを閉じる
                    :1tabclose      " 最初のタブページを閉じる
                    :$tabclose      " 最後のタブページを閉じる
                    :tabclose -2    " 2 つ前のタブページを閉じる
                    :tabclose +     " 次のタブページを閉じる

タブページが閉じられると、次のタブページがカレントタブページになる。この動作は
'tabclose' オプションを使用してカスタマイズできる。

                    :1tabonly       " 最初のタブページ以外のすべてのタブページを閉じる
                    :$tabonly       " 最後のタブページ以外のすべてのタブページを閉じる
                    :tabonly -      " 前のタブページ以外のすべての

                    :tabonly +2     " 2 つ次のタブページ以外のすべての
                                    " タブページを閉じる

                    :tabonly $      " 最後のタブページ以外のすべてのタブページを閉じる
                    :tabonly #      " 最後にアクセスしたタブページ以外の

タブページを並べ替える:

タブページに対してループする:

                                                        :tabd :tabdo
:[range]tabd[o] {cmd}
                各タブページで {cmd} を実行するか、または [range] が指定された
                場合、タブページ番号が [range] 内にあるタブページでのみ実行す
                る。これは、次のようにするのと同様に動作する:
                        :tabfirst
                        :{cmd}
                        :tabnext
                        :{cmd}
                        etc.
                これは各タブページのカレントウィンドウでのみ動作する。
                あるタブページでエラーが検出されると、それ以降のタブページは訪
                問されない。
                最後のタブページ (またはエラーが発生した場所) がカレントタブ
                ページになる。
                {cmd} は複数のコマンドをつなげるために '|' を含むことができる。
                {cmd} はタブページを開くこと、閉じること、または並べ替えること
                をしてはならない。
                :windo、:argdo、:bufdo、:cdo、:ldo、:cfdo、および
                :lfdo も参照

3. その他の項目                                         tab-page-other

                                                        tabline-menu
GUI のタブページ行にはポップアップメニューがある。それは右クリックでアクセスで
きる。その項目は次のとおり:
        Close           マウスポインタの下のタブページを閉じる。マウスポインタ
                        の下にラベルがない場合はカレントタブページ。
        New Tab         空のバッファを編集するタブページを開く。それはマウスポ
                        インタの左に現れる。
        Open Tab...     "New Tab" と同様で、さらにファイルセレクタを使用して、
                        編集するファイルを選択する。

差分モードはタブページごとに動作する。1 つのタブページ内で、いくつかのファイル
間の差分を見ることができる。他のタブページでは、他のファイル間の違いを表示でき
る。

タブページにローカルな変数は "t:" で始まる。tabpage-variable

現在のところ、タブページにローカルなオプションは 1 つだけである: 'cmdheight'。

                                                tabnew-autocmd
TabLeave および TabEnter 自動コマンドイベントを使用すると、あるタブページから
別のタブページに切り替えるときに何かを行うことができる。正確な順序は、何をして
いるかによって異なる。新しいタブページを作成するとき、これは同じバッファで新し
いウィンドウを作成してから別のバッファを編集するかのように動作する。したがっ
て、":tabnew" は次を発生させる:
        WinLeave                カレントウィンドウを離れる
        TabLeave                カレントタブページを離れる
        WinEnter                新しいタブページ内のウィンドウに入る
        TabEnter                新しいタブページに入る
        BufLeave                カレントバッファを離れる
        BufEnter                新しい空のバッファに入る

別のタブページに切り替えるときの順序は:
        BufLeave
        WinLeave
        TabLeave
        TabEnter
        WinEnter
        BufEnter

4. 'tabline' の設定                                     setting-tabline

'tabline' オプションは、タブページラベルのある行がどのように見えるかを指定す
る。これは GUI のタブ行がないときにのみ使用される。

'showtabline' オプションを使用して、タブページラベルのある行をいつ表示したいか
を指定できる: 決して表示しない、2 つ以上のタブページがあるとき、または常に。

タブページ行のハイライトは、グループ TabLine TabLineSel および TabLineFill で
設定される。hl-TabLine hl-TabLineSel hl-TabLineFill

変更されたウィンドウを持つタブページには "+" が表示される。タブページ内のウィ
ンドウの数も表示される。したがって、"3+" は 3 つのウィンドウがあり、そのうちの
1 つに変更されたバッファがあることを意味する。

複数のタブページが開いているとき、最後の桁に "X" (閉じるボタン) が表示される。
ただし 'mouse' が有効な場合に限る。

'tabline' オプションを使うと、タブページラベルへのあなたの好みの方法を定義でき
る。これは簡単ではないので、ここで例を示す。

基本については 'statusline' オプションを参照。'tabline' および 'tabpanel' オプ
ションでも同じ項目を使用できる。さらに、tabpagebuflist()、tabpagenr()、お
よび tabpagewinnr() 関数が便利である。

タブラベルの数は変化するので、オプション全体に式を使用する必要がある。次のよう
なもの:
        :set tabline=%!MyTabLine()

そして、すべてのタブページラベルを一覧表示する MyTabLine() 関数を定義する。便
利な方法は、それを 2 つの部分に分けることである: まずすべてのタブページを巡回
し、それらのラベルを定義する。次に各タブページのラベルを取得する。

        function MyTabLine()
          let s = ''
          for i in range(tabpagenr('$'))
            " ハイライトを選択する
            if i + 1 == tabpagenr()
              let s ..= '%#TabLineSel#'
            else
              let s ..= '%#TabLine#'
            endif

            " タブページ番号を設定する (マウスクリック用)
            let s ..= '%' .. (i + 1) .. 'T'

            " ラベルは MyTabLabel() によって作られる
            let s ..= ' %{MyTabLabel(' .. (i + 1) .. ')} '
          endfor

          " 最後のタブページの後は TabLineFill で埋め、タブページ番号をリセットする
          let s ..= '%#TabLineFill#%T'

          " カレントタブページを閉じるラベルを右寄せする
          if tabpagenr('$') > 1
            let s ..= '%=%#TabLine#%999Xclose'
          endif

          return s
        endfunction

ここで、MyTabLabel() 関数が各タブページに対して、そのラベルを取得するために呼
ばれる。

        function MyTabLabel(n)
          let buflist = tabpagebuflist(a:n)
          let winnr = tabpagewinnr(a:n)
          return bufname(buflist[winnr - 1])
        endfunction

これは単純な例にすぎず、既定のものに似たタブページ行になるが、変更されたバッ
ファに対する + の追加や名前の切り詰めは行わない。十分な余地がない場合は、賢い
方法でラベルの幅を縮めたくなるだろう。使用可能なスペースについては 'columns'
オプションを確認すること。

==============================================================================
5. 'tabpanel' の設定                            tabpanel setting-tabpanel

タブパネルは、ウィンドウの横に沿ってタブページラベルを表示する縦のサイドバーで
ある。それは次のように見える:

        +-----------+----------------------------------
        |(1)        |text text text text text text text
        |  ~/aaa.txt|text text text text text text text
        |(2)        |text text text text text text text
        |  ~/.vimrc |text text text text text text text
        |(3)        |text text text text text text text
        |  ~/bbb.js |text text text text text text text
        |  ~/ccc.css|text text text text text text text
        |           |text text text text text text text
        |           |text text text text text text text
        |           |text text text text text text text

タブパネルを設定するには、以下のオプションを使用する: 'tabpanel'、
'showtabpanel'、および 'tabpanelopt'。
'tabpanel' オプションは 'statusline' または 'tabline' と同様に機能し、
'showtabpanel' オプションは 'laststatus' または 'showtabline' と同様に機能す
る。

'tabpanelopt' オプションの "columns:" 項目は、タブパネルの幅を指定する:

              +------ この幅
              |
         <----+----->
        +-----------+----------------------------------
        |(1)        |text text text text text text text
        |  ~/aaa.txt|text text text text text text text
        |(2)        |text text text text text text text

'tabpanelopt' オプションの "align:" 項目は、タブパネルをウィンドウの左側または
右側のどちらに表示するかを決定する:

        +----------------------------------+-----------
        |text text text text text text text|(1)
        |text text text text text text text|  ~/aaa.txt
        |text text text text text text text|(2)

'tabpanelopt' オプションの "vert" 項目は、タブパネルとウィンドウの表示部分の間
に縦の区切りを表示するかどうかを指定する:

                    +------ これ
                    |
                    v
        +-----------+----------------------------------
        |(1)        |text text text text text text text
        |  ~/aaa.txt|text text text text text text text
        |(2)        |text text text text text text text

縦の区切り文字は 'fillchars' の "tpl_vert" から取られる。

タブページラベルの見た目は、ハイライトグループを使用してカスタマイズできる:
hl-TabPanel hl-TabPanelSel hl-TabPanelFill

タブパネル内でのスクロール                             tabpanel-scroll

タブページリストの高さの合計が見える画面の高さを超える場合、タブパネル領域上の
マウスホイールイベントはタブページリストを上下にスクロールする。スクロールの幅
は 'mousescroll' の設定に従う。タブパネル領域内のホイールイベントはタブパネル
によって消費され、<ScrollWheelUp> または <ScrollWheelDown> のマッピングを
発生させない。

カレントタブページは常に見える位置に移される: 選択されたタブページが (gt、
gT、:tabnext などによって) 変わると、カレントのエントリが見えるようにパネ
ルがスクロールする。

現在のスクロール位置を示す縦スクロールバーを表示するには、'tabpanelopt' に
"scrollbar" を追加する:
        :set tabpanelopt+=scrollbar

'tabpanelopt' の "align:" 設定に関係なく、1 桁のスクロールバーが常にタブパネル
の右端に表示される。スクロールバーの桁をクリックするとつまみがクリック位置に移
動し、つまみをドラッグして連続的にスクロールできる。

スクロールバーは、トラックに hl-PmenuSbar ハイライトグループを、つまみに
hl-PmenuThumb を使用する。

スクロールオフセットは再描画をまたいで記憶される。

タブパネル内でのマウスクリック                 tabpanel-mouse

タブパネル内の行を左クリックすると、その行が属するタブページが選択される。タブ
ラインとは異なり、タブパネル内でのダブルクリックは新しい空のタブページを開か
ず、シングルクリックと同じに扱われる。

より細かく制御するために、'tabpanel' の値に stl-%[FuncName] クリック領域を含
めることができる。それらの領域でのクリックは、タブページの選択にフォールスルー
する代わりに、コールバック関数に送られる。

==============================================================================
6. 'guitablabel' の設定                                 setting-guitablabel

GUI のタブページ行が表示されているとき、'guitablabel' を使用して、各タブページ
に表示するラベルを指定できる。タブページ行全体を一度に指定する 'tabline' とは
異なり、'guitablabel' は各ラベルに対して個別に使用される。

'guitabtooltip' はよく似ており、同じラベルのツールチップに使用される。これはマ
ウスポインタがラベル上にあるときだけ表示されるので、通常はより長い。ただし、一
部のシステムでのみサポートされている。

値の書式については 'statusline' オプションを参照。

"%N" 項目はカレントタブページ番号に使用できる。オプションが評価されるとき、
v:lnum 変数にもこの番号が設定される。
ファイル名を使用する項目は、タブページのカレントウィンドウを参照する。

Note このオプションではシンタックスハイライトは使用されないことに注意。%T およ
び %X 項目も無視される。

タブページ番号およびバッファ名をラベルに入れる単純な例:
        :set guitablabel=%N\ %f

既定の 'guitablabel' に似た例: タブページ内のウィンドウの数、および変更された
バッファがある場合は '+' を表示する:

        function GuiTabLabel()
          let label = ''
          let bufnrlist = tabpagebuflist(v:lnum)

          " タブページ内のバッファの 1 つが変更されている場合、'+' を追加する
          for bufnr in bufnrlist
            if getbufvar(bufnr, "&modified")
              let label = '+'
              break
            endif
          endfor

          " 2 つ以上ある場合、タブページ内のウィンドウの数を付け足す
          let wincount = tabpagewinnr(v:lnum, '$')
          if wincount > 1
            let label ..= wincount
          endif
          if label != ''
            let label ..= ' '
          endif

          " バッファ名を付け足す
          return label .. bufname(bufnrlist[tabpagewinnr(v:lnum) - 1])
        endfunction

        set guitablabel=%{GuiTabLabel()}

Note オプションを設定する前に関数を定義しなければならないことに注意。そうしな
いと、関数が不明であるというエラーメッセージが出る。

既定のラベルに戻したい場合、空文字列を返す。

あるタブページに対して特定のものを表示したい場合、タブページローカル変数を使用
したいかもしれない。t:var
