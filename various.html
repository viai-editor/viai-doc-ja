==============================================================================
1. さまざまなコマンド                                   various-cmds

                                                        CTRL-L
CTRL-L                  画面をクリアして再描画する。再描画は、先行入力を処理し
                        た後に、遅れて行われることがある。

                                                        :redr :redraw
:redr[aw][!]            画面を今すぐ再描画する。! が含まれる場合、先にクリアさ
                        れる。
                        スクリプトまたは関数 (または 'lazyredraw' が設定されて
                        いる場合はマッピング) の中で画面を再描画するのに使用で
                        きる。

                                                :redraws :redrawstatus
:redraws[tatus][!]      カレントウィンドウのステータス行を再描画する。! が含ま
                        れる場合、全てのステータス行が再描画される。
                        'statusline' が自動的な更新を引き起こさない項目を含む
                        場合に、ステータス行を更新するのに便利である。
                        最後のウィンドウにステータス行が無い場合、代わりにルー
                        ラーが再描画される。これは 'rulerformat' がそのような
                        項目を含む場合に便利である。
                        コマンドラインが編集中の場合、再描画は後まで延期され
                        る。

                                                :redrawt :redrawtabline
:redrawt[abline]        タブラインを再描画する。'tabline' が自動的な更新を発生
                        させない項目を含む場合に、タブラインを更新するのに便利
                        である。

                                E1547 :redrawtabp :redrawtabpanel
:redrawtabp[anel]       タブパネルを再描画する  'tabpanel' が自動的な更新を発
                        生させない項目を含む場合に、タブパネルを更新するのに便
                        利である。

                                                        N<Del>
<Del>                   数値を入力している時: 最後の桁を削除する。
                        Note: これに <BS> を使用したい場合、このマッピングを
                        .vimrc に追加する:
                                :map CTRL-V <BS>   CTRL-V <Del>
                        <Del> キーが望みどおりに動作しない場合、:fixdel を参
                        照。

:as[cii]        または                                  ga :as :ascii
ga                      カーソル下の文字の ascii 値を 10 進数、16 進数および 8
                        進数で表示する。
                        覚え方: Get Ascii value.

                        例えば、カーソルが 'R' の上にある場合:
                                <R>  82,  Hex 52,  Octal 122
                        文字が標準ではない ASCII 文字だが、'isprint' オプショ
                        ンに従えば表示可能である場合、表示できない形式も表示さ
                        れる。

                        文字が 127 より大きい場合:
                                <<81>>  129,  Hex 0081,  Octal 201
                                 <p>    254,  Hex 00fe,  Octal 376
                        (ここで <p> は特殊文字である)

                        ファイル中の <Nul> 文字は内部では <NL> として格納され
                        るが、次のように表示される:
                                <^@>  0,  Hex 00,  Octal 000

                        文字が合成文字を持つ場合、それらも表示される。
                        'maxcombine' の値は関係ない。

                        文字がダイグラフとして入力できる場合、その文字を作成す
                        るのに使用できる 2 つの文字も出力する:
                                <ö> 246, Hex 00f6, Oct 366, Digr o:
                        これは、ö を挿入するのに CTRL-K o : と入力できることを
                        示している。

                                                        g8
g8                      カーソル下の文字に使用されているバイトの 16 進数の値
                        を、その文字が UTF-8 エンコーディングであると仮定し
                        て表示する。これは合成文字も表示する。'maxcombine' の
                        値は関係ない。
                        2 つの合成文字を持つ文字の例:
                                e0 b8 81 + e0 b8 b9 + e0 b9 89

                                                        8g8
8g8                     カーソル位置またはそれ以降にある不正な UTF-8 バイトシー
                        ケンスを探す。これは 2 つの状況で動作する:
                        1. 'encoding' が任意の 8 ビットエンコーディングの場合
                        2. 'encoding' が "utf-8" で、'fileencoding' が任意の 8
                           ビットエンコーディングの場合
                        従って、UTF-8 のはずだったが、不正なバイトを含むために
                        8 ビットエンコーディングであるかのように読み込まれた
                        ファイルを編集する時に使用できる。
                        ファイルの末尾を越えて折り返さない。
                        Note カーソルが不正なバイトの上にある場合、またはカー
                        ソルがマルチバイト文字の途中にある場合、このコマンドは
                        カーソルを移動しないことに注意。

                                                :p :pr :print E749
:[range]p[rint] [flags]
                        [range] の行を表示する (既定はカレント行)。Vi 互換性の
                        ため :[range]| と綴ることもできる (:bar を参照)。
                        空のバッファではエラーになる。
                        Note: テキストを紙に印刷する方法を探している場合、
                        :hardcopy を参照。GUI では File.Print メニュー項目を
                        使用できる。
                        [flags] については ex-flags を参照。
                        :filter コマンドを使用して、パターンにマッチする行だ
                        けを表示できる。

:[range]p[rint] {count} [flags]
                        [range] から始まる {count} 行を表示する (既定はカレン
                        ト行 cmdline-ranges)。
                        [flags] については ex-flags を参照。

                                                        :P :Print
:[range]P[rint] [count] [flags]
                        ":print" と全く同じ。シフトキーを長く押しすぎる人のた
                        めに Vi に追加されたらしい... このコマンドは Vim9
                        script ではサポートされていない。
                        Note: ユーザーコマンドでこのコマンドを上書きできる。
                        [flags] については ex-flags を参照。

                                                        :l :list
:[range]l[ist] [count] [flags]
                        :print と同じだが、表示できない文字を '^' 付きで表示
                        し、行の後ろに $ を置く。これは 'listchars' オプション
                        でさらに変更できる。
                        [flags] については ex-flags を参照。

                                                        :nu :number
:[range]nu[mber] [count] [flags]
                        :print と同じだが、各行の前にその行番号を付ける。
                        ('highlight' および 'numberwidth' オプションも参照)。
                        [flags] については ex-flags を参照。

                                                        :#
:[range]# [count] [flags]
                        :number の同義語。

                                                        :#! vim-shebang
:#!{anything}           無視されるので、Vim script を以下のように始めることが
                        できる:
                                #!vim -S
                                let mylogbook='$HOME/logbook.md'
                                exe $':e {mylogbook}'
                                $
                                put ='## ' .. strftime('%d. %b %Y')
                                norm! o

                        そのスクリプトを実行可能にし、新しい日記のエントリを作
                        成するためにそれを実行する。

                                                        :z E144
:[range]z[+-^.=][count] [range] で指定された行の周囲、または [range] が無い場
                        合はカレント行の周囲の、数行のテキストを表示する。

                        [count] がある場合、それが表示される行数になる。[count]
                        が無く、ウィンドウが 1 つだけの場合、'scroll' オプショ
                        ンの値の 2 倍が使用され、そうでない場合はカレントウィ
                        ンドウの高さから 3 を引いた値が使用される。これが以下
                        の表の "scr" の値である。

                        [count] がある場合、'window' オプションがその値に設定
                        される。

                        :z は単独で使用するか、またはいくつかのマークのいずれ
                        かを後ろに付けて使用できる。それらは以下の効果を持つ:

                        マーク 最初の行      最後の行       新しいカーソル行
                        ----   ----------    ---------      ------------
                        +      カレント行    1 scr 前方     1 scr 前方
                        -      1 scr 後方    カレント行     カレント行
                        ^      2 scr 後方    1 scr 後方     1 scr 後方
                        .      1/2 scr 後方  1/2 scr 前方   1/2 scr 前方
                        =      1/2 scr 後方  1/2 scr 前方   カレント行

                        マークを全く指定しないのは "+" と同じである。
                        マークが "=" の場合、カレント行の周囲にダッシュの行が
                        表示される。

                        'number' オプションが設定されている場合、出力に絶対行
                        番号が含まれる。

                                                        :z!
:[range]z![+-^.=][count]
                        ":z" と同様だが、[count] が指定されていない場合、既定
                        値は Vim ウィンドウの高さから 1 を引いた値になる。

:[range]z[!]#[+-^.=][count]                             :z#
                        ":z" または ":z!" と同様だが、行に番号を付ける。

                                                        :=
:= [flags]              最終行の行番号を表示する。
                        [flags] については ex-flags を参照。

:{range}= [flags]       {range} の最終行の行番号を表示する。例えば、これはカレ
                        ント行の行番号を表示する:
                                :.=
                        [flags] については ex-flags を参照。

:norm[al][!] {commands}                                 :norm :normal
                        ノーマルモードコマンド {commands} を実行する。これによ
                        り、コマンドラインで入力したノーマルモードコマンドを実
                        行できる。{commands} は入力されたかのように実行される。
                        undo では全てのコマンドがまとめて undo される。エラー
                        に遭遇すると実行は停止する。

                        [!] が指定された場合、マッピングは使用されない。それが
                        無い場合、このコマンドが再マップ不可のマッピング
                        (:noremap) から呼ばれた時でも、引数はマップされうる。

                        {commands} は完全なコマンドであるべきである。{commands}
                        がコマンドを完了していない場合、最後のコマンドは <Esc>
                        または <C-C> が入力されたかのように中断される。
                        これは、挿入コマンドは完了していなければならないことを
                        意味する (挿入モードを開始するには、:startinsert を
                        参照)。":" コマンドも同様に完了していなければならない。
                        そして、"Q" または "gQ" を使用して Ex モードを開始する
                        ことはできない。

                        ":normal" の実行中は表示は更新されない。

                        {commands} は空白で始めることはできない。その前にカウ
                        ント 1 (いち) を置くこと。"1 " は 1 つの空白である。

                        {commands} に対しては 'insertmode' オプションは無視さ
                        れる。

                        '|' は全てコマンドの一部とみなされるため、このコマンド
                        の後に別のコマンドを続けることはできない。

                        このコマンドは再帰的に使用できるが、その深さは
                        'maxmapdepth' によって制限される。

                        代わりの方法は :execute を使用することで、これは引数
                        として式を使用する。これにより、特殊文字を表すために表
                        示可能な文字を使用できる。

                        例:
                                :exe "normal \<c-w>\<c-w>"

:{range}norm[al][!] {commands}                          :normal-range
                        {range} の各行に対してノーマルモードコマンド {commands}
                        を実行する。{commands} を実行する前に、各行について、
                        カーソルは範囲の最初の桁に置かれる。それ以外は範囲なし
                        の ":normal" コマンドと同じである。

                                                        :sh :shell E371
:sh[ell]                このコマンドはシェルを起動する。シェルが終了すると
                        ("exit" コマンドの後)、Vim に戻る。シェルコマンドの名
                        前は 'shell' オプションから得られる。
                                                        E360
                        Note: これは、Amiga 上の Vim がコンパイラから QuickFix
                        モードで起動された場合は動作しない。コンパイラが stdin
                        を非対話モードに設定しているためである。

                                                        :!cmd :!
:!{cmd}                 シェルで {cmd} を実行する。'shell' および 'shelltype'
                        オプションも参照。フィルタコマンドについては、
                        :range! を参照。

                        Vim は、オプション 'shell'、'shcf'、'sxq' および 'shq'
                        を使用して、以下の順でコマンドラインを組み立てる:
                        &sh &shcf &sxq &shq {cmd} &shq &sxq
                        そのため、'sxq' および 'shq' の両方を設定することは可
                        能だが、役に立つことはまれである。{cmd} の中の追加の
                        エスケープは 'sxe' オプションによる場合もある。

                        また、{cmd} 中の全ての cmdline-special 文字は、シェ
                        ルに渡す前に Vim によって置換される。

                                                        E34
                        {cmd} 中の '!' は全て直前の外部コマンドで置換される
                        ('cpoptions' も参照)。ただし、'!' の前にバックスラッ
                        シュがある場合はそうではなく、その場合はそのバックス
                        ラッシュが削除される。例: ":!ls" の後の
                        ":!echo ! \! \\!" は "echo ls ! \!" を実行する。

                        {cmd} 中の '|' はシェルに渡され、それを使って Vim コマ
                        ンドを追加することはできない。:bar を参照。

                        {cmd} が "%" を含む場合、それはカレントファイル名に展
                        開され、"#" は代替ファイル名に展開される。ファイル名中
                        の特殊文字はエスケープされない。それらの特殊な意味を避
                        けるには引用符を使用する:
                                :!ls "%"
                        ファイル名が "$" を含む場合、単一引用符の方がうまく動
                        作するかもしれないが、これはファイル名が単一引用符を含
                        まない場合にだけ動作する:
                                :!ls '%'
                        これは常に動作するはずだが、入力が多くなる:
                                :exe "!ls " .. shellescape(expand("%"),1)
                        リテラルの "%" または "#" を得るには、その前にバックス
                        ラッシュを付ける。例えば、"%" で始まる全てのファイルを
                        一覧表示するには:
                                :!ls \%*

                        改行文字は {cmd} を終了させ、その後に続くものは後続の
                        ":" コマンドとして解釈される。しかし、改行の前にバック
                        スラッシュがある場合、それは削除され、{cmd} は続く。改
                        行の前にいくつのバックスラッシュがあっても関係なく、1
                        つだけが削除される。

                        Unix では、コマンドは通常、非対話シェルで実行される。
                        対話シェルを使用したい場合 (エイリアスを使用するため)、
                        'shellcmdflag' を "-ic" に設定する。
                        Win32 については :!start も参照。

                        コマンドが実行された後、カレントファイルのタイムスタン
                        プおよびサイズがチェックされる timestamp。

                        コマンドが何かテキストを表示したかもしれないため、コマ
                        ンドが終了した後で Vim は画面を再描画する。これには、
                        メッセージを読めるように hit-enter プロンプトが必要に
                        なる。これを避けるには次を使用する:
                                :silent !{cmd}
                        その場合は画面は再描画されないため、コマンドが何かを表
                        示した場合は CTRL-L または ":redraw!" を使用する必要が
                        ある。しかし、これは t_ti および t_te の termcap
                        エントリが何に設定されているかによる。

                        ヒント: Vim ウィンドウで {cmd} を実行したい場合は
                        :terminal コマンドを使用する。
                        :term ++shell ++close {cmd} は :!{cmd} が行うこと
                        に近いものとして役立つだろう。

                                                        :!!
:!!                     最後の ":!{cmd}" を繰り返す。

                                                        :ve :ver :version
:ve[rsion]              エディタのバージョン番号を表示する。使用したコンパイラ
                        が "__DATE__" を理解する場合、コンパイル日付が示され
                        る。そうでない場合は固定のリリース日付が表示される。
                        以下の行には、Vim がコンパイルされた時にどの機能が有効
                        にされたかについての情報が含まれる。前に '+' がある場
                        合、その機能は含まれ、'-' がある場合は除外されている。
                        これを変更するには、feature.h を編集して Vim を再コン
                        パイルしなければならない。
                        式の中でこれをチェックするには、has() を参照。
                        ここに機能の概要を示す。
                        1 列目は、それらが含まれる最小のバージョンを示す:
                           T    tiny (常に)
                           N    normal
                           H    huge
                           m    手動で有効化されるか、または他の機能に依存する
                           -    決して含まれない、機能は削除された
                         (なし) システム依存
                        従って、機能が "N" でマークされている場合、それは Vim
                        の normal および huge バージョンに含まれる。

                                                        :redi :redir
:redi[r][!] > {file}    メッセージをファイル {file} にリダイレクトする。コマン
                        ドの出力であるメッセージは、リダイレクトが終了するまで
                        そのファイルに書き込まれる。メッセージは引き続き画面に
                        も表示される。[!] が含まれる場合、既存のファイルは上書
                        きされる。[!] が省略され、{file} が存在する場合、この
                        コマンドは失敗する。

                        一度にアクティブにできる ":redir" は 1 つだけである。
                        ":redir" を呼び出すと、新しい対象へのリダイレクトを開
                        始する前に、アクティブなリダイレクトを閉じる。再帰的に
                        使用するには execute() を参照。

                        メッセージおよびコマンドが画面にエコーされるのを止める
                        には、コマンドを関数に入れ、それを
                        ":silent call Function()" で呼び出す。
                        代わりの方法は 'verbosefile' オプションを使用すること
                        で、これは ":redir" と組み合わせて使用できる。

:redi[r] >> {file}      メッセージをファイル {file} にリダイレクトする。{file}
                        が既に存在する場合は追加する。

:redi[r] @{a-zA-Z}
:redi[r] @{a-zA-Z}>     メッセージをレジスタ {a-z} にリダイレクトする。レジス
                        タ名が大文字 {A-Z} で指定された場合は、そのレジスタの
                        内容に追加する。レジスタ名の後の ">" は省略可能である。
:redi[r] @{a-z}>>       メッセージをレジスタ {a-z} に追加する。

:redi[r] @*>
:redi[r] @+>            メッセージをセレクションまたはクリップボードにリダイレ
                        クトする。後方互換性のため、レジスタ名の後の ">" は省
                        略できる。quotestar および quoteplus を参照。
:redi[r] @*>>
:redi[r] @+>>           メッセージをセレクションまたはクリップボードに追加す
                        る。

:redi[r] @">            メッセージを無名レジスタにリダイレクトする。後方互換性
                        のため、レジスタ名の後の ">" は省略できる。
:redi[r] @">>           メッセージを無名レジスタに追加する。
                                                        E1092
:redi[r] => {var}       メッセージを変数にリダイレクトする。
                        旧来のスクリプトでは: 変数が存在しない場合、それは作成
                        される。変数が存在する場合、それは空文字列に初期化され
                        る。リダイレクトが開始した後に、変数が削除されるか、
                        ロックされるか、または変数の型が変更された場合、それ以
                        降のコマンド出力メッセージはエラーを引き起こす。ローカ
                        ル変数 (関数内の l:var またはスクリプト内の s:var) を
                        使用していて、別の :redir によって現在のものが終了す
                        る場合、スコープが異なっているかもしれず、代入は失敗す
                        る。Vim9 script では: 変数は文字列として宣言されていな
                        ければならない。
                        リダイレクトが終了するまで、変数は空のままである。文字
                        列変数だけを使用できる。
                        1 つのコマンドの出力を得るには、リダイレクトの代わりに
                        execute() 関数を使用できる。

:redi[r] =>> {var}      メッセージを既存の変数に追加する。文字列変数だけを使用
                        できる。
                                                                 E1185
:redi[r] END            メッセージのリダイレクトを終了する。

                                                        :filt :filter
:filt[er][!] {pattern} {command}
:filt[er][!] /{pattern}/ {command}
                        {command} の出力を {pattern} にマッチする行に制限する。
                        例えば、xml ファイルだけを一覧表示するには:
                                :filter /\.xml$/ oldfiles
                        [!] が指定された場合、{command} の出力を {pattern} に
                        マッチしない行に制限する。

                        {pattern} は Vim の検索パターンである。/ で囲む代わり
                        に、{pattern} の中に現れない限り、ID 文字以外の任意の
                        文字 ('isident' を参照) を使用できる。
                        囲み文字が無い場合、パターンにバー文字を含めることはで
                        きない。'ignorecase' は使用されない。

                        パターンは出力の関連する部分に対してマッチされ、必ずし
                        も行全体に対してではない。フィルタリングをサポートして
                        いるのは一部のコマンドだけである。動作するかどうか、試
                        してチェックすること。フィルタリングをサポートするコマ
                        ンドの一部:
                           :#          - 行全体をフィルタする
                           :clist      - ファイル名またはモジュール名でフィルタする
                           :command    - コマンド名でフィルタする
                           :files      - ファイル名でフィルタする
                           :highlight  - ハイライトグループでフィルタする
                           :history    - 履歴のコマンドでフィルタする
                           :jumps      - ファイル名でフィルタする
                           :let        - 変数名でフィルタする
                           :list       - 行全体をフィルタする
                           :llist      - ファイル名またはモジュール名でフィルタする
                           :marks      - カレントファイル内ではテキストで、
                                           または他のファイルではファイル名でフィルタする
                           :oldfiles   - ファイル名でフィルタする
                           :registers  - レジスタの内容でフィルタする
                                           (複数行では動作しない)
                           :set        - オプション名でフィルタする

                        通常のメッセージだけがフィルタされ、エラーメッセージは
                        フィルタされない。

                                                :sil :silent :silent!
:sil[ent][!] {command}  {command} を静かに実行する。通常のメッセージは表示され
                        ず、メッセージ履歴にも追加されない。
                        [!] が付けられた場合、エラーメッセージもスキップされ、
                        エラーが検出されてもコマンドおよびマッピングは中断され
                        ない。v:errmsg は引き続き設定される。[!] が使用され
                        ない場合、エラーメッセージによって、それ以降のメッセー
                        ジが通常どおり表示される。:redir で開始されたリダイ
                        レクトは、小さな違いがあるかもしれないが、通常どおり継
                        続する。これにより、コマンドの出力を画面上で見ずにリダ
                        イレクトできる。例:
                            :redir >/tmp/foobar
                            :silent g/Aap/p
                            :redir END
                        ノーマルモードコマンドを静かに実行するには、:normal
                        コマンドを使用する。例えば、メッセージなしで文字列を検
                        索するには:
                            :silent exe "normal /path\<CR>"
                        ":silent!" は、失敗するかもしれないが、その失敗を無視
                        すべきコマンドを実行するのに便利である。例:
                            :let v:errmsg = ""
                            :silent! /^begin
                            :if v:errmsg != ""
                            : ... パターンが見つからなかった
                        ":silent" は hit-enter プロンプトも回避する。これを外
                        部コマンドに使用する場合、画面が乱れることがある。その
                        場合は CTRL-L を使用してきれいにする。
                        ":silent menu ..." はコマンドラインのコマンドをエコー
                        しないメニューを定義する。ただし、そのコマンドは依然と
                        してメッセージを出力する。それを避けるには、コマンド自
                        体の中で ":silent" を使用する:
                        ":silent menu .... :silent command"。

                                                :uns :unsilent
:uns[ilent] {command}   {command} を静かにせずに実行する。:silent がこのコマ
                        ンドに至るために使用された場合にだけ違いが生じる。
                        :silent が使用された場合でもメッセージを出すにはこれ
                        を使用する。この例では、ファイルを読み込む時のメッセー
                        ジを避けるために :silent が使用され、各ファイルの最
                        初の行を一覧表示できるようにするために :unsilent が
                        使用されている。
                :silent argdo unsilent echo expand('%') .. ": " .. getline(1)


                                                :verb :verbose
:[count]verb[ose] {command}
                        'verbose' を [count] に設定して {command} を実行する。
                        [count] が省略された場合は 1 が使用される。":0verbose"
                        は 'verbose' をゼロに設定するのに使用できる。
                        ":silent" を併せて使用すると、メッセージは生成されるが
                        表示されない。
                        ":silent" と ":verbose" の組み合わせは、メッセージを生
                        成し、それを v:statusmsg などでチェックするのに使用
                        できる。例えば:
                                :let v:statusmsg = ""
                                :silent verbose runtime foobar.vim
                                :if v:statusmsg != ""
                                :  " foobar.vim が見つからなかった
                                :endif
                        別のコマンドを連結する場合、":verbose" は最初のコマン
                        ドにだけ適用される:
                                :4verbose set verbose | set verbose
                                  verbose=4
                                  verbose=0
                        冗長メッセージをファイルに記録するには、'verbosefile'
                        オプションを使用する。

                                                        :verbose-cmd
'verbose' がゼロ以外の場合、Vim のオプション、キーマップ、短縮入力、ユーザー定
義関数、コマンド、ハイライトグループ、または自動コマンドの値を一覧表示すると、
それが最後にどこで定義されたかも表示される。手動で定義された場合は "Last set"
メッセージは表示されない。関数、ユーザーコマンド、または自動コマンドの実行中に
定義された場合は、それが定義されたスクリプトが報告される。
{Vim が +eval 機能なしでコンパイルされた場合は使用できない}

                                                        K
K                       カーソル下のキーワードを調べるプログラムを実行する。プ
                        ログラムの名前は 'keywordprg' (kp) オプションで指定さ
                        れる (既定値は "man")。キーワードは、英字、数字、およ
                        び 'iskeyword' 内の文字で構成される。カーソル下または
                        カーソルの右にあるキーワードが使用される。同じことは次
                        のコマンドでもできる:
                                :!{program} {keyword}
                        Vim の tools ディレクトリに、使用するプログラムの例が
                        ある。それは "ref" と呼ばれ、簡単なスペルチェックを行
                        う。
                        特別な場合:
                        - 'keywordprg' が ":" で始まる場合、[count] 付きの Vim
                          の Ex コマンドとして呼び出される。
                        - 'keywordprg' が空の場合、":help" コマンドが使用され
                          る。その場合は、より多くのヘルプを見つけられるよう
                          に、'iskeyword' により多くの文字を含めるとよい。
                        - 'keywordprg' が "man" と等しいか、または ":" で始ま
                          る場合、"K" の前の [count] は keywordprg の後、キー
                          ワードの前に挿入される。例えば、カーソルが "mkdir"
                          の上にある時に "2K" を使用すると、次のようになる:
                                !man 2 mkdir
                        - 'keywordprg' が "man -s" と等しい場合、"K" の前のカ
                          ウントは "-s" の後に挿入される。カウントが無い場合、
                          "-s" は削除される。

                                                        v_K
{Visual}K               "K" と同様だが、ビジュアルにハイライトされたテキストを
                        キーワードに使用する。ハイライトされたテキストが 1 行
                        以内の場合にだけ動作する。

[N]gs                                                   gs :sl :sleep
:[N]sl[eep] [N][m]      [N] 秒間何もしない。[m] が含まれる場合、[N] ミリ秒間ス
                        リープする。"gs" のカウントは常に秒を使用する。既定値
                        は 1 秒である。
                             :sleep          "1 秒間スリープする
                             :5sleep         "5 秒間スリープする
                             :sleep 100m     "100 ミリ秒間スリープする
                             10gs            "10 秒間スリープする
                        CTRL-C (MS-Windows では CTRL-Break) で中断できる。"gs"
                        は "goto sleep" を表す。
                        スリープ中、カーソルは、見える位置にある場合はテキスト
                        内に置かれる。
                        キューに入れられたメッセージおよびタイマー (+timers)
                        もスリープ中に処理される。

                                                        :sl! :sleep!
:[N]sl[eep]! [N][m]     上記と同じだが、カーソルを非表示にする。

                                                        :xrestore :xr
:xr[estore] [display]   X11 サーバーへの接続を再初期化する。X サーバーが再起動
                        した後、例えば screen/tmux の中で Vim を長時間実行して
                        いて異なるマシンから接続する場合に便利である。
                        [display] は $DISPLAY 環境変数の形式であるべきである
                        (例: "localhost:10.0")
                        [display] が省略された場合、このコマンドの前回の実行で
                        使用されたのと同じ値を使用して、X11 サーバーへの接続を
                        再初期化する。値が一度も指定されていない場合、Vim が起
                        動された時の $DISPLAY 環境変数の値を使用する。これは
                        v:clipmethod も更新する。
                        {Vim が +xterm_clipboard 機能付きでコンパイルされた
                        場合のみ使用可能}

                                                        :clipreset :clip
:clip[reset]            'clipmethod' オプションを使用して、クリップボードにア
                        クセスするための新しい方式を選択しようと試みる。これ
                        は、現在の方式が使用できなくなり、別の方式を試したい場
                        合に便利である。
                        {Vim が +clipboard 機能付きでコンパイルされた場合の
                        み使用可能}

                                                        g_CTRL-A
g CTRL-A                Vim が MEM_PROFILING を定義してコンパイルされた場合の
                        み (これは非常にまれである): メモリ使用量の統計を表示
                        する。Vim のデバッグにのみ役立つ。
                        ビジュアルモードでのインクリメントについては
                        v_g_CTRL-A を参照。

2. Vim を less または more のように使う                         less

less または more プログラムを使用してファイルを見ると、構文ハイライトが得られ
ない。そのため、代わりに Vim を使用したいだろう。これは、シェルスクリプト
"$VIMRUNTIME/macros/less.sh" を使用することでできる。

このシェルスクリプトは Vim script "$VIMRUNTIME/macros/less.vim" を使用する。こ
れは less がサポートするコマンドをシミュレートするマッピングを設定する。それ以
外では、引き続き Vim のコマンドを使用できる。

これは完璧ではない。例えば、短いファイルを見る場合でも、Vim は画面全体を使用す
る。しかし、ほとんどの用途には十分うまく動作し、構文ハイライトも得られる。

"h" キーで、使用可能なコマンドの短い概要が表示される。

less を使用する時にオプションを異なる設定にしたい場合、vimrc で LessInitFunc
を定義する。例えば:

        func LessInitFunc()
          set nocursorcolumn nocursorline
        endfunc
