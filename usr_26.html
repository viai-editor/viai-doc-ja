                                  繰り返し


編集作業がまったく構造を持たないことはめったにありません。変更は何度も行う必要
があることがよくあります。この章では、変更を繰り返すための便利な方法をいくつか
説明します。

26.1  ビジュアルモードで繰り返す

ビジュアルモードは、任意の範囲の行で変更を行うのにとても便利です。ハイライトさ
れたテキストが見えるので、正しい行が変更されるかを確認できます。しかし、選択す
るにはいくらかタイプする必要があります。"gv" コマンドは同じ範囲を再び選択しま
す。これにより、同じテキストに対して別の操作を行うことができます。
   "2001" を "2002" に、および "2000" を "2001" に変更したい行がいくつかあると
します:

        The financial results for 2001 are better
        than for 2000.  The income increased by 50%,
        even though 2001 had more rain than 2000.
                        2000            2001
        income          45,403          66,234

まず "2001" を "2002" に変更します。ビジュアルモードで行を選択し、これを使いま
す:

        :s/2001/2002/g

次に "gv" を使って同じテキストを再選択します。カーソルがどこにあっても構いませ
ん。それから ":s/2000/2001/g" を使って 2 つ目の変更を行います。
   もちろん、これらの変更は何度でも繰り返せます。

26.2  加算と減算

ある数を別の数に変える変更を繰り返すときは、決まった差であることがよくありま
す。上の例では、それぞれの年に 1 を足しました。出てくる年ごとに置換コマンドを
タイプする代わりに、CTRL-A コマンドを使うことができます。
   上と同じテキストを使って、年を検索します:

        /19[0-9][0-9]\|20[0-9][0-9]

ここで CTRL-A を押します。年が 1 増えます:

        The financial results for 2002 are better
        than for 2000.  The income increased by 50%,
        even though 2001 had more rain than 2000.
                        2000            2001
        income          45,403          66,234

"n" を使って次の年を見つけ、"." を押して CTRL-A を繰り返します ("." の方が少し
速くタイプできます)。出てくるすべての年について "n" および "." を繰り返します。
   ヒント: 'hlsearch' オプションを設定すると、これから変更するマッチが見えるの
で、先を見越して速く作業できます。

1 より大きい数を足すには、CTRL-A の前に数を付けます。このリストがあるとします:

        1.  item four
        2.  item five
        3.  item six

カーソルを "1." に移動して、こうタイプします:

        3 CTRL-A

"1." は "4." に変わります。ここでも、"." を使って他の数にこれを繰り返せます。

別の例:

        006     foo bar
        007     foo bar

これらの数に CTRL-A を使うと、結果はこうなります:

        007     foo bar
        010     foo bar

7 足す 1 が 10?  ここで起きたのは、先頭にゼロがあるので、Vim が "007" を 8 進
数と認識したということです。この表記は C のプログラムでよく使われます。先頭に
ゼロがある数を 8 進数として扱ってほしくない場合は、これを使います:

        :set nrformats-=octal

CTRL-X コマンドは、同じようにして減算を行います。

26.3  多くのファイルで変更する

"x_cnt" という変数があり、それを "x_counter" に変えたいとします。この変数は、
いくつかの C ファイルで使われています。すべてのファイルで変更する必要がありま
す。これがそのやり方です。
   関係するファイルをすべて引数リストに入れます:

        :args *.c

これはすべての C ファイルを見つけて、最初のファイルを編集します。ここで、これ
らすべてのファイルに対して置換コマンドを実行できます:

        :argdo %s/\<x_cnt\>/x_counter/ge | update

":argdo" コマンドは、別のコマンドを引数に取ります。そのコマンドは引数リストの
すべてのファイルで実行されます。
   それに続く "%s" 置換コマンドは、すべての行に作用します。これは "\<x_cnt\>"
で単語 "x_cnt" を見つけます。"\<" および "\>" は、単語全体だけにマッチさせ、
"px_cnt" または "x_cnt2" にはマッチさせないために使います。
   置換コマンドのフラグには、同じ行のすべての "x_cnt" を置換するための "g" が
含まれています。"e" フラグは、ファイルの中に "x_cnt" が無いときにエラーメッセー
ジを出さないために使います。そうしないと、":argdo" は "x_cnt" が見つからなかっ
た最初のファイルで中断してしまいます。
   "|" は 2 つのコマンドを区切ります。以下の "update" コマンドは、ファイルが変
更されたときだけファイルを書き込みます。"x_cnt" が "x_counter" に変更されなかっ
た場合は、何も起きません。

":windo" コマンドもあり、これはすべてのウィンドウで引数を実行します。また
":bufdo" は、すべてのバッファで引数を実行します。思っているより多くのファイル
がバッファリストにあるかもしれないので、これには注意してください。":buffers"
コマンド (または ":ls") で確認してください。

26.4  シェルスクリプトから Vim を使う

文字列 "-person-" を "Jones" に変えてから印刷する必要があるファイルがたくさん
あるとします。どうすればよいでしょうか?  1 つの方法は、たくさんタイプすること
です。もう 1 つは、その作業を行うシェルスクリプトを書くことです。
   Vim エディタは、ノーマルモードのコマンドを使うと、画面指向のエディタとして
素晴らしい仕事をします。しかしバッチ処理では、ノーマルモードのコマンドからは、
分かりやすくコメント付きのコマンドファイルにはなりません。そのためここでは、代
わりに Ex モードを使います。このモードは、バッチファイルに入れやすい、よいコマ
ンドラインインターフェイスを提供します。("Ex コマンド" は、コマンドライン (:)
のコマンドの別名にすぎません。)
   必要な Ex モードのコマンドは以下のとおりです:

        %s/-person-/Jones/g
        write tempfile
        quit

これらのコマンドを "change.vim" ファイルに入れます。そして、エディタをバッチ
モードで実行するには、このシェルスクリプトを使います:

        for file in *.txt; do
          vim -e -s $file < change.vim
          lpr -r tempfile
        done

for-done ループは、間にある 2 行を、$file 変数に毎回違うファイル名を設定しなが
ら繰り返すシェル構文です。
   2 行目は、ファイル $file に対して Vim エディタを Ex モード (-e 引数) で実行
し、ファイル "change.vim" からコマンドを読み込みます。-s 引数は、Vim にサイレ
ントモードで動作するように指示します。言い換えると、:prompt、またはその他のど
んなプロンプトも出力し続けないということです。
   "lpr -r tempfile" コマンドは、結果の "tempfile" を印刷し、それを削除します
(-r 引数がそれを行います)。


標準入力から読み込む

Vim は標準入力のテキストを読み込むことができます。通常はそこからコマンドを読み
込むので、代わりにテキストを読み込むように Vim に指示する必要があります。これ
は、ファイルの代わりに "-" 引数を渡すことで行います。例:

        ls | vim -

これにより、テキストを先にファイルに保存せずに、"ls" コマンドの出力を編集でき
ます。
   テキストを読み込むのに標準入力を使う場合は、"-S" 引数を使ってスクリプトを読
み込むことができます:

        producer | vim -S change.vim -


ノーマルモードのスクリプト

本当にスクリプトでノーマルモードのコマンドを使いたい場合は、このように使えます:


        vim -s script file.txt ...

        Note:
        "-s" は "-e" なしで使うと意味が違います。ここでは、"script" をノーマル
        モードのコマンドとして読み込むという意味です。"-e" と一緒に使うと、サ
        イレントにするという意味になり、次の引数をファイル名として使いません。

"script" の中のコマンドは、タイプしたのと同じように実行されます。改行は
<Enter> を押したと解釈されることを忘れないでください。ノーマルモードでは、それ
はカーソルを次の行に移動します。
   スクリプトを作るには、スクリプトファイルを編集して、コマンドをタイプすれば
よいです。結果がどうなるかを想像する必要があり、それは少し難しいかもしれませ
ん。別の方法は、コマンドを手で実行しながら記録することです。そのやり方はこうで
す:

        vim -w script file.txt ...

タイプしたキーはすべて "script" に書き込まれます。小さな間違いをしても、そのま
ま続けて、後でスクリプトを編集することを覚えておけばよいです。
   "-w" 引数は、既存のスクリプトに追加します。スクリプトを少しずつ記録したいと
きに便利です。一から始めて全部やり直したい場合は、"-W" 引数を使います。これは
既存のファイルを上書きします。
