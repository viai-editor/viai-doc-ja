                     VIAI ユーザーマニュアル


                           編集するファイルを見つける


ファイルはあらゆる場所にあります。では、どうやってそれらを見つけるのでしょう?
Vim はディレクトリツリーをブラウズするさまざまな方法を提供しています。別のファ
イルの中で言及されているファイルにジャンプするコマンドがあります。そして、Vim
はどのファイルを以前に編集したかを覚えています。

22.1  ファイルブラウザー

Vim には、ディレクトリを編集できるようにするプラグインがあります。これを試して
ください:

        :edit .

自動コマンドおよび Vim script の魔法によって、ウィンドウはディレクトリの内容で
満たされます。それはこのように見えます (78 文字に収まるように少し整理してあり
ます):

  " ==========================================================================
  " Netrw Directory Listing                                       (netrw v184)
  "   /path/to/vim/runtime/doc
  "   Sorted by      name
  "   Sort sequence: [\/]$,*,\(\.bak\|\~\|\.o\|\.h\|\.info\|\.swp\)[*@]\=$
  "   Quick Help: <F1>:help -:go up dir D:delete R:rename s:sort-by x:special
  " ==========================================================================
  ../
  ./
  check/
  Makefile
  autocmd.txt
  change.txt
  eval.txt
  filetype.txt
  help.txt.info

これらの項目が見えます:

1. ブラウズツールの名前およびそのバージョン番号
2. ブラウズしているディレクトリの名前
3. ソートの方法 (名前、時刻、またはサイズによることがある)
4. 名前がどのようにソートされるか (ディレクトリが最初、次に拡張子順、など)
5. ヘルプの表示方法 (<F1> キー)、および使用できるコマンドの要約リスト
6. "../" を含むファイルの一覧 (親ディレクトリを一覧表示する)。

構文ハイライトを有効にしている場合は、見つけやすくするために、それぞれの部分が
ハイライトされます。

テキスト内を移動するには、ノーマルモードの Vim コマンドを使えます。例えば、カー
ソルをファイルの上に移動して <Enter> を押してください。そうすると、そのファイ
ルを編集することになります。ブラウザーに戻るには、再び ":edit ." を使うか、ま
たは ":Explore" を使います。CTRL-O も動作します。

カーソルがディレクトリ名の上にある時に <Enter> を使ってみてください。その結果、
ファイルブラウザーはそのディレクトリに移動し、そこで見つかった項目を表示しま
す。最初のディレクトリ "../" の上で <Enter> を押すと、1 つ上の階層に移動しま
す。"-" を押すと、先に "../" の項目に移動する必要なしに、同じことをします。

<F1> を押すと、netrw ファイルブラウザーでできることについてのヘルプが得られま
す。これが得られるものです:

 QUICK HELP                                             netrw-quickhelp
                       (Use ctrl-] to select a topic)
        Intro to Browsing...............................netrw-intro-browse
          Quick Reference: Maps.........................netrw-quickmap
          Quick Reference: Commands.....................netrw-browse-cmds

したがって、<F1> キーは netrw のディレクトリブラウズの内容のヘルプページに移動
します。これは通常のヘルプページです。タグ付きのヘルプ項目にジャンプするには通
常の CTRL-] を、戻るには CTRL-O を使います。ですから、netrw-quickmap の
上で CTRL-] すると、ここにジャンプします:

                                netrw-quickmap  netrw-quickmaps
 QUICK REFERENCE: MAPS                          netrw-browse-maps

          ---                   -----------------                       ----
          Map                   Quick Explanation                       Link
          ---                   -----------------                       ----
         <F1>   Causes Netrw to issue help
         <cr>   Netrw will enter the directory or read the file      netrw-cr
         <del>  Netrw will attempt to remove the file/directory      netrw-del
         (etc.)

表示および編集するファイルを選択するには (カーソルをファイル名の上に置いて):

           o    Enter the file/directory under the cursor in a new   netrw-o
                browser window.  A horizontal split is used.
           O    Obtain a file specified by cursor                    netrw-O
           p    Preview the file                                     netrw-p
           P    Browse in the previously used window                 netrw-P
           v    Enter the file/directory under the cursor in a new   netrw-v
                browser window.  A vertical split is used.

以下のノーマルモードのコマンドを使って、ブラウザーの表示を制御できます:

           i    Cycle between thin, long, wide, and tree listings    netrw-i
           r    Reverse sorting order                                netrw-r
           s    Select sorting style: by name, time, or file size    netrw-s

追加のノーマルモードのコマンドのいくつかの例として:

           cd   Make browsing directory the current directory        netrw-cd
           D    Attempt to remove the file(s)/directory(ies)         netrw-D
           gb   Go to previous bookmarked directory                  netrw-gb
           mb   Bookmark current directory                           netrw-mb
           R    Rename the designated file(s)/directory(ies)         netrw-R

コマンドモードも使えます。これも、単なる例です:

     :Explore[!]  [dir] Explore directory of current file......netrw-explore
     :Hexplore[!] [dir] Horizontal Split & Explore.............netrw-explore

netrw ブラウザーは、ローカルマシンだけに限定されません。このような URL も使え
ます:

        :Explore ftp://somehost/path/to/dir/
        :e scp://somehost/path/to/dir/

        Note: 末尾の "/" は重要です。

詳しくは netrw-browse を参照してください。

22.2  カレントディレクトリ

シェルと同じように、Vim にはカレントディレクトリの概念があります。ホームディレ
クトリにいて、"VeryLongFileName" ディレクトリにあるいくつかのファイルを編集し
たいとします。このようにできます:

        :edit VeryLongFileName/file1.txt
        :edit VeryLongFileName/file2.txt
        :edit VeryLongFileName/file3.txt

入力の多くを避けるには、こうします:

        :cd VeryLongFileName
        :edit file1.txt
        :edit file2.txt
        :edit file3.txt

":cd" コマンドはカレントディレクトリを変更します。カレントディレクトリが何かは
":pwd" コマンドで見られます:

        :pwd
        /home/Bram/VeryLongFileName

Vim は最後に使ったディレクトリを覚えています。そこに戻るには "cd -" を使いま
す。例:

        :pwd
        /home/Bram/VeryLongFileName
        :cd /etc
        :pwd
        /etc
        :cd -
        :pwd
        /home/Bram/VeryLongFileName
        :cd -
        :pwd
        /etc


ウィンドウローカルディレクトリ

ウィンドウを分割すると、両方のウィンドウが同じカレントディレクトリを使います。
新しいウィンドウでどこか別の場所にあるいくつかのファイルを編集したい場合は、も
う一方のウィンドウのカレントディレクトリを変更せずに、新しいウィンドウに別の
ディレクトリを使わせることができます。これはローカルディレクトリと呼ばれます。


        :pwd
        /home/Bram/VeryLongFileName
        :split
        :lcd /etc
        :pwd
        /etc
        CTRL-W w
        :pwd
        /home/Bram/VeryLongFileName

:lcd コマンドが使われていない限り、すべてのウィンドウは同じカレントディレク
トリを共有します。あるウィンドウで :cd コマンドを実行すると、もう一方のウィ
ンドウのカレントディレクトリも変更されます。
   :lcd が使われたウィンドウでは、別のカレントディレクトリが記憶されます。他
のウィンドウで :cd または :lcd を使っても、それは変更されません。
   別のカレントディレクトリを使っているウィンドウで :cd コマンドを使うと、共
有ディレクトリを使う状態に戻ります。


タブローカルディレクトリ

新しいタブページを開くと、そのタブページは、新しいタブページが開かれた元の前の
タブページのウィンドウのディレクトリを使います。:tcd コマンドを使うと、カレ
ントタブページのディレクトリを変更できます。ウィンドウローカルディレクトリを持
つウィンドウを除いて、タブページ内のすべてのウィンドウはこのディレクトリを共有
します。このタブページで開かれた新しいウィンドウはすべて、このディレクトリをカ
レントワーキングディレクトリとして使います。タブページで :cd コマンドを使っ
ても、タブローカルディレクトリを持つタブページのワーキングディレクトリは変更さ
れません。タブページで :cd コマンドを使ってグローバルワーキングディレクトリ
が変更されると、カレントタブページのワーキングディレクトリも変更されます。

22.3  ファイルを探す

この行を含む C プログラムを編集しているとします:

        #include "inits.h"

その "inits.h" ファイルに何が入っているかを見たいとします。カーソルをファイル
の名前の上に移動して、こう入力します:

        gf

Vim はそのファイルを見つけて編集します。
   ファイルがカレントディレクトリにない場合はどうでしょう? Vim はファイルを見
つけるために 'path' オプションを使います。このオプションは、ファイルを探す場所
であるディレクトリ名のリストです。
   インクルードファイルが "c:/prog/include" にあるとします。このコマンドはそれ
を 'path' オプションに追加します:

        :set path+=c:/prog/include

このディレクトリは絶対パスです。どこにいても、同じ場所になります。ファイルがあ
る場所の下のサブディレクトリにファイルを置いている場合はどうでしょう? その場合
は、相対パス名を指定できます。これはドットで始まります:

        :set path+=./proto

これは、"gf" を使うファイルがあるディレクトリの下の、"proto" ディレクトリの中
を探すように Vim に指示します。したがって、"inits.h" の上で "gf" を使うと、Vim
はファイルのディレクトリから始めて "proto/inits.h" を探します。
   "./" がない場合、すなわち "proto" の場合、Vim はカレントディレクトリの下の
"proto" ディレクトリの中を探します。そして、カレントディレクトリは、編集してい
るファイルがある場所ではないかもしれません。

'path' オプションでは、ファイルを探すディレクトリを、他にもさまざまな方法で指
定できます。'path' オプションのヘルプを参照してください。
   'isfname' オプションは、どの文字がファイル名に含まれ、どの文字が含まれない
か (例えば、上の例の " 文字) を決めるのに使われます。

ファイル名は分かっているけれど、それがファイル内にない場合は、それを入力できま
す:

        :find inits.h

そうすると、Vim は 'path' オプションを使ってファイルを見つけようとします。これ
は、'path' を使うことを除けば、":edit" コマンドと同じです。

見つけたファイルを新しいウィンドウで開くには、"gf" の代わりに CTRL-W f を使う
か、または ":find" の代わりに ":sfind" を使います。


'path' 内のどこかにあるファイルを編集するために、Vim を直接起動するよい方法:

        vim "+find stdio.h"

これは、'path' の値の中からファイル "stdio.h" を見つけます。引用符は 1 つの引
数にするために必要です -+c。

22.4  バッファリスト

Vim エディタは、編集中のファイルを表すのにバッファという用語を使います。実は、
バッファは編集しているファイルのコピーです。バッファの変更を終えたら、バッファ
の内容をファイルに書き込みます。バッファには、ファイルの内容だけでなく、それに
伴うすべてのマーク、設定、およびその他のものも含まれます。


隠れバッファ

ファイル one.txt を編集していて、ファイル two.txt を編集する必要があるとしま
す。単に ":edit two.txt" を使うこともできますが、one.txt に変更を加えたので、
それはうまくいきません。また、one.txt はまだ書き込みたくありません。Vim には解
決策があります:

        :hide edit two.txt

バッファ "one.txt" は画面から消えますが、Vim はまだこのバッファを編集している
ことを知っているので、変更されたテキストを保持します。これは隠れバッファと呼ば
れます: バッファはテキストを含んでいますが、それを見ることはできません。
   ":hide" の引数は別のコマンドです。":hide" は、そのコマンドを 'hidden' オプ
ションが設定されているかのように動作させます。このオプションを自分で設定するこ
ともできます。その効果は、どのバッファも放棄された時に隠れた状態になるというこ
とです。
   気を付けてください! 変更のある隠れバッファがある時は、すべてのバッファを保
存したことを確かめずに Vim を終了しないでください。


非アクティブバッファ

バッファが 1 回使われると、Vim はそれについての情報をいくらか覚えています。そ
れがウィンドウに表示されておらず、隠れてもいない場合でも、まだバッファリストに
あります。これは非アクティブバッファと呼ばれます。概要:

        アクティブ              ウィンドウに表示され、テキストが読み込まれている。
        隠れ            ウィンドウになく、テキストが読み込まれている。
        非アクティブ    ウィンドウになく、テキストが読み込まれていない。

非アクティブバッファは記憶されます。Vim はそれらについて、マークのような情報を
保持しているからです。そして、ファイル名を覚えておくことも役に立ちます。そうす
れば、どのファイルを編集したかを見ることができます。そして、それらを再び編集す
ることも。


バッファを一覧表示する

このコマンドでバッファリストを表示します:

        :buffers

同じことをするコマンドで、バッファを一覧表示するものとしてはあまり分かりやすく
ありませんが、入力するのはずっと短いものがあります:

        :ls

出力はこのようになるでしょう:

  1 #h   "help.txt"                     line 62
  2 %a + "usr_21.txt"                   line 1
  3      "usr_toc.txt"                  line 1

最初の列にはバッファ番号が入っています。これを使うと、名前を入力しなくてもバッ
ファを編集できます。以下を参照してください。
   バッファ番号の後にはフラグが来ます。次に、ファイルの名前、およびカーソルが
最後にあった行番号が来ます。
   表示されうるフラグはこれらです (左から右へ):

        u       バッファは非リスト unlisted-buffer。
         %      カレントバッファ。
         #      オルタネートバッファ。
          a     バッファは読み込まれ、表示されている。
          h     バッファは読み込まれているが、隠れている。
           =    バッファは読み込み専用。
           -    バッファは変更できない、'modifiable' オプションがオフ。
            +   バッファは変更されている。


バッファを編集する

バッファはその番号で編集できます。そうすればファイル名を入力しなくて済みます:


        :buffer 2

しかし、番号を知る唯一の方法は、バッファリストを見ることです。代わりに、名前、
またはその一部を使えます:

        :buffer help

Vim は入力した名前に最もよく一致するものを見つけます。名前に一致するバッファが
1 つだけの場合は、それが使われます。この場合は "help.txt" です。
   バッファを新しいウィンドウで開くには:

        :sbuffer 3

これも名前で動作します。


バッファリストを使う

これらのコマンドでバッファリスト内を移動できます:

        :bnext          次のバッファへ移動する
        :bprevious      前のバッファへ移動する
        :bfirst         最初のバッファへ移動する
        :blast          最後のバッファへ移動する

リストからバッファを削除するには、このコマンドを使います:

        :bdelete 3

繰り返しになりますが、これも名前で動作します。
   アクティブだった (ウィンドウ内に見えていた) バッファを削除すると、そのウィ
ンドウは閉じられます。カレントバッファを削除すると、カレントウィンドウが閉じら
れます。それが最後のウィンドウだった場合は、Vim は編集する別のバッファを見つけ
ます。何も編集していない状態にはなれません!

        Note: ":bdelete" でバッファを削除した後でも、Vim はまだそれを覚えてい
        ます。実際には "非リスト" にされ、":buffers" のリストにはもう表示され
        ません。":buffers!" コマンドは非リストバッファを一覧表示します (そう、
        Vim は不可能なことができるのです)。本当に Vim にバッファを忘れさせるに
        は、":bwipe" を使います。'buflisted' オプションも参照してください。
