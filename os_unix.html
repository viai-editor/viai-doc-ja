                                                                unix Unix
このファイルには、Unix 版 Vim の特記事項が書かれている。

Unix で Vim をコンパイルするには、src ディレクトリの "INSTALL" と "Makefile"
を参照。

デフォルトのヘルプファイル名は "/usr/local/lib/vim/help.txt" である
"s:.vimrc" と "s:.exrc" の代わりに "$HOME/.vimrc" と "$HOME/.exrc" が使われる。
さらに、"/usr/local/etc/vimrc" が最初に使われる。
"/usr/local/share" が存在する場合は、"/usr/local/lib" の代わりにそれが使われ
る。

(フィルタ処理用の) 一時ファイルは "/tmp" に置かれる。ほかの場所に置きたい場合
は、環境変数 $TMPDIR に好みのディレクトリを設定すること。

ワイルドカード展開では、'~' (ホームディレクトリ) と '$'
(環境変数) を使える。

                                                                fork spoon
外部コマンドの実行には、可能なら fork()/exec() が使われ、そうでなければ
system() が使われる。system() は少し遅い。":version" の出力には、fork()/exec()
が使われる場合は +fork が、system() が使われる場合は +system() が含まれる。
これはコンパイル時に変更できる。
(GUI 版の fork については gui-fork を参照。)

歴史的な理由から、Unix では端末の更新は遅いと想定されているので (例: シリアル
回線の端末、suntools のシェルウィンドウ)、'showcmd' と 'ruler' オプションはデ
フォルトでオフになっている。速い端末を使っている場合は、これらを
オンに設定してみること:
        set showcmd ruler

xterm の中で Vim を使っているときは、'mouse' を "a" に設定すれば、マウスのク
リックを Vim で使える。X-server にアクセスできる場合は、GUI スタイルのコピー/
ペーストが使われ、マウスでドラッグしている間、視覚的なフィードバックが表示され
る。
それでもマウスで xterm のコピー/ペーストをしたい場合は、マウスを使うときに
Shift キーを押すこと。mouse-using を参照。xterm が十分に新しければ、ドラッグ
中の視覚的なフィードバックは 'ttymouse' オプションでも実現できる。

                                                                terminal-colors
Vim で色を使うには、以下の例が使える (端末が色をサポートしているが、"T_Co" が
空かゼロの場合):
   :set t_me=^[[0;1;36m     " ノーマルモード (t_mr と t_md を元に戻す)
   :set t_mr=^[[0;1;33;44m  " リバース (反転) モード
   :set t_md=^[[1;33;41m    " 太字モード
   :set t_se=^[[1;36;40m    " 強調表示の終了
   :set t_so=^[[1;32;45m    " 強調表示モード
   :set t_ue=^[[0;1;36m     " 下線の終了
   :set t_us=^[[1;32m       " 下線モードの開始
[^[ は <Esc> である。入力するには CTRL-V <Esc> とタイプする]

本物のカラー端末では、":highlight" コマンドが使える。

"tools/vim132" ファイルは、vt100 とその類似の端末で Vim を 132 カラムモードに
するために使えるシェルスクリプトである。
