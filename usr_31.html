                     VIAI ユーザーマニュアル


                              GUI を活用する


Vim は端末でうまく動作しますが、GUI にはいくつかの追加項目があります。ファイル
を使うコマンドには、ファイルブラウザーを使えます。選択肢の間で選択をするための
ダイアログ。メニュー項目に素早くアクセスするには、キーボードショートカットを使
います。

31.1  ファイルブラウザー

File/Open... メニューを使うと、ファイルブラウザーが表示されます。これにより、
編集したいファイルを見つけやすくなります。しかし、ウィンドウを分割して別のファ
イルを編集したい場合はどうでしょうか? これにはメニュー項目がありません。まず
Window/Split を使い、それから File/Open... を使うこともできますが、それは手間
が増えます。
   ほとんどのコマンドは Vim でタイプしているので、タイプしたコマンドでファイル
ブラウザーを開くこともできます。split コマンドがファイルブラウザーを使うように
するには、"browse" を前に付けます:

        :browse split

ファイルを選択すると、それに対して ":split" コマンドが実行されます。ファイルダ
イアログをキャンセルすると、何も起こらず、ウィンドウは分割されません。
   ファイル名の引数を指定することもできます。これは、ファイルブラウザーにどこ
から始めるかを伝えるのに使われます。例:

        :browse split /etc

ファイルブラウザーが、ディレクトリ "/etc" から始まってポップアップします。

":browse" コマンドは、ファイルを開くほぼすべてのコマンドの前に付けることができ
ます。
   ディレクトリが指定されていない場合、Vim はファイルブラウザーをどこから始め
るかを決めます。デフォルトでは前回と同じディレクトリを使います。したがって、
":browse split" を使って "/usr/local/share" 内のファイルを選択した場合、次に
":browse" を使うときには、再び "/usr/local/share" から始まります。
   これは 'browsedir' オプションで変更できます。これは 3 つの値のうちの 1 つを
持つことができます:

        last            最後にブラウズしたディレクトリを使う (デフォルト)
        buffer          カレントバッファと同じディレクトリを使う
        current         カレントディレクトリを使う

例えば、ディレクトリ "/usr" にいて、ファイル "/usr/local/share/readme" を編集
しているとき、このコマンドは:

        :set browsedir=buffer
        :browse edit

ブラウザーを "/usr/local/share" で開始します。代わりに:

        :set browsedir=current
        :browse edit

ブラウザーを "/usr" で開始します。

        Note:
        マウスを使わずに済むように、ほとんどのファイルブラウザーは、キーを押し
        て移動する方法を提供しています。これはシステムごとに異なるので、ここで
        は説明しません。Vim は可能なら標準のブラウザーを使います。キーボード
        ショートカットについての説明は、システムのドキュメントのどこかにあるは
        ずです。

GUI 版を使っていないときは、ファイルブラウザーのようにファイルを選択するのに、
ファイルエクスプローラーウィンドウを使うことができます。しかし、これは
":browse" コマンドでは動作しません。netrw-browse を参照してください。

31.2  確認

Vim は、うっかりファイルを上書きすることおよびその他の変更を失う方法から、あな
たを守ります。やるとまずいかもしれないことをすると、Vim はエラーメッセージを出
し、本当にそれを行いたいなら ! を付けるよう提案します。
   ! を付けてコマンドをタイプし直すのを避けるため、Vim にダイアログを出させる
ことができます。そうすれば、"OK" または "Cancel" を押して、何をしたいかを Vim
に伝えられます。
   例えば、あるファイルを編集していて、それに変更を加えたとします。これで別の
ファイルの編集を始めます:

        :confirm edit foo.txt

Vim は、だいたいこのように見えるダイアログをポップアップします:

        +-----------------------------------+
        |                                   |
        |   ?   Save changes to "bar.txt"?  |
        |                                   |
        |   YES   NO             CANCEL     |
        +-----------------------------------+

では、選択をしてください。変更を本当に保存したい場合は "YES" を選択します。変
更を永久に失いたい場合は: "NO"。何をしていたかを忘れてしまい、実際に何が変更さ
れたのかを確認したい場合は "CANCEL" を使います。変更が残ったままの同じファイル
に戻ります。

":browse" と同様に、":confirm" コマンドは、別のファイルを編集するほとんどのコ
マンドの前に付けることができます。これらは組み合わせることもできます:

        :confirm browse edit

これは、カレントバッファが変更されていた場合にダイアログを出します。それから、
編集するファイルを選択するためのファイルブラウザーをポップアップします。

        Note:
        ダイアログでは、キーボードを使って選択肢を選ぶことができます。通常は
        <Tab> キーおよびカーソルキーで選択肢が変わります。<Enter> を押すと選択
        肢が選択されます。ただし、これはシステムに依存します。

GUI を使っていないときも、":confirm" コマンドは同様に動作します。ダイアログを
ポップアップする代わりに、Vim は Vim ウィンドウの下部にメッセージを表示し、選
択をするためにキーを押すよう求めます。

        :confirm edit main.c
        Save changes to "Untitled"?
        [Y]es, (N)o, (C)ancel: 

これで、選択肢に対応する 1 つのキーを押せます。コマンドラインでの他の入力と違
い、<Enter> を押す必要はありません。

31.3  メニューショートカット

すべての Vim コマンドにはキーボードが使われます。メニューは、コマンドが何と呼
ばれているかを知らなくても、コマンドを選択する簡単な方法を提供します。しかし、
キーボードから手を離してマウスをつかむ必要があります。
   メニューは、多くの場合キーでも選択できます。これはシステムに依存しますが、
たいていはこのように動作します。<Alt> キーを、メニューの下線付きの文字と組み合
わせて使います。例えば、<A-w> (<Alt> および w) は Window メニューをポップアッ
プします。
   Window メニューでは、"split" 項目は p に下線が付いています。それを選択する
には、<Alt> キーを離して p を押します。

<Alt> キーで最初にメニューを選択した後は、カーソルキーを使ってメニュー内を移動
できます。<Right> はサブメニューを選択し、<left> はそれを閉じます。<Esc> もメ
ニューを閉じます。<Enter> はメニュー項目を選択します。

メニュー項目を選択するために <Alt> キーを使うことと、マッピングのために <Alt>
キーの組み合わせを使うことの間には、衝突があります。'winaltkeys' オプションは、
<Alt> キーで何をすべきかを Vim に伝えます。
   デフォルト値 "menu" は賢い選択です: キーの組み合わせがメニューショートカッ
トである場合、それはマップできません。他のすべてのキーはマッピングに使えます。
   値 "no" は、メニューに <Alt> キーを一切使いません。したがって、メニューには
マウスを使わなければならず、すべての <Alt> キーをマップできます。
   値 "yes" は、Vim がメニューにどの <Alt> キーも使うことを意味します。<Alt>
キーの組み合わせの中には、メニューの選択以外のことも行うものがあります。

31.4  Vim ウィンドウの位置とサイズ

画面上の現在の Vim ウィンドウの位置を見るには、これを使います:

        :winpos

これは GUI でのみ動作します。出力はこのようになるでしょう:

        Window position: X 272, Y 103

位置はスクリーンのピクセル単位で与えられます。これで、その数値を使って Vim を
どこか別の場所に移動できます。例えば、左に 100 ピクセル移動するには:

        :winpos 172 103

        Note:
        報告された位置と、ウィンドウが移動する場所の間には、小さなずれがあるか
        もしれません。これはウィンドウの周りの枠のためです。これはウィンドウマ
        ネージャーによって追加されます。

スタートアップスクリプトでこのコマンドを使って、ウィンドウを特定の位置に配置す
ることができます。

Vim ウィンドウのサイズは文字単位で計算されます。したがって、これは使われている
フォントのサイズに依存します。現在のサイズはこのコマンドで見ることができます:


        :set lines columns

サイズを変更するには、'lines' および/または 'columns' オプションを新しい値に設
定します:

        :set lines=50
        :set columns=80

サイズの取得は、GUI と同様に端末でも動作します。サイズの設定は、ほとんどの端末
ではできません。

X-Windows 版の gvim は、ウィンドウのサイズおよび位置を指定する引数を付けて起動
できます:

        gvim -geometry {width}x{height}+{x-offset}+{y-offset}

{width} および {height} は文字単位で、{x-offset} および {y-offset} はピクセル
単位です。例:

        gvim -geometry 80x25+100+300

31.5  その他

gvim を使って電子メールのメッセージを編集できます。電子メールプログラムで、メッ
セージ用のエディタとして gvim を選択しなければなりません。それを試してみると、
うまく動かないことが分かるでしょう: gvim がまだ実行中なのに、メールプログラム
は編集が終わったと考えるのです!
   何が起こっているかというと、gvim は、起動されたシェルから切り離されるので
す。端末で gvim を起動したときは、その端末で他の作業ができるので、それで問題あ
りません。しかし、本当に gvim が終了するのを待ちたい場合は、切り離されるのを防
がなければなりません。"-f" 引数がこれを行います:

        gvim -f file.txt

"-f" はフォアグラウンドを表します。これで、Vim は、編集を終えて終了するまで、
起動されたシェルをブロックします。


GUI の遅延起動

Unix では、まず端末で Vim を起動することができます。同じシェルでさまざまな作業
をする場合、それは便利です。ファイルを編集していて、結局 GUI を使いたいと決め
た場合は、これで起動できます:

        :gui

Vim は GUI ウィンドウを開き、もう端末を使わなくなります。端末を他のことに使い
続けることができます。ここでは、GUI をフォアグラウンドで実行するために "-f" 引
数が使われます。":gui -f" を使うこともできます。


gvim スタートアップファイル

gvim は起動するとき、gvimrc ファイルを読み込みます。それは、Vim の起動時に使わ
れる vimrc ファイルに似ています。gvimrc ファイルは、GUI が起動されるときにだけ
使われる設定およびコマンドに使うことができます。例えば、異なるウィンドウサイズ
を設定するために 'lines' オプションを設定できます:

        :set lines=55

端末ではこれをしたくないでしょう。そのサイズは固定されているからです (サイズ変
更をサポートしている xterm を除く)。
   gvimrc ファイルは vimrc ファイルと同じ場所で検索されます。通常、その名前は
Unix では "~/.gvimrc" であり、MS-Windows では "$VIM/_gvimrc" です。$MYGVIMRC
環境変数がそれに設定されるので、ファイルがある場合は、このコマンドを使ってそれ
を編集できます:

        :edit $MYGVIMRC

   何らかの理由で通常の gvimrc ファイルを使いたくない場合は、"-U" 引数で別の
ファイルを指定できます:

        gvim -U thisrc ...

これにより、異なる種類の編集のために gvim を起動できます。例えば、別のフォント
サイズを設定することができるでしょう。
   gvimrc ファイルの読み込みを完全にスキップするには:

        gvim -U NONE ...
