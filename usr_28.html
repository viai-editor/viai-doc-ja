                                   折り畳み


構造化されたテキストは、セクションに分けることができます。そしてセクションはサ
ブセクションに。折り畳みを使うと、セクションを 1 行として表示して、概要を示す
ことができます。この章では、これを行うさまざまな方法を説明します。

28.1  折り畳みとは何か?

折り畳みは、バッファ内の行の範囲を画面上で 1 行として表示するために使われます。
短くするために折り畳んだ紙のようなものです:

        +------------------------+
        | 1 行目                 |
        | 2 行目                 |
        | 3 行目                 |
        |_______________________ |
        \                        \
         \________________________\
         / 折り畳まれた行         /
        /________________________/
        | 12 行目                |
        | 13 行目                |
        | 14 行目                |
        +------------------------+

テキストは変更されずにバッファ内にあります。折り畳みによって影響を受けるのは、
行の表示のされ方だけです。

折り畳みの利点は、セクションの行を折り畳んで、それをセクションがあることを示す
1 行で置き換えることで、テキストの構造のよりよい概要をつかめることです。

28.2  手動折り畳み

試してみましょう: 段落内にカーソルを置いて、こうタイプします:

        zfap

段落がハイライトされた 1 行に置き換えられるのがわかるでしょう。折り畳みを作成
したのです。zf はオペレータで、ap はテキストオブジェクトの選択です。zf
オペレータは任意の移動コマンドと一緒に使って、それが移動したテキストに対する折
り畳みを作成できます。zf はビジュアルモードでも機能します。

テキストを再び見るには、こうタイプして折り畳みを開きます:

        zo

そして、こうすると再び折り畳みを閉じることができます:

        zc

折り畳みのコマンドはすべて "z" で始まります。少し空想すると、これは折り畳んだ
紙を横から見たように見えます。"z" の後の文字は、コマンドを覚えやすくするための
記憶を助ける意味を持っています:

        zf      F-old 作成
        zo      折り畳みを O-pen する
        zc      折り畳みを C-lose する

折り畳みは入れ子にできます: 折り畳みを含むテキストの領域を再び折り畳むことがで
きます。例えば、このセクションの各段落を折り畳み、それからこの章のすべてのセク
ションを折り畳むことができます。試してみてください。章全体の折り畳みを開くと、
入れ子の折り畳みが元のとおりに復元されることに気付くでしょう。いくつかは開いて
いて、いくつかは閉じているかもしれません。

いくつかの折り畳みを作成して、今度はテキストをすべて見たいとします。各折り畳み
へ移動して "zo" とタイプすることもできます。これをもっと速く行うには、このコマ
ンドを使います:

        zr

これは折り畳みを R-educe します。その逆は:

        zm

これは M-ore 折り畳みます。"zr" および "zm" を繰り返して、何段階かの入れ子の折
り畳みを開いたり閉じたりできます。

何段階も深く入れ子にしている場合、それらすべてを以下で開くことができます:

        zR

これは、折り畳みが 1 つも残らなくなるまで R-educe します。そして、以下ですべて
の折り畳みを閉じることができます:

        zM

これは M-ore and M-ore 折り畳みます。

zn コマンドで素早く折り畳みを無効にできます。そして zN で折り畳みを元のと
おりに戻せます。zi は 2 つの間を切り替えます。これは便利な作業方法です:
- あなたのファイルの概要をつかむために折り畳みを作成する
- あなたの作業をしたい場所へ移動する
- zi を実行してテキストを見て、それを編集する
- 再び zi を実行して移動に戻る

手動折り畳みについての詳細はリファレンスマニュアルで: fold-manual

28.3  折り畳みを操作する

いくつかの折り畳みが閉じているとき、"j" および "k" のような移動コマンドは、折
り畳みをそれが 1 つの空の行であるかのように移動します。これにより、折り畳まれ
たテキスト上を素早く移動できます。

折り畳みを 1 行であるかのようにヤンク、削除、および貼り付けできます。これはプ
ログラム内の関数を並べ替えたい場合にとても便利です。まず、正しい 'foldmethod'
を選択して、各折り畳みに関数全体 (またはそれより少し少なく) が含まれるようにし
ます。それから "dd" で関数を削除し、カーソルを移動して "p" で貼り付けます。関
数のいくつかの行が折り畳みの上または下にある場合、ビジュアル選択を使えます:
- 移動する最初の行にカーソルを置く
- "V" を押してビジュアルモードを開始する
- 移動する最後の行にカーソルを置く
- "d" を押して選択した行を削除する。
- 新しい位置にカーソルを移動し、そこに行を "p" で貼り付ける。

折り畳みがどこにあるか、つまり zo コマンドが実際にどこで機能するかを、見たり
覚えたりするのは難しいことがあります。定義された折り畳みを見るには:

        :set foldcolumn=4

これは、折り畳みを示す小さな列をウィンドウの左に表示します。
閉じた折り畳みには "+" が表示されます。開いた各折り畳みの開始には "-" が表示さ
れ、折り畳みの以降の行には "|" が表示されます。

マウスを使って、foldcolumn の "+" をクリックして折り畳みを開くことができます。
"-" またはその下の "|" をクリックすると、開いた折り畳みを閉じます。

カーソル行のすべての折り畳みを開くには zO を使います。
カーソル行のすべての折り畳みを閉じるには zC を使います。
カーソル行の折り畳みを削除するには zd を使います。
カーソル行のすべての折り畳みを削除するには zD を使います。

挿入モードでは、カーソル行の折り畳みは決して閉じられません。これにより、タイプ
しているものを見ることができます!

ジャンプしたり、カーソルを左または右に移動したりすると、折り畳みは自動的に開か
れます。例えば、"0" コマンドはカーソル下の折り畳みを開きます ('foldopen' が既
定値である "hor" を含んでいる場合)。'foldopen' オプションを変更して、特定のコ
マンドで折り畳みを開くようにできます。カーソル下の行を常に開いておきたい場合、
こうします:

        :set foldopen=all

警告: そうすると閉じた折り畳みの上に移動できなくなります。これは一時的にだけ使
い、その後既定値に戻したいかもしれません:

        :set foldopen&

折り畳みが、その外に移動したときに自動的に閉じるようにできます:

        :set foldclose=all

これは、カーソルを含まないすべての折り畳みに 'foldlevel' を再適用します。この
感じが好きかどうかは、試してみる必要があります。zm を使ってもっと折り畳み、
zr を使って少なく折り畳みます (折り畳みを減らす)。

折り畳みはウィンドウにローカルです。これにより、同じバッファで 2 つのウィンド
ウを開き、1 つは折り畳みあり、1 つは折り畳みなしにできます。または、1 つはすべ
ての折り畳みを閉じ、1 つはすべての折り畳みを開いた状態にできます。

28.4  折り畳みの保存と復元

ファイルを放棄すると (別のファイルの編集を開始すると)、折り畳みの状態は失われ
ます。後で同じファイルに戻ってくると、手動で開いたり閉じたりした折り畳みはすべ
て既定に戻っています。折り畳みが手動で作成されていたときは、すべての折り畳みが
なくなっています! 折り畳みを保存するには :mkview コマンドを使います:

        :mkview

これは、ファイルのビューに影響する設定およびその他のものを保存します。
'viewoptions' オプションで何を保存するかを変更できます。
後で同じファイルに戻ってきたとき、ビューを再び読み込むことができます:

        :loadview

1 つのファイルに最大 10 個のビューを保存できます。例えば、現在の設定を 3 番目
のビューとして保存し、2 番目のビューを読み込むには:

        :mkview 3
        :loadview 2

Note 行を挿入または削除すると、ビューが無効になるかもしれないことに注意してく
ださい。また、ビューを保存する場所を指定する 'viewdir' オプションも確認してく
ださい。時々古いビューを削除したいかもしれません。

28.5  インデントによる折り畳み

zf で折り畳みを定義するのは大変な作業です。あなたのテキストが、下位レベルの
項目により大きなインデントを付けることで構造化されている場合、インデント折り畳
み方法を使えます。これは、同じインデントを持つ行の連続ごとに折り畳みを作成しま
す。より大きなインデントを持つ行は、入れ子の折り畳みになります。これは多くのプ
ログラミング言語でうまく機能します。

'foldmethod' オプションを設定して試してみてください:

        :set foldmethod=indent

それから zm および zr コマンドを使って、もっと折り畳んだり、折り畳みを減ら
したりできます。この例のテキストで見るとわかりやすいです:

この行はインデントされていない
        この行は 1 回インデントされている
                この行は 2 回インデントされている
                この行は 2 回インデントされている
        この行は 1 回インデントされている
この行はインデントされていない
        この行は 1 回インデントされている
        この行は 1 回インデントされている

Note インデントの量と折り畳みの深さの間の関係は 'shiftwidth' オプションに依存
することに注意してください。'shiftwidth' 分のインデントごとに、折り畳みの深さ
に 1 が加わります。これは折り畳みレベルと呼ばれます。

zr および zm コマンドを使うと、実際には 'foldlevel' オプションを増やしたり
減らしたりしています。これを直接設定することもできます:

        :set foldlevel=3

これは、'shiftwidth' の 3 倍以上のインデントを持つすべての折り畳みが閉じられる
ことを意味します。foldlevel が低いほど、多くの折り畳みが閉じられます。
'foldlevel' が 0 のとき、すべての折り畳みが閉じられます。zM は 'foldlevel'
を 0 に設定します。反対のコマンド zR は、'foldlevel' をファイル内に存在する
最も深い折り畳みレベルに設定します。

したがって、折り畳みを開いたり閉じたりする方法は 2 つあります:
(A) 折り畳みレベルを設定することによって。
    これは、"ズームアウト" してテキストの構造を見て、カーソルを移動し、再びテ
    キストに "ズームイン" する、非常に素早い方法を提供します。

(B) zo および zc コマンドを使って特定の折り畳みを開くか、または閉じること
    によって。
    これにより、開いておきたい折り畳みだけを開き、他の折り畳みは閉じたままにで
    きます。

これは組み合わせることができます: まず zm を何回か使ってほとんどの折り畳みを
閉じ、それから zo で特定の折り畳みを開くことができます。または、zR ですべ
ての折り畳みを開き、それから zc で特定の折り畳みを閉じます。

しかし、'foldmethod' が "indent" のときは、インデントと折り畳みレベルの間の関
係と衝突するので、手動で折り畳みを定義することはできません。

インデントによる折り畳みについての詳細はリファレンスマニュアルで:
fold-indent

28.6  マーカーを使った折り畳み

テキスト内のマーカーは、折り畳み領域の開始および終了を指定するために使われま
す。これにより、どの行が折り畳みに含まれるかを正確に制御できます。欠点は、テキ
ストを変更する必要があることです。

試してみてください:

        :set foldmethod=marker

C プログラム内に現れるかもしれない例のテキスト:

        /* foobar () {{ "{{{" }} */
        int foobar()
        {
                /* 値を返す {{ "{{{" }} */
                return 42;
                /* }}} */
        }
        /* }}} */

折り畳まれた行はマーカーの前のテキストを表示することに注意してください。これ
は、折り畳みが何を含んでいるかを伝えるのにとても便利です。

いくつかの行を移動した後にマーカーが正しく対にならないと、かなり厄介です。これ
は番号付きのマーカーを使うことで避けられます。例:

        /* グローバル変数 {{ "{{{" }}1 */
        int varA, varB;

        /* 関数 {{ "{{{" }}1 */
        /* funcA() {{ "{{{" }}2 */
        void funcA() {}

        /* funcB() {{ "{{{" }}2 */
        void funcB() {}
        /* }}}1 */

番号付きのマーカーごとに、指定されたレベルの折り畳みが開始します。これにより、
より高いレベルの折り畳みはここで終了します。番号付きの開始マーカーだけを使っ
て、すべての折り畳みを定義することができます。別の折り畳みが開始する前に明示的
に折り畳みを終了させたいときだけ、終了マーカーを追加する必要があります。

マーカーを使った折り畳みについての詳細はリファレンスマニュアルで:
fold-marker

28.7  構文による折り畳み

言語ごとに、Vim は異なる構文ファイルを使います。これはファイル内のさまざまな項
目の色を定義します。これを Vim で、色をサポートする端末で読んでいる場合、目に
している色は "help" 構文ファイルによって作られています。
   構文ファイルでは、"fold" 引数を持つ構文アイテムを追加できます。これらは折り
畳み領域を定義します。これには構文ファイルを書き、そこにこれらのアイテムを追加
する必要があります。それはそれほど簡単ではありません。しかし、一度行えば、すべ
ての折り畳みは自動的に行われます。
   ここでは、既存の構文ファイルを使っていると仮定します。そうすると、それ以上
説明することはありません。上で説明したように、折り畳みを開いたり閉じたりできま
す。ファイルを編集すると、折り畳みは自動的に作成および削除されます。

構文による折り畳みについての詳細はリファレンスマニュアルで: fold-syntax

28.8  式による折り畳み

これはインデントによる折り畳みと似ていますが、行のインデントを使う代わりに、
ユーザー関数が呼ばれて行の折り畳みレベルを計算します。これは、テキスト内の何か
がどの行が一緒に属するかを示しているテキストに使えます。例としては、引用された
テキストが行の前の ">" で示される電子メールのメッセージがあります。これらの引
用を折り畳むには、これを使います:

        :set foldmethod=expr
        :set foldexpr=strlen(substitute(substitute(getline(v:lnum),'\\s','',\"g\"),'[^>].*','',''))

このテキストで試すことができます:

> 彼が書いた引用テキスト
> 彼が書いた引用テキスト
> > 私が書いた二重に引用されたテキスト
> > 私が書いた二重に引用されたテキスト

例で使われた 'foldexpr' の説明 (内側から外側へ):
   getline(v:lnum)                      現在の行を取得する
   substitute(...,'\\s','','g')         行からすべての空白を取り除く
   substitute(...,'[^>].*','','')       先頭の '>' の後のすべてを取り除く
   strlen(...)                          文字列の長さを数える。これは
                                        見つかった '>' の数である

Note ":set" コマンドでは、すべての空白、ダブルクォート、およびバックスラッシュ
の前にバックスラッシュを挿入しなければならないことに注意してください。これで混
乱する場合は、以下を実行して

        :set foldexpr

実際の結果の値を確認してください。複雑な式を修正するには、コマンドライン補完を
使います:

        :set foldexpr=<Tab>

ここで <Tab> は実際の Tab です。Vim が以前の値を入力するので、それを編集できま
す。

式がもっと複雑になったときは、それを関数に入れて、その関数を呼び出すように
'foldexpr' を設定すべきです。

式による折り畳みについての詳細はリファレンスマニュアルで: fold-expr

28.9  変更されていない行の折り畳み

これは、同じウィンドウで 'diff' オプションを設定したときに便利です。vimdiff
コマンドがこれを行ってくれます。例:

        :setlocal diff foldmethod=diff scrollbind nowrap foldlevel=1

同じファイルの異なるバージョンを表示しているすべてのウィンドウでこれを行いま
す。ファイル間の違いがはっきりとわかり、その一方で変更されていないテキストは折
り畳まれます。

詳細は fold-diff を参照してください。

28.10 どの折り畳み方法を使うか?

これらすべての可能性があると、どの方法を選ぶべきか迷うでしょう。残念ながら、黄
金律はありません。以下にいくつかのヒントを示します。

編集している言語に折り畳みのある構文ファイルがある場合、それがおそらく最良の選
択です。ない場合は、それを書いてみることもできます。これには検索パターンについ
ての十分な知識が必要です。簡単ではありませんが、機能するようになれば、手動で折
り畳みを定義する必要はなくなります。

構造化されていないテキストには、領域を手動で折り畳むコマンドをタイプすることが
使えます。それから :mkview コマンドを使って、あなたの折り畳みを保存および復
元します。

マーカー方法では、ファイルを変更する必要があります。ファイルを他の人と共有して
いる場合、または会社の標準に従わなければならない場合、それらを追加することは許
可されないかもしれません。
   マーカーの主な利点は、それらを望む場所に正確に置けることです。これにより、
折り畳みをカットおよびペーストしたときに数行が漏れることを避けられます。そし
て、折り畳みに何が含まれているかについてのコメントを追加できます。

インデントによる折り畳みは、多くのファイルで機能するものですが、常にうまく機能
するとは限りません。他の方法の 1 つを使えないときに使ってください。しかし、ア
ウトラインを書くにはとても便利です。その場合、ネストのレベルごとに明確に 1 つ
の 'shiftwidth' を使います。

式による折り畳みは、ほとんどすべての構造化されたテキストで折り畳みを作成できま
す。特に、折り畳みの開始および終了を簡単に認識できる場合は、指定するのは非常に
簡単です。
   "expr" 方法を使って折り畳みを定義したが、それらが望むとおりでない場合、
"manual" 方法に切り替えることができます。これは定義された折り畳みを削除しませ
ん。その後、手動で折り畳みを削除または追加できます。
