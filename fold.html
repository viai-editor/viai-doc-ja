1. 折り畳み方法                                 fold-methods

折り畳みの方法は 'foldmethod' オプションで設定できる。

'foldmethod' を "manual" 以外の値に設定すると、すべての折り畳みが削除され、新
しい折り畳みが作成される。"manual" 方法に切り替えても、既存の折り畳みは削除さ
れない。これを使って、まず折り畳みを自動的に定義し、それから手動で変更すること
ができる。

折り畳みを選択する方法は 6 つある:
        manual          手動で折り畳みを定義する
        indent          インデントが多いほど折り畳みレベルが高くなる
        expr            折り畳みを定義する式を指定する
        syntax          構文ハイライトによって定義される折り畳み
        diff            変更されていないテキストの折り畳み
        marker          テキスト中のマーカーによって定義される折り畳み


MANUAL                                          fold-manual

コマンドを使って、折り畳みの領域を手動で定義する。これは、テキストを解析して折
り畳みを見つけるスクリプトからも使用できる。

折り畳みのレベルは、その入れ子によってのみ定義される。ある範囲の行の折り畳みの
折り畳みレベルを上げるには、その中に同じ行を持つ折り畳みを定義する。

手動の折り畳みは、ファイルを放棄すると失われる。折り畳みを保存するには
:mkview コマンドを使う。ビューは後で :loadview で復元できる。


INDENT                                          fold-indent

折り畳みは、行のインデントによって自動的に定義される。

foldlevel は、行のインデントを 'shiftwidth' で割ったもの (切り捨て) から計算さ
れる。同じまたはより高い折り畳みレベルを持つ一連の行が 1 つの折り畳みを形成し、
より高いレベルを持つ行は入れ子の折り畳みを形成する。

折り畳みの入れ子は 'foldnestmax' で制限される。

いくつかの行は無視され、その上または下の行の折り畳みレベルのうち、低い方を得
る。これらは、空行または空白の行、および 'foldignore' 内の文字で始まる行であ
る。'foldignore' 内の文字を調べる前に、ホワイトスペースはスキップされる。C で
は、プリプロセッサの行を無視するために "#" を使う。

別の方法で行を無視したいときは、"expr" 方法を使う。行のインデントを得るために、
'foldexpr' の中で indent() 関数を使用できる。


EXPR                                            fold-expr

折り畳みは、"indent" 方法と同様に、その foldlevel によって自動的に定義される。
行の foldlevel を得るために、'foldexpr' オプションの値が評価される。例:
これは、タブで始まるすべての連続した行に対して折り畳みを作成する:
        :set foldexpr=getline(v:lnum)[0]==\"\\t\"
これは、空行で区切られた段落から折り畳みを作る:
        :set foldexpr=getline(v:lnum)=~'^\\s*$'&&getline(v:lnum+1)=~'\\S'?'<1':1
これも同じことをする:
        :set foldexpr=getline(v:lnum-1)=~'^\\s*$'&&getline(v:lnum)=~'\\S'?'>1':1

Note ":set" が異なる扱いをする文字 (スペース、バックスラッシュ、ダブルクォート
など、option-backslash を参照) をエスケープするために、バックスラッシュを使
わなければならないことに注意。

最も効率的なのは、引数なしのコンパイル済み関数を呼ぶことである:
        :set foldexpr=MyFoldLevel()
関数は v:lnum を使わなければならない。expr-option-function を参照。

これらが、式が評価される条件である:

- カレントバッファおよびウィンドウが、その行に設定される。
- 変数 "v:lnum" が行番号に設定される。

そして、foldexpr の結果が以下のように折り畳みレベルを決定する:
  値                    意味
  0                     その行は折り畳みに含まれない
  1, 2, ..              その行はこのレベルの折り畳みに含まれる
  -1                    折り畳みレベルは未定義で、この行の前または後の行の折り
                        畳みレベルのうち、最も低いものを使う。
  "="                   前の行の折り畳みレベルを使う
  "a1", "a2", ..        前の行の折り畳みレベルに 1、2、.. を加え、その結果を現
                        在の行に使う
  "s1", "s2", ..        前の行の折り畳みレベルから 1、2、.. を引き、その結果を
                        次の行に使う
  "<1", "<2", ..        このレベルの折り畳みがこの行で終わる
  ">1", ">2", ..        このレベルの折り畳みがこの行で始まる

結果の値 "="、"s"、および "a" はより高コストである。fold-expr-slow を参照。

折り畳みの開始 (終了) を ">1" ("<1") でマークする必要はなく、折り畳みレベルが
前の行の折り畳みレベルより高い (低い) ときにも折り畳みは開始 (終了) する。

式に副作用があってはならない。バッファ内のテキスト、カーソル位置、検索パター
ン、オプションなどを変更してはならない。
注意深くする場合、それらを変更して復元することができる。

式に何らかのエラーがある場合、または結果の値が認識されない場合、エラーメッセー
ジは出ず、折り畳みレベルは 0 になる。
デバッグのために 'debug' オプションを "msg" に設定することができ、そうするとエ
ラーメッセージが見えるようになる。

'foldexpr' の式が s: または <SID> で始まる場合、それはスクリプト ID
(local-function) に置き換えられる。例:
                set foldexpr=s:MyFoldExpr()
                set foldexpr=<SID>SomeFoldExpr()

"a1" および "s1" を使う例: 複数行の C コメントに対して、"/*" を含む行は折り畳
みを開始するために "a1" を返し、"*/" を含む行はその行の後で折り畳みを終了する
ために "s1" を返す:
  if match(thisline, '/\*') >= 0
    return 'a1'
  elseif match(thisline, '\*/') >= 0
    return 's1'
  else
    return '='
  endif
しかし、これは 1 行のコメント、文字列などでは機能しない。

foldlevel() は、前の折り畳みレベルに対する相対的な折り畳みレベルを計算するの
に役立つ。しかし、レベルがまだ分からない場合、foldlevel() は -1 を返すことがあ
ることに注意。また、それは行の先頭でのレベルを返すが、折り畳みはその行で終わる
かもしれない。

折り畳みが適切に更新されないことがある。折り畳みの更新を強制するには、zx ま
たは zX を使用できる。

計算コストの最小化                                     fold-expr-slow

特に、すべての行の折り畳みレベルを最初に計算しなければならないとき、その計算コ
ストのために、この折り畳み方法は Vim を応答しなくさせることがある。その後、変
更のたびに、Vim は foldlevel の計算を、それによって折り畳みレベルが影響を受け
た行に制限する (そして、他のすべての行の既知の foldlevel を再利用する)。

したがって、折り畳みの式は、ある行の計算に必要な依存する行の数を最小にするよう
努めるべきである: 例えば、"="、"a"、および "s" の戻り値は、独立した折り畳みレ
ベルが見つかるまで前の行の折り畳みレベルの評価を必要とするので、それらを避ける
ようにする。

これが難しいと分かった場合、次善の策は、b:changedtick のときだけ更新される
バッファローカル変数 (b:foldlevels) に、すべての折り畳みレベルをキャッシュする
ことかもしれない:

  vim9script
  def MyFoldFunc(): number
    if b:lasttick == b:changedtick
      return b:foldlevels[v:lnum - 1]
    endif
    b:lasttick = b:changedtick
    b:foldlevels = []
    # foldlevel を計算する ...
    return b:foldlevels[v:lnum - 1]
  enddef
  set foldexpr=s:MyFoldFunc()

上の例では、引数なしのプリコンパイル済み Vim9 script 関数 (それでも v:lnum を
使わなければならない) を使うことで、さらなる高速化が得られた。
expr-option-function を参照。

SYNTAX                                          fold-syntax

折り畳みは、"fold" 引数を持つ構文アイテムによって定義される。:syn-fold

折り畳みレベルは、折り畳みの入れ子によって定義される。折り畳みの入れ子は
'foldnestmax' で制限される。

適切な構文同期を指定するよう注意すること。これが正しく行われていない場合、折り
畳みが表示されるハイライトと異なることがある。これは、複数行にマッチするパター
ンを使うときに特に関係がある。疑わしい場合、力ずくの同期を使ってみること:
        :syn sync fromstart


DIFF                                            fold-diff

折り畳みは、変更の一部または変更の近くではないテキストに対して自動的に定義され
る。

この方法は、カレントウィンドウに 'diff' オプションが設定されていて、変更が表示
されているときだけ正しく機能する。そうでない場合、バッファ全体が 1 つの大きな
折り畳みになる。

'diffopt' オプションを使ってコンテキストを指定できる。つまり、折り畳みと変更の
間にある、折り畳みに含まれない行の数である。例えば、8 行のコンテキストを使うに
は:
        :set diffopt=filler,context:8
既定のコンテキストは 6 行である。

'scrollbind' も設定されているとき、Vim は、同じテキストが見えるように、他の
diff ウィンドウで同じ折り畳みを開いたままにしようとする。


MARKER                                          fold-marker

テキスト中のマーカーが、折り畳みがどこで始まりどこで終わるかを示す。これによ
り、折り畳みを正確に指定できる。これにより、間違った行を含める危険なしに、折り
畳みを削除および貼り付けできる。'foldtext' オプションは通常、マーカーの前のテ
キストが折り畳まれた行に表示されるように設定される。これにより、折り畳みに名前
を付けることができる。

マーカーは、レベルを含むか、または対応するペアを使うことができる。レベルを含め
る方が簡単で、終了マーカーを追加する必要がなく、対応しないマーカーのペアによる
問題を避けられる。例:
        /* グローバル変数 {{ "{{{" }}1 */
        int varA, varB;

        /* 関数 {{ "{{{" }}1 */
        /* funcA() {{ "{{{" }}2 */
        void funcA() {}

        /* funcB() {{ "{{{" }}2 */
        void funcB() {}
                                                        {{ "{{{" }} }}}
折り畳みは "{{ "{{{" }}" マーカーで始まる。後に続く数字が折り畳みレベルを指定する。何
が起こるかは、現在の折り畳みレベルとマーカーで与えられたレベルの差によって決ま
る:
1. 同じ折り畳みレベルのマーカーに出会った場合、前の折り畳みが終わり、同じレベ
   ルの別の折り畳みが始まる。
2. より高い折り畳みレベルのマーカーが見つかった場合、入れ子の折り畳みが開始さ
   れる。
3. より低い折り畳みレベルのマーカーが見つかった場合、このレベルを含めてこのレ
   ベルまでのすべての折り畳みが終わり、指定されたレベルの折り畳みが始まる。

数字は折り畳みレベルを示す。0 は使えない (レベル 0 のマーカーは無視される)。終
了する折り畳みのレベルを示すために、"}}}" に数字を付けて使うことができる。後に
続く行の折り畳みレベルは、示されたレベルより 1 少なくなる。Note Vim は対応する
マーカーのレベルまでさかのぼらないことに注意 (それには時間がかかりすぎる)。例:


        {{ "{{{" }}1
        ここの折り畳みレベルは 1
        {{ "{{{" }}3
        ここの折り畳みレベルは 3
        }}}3
        ここの折り畳みレベルは 2

"{{ "{{{" }}" および "}}}" マーカーの対応するペアを使って、折り畳みを定義することもで
きる。各 "{{ "{{{" }}" は折り畳みレベルを 1 つ増やし、各 "}}}" は折り畳みレベルを 1 つ
減らす。マーカーの対応を保つよう注意すること! 例:

        {{ "{{{" }}
        ここの折り畳みレベルは 1
        {{ "{{{" }}
        ここの折り畳みレベルは 2
        }}}
        ここの折り畳みレベルは 1

番号付きのマーカーと番号なしのマーカーを混ぜて使うことができる。これを行う便利
な方法は、大きな折り畳みには番号付きのマーカーを使い、関数内では局所的に番号な
しのマーカーを使うことである。例えば、"構造体定義"、"ローカル変数"、および
"関数" のような、あなたのファイルのセクションにはレベル 1 の折り畳みを使う。各
定義および関数にはレベル 2 のマーカーを使い、関数の中では番号なしのマーカーを
使う。関数内で折り畳みを分割するために変更を加えるとき、マーカーの番号を付け直
す必要はない。

マーカーは 'foldmarker' オプションで設定できる。ファイルを Vim ユーザーの間で
交換できるように、これを既定値の "{{ "{{" }}{,}}}" のままにしておくことを推奨する。ファ
イルにとって必要なときだけ変更すること (例えば、ファイルが別の折り畳みエディタ
のマーカーを含んでいるか、または既定のマーカーがファイルの言語にとって問題を起
こす場合)。

                                                        fold-create-marker
"zf" を使って、マーカーで定義される折り畳みを作成できる。Vim がマーカーを挿入
してくれる。Vim は、'foldmarker' で指定されたとおりに、開始マーカーおよび終了
マーカーを追加する。マーカーは行末に追加される。'commentstring' が空でない場
合、それが使われる。
これが正しく機能しないとき:
- 行がすでにレベル番号付きのマーカーを含んでいる。そのとき Vim は何をすべきか
  分からない。
- 近くの折り畳みが、そのマーカーにレベル番号を使っていて、それが邪魔になる。
- 行がコメントの中にあり、'commentstring' が空ではなく、かつ入れ子のコメントが
  機能しない。例えば C では: コメントの中に /* {{ "{{{" }} */ を追加すると、既存のコメ
  ントが切り詰められる。マーカーをコメントの前または後に置くか、またはマーカー
  を手動で追加すること。
一般的に、すでにレベル番号付きのマーカーがあるときに、Vim にマーカーを作成させ
るのは良い考えではない。

                                                        fold-delete-marker
"zd" を使って、マーカーで定義された折り畳みを削除できる。Vim がマーカーを削除
してくれる。Vim は、'foldmarker' で指定されたとおりの開始マーカーおよび終了マー
カーを、折り畳みの開始および終了の位置で探す。マーカーの周りのテキストが
'commentstring' にマッチするとき、そのテキストも削除される。
これが正しく機能しないとき:
- 1 行が複数のマーカーを含み、そのうちの 1 つがレベルを指定している。これが折
  り畳みを削除するという望んだ効果を持つかどうかを確認せずに、最初のものだけが
  削除される。
- マーカーがレベル番号を含んでいて、同時に複数の折り畳みを開始するか、または終
  了するために使われている。

2. 折り畳みコマンド                             fold-commands E490

すべての折り畳みコマンドは "z" で始まる。ヒント: 横から見た場合、"z" は折り畳
んだ紙のように見える。


折り畳みの作成と削除
                                                        zf E350
zf{motion}  または
{Visual}zf      折り畳みを作成するオペレータ。
                これは 'foldmethod' が "manual" または "marker" のときだけ機能
                する。
                "manual" 方法では、新しい折り畳みは閉じられる。
                'foldenable' が設定される。
                fold-create-marker も参照。

                                                        zF
zF              [count] 行の折り畳みを作成する。"zf" のように機能する。

:{range}fo[ld]                                          :fold :fo
                {range} の行の折り畳みを作成する。"zf" のように機能する。

                                                        zd E351
zd              カーソル位置の折り畳みを 1 つ削除する。カーソルが折り畳まれた
                行の上にあるとき、その折り畳みが削除される。入れ子の折り畳みは
                1 レベル上に移動される。ビジュアルモードでは、選択範囲内に (部
                分的に) あるすべての折り畳みの 1 レベルが削除される。
                注意: これは予想より多くの折り畳みを簡単に削除してしまい、手動
                の折り畳みに対する undo はない。
                これは 'foldmethod' が "manual" または "marker" のときだけ機能
                する。
                fold-delete-marker も参照。

                                                        zD
zD              カーソル位置の折り畳みを再帰的に削除する。ビジュアルモードで
                は、選択範囲内に (部分的に) あるすべての折り畳み、およびそれら
                の中の入れ子のすべての折り畳みが削除される。
                これは 'foldmethod' が "manual" または "marker" のときだけ機能
                する。
                fold-delete-marker も参照。

                                                        zE E352
zE              ウィンドウ内のすべての折り畳みを除去する。
                これは 'foldmethod' が "manual" または "marker" のときだけ機能
                する。
                fold-delete-marker も参照。


折り畳みを開くことと閉じること

'foldminlines' より小さい折り畳みは、常に開いているかのように表示される。した
がって、以下のコマンドは小さい折り畳みでは異なる動作をすることがある。

                                                        zo
zo              カーソルの下の折り畳みを 1 つ開く。カウントが与えられたとき、
                その数の深さまで折り畳みが開かれる。ビジュアルモードでは、選択
                範囲内のすべての行に対して、折り畳みが 1 レベル開かれる。

                                                        zO
zO              カーソルの下のすべての折り畳みを再帰的に開く。カーソル行を含ま
                ない折り畳みは変更されない。
                ビジュアルモードでは、選択範囲内にある、部分的にだけ選択されて
                いるものも含めたすべての折り畳みを開く。

                                                        zc
zc              カーソルの下の折り畳みを 1 つ閉じる。カウントが与えられたとき、
                その数の深さまで折り畳みが閉じられる。ビジュアルモードでは、選
                択範囲内のすべての行に対して、折り畳みが 1 レベル閉じられる。
                'foldenable' が設定される。

                                                        zC
zC              カーソルの下のすべての折り畳みを再帰的に閉じる。カーソル行を含
                まない折り畳みは変更されない。
                ビジュアルモードでは、選択範囲内にある、部分的にだけ選択されて
                いるものも含めたすべての折り畳みを閉じる。
                'foldenable' が設定される。

                                                        za
za              概要: カーソルの下の折り畳みを切り替える。
                閉じた折り畳みの上にあるとき: それを開く。折り畳みが入れ子に
                なっているとき、"za" を何回か使わなければならないことがある。
                カウントが与えられたとき、その数の閉じた折り畳みが開かれる。
                開いた折り畳みの上にあるとき: それを閉じ、'foldenable' を設定
                する。再び "za" を使うと折り畳みが開くので、これは 1 レベルだ
                けを閉じる。カウントが与えられたとき、その数の折り畳みが閉じら
                れる (これは "za" をその回数繰り返すのと同じではない)。

                                                        zA
zA              閉じた折り畳みの上にあるとき: それを再帰的に開く。
                開いた折り畳みの上にあるとき: それを再帰的に閉じ、'foldenable'
                を設定する。

                                                        zv
zv              カーソル行を表示する: カーソルがある行が折り畳まれていない状態
                になるのに、ちょうど十分なだけ折り畳みを開く。

                                                        zx
zx              折り畳みを更新する: 手動で開いた折り畳みおよび閉じた折り畳みを
                undo する: 'foldlevel' を再適用し、それから "zv" を行う: カー
                ソル行を表示する。
                折り畳みの再計算も強制する。これは、'foldexpr' を使用していて、
                折り畳みが適切に更新されない結果になるような方法でバッファが変
                更されたときに便利である。

                                                        zX
zX              手動で開いた折り畳みおよび閉じた折り畳みを undo する:
                'foldlevel' を再適用する。zx と同様に、折り畳みの再計算も強
                制する。

                                                        zm
zm              より多く折り畳む: 'foldlevel' から v:count1 を引く。
                'foldlevel' がすでに 0 だった場合、何も起こらない。
                'foldenable' が設定される。

                                                        zM
zM              すべての折り畳みを閉じる: 'foldlevel' を 0 に設定する。
                'foldenable' が設定される。

                                                        zr
zr              折り畳みを減らす: 'foldlevel' に v:count1 を加える。

                                                        zR
zR              すべての折り畳みを開く。これは 'foldlevel' を最も高い折り畳み
                レベルに設定する。

                                                        :foldo :foldopen
:{range}foldo[pen][!]
                {range} 内の折り畳みを開く。[!] が付けられたとき、すべての折り
                畳みが開かれる。{range} 内のすべてのテキストを見るのに便利であ
                る。[!] なしでは、折り畳みが 1 レベル開かれる。

                                                        :foldc :foldclose
:{range}foldc[lose][!]
                {range} 内の折り畳みを閉じる。[!] が付けられたとき、すべての折
                り畳みが閉じられる。{range} 内のすべてのテキストを隠すのに便利
                である。[!] なしでは、折り畳みが 1 レベル閉じられる。

                                                        zn
zn              折り畳みなし: 'foldenable' をリセットする。すべての折り畳みが
                開く。

                                                        zN
zN              通常の折り畳み: 'foldenable' を設定する。すべての折り畳みが以
                前と同じ状態になる。

                                                        zi
zi              'foldenable' を反転する。


折り畳みを越えて移動する
                                                        [z
[z              現在の開いている折り畳みの開始に移動する。すでに開始にいる場
                合、それを含む折り畳みの開始に移動する。それを含む折り畳みがな
                い場合、コマンドは失敗する。
                カウントが使われたとき、コマンドを [count] 回繰り返す。

                                                        ]z
]z              現在の開いている折り畳みの終了に移動する。すでに終了にいる場
                合、それを含む折り畳みの終了に移動する。それを含む折り畳みがな
                い場合、コマンドは失敗する。
                カウントが使われたとき、コマンドを [count] 回繰り返す。

                                                        zj
zj              次の折り畳みの開始へ下方向に移動する。閉じた折り畳みは 1 つの
                折り畳みとして数えられる。
                カウントが使われたとき、コマンドを [count] 回繰り返す。
                このコマンドは operator の後に使用できる。

                                                        zk
zk              前の折り畳みの終了へ上方向に移動する。閉じた折り畳みは 1 つの
                折り畳みとして数えられる。
                カウントが使われたとき、コマンドを [count] 回繰り返す。
                このコマンドは operator の後に使用できる。


折り畳みに対してコマンドを実行する

:[range]foldd[oopen] {cmd}              :foldd :folddo :folddoopen
                閉じた折り畳みの中にないすべての行に対して {cmd} を実行する。
                [range] が与えられたとき、それらの行だけが使われる。
                {cmd} が実行されるたびに、カーソルはそれが実行される対象の行に
                置かれる。
                これは ":global" コマンドのように機能する: まず、閉じた折り畳
                みの中にないすべての行がマークされる。それから、マークされたす
                べての行に対して {cmd} が実行される。したがって、{cmd} が折り
                畳みを変更したとき、それはどこで実行されるかに影響しない (もち
                ろん、行が削除されたときを除く)。
                例:
                        :folddoopen s/end/loop_end/ge
                Note "end" がマッチしないところでエラーメッセージが出るのを避
                けるための、"e" フラグの使用に注意。

:[range]folddoc[losed] {cmd}                    :folddoc :folddoclosed
                閉じた折り畳みの中にあるすべての行に対して {cmd} を実行する。
                それ以外は ":folddoopen" と同様。

3. 折り畳みオプション                           fold-options

色                                                     fold-colors

閉じた折り畳みの色は、Folded グループ hl-Folded で設定される。折り畳みカラム
の色は、FoldColumn グループ hl-FoldColumn で設定される。色を設定する例:

        :highlight Folded guibg=grey guifg=blue
        :highlight FoldColumn guibg=darkgrey guifg=white


FOLDLEVEL                                               fold-foldlevel

'foldlevel' は数値オプションである: 高いほど、より多くの折り畳まれた領域が開
く。'foldlevel' が 0 のとき、すべての折り畳みが閉じられる。
'foldlevel' が正のとき、いくつかの折り畳みが閉じられる。
'foldlevel' が非常に高いとき、すべての折り畳みが開く。
'foldlevel' は、変更されたときに適用される。その後、手動で折り畳みを開き、閉じ
ることができる。
増やされたとき、新しいレベルより上の折り畳みが開かれる。手動で開かれた折り畳み
は閉じられない。
減らされたとき、新しいレベルより上の折り畳みが閉じられる。手動で閉じられた折り
畳みは開かれない。


FOLDTEXT                                                fold-foldtext

'foldtext' は式を指定する文字列オプションである。この式は、閉じた折り畳みに表
示されるテキストを得るために評価される。例:

    :set foldtext=v:folddashes.substitute(getline(v:foldstart),'/\\*\\\|\\*/\\\|{{ "{{{" }}\\d\\=','','g')

これは、"/*"、"*/"、および "{{ "{{{" }}" を取り除いた、折り畳みの最初の行を表示する。
Note ":set" コマンドによっていくつかの文字が解釈されるのを避けるための、バック
スラッシュの使用に注意。関数を定義してそれを呼ぶ方がはるかに簡単である:

    :set foldtext=MyFoldText()
    :function MyFoldText()
    :  let line = getline(v:foldstart)
    :  let sub = substitute(line, '/\*\|\*/\|{{ "{{{" }}\d\=', '', 'g')
    :  return v:folddashes .. sub
    :endfunction

引数なしの関数呼び出しを使う利点は、それがより速いことである。
expr-option-function を参照。

'foldtext' の評価は sandbox の中で行われる。カレントウィンドウは、その行を表
示しているウィンドウに設定される。コンテキストは、オプションが最後に設定された
スクリプトに設定される。

エラーは無視される。デバッグするには、'debug' オプションを "throw" に設定する。

既定値は foldtext() である。これは、ほとんどの種類の折り畳みに対して妥当なテ
キストを返す。それが気に入らない場合、あなた自身の 'foldtext' の式を指定でき
る。それは、これらの特別な Vim 変数を使用できる:
        v:foldstart     折り畳みの最初の行の行番号
        v:foldend       折り畳みの最後の行の行番号
        v:folddashes    foldlevel を表すダッシュを含む文字列。
        v:foldlevel     その折り畳みの foldlevel

結果の中では、TAB はスペースに置き換えられ、表示できない文字は表示可能な文字に
される。

結果の行は、ウィンドウに収まるように切り詰められ、折り返されることはない。
テキストの後に余裕があるとき、それは 'fillchars' で指定された文字で埋められる。

'foldtext' の式が s: または <SID> で始まる場合、それはスクリプト ID
(local-function) に置き換えられる。例:
                set foldtext=s:MyFoldText()
                set foldtext=<SID>SomeFoldText()

Note ":set" コマンドが異なる扱いをする文字にはバックスラッシュを使う必要がある
ことに注意: スペース、バックスラッシュ、およびダブルクォート。
option-backslash


FOLDCOLUMN                                              fold-foldcolumn

'foldcolumn' は数値で、折り畳みを示すための、ウィンドウの横にあるカラムの幅を
設定する。それが 0 のとき、foldcolumn はない。通常の値は 4 または 5 である。役
に立つ最小の値は 2 だが、1 でもいくらかの情報は得られる。最大値は 12 である。

開いた折り畳みは、一番上に '-' があり、その下に '|' 文字があるカラムで示され
る。このカラムは、開いた折り畳みが終わるところで終わる。折り畳みが入れ子になっ
ているとき、入れ子の折り畳みは、それを含む折り畳みの 1 文字右になる。

閉じた折り畳みは '+' で示される。

これらの文字は 'fillchars' オプションで変更できる。

折り畳みカラムが狭すぎて入れ子のすべての折り畳みを表示できないところでは、入れ
子のレベルを示す数字が表示される。この動作を上書きするには、'fillchars' オプ
ションの "foldinner" 文字を使用できる。

マウスを使って、折り畳みカラムの中をクリックすることで、折り畳みを開き、閉じる
こともできる:
- この行の閉じた折り畳みを開くには、'+' をクリックする。
- この行の開いた折り畳みを閉じるには、それ以外の空白でない文字をクリックする。


その他のオプション

'foldenable'  'fen':    設定されていない間、すべての折り畳みを開く。
'foldexpr'    'fde':    "expr" 折り畳みに使われる式。
'foldignore'  'fdi':    "indent" 折り畳みに使われる文字。
'foldmarker'  'fmr':    "marker" 折り畳みに使われる、定義されたマーカー。
'foldmethod'  'fdm':    現在の折り畳み方法の名前。
'foldminlines' 'fml':   折り畳みが閉じて表示されるための、最小の画面行数。
'foldnestmax' 'fdn':    "indent" および "syntax" 折り畳みの最大の入れ子。
'foldopen'    'fdo':    どの種類のコマンドが閉じた折り畳みを開くか。
'foldclose'   'fcl':    カーソルの下にない折り畳みがいつ閉じられるか。

4. 折り畳みの動作                                       fold-behavior

カーソルを上または下に移動するとき、およびスクロールするとき、カーソルは一連の
折り畳まれた行の最初の行に移動する。カーソルがすでに折り畳まれた行の上にあると
き、カーソルは次の折り畳まれていない行、または次の閉じた折り畳みに移動する。

カーソルが折り畳まれた行の上にある間、カーソルは常に最初のカラムに表示される。
ルーラーは実際のカーソル位置を表示するが、行が折り畳まれているので、そこに表示
することはできない。

多くの移動コマンドは、一連の折り畳まれた行を空行のように扱う。例えば、"w" コマ
ンドは最初のカラムで 1 回止まる。

閉じた折り畳みの中で検索を開始するとき、現在の折り畳みの中のマッチは見つからな
い。前方検索は常に閉じた折り畳みの終わりから開始し、後方検索は閉じた折り畳みの
開始から開始するかのようである。

挿入モードでは、カーソル行は決して折り畳まれない。これにより、タイプしているも
のを見ることができる!

オペレータを使うとき、閉じた折り畳みは全体として含まれる。したがって、"dl" は
カーソルの下の閉じた折り畳み全体を削除する。

バッファの行に対して作用する Ex コマンドでは、範囲は常に閉じた折り畳みの最初の
行で始まり、閉じた折り畳みの最後の行で終わるように調整される。したがって、この
コマンドは:
        :s/foo/bar/g
カーソルを閉じた折り畳みの上に置いて使われたとき、折り畳みのすべての行で "foo"
を "bar" に置き換える。
これは :folddoopen および :folddoclosed では起こらない。

Note :source のような一部の Ex コマンドでは、2 つの行指定子の [range] を使う
ときだけ範囲が調整されることに注意。

以前に編集されたことのあるバッファを編集するとき、最後に使われた折り畳みの設定
が再び使われる。手動の折り畳みでは、定義された折り畳みが復元される。すべての折
り畳み方法で、手動で開いた折り畳みおよび閉じた折り畳みが復元される。
このバッファがこのウィンドウで編集されたことがある場合、その当時の値が使われ
る。そうでない場合、バッファが最後に編集されたウィンドウの値が使われる。
