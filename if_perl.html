1. Perl ファイルの編集                                  perl-editing

Vim の構文ハイライトは Perl および POD ファイルをサポートしている。ファイル名
に .pl または .pm の拡張子がある場合、Vim はファイルを Perl のコードとみなす。
ファイルタイプが検出されていない場合、Vim はファイルの shebang 行も調べて、ファ
イルが Perl スクリプトかどうかを確認する。ファイル名に .POD の拡張子がある場
合、Vim はファイルを POD テキストとみなす。

Perl でタグを使うには、Universal/Exuberant Ctags が必要である。ここを見ること:
        Universal Ctags (推奨): https://ctags.io
        Exuberant Ctags: http://ctags.sourceforge.net

代わりに、Perl スクリプト pltags.pl を使うこともできる。これは
$VIMRUNTIME/tools ディレクトリで Vim と一緒に配布されている。このスクリプトは
現在、Exuberant ctags の Perl サポートより多くの機能を持っている。

==============================================================================
2. Perl インターフェイス付きでの Vim のコンパイル       perl-compiling

Perl インターフェイス付きで Vim をコンパイルするには、最近のバージョンの Perl
が必要である。Vim をコンパイルする前に Perl がインストールされていなければなら
ない。

Vim 用の Perl パッチは以下によって作られた:
        Sven Verdoolaege <skimo@breughel.ufsia.ac.be>
        Matt Gerassimof

MS-Windows (および他のプラットフォーム) 用の Perl は以下で見つけられる:
        http://www.perl.org/
ActiveState のものは動作するはずで、Strawberry Perl は良い代替である。

3. Perl インターフェイスの使用                          perl-using

                                                        :perl :pe
:pe[rl] {cmd}           Perl コマンド {cmd} を実行する。現在のパッケージは
                        "main" である。:perl が動作しているかをテストする簡
                        単な例:
                                :perl VIM::Msg("Hello")

:pe[rl] << [trim] [{endmarker}]
{script}
{endmarker}
                        Perl スクリプト {script} を実行する。
                        {script} の後の {endmarker} の前に空白文字を置いてはな
                        らない。

                        [endmarker] を省略した場合、:append および :insert
                        コマンドと同様に、ドット '.' がデフォルトになる。関数
                        の中では '.' を使うと役に立つ。"$i;" は Vim には
                        :insert コマンドの始まりのように見えるからである。

                        この形式の :perl コマンドは、主に vim script に perl
                        コードを含めるのに便利である。
                        Note: このコマンドは Perl 機能が組み込まれていないとき
                        は動作しない。エラーを避けるには、script-here を参
                        照。


Vim script の例:

        function! WhitePearl()
        perl << EOF
                VIM::Msg("pearls are nice for necklaces");
                VIM::Msg("rubys for rings");
                VIM::Msg("pythons for bags");
                VIM::Msg("tcls????");
        EOF
        endfunction

使っている Perl のバージョンを確認するには:
        :perl print $^V


                                                        :perldo :perld
:[range]perld[o] {cmd}  [range] の各行に対して Perl コマンド {cmd} を実行する。
                        $_ には各行のテキストが順に、末尾の <EOL> なしで設定さ
                        れる。$_ を設定するとテキストが変更されるが、このコマ
                        ンドを使って行を追加または削除することはできないことに
                        注意。
                        [range] のデフォルトはファイル全体: "1,$" である。

ここに試せることがいくつかある:

  :perl $a=1
  :perldo $_ = reverse($_);1
  :perl VIM::Msg("hello")
  :perl $line = $curbuf->Get(42)
                                                        E299
sandbox 内での Perl コマンドの実行は制限される。":perldo" はまったく使えな
い。":perl" は可能であれば Safe 環境で評価される。


                                                        perl-overview
これが Perl で使用できる関数の概要である:

  :perl VIM::Msg("Text")                # メッセージを表示する
  :perl VIM::Msg("Wrong!", "ErrorMsg")  # エラーメッセージを表示する
  :perl VIM::Msg("remark", "Comment")   # ハイライトされたメッセージを表示する
  :perl VIM::SetOption("ai")            # vim のオプションを設定する
  :perl $nbuf = VIM::Buffers()          # バッファの数を返す
  :perl @buflist = VIM::Buffers()       # すべてのバッファの配列を返す
  :perl $mybuf = (VIM::Buffers('qq.c'))[0] # 'qq.c' のバッファオブジェクトを返す
  :perl @winlist = VIM::Windows()       # すべてのウィンドウの配列を返す
  :perl $nwin = VIM::Windows()          # ウィンドウの数を返す
  :perl ($success, $v) = VIM::Eval('&path') # $v: オプション 'path'、$success: 1
  :perl ($success, $v) = VIM::Eval('&xyz')  # $v: '' および $success: 0
  :perl $v = VIM::Eval('expand("<cfile>")') # <cfile> を展開する
  :perl $curwin->SetHeight(10)          # ウィンドウの高さを設定する
  :perl @pos = $curwin->Cursor()        # (row, col) の配列を返す
  :perl @pos = (10, 10)
  :perl $curwin->Cursor(@pos)           # カーソルを @pos に設定する
  :perl $curwin->Cursor(10,10)          # カーソルを 10 行 10 列に設定する
  :perl $mybuf = $curwin->Buffer()      # ウィンドウのバッファオブジェクトを返す
  :perl $curbuf->Name()                 # バッファ名を返す
  :perl $curbuf->Number()               # バッファ番号を返す
  :perl $curbuf->Count()                # 行数を返す
  :perl $l = $curbuf->Get(10)           # 10 行目を返す
  :perl @l = $curbuf->Get(1 .. 5)       # 1 行目から 5 行目を返す
  :perl $curbuf->Delete(10)             # 10 行目を削除する
  :perl $curbuf->Delete(10, 20)         # 10 行目から 20 行目を削除する
  :perl $curbuf->Append(10, "Line")     # 1 行を追加する
  :perl $curbuf->Append(10, "Line1", "Line2", "Line3") # 3 行を追加する
  :perl @l = ("L1", "L2", "L3")
  :perl $curbuf->Append(10, @l)         # L1、L2 および L3 を追加する
  :perl $curbuf->Set(10, "Line")        # 10 行目を置き換える
  :perl $curbuf->Set(10, "Line1", "Line2")      # 10 行目および 11 行目を置き換える
  :perl $curbuf->Set(10, @l)            # 3 行を置き換える

                                                        perl-Msg
VIM::Msg({msg}, {group}?)
                        メッセージ {msg} を表示する。省略可能な引数 {group}
                        は、Vim がそのメッセージに使うハイライトグループを指定
                        する。

                                                        perl-SetOption
VIM::SetOption({arg})   vim のオプションを設定する。{arg} には ":set" コマンド
                        が受け付ける任意の引数を指定できる。Note これは引数の
                        中に空白が許されないことを意味することに注意! :set
                        を参照。

                                                        perl-Buffers
VIM::Buffers([{bn}...]) 引数が無い場合、配列コンテキストではすべてのバッファの
                        リストを返し、スカラーコンテキストではバッファの数を返
                        す。バッファ名または番号 {bn} のリストに対しては、Vim
                        内部の bufname() 関数と同じ規則を使って、{bn} にマッ
                        チするバッファのリストを返す。
                        WARNING: :bwipe が使われるとリストは無効になる。それ
                        でも使うと Vim がクラッシュすることがある。

                                                        perl-Windows
VIM::Windows([{wn}...]) 引数が無い場合、配列コンテキストではすべてのウィンドウ
                        のリストを返し、スカラーコンテキストではウィンドウの数
                        を返す。ウィンドウ番号 {wn} のリストに対しては、それら
                        の番号を持つウィンドウのリストを返す。
                        WARNING: ウィンドウが閉じられるとリストは無効になる。
                        それでも使うと Vim がクラッシュすることがある。

                                                        perl-DoCommand
VIM::DoCommand({cmd})   Ex コマンド {cmd} を実行する。

                                                        perl-Eval
VIM::Eval({expr})       {expr} を評価し、リストコンテキストでは (success,
                        value) を返し、スカラーコンテキストでは value だけを返
                        す。
                        success=1 は、val に {expr} の値が入っていることを示
                        す。success=0 は式の評価に失敗したことを示す。'@x' は
                        レジスタ x の内容を返し、'&x' はオプション x の値を返
                        し、'x' は内部 variables x の値を返し、'$x' は perl
                        の $ENV{x} と同等である。コマンドラインからアクセスで
                        きるすべての functions が {expr} に使える。
                        List は、項目を連結して改行を挿入することで文字列に
                        変換される。

                                                        perl-Blob
VIM::Blob({expr})       スカラー値から Blob リテラル文字列 0zXXXX を返す。

                                                        perl-SetHeight
Window->SetHeight({height})
                        Window の高さを、画面の制限内で {height} に設定する。

                                                        perl-GetCursor
Window->Cursor({row}?, {col}?)
                        引数が無い場合、Window 内の現在のカーソル位置の (row,
                        col) 配列を返す。{row} および {col} 引数がある場合、
                        Window のカーソル位置を {row} および {col} に設定する。
                        Note {col} は Perl 流に 0 から数えるので、Vim のルー
                        ラーの値より 1 小さいことに注意。

Window->Buffer()                                        perl-Buffer
                        与えられた Window に対応する Buffer オブジェクトを返
                        す。

                                                        perl-Name
Buffer->Name()          Buffer のファイル名を返す。

                                                        perl-Number
Buffer->Number()        Buffer の番号を返す。

                                                        perl-Count
Buffer->Count()         Buffer の行数を返す。

                                                        perl-Get
Buffer->Get({lnum}, {lnum}?, ...)
                        指定された各 {lnum} について、Buffer の {lnum} 行目の
                        テキスト文字列を返す。{lnum} のリストを指定した配列を
                        渡すことができる。

                                                        perl-Delete
Buffer->Delete({lnum}, {lnum}?)
                        Buffer の {lnum} 行目を削除する。2 つ目の {lnum} があ
                        る場合、最初の {lnum} から 2 つ目の {lnum} までの範囲
                        の行を削除する。

                                                        perl-Append
Buffer->Append({lnum}, {line}, {line}?, ...)
                        各 {line} 文字列を Buffer の {lnum} 行目の後に追加す
                        る。{line} のリストは配列でもよい。

                                                        perl-Set
Buffer->Set({lnum}, {line}, {line}?, ...)
                        Buffer の {lnum} 行目から始めて、Buffer の 1 行以上を
                        指定された {lines}s で置き換える。{line} のリストは配
                        列でもよい。引数が無効な場合、置き換えは行われない。

$main::curwin
                        現在のウィンドウオブジェクト。

$main::curbuf
                        現在のバッファオブジェクト。


                                                        script-here
スクリプト言語をインラインで使う場合、その言語がサポートされていないときはこれ
をスキップしたいことがあるだろう。
   if has('perl')
     perl << EOF
       print 'perl works'
   EOF
   endif
Note "EOF" は、前に空白を置かずに行頭になければならないことに注意。

4. 動的ローディング                                     perl-dynamic

MS-Windows および Unix では、Perl ライブラリを動的に読み込むことができる。その
とき :version の出力には +perl/dyn が含まれる。

これは、Vim が必要なときにだけ Perl の DLL または共有ライブラリファイルを検索
することを意味する。Perl インターフェイスを使わない場合はそれは必要なく、した
がって、このファイルなしで Vim を使うことができる。


MS-Windows

Perl は http://www.perl.org からダウンロードできる。Vim のビルドには
ActiveState のものが使われた。

Perl インターフェイスを使うには、Perl の DLL が検索パスになければならない。
Vim が perl512.dll を見つけられないと報告する場合、$PATH にそれがあるディレク
トリが含まれていることを確かめること。Perl のインストーラは通常それを行う。
どのディレクトリが使われるかを見るには、コンソールウィンドウで "path" とタイプ
する。'perldll' オプションを使って Perl の DLL を指定することもできる。

DLL の名前は、Vim がコンパイルされたときの Perl のバージョンと一致しなければな
らない。現在の名前は "perl512.dll" である。これは Perl 5.12 用である。確実に知
るには、"gviai.exe" を編集して "perl\d*.dll\c" を検索する。


Unix

'perldll' オプションを使って、コンパイル時に指定された DYNAMIC_PERL_DLL ファイ
ルの代わりに Perl の共有ライブラリファイルを指定できる。共有ライブラリのバー
ジョンは、Vim がコンパイルされたときの Perl のバージョンと一致しなければならな
い。

Note: Perl をローカルでビルドしている場合、Vim がそれに対して正しくリンクでき
るように、スレッドサポート付きでコンパイルされたバージョンを使う必要がある。
Perl を configure するときに -Dusethreads フラグを使うことができ、perl -V
を実行して USE_ITHREADS が "Compile-time options" の下にあることを確かめるこ
とで、Perl のバイナリでそれが有効になっているかを確認できる。
