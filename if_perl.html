==============================================================================
1. Perl のファイルを編集する                            perl-editing

Vim の構文ハイライト(syntax highlighting)は Perl と POD のファイルもサポートし
ている。Vim はファイルの拡張子が .pl か .pm であると、Perl のコードだと想定
する。Vimは、ファイルタイプが検出されなかった場合、ファイルの shebang 行も調べ
て、ファイルが Perl スクリプトかどうかを確認する。ファイル名に .POD サフィック
スが付いている場合、Vim はファイルが POD テキストであると想定する。

Perl でタグを使うには、Universal/Exuberant Ctags が必要である。ここを訪れるこ
と:
        Universal Ctags (推奨): https://ctags.io
        Exuberant Ctags: http://ctags.sourceforge.net

Perl スクリプトの "pltags.pl" を使うこともできる。これは $VIMRUNTIME/tools ディ
レクトリにある。これは今のところ最新のctagsよりも高機能である。

==============================================================================
2. Perl インターフェイス付きのコンパイル                perl-compiling

Perl インターフェイス付きで Vim をコンパイルするには、最新バージョンの Perl が
必要である。Vim をコンパイルする前に、Perl がインストールされている必要がある。

Vim への Perl パッチは、次の方によって作成された:
        Sven Verdoolaege <skimo@breughel.ufsia.ac.be>
        Matt Gerassimof

MS-Windows用 (および他のプラットフォームの) Perl は、次の場所で見つけることが
できる:
        http://www.perl.org/
ActiveState のものも動作するはずだが、Strawberry Perlは良い選択肢である。

3. Perl インターフェイスを使う                          perl-using

                                                        :perl :pe
:pe[rl] {cmd}           Perl コマンド {cmd} を実行する。現在のパッケージは
                        "main" である。:perl が動作するかを確認する単純な例
                        は:
                                :perl VIM::Msg("Hello")

:pe[rl] << [trim] [{endmarker}]
{script}
{endmarker}
                        Perlスクリプト {script} を実行する。
                        {script} の後ろの {endmarker} の前に空白を置いてはいけ
                        ない。

                        [endmarker] を省略した時は :append や :insert のよ
                        うにドット '.' が使われる。これは関数の中で使う時に便
                        利である。なぜなら "$i;" は :insert コマンドの開始と
                        紛らわしいからである。

                        この方法は Vim script の中にPerlスクリプトを埋め込む時
                        に便利である。
                        Note: Perl のサポートを有効にしてコンパイルされていな
                        いとこのコマンドは機能しない。エラーを回避するには
                        script-here を参照すること。


Vim script の例:

        function! WhitePearl()
        perl << EOF
                VIM::Msg("pearls are nice for necklaces");
                VIM::Msg("rubys for rings");
                VIM::Msg("pythons for bags");
                VIM::Msg("tcls????");
        EOF
        endfunction

使っている Perl のバージョンを見るには:
        :perl print $^V


                                                        :perldo :perld

:[range]perld[o] {cmd}  Perl コマンド {cmd} を {range} のそれぞれの行に対して
                        実行する。$_ はテキスト中のそれぞれの行のテキストに、
                        余計な <EOL> なしでセットされる。$_ をセットすることで
                        テキストを変更するが、このコマンドを使って行を挿入した
                        り、削除したりすることはできないということに注意するこ
                        と。
                        デフォルトの [range] はすべての行である: "1,$"。

いくつかの例をあげると:

   :perl $a=1
   :perldo $_ = reverse($_);1
   :perl VIM::Msg("hello")
   :perl $line = $curbuf->Get(42)
                                                        E299
sandboxの中のPerlコマンドの実行は制限されている。":perldo" は常に使えない。
":perl" は安全な環境の中で、可能なら評価される。

                                                        perl-overview
Perl で使える関数の一覧である:

   :perl VIM::Msg("Text")               # メッセージを表示する
   :perl VIM::Msg("Wrong!", "ErrorMsg") # エラーメッセージを表示する
   :perl VIM::Msg("remark", "Comment")  # ハイライトされたメッセージを表示する
   :perl VIM::SetOption("ai")           # Vim のオプションをセットする
   :perl $nbuf = VIM::Buffers()         # 全てのバッファ数を返す
   :perl @buflist = VIM::Buffers()      # 全てのバッファの配列を返す
   :perl $mybuf = (VIM::Buffers('qq.c'))[0] # 'qq.c' のバッファオブジェクト
                                            # を返す
   :perl @winlist = VIM::Windows()      # 全てのウィンドウの配列を返す
   :perl $nwin = VIM::Windows()         # ウィンドウ数を返す
   :perl ($success, $v) = VIM::Eval('&path') # $v: 'path' オプション、
                                             # $success: 1
   :perl ($success, $v) = VIM::Eval('&xyz')  # $v: '' $sucess: 0
   :perl $v = VIM::Eval('expand("<cfile>")') # <cfile> を展開
   :perl $curwin->SetHeight(10)         # ウィンドウの高さを設定する
   :perl @pos = $curwin->Cursor()       # (行, 列) 配列を返す
   :perl @pos = (10, 10)
   :perl $curwin->Cursor(@pos)          # カーソルを @pos にセットする
   :perl $curwin->Cursor(10,10)         # カーソルを10行10列目にセットする
   :perl $mybuf = $curwin->Buffer()     # ウィンドウのバッファオブジェクトを
                                        # 返す
   :perl $curbuf->Name()                # バッファ名を返す
   :perl $curbuf->Number()              # returns buffer number
   :perl $curbuf->Count()               # 行数を返す
   :perl $l = $curbuf->Get(10)          # 10 行目を返す
   :perl @l = $curbuf->Get(1 .. 5)      # 1行目から5行目までを返す
   :perl $curbuf->Delete(10)            # 10行目を削除する
   :perl $curbuf->Delete(10, 20)        # 10行目から20行目までを削除する
   :perl $curbuf->Append(10, "Line")    # 行を挿入する
   :perl $curbuf->Append(10, "Line1", "Line2", "Line3") # 3行挿入する
   :perl @l = ("L1", "L2", "L3")
   :perl $curbuf->Append(10, @l)        # L1, L2, L3 を挿入する
   :perl $curbuf->Set(10, "Line")       # 10行目を置き換える
   :perl $curbuf->Set(10, "Line1", "Line2")     # 10行目と11行目を置き換える
   :perl $curbuf->Set(10, @l)           # 3行置き換える

                                                        perl-Msg
VIM::Msg({msg}, {group}?)
                        {msg} メッセージを表示する。オプショナルな {group} 引
                        数は、そのメッセージの Vim でのハイライトグループを指
                        定する。

                                                        perl-SetOption
VIM::SetOption({arg})   Vim のオプションをセットする。{arg} は ":set" コマンド
                        で使える引数であればなんでもよい。このことは、引数の中
                        にスペースを入れることは許されないということを意味する
                        ので、注意すること。参照: :set

                                                        perl-Buffers
VIM::Buffers([{bn}...]) 引数なしだと、配列コンテキストではすべてのバッファのリ
                        ストを、スカラーコンテキストではバッファの数を返す。
                        バッファ名 {bn} もしくは、バッファ番号 {bn} のリストが
                        与えられた場合は、{bn} にマッチするバッファのリストを
                        返す。ここでは Vim の内部関数 bufname() と同じルール
                        が用いられる。
                        警告: :bwipe が使われると、このリストは無効になる。
                        それを使おうとすると Vim がクラッシュすることがある。

                                                        perl-Windows
VIM::Windows([{wn}...]) 引数なしだと、配列コンテキストではすべてのウィンドウの
                        リストを返し、スカラーコンテキストではウィンドウの数を
                        返す。ウィンドウ数 {wn} にリストが与えられた場合は、そ
                        れらの番号のウィンドウのリストを返す。
                        警告: :bwipe が使われると、このリストは無効になる。
                        それを使おうとすると Vim がクラッシュすることがある。

                                                        perl-DoCommand
VIM::DoCommand({cmd})   Ex コマンド {cmd} を実行する。

                                                        perl-Eval
VIM::Eval({expr})       {expr} を評価して、リストコンテキストでは (success,
                        value) を返し、スカラーコンテキストでは単に値を返す。
                        success=1 だと、val は {expr} の値を含む;
                        success=0 だと、式の評価に失敗したことを示している。
                        '@x' はレジスタ x の内容を返し、'&x' はオプション x の
                        値を返す。'x' は内部変数 variables x を返し、'$x'は
                        Perl の $ENV{x} と同じである。コマンドラインからアクセ
                        スできるすべての functions は {expr} に使うことがで
                        きる。リスト List は文字列に変換される。そのとき各要
                        素の間に改行が挿入され、連結される。

                                                        perl-Blob
VIM::Blob({expr})       スカラー値から Blob リテラル文字列 0zXXXX を返す。

                                                        perl-SetHeight
Window->SetHeight({height})
                        ウィンドウの高さをスクリーンの上限以内で {height} に
                        セットする。

                                                        perl-GetCursor
Window->Cursor({row}?, {col}?)
                        引数なしだと、ウィンドウの現在のカーソル位置の (row,
                        col) 配列を返す。{row} と {col} 引数をつけてよばれる
                        と、ウィンドウのカーソル位置を {row} と {col} にセット
                        する。{col} は Perl のように0から数えられるので、Vim
                        のルーラーの値より1つ小さくなるということに注意するこ
                        と。

Window->Buffer()                                        perl-Buffer
                        与えられたウィンドウに対応するバッファオブジェクトを返
                        す。

                                                        perl-Name
Buffer->Name()          バッファのファイル名を返す。

                                                        perl-Number
Buffer->Number()        バッファの番号を返す。

                                                        perl-Count
Buffer->Count()         バッファの行数を返す。

                                                        perl-Get
Buffer->Get({lnum}, {lnum}?, ...)
                        バッファの {lnum} 行目のテキストを、指定されているそれ
                        ぞれの {lnum} に関して返す。{lnum} のリストとして配列
                        を渡すこともできる。

                                                        perl-Delete
Buffer->Delete({lnum}, {lnum}?)
                        バッファの {lnum} 行目を削除する。二つ目の {lnum} が指
                        定されていると、始めの {lnum} から二つ目の {lnum} まで
                        の範囲の行が削除される。

                                                        perl-Append
Buffer->Append({lnum}, {line}, {line}?, ...)
                        それぞれの {line} をバッファの {lnum} 行目の後に挿入す
                        る。{line} のリストは配列でもよい。

                                                        perl-Set
Buffer->Set({lnum}, {line}, {line}?, ...)
                        バッファの行を1行以上 {line} で指定される行で置き換え
                        る。置き換えは、{lnum} から始まり、{line} は配列でもよ
                        い。引数が有効でないものであれば、置き換えは起こらな
                        い。

$main::curwin
                        現在のウィンドウオブジェクト

$main::curbuf
                        現在のバッファオブジェクト


                                                        script-here
Vim script にその他のスクリプトを埋め込むときに、その言語がサポートされていな
い場合、その部分をスキップしたいだろう。
   if has('perl')
     perl << EOF
       print 'perl works'
   EOF
   endif
Note: "EOF" は前に空白を入れずに行頭に置く必要がある。

4. 動的ローディング                                     perl-dynamic

MS-Windows と Unix では Perl ライブラリを動的に読み込むことが可能である。これ
を行うと :version の出力に +perl/dyn が含まれるようになる。

この場合、Vimは必要になったときだけPerlのDLLや共有ライブラリのファイルを検索す
る。Perlインターフェイスを使わないときはDLLを必要としないので、DLLなしでVim を
使うことができる。

MS-Windows

http://www.perl.org から Perl をダウンロードできる。Vim のビルドには
ActiveState のものが使われた。

Perl インターフェイスを使うには Perl の DLL が検索パス内に存在しなければならな
い。perl512.dll が見つからないというようなメッセージが表示された場合は、$PATH
に適切なディレクトリが含まれているかどうか確認すること。通常は Perl のインス
トーラによって設定されるだろう。コンソールウィンドウで "path" とタイプすると、
どのディレクトリが検索パスになっているか確認できる。また 'perldll' オプション
を Perl の DLL を指定するのに使うこともできる。

DLLの名前はVimをコンパイルした時のPerlのバージョンに一致しなければならない。現
在その名前は "perl512.dll" である。これはPerl5.12用である。これを確かめるには、
"gvim.exe" を開き、"perl\d*.dll\c" を検索すること。


Unix

コンパイル時に DYNAMIC_PERL_DLL で指定されたファイルの代わりに 'perldll' オプ
ションで使用する Perl の共有ライブラリのファイルを指定するのに使える。共有ライ
ブラリのバージョンは Vim と共にコンパイルされた Perl のバージョンと一致してい
なければならない。

Note: Perl をローカルでビルドする場合、Vim が正常にリンクするためには、スレッ
ドサポート付きでコンパイルされたバージョンを使用する必要がある。Perl を構成す
るときに -Dusethreads フラグを使うことができ、Perl のバイナリでこのフラグが
有効になっているかどうかは perl -V を実行して "Compile-time options" の下に
USE_ITHREADS があるかどうかで確認することができる。
