はじめに                                                      ps1-syntax

このプラグインは、Windows PowerShell のスクリプト、モジュール、XML 設定ファイ
ル用に、Vim のシンタックス、インデント、ファイルタイプ検出を提供する。


概要                                                          ps1-about

最新版の入手やバグの報告は GitHub で:

https://github.com/PProvost/vim-ps1


折り畳み                                                      ps1-folding

ps1 シンタックスファイルは、スクリプトブロックと、スクリプト内のデジタル署名に
対して、シンタックス折り畳み (:syn-fold を参照) を提供する。

'foldmethod' が "syntax" に設定されている場合、.vimrc 内か、スクリプトを開く前
に以下を使わない限り、関数のスクリプトブロックは折り畳まれる:

    :let g:ps1_nofold_blocks = 1

以下を使わない限り、スクリプト内のデジタル署名も折り畳まれる:

    :let g:ps1_nofold_sig = 1

Note: シンタックス折り畳みにより、特に大きなファイルでは、シンタックスハイライ
トがかなり遅くなることがある。


コンパイラ                                                    ps1-compiler

powershell の :compiler スクリプトは、:make が PowerShell でスクリプトを実
行するように設定する。

気の利いたデフォルトの PowerShell コマンドを選ぼうとする: 利用できれば pwsh、
そうでなければ powershell。ただし、コマンドはカスタマイズできる:

    :let g:ps1_makeprg_cmd = '/path/to/pwsh'

例外の種類の情報を表示するかどうかを設定するには:

    :let g:ps1_efm_show_error_categories = 1


キーワード検索                                               ps1-keyword

PowerShell の Get-Help を使ってキーワードを調べるには、K キーを押す。より便
利にページングするには、ページャー less がインストールされているべきである。
これは多くの Linux ディストリビューションと macOS に含まれている。

Windows 向けにも、https://chocolatey.org/packages/less/ のように、他の多くの配
布物がある。less が環境変数 PATH に列挙されたディレクトリにあることを確か
めること。上記の chocolatey はそうしている。
