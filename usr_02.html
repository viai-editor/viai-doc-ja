02.1  初めて Vim を実行する

Vim を起動するには、このコマンドを入力します:

        gvim file.txt

UNIX では、これを任意のコマンドプロンプトでタイプできます。Microsoft Windows
を実行している場合、コマンドプロンプトを開いてコマンドを入力します。
   どちらの場合も、Vim は file.txt という名前のファイルの編集を開始します。こ
れは新しいファイルなので、空のウィンドウが得られます。あなたの画面はこのように
見えるでしょう:

        +---------------------------------------+
        |#                                      |
        |~                                      |
        |~                                      |
        |~                                      |
        |~                                      |
        |"file.txt" [New file]                  |
        +---------------------------------------+
                ('#' はカーソル位置です。)

チルダ (~) の行は、ファイルにない行を示します。言い換えると、Vim は表示するファ
イルがなくなると、チルダの行を表示します。画面の下部では、メッセージ行が、ファ
イルの名前が file.txt であることを示し、新しいファイルを作成していることを示し
ます。メッセージの情報は一時的なもので、他の情報がそれを上書きします。


Vim コマンド

gvim コマンドは、エディタに編集用の新しいウィンドウを作成させます。このコマン
ドを使う場合:

        vim file.txt

編集はあなたのコマンドウィンドウの中で行われます。言い換えると、xterm の中で実
行している場合、エディタはあなたの xterm ウィンドウを使います。MS-Windows のコ
マンドプロンプトウィンドウを使っている場合、編集はこのウィンドウの中で行われま
す。ウィンドウ内のテキストはどちらのバージョンでも同じように見えますが、gvim
にはメニューバーのような追加の機能があります。それについては後で詳しく。

02.2  テキストを挿入する

Vim エディタはモーダルエディタです。これは、あなたがどのモードにいるかによっ
て、エディタが異なる振る舞いをすることを意味します。2 つの基本的なモードは、
ノーマルモードおよび挿入モードと呼ばれます。ノーマルモードでは、あなたがタイプ
する文字はコマンドです。挿入モードでは、文字はテキストとして挿入されます。
   Vim を起動したばかりなので、Vim はノーマルモードになっています。挿入モード
を開始するには、"i" コマンド (Insert の i) をタイプします。それからテキストを
入力できます。それはファイルに挿入されます。間違えた場合も心配しないでください;
後で修正できます。以下のプログラマの戯れ詩を入力するには、こうタイプします:

        iA very intelligent turtle
        Found programming UNIX a hurdle

"turtle" をタイプした後、<Enter> キーを押して新しい行を開始します。最後に、
<Esc> キーを押して挿入モードを止め、ノーマルモードに戻ります。これで、あなたの
Vim ウィンドウに 2 行のテキストがあります:

        +---------------------------------------+
        |A very intelligent turtle              |
        |Found programming UNIX a hurdle        |
        |~                                      |
        |~                                      |
        |                                       |
        +---------------------------------------+


モードは何?

あなたがどのモードにいるかを見られるようにするには、このコマンドをタイプします:


        :set showmode

コロンをタイプすると、Vim がカーソルをウィンドウの最終行に移動することに気付く
でしょう。そこはコロンコマンド (コロンで始まるコマンド) をタイプする場所です。
<Enter> キーを押してこのコマンドを終えます (コロンで始まるすべてのコマンドはこ
の方法で終えます)。
   ここで、"i" コマンドをタイプした場合、Vim はウィンドウの下部に --INSERT--
を表示します。これは、あなたが挿入モードにいることを示します。

        +---------------------------------------+
        |A very intelligent turtle              |
        |Found programming UNIX a hurdle        |
        |~                                      |
        |~                                      |
        |-- INSERT --                           |
        +---------------------------------------+

<Esc> を押してノーマルモードに戻る場合、最後の行は空にされます。


トラブルから抜け出す

Vim 初心者にとっての問題の 1 つはモードの混乱で、それは、あなたがどのモードに
いるかを忘れることによって、または誤ってモードを切り替えるコマンドをタイプする
ことによって引き起こされます。どのモードにいても、ノーマルモードに戻るには
<Esc> キーを押します。2 回押さなければならないこともあります。Vim があなたに
ビープ音を返した場合、あなたはすでにノーマルモードにいます。

02.3  あちこち移動する

ノーマルモードに戻った後、これらのキーを使って移動できます:

        h   左                                                  hjkl
        j   下
        k   上
        l   右

最初は、これらのコマンドはでたらめに選ばれたように見えるかもしれません。結局の
ところ、右に l を使うなんて、いったい誰が聞いたことがあるでしょう? しかし実際
には、これらの選択にはとても良い理由があります: カーソルの移動はエディタであな
たが最もよく行うことであり、これらのキーはあなたの右手のホームロウ上にありま
す。言い換えると、これらのコマンドは、あなたがそれらを最も速くタイプできる場所
に置かれています (特に 10 本の指でタイプするとき)。

        Note:
        矢印キーを使ってカーソルを移動することもできます。しかし、そうした場
        合、矢印キーを押すには手をテキストキーから矢印キーに移動しなければなら
        ないので、編集が大幅に遅くなります。1 時間に何百回もそれをしているかも
        しれないことを考えると、これはかなりの時間を取ることがあります。
           また、矢印キーがないキーボード、または矢印キーを珍しい場所に配置し
        ているキーボードがあります; したがって、hjkl キーの使い方を知っている
        ことは、そのような状況で役に立ちます。

これらのコマンドを覚える 1 つの方法は、h が左にあり、l が右にあり、j が下を指
している、ということです。絵にすると:

                       k
                   h     l
                     j

これらのコマンドを学ぶ最良の方法は、それらを使うことです。"i" コマンドを使っ
て、さらに何行かのテキストを挿入してください。それから hjkl キーを使って移動
し、どこかに単語を挿入してください。ノーマルモードに戻るために <Esc> を押すの
を忘れないでください。vimtutor も、やりながら学ぶよい方法です。

日本のユーザーのために、Hiroshi Iwatani がこれを使うことを提案しました:

                        Komsomolsk
                            ^
                            |
           Huan Ho      <--- --->  Los Angeles
        (黄河)              |
                            v
                          Java (島、プログラミング言語ではない)

02.4  文字を削除する

文字を削除するには、カーソルをその上に移動して "x" をタイプします。(これは、物
の上に xxxx をタイプすることで物を削除していた、タイプライターの昔の時代への先
祖返りです。) 例えば、カーソルを最初の行の先頭に移動し、xxxxxxx (7 つの x) を
タイプして "A very " を削除します。結果はこのようになるはずです:

        +---------------------------------------+
        |intelligent turtle                     |
        |Found programming UNIX a hurdle        |
        |~                                      |
        |~                                      |
        |                                       |
        +---------------------------------------+

これで、例えばこうタイプすることで、新しいテキストを挿入できます:

        iA young <Esc>

これは挿入を開始し (i)、"A young" という単語を挿入し、それから挿入モードを終了
します (最後の <Esc>)。結果:

        +---------------------------------------+
        |A young intelligent turtle             |
        |Found programming UNIX a hurdle        |
        |~                                      |
        |~                                      |
        |                                       |
        +---------------------------------------+


行を削除する

行全体を削除するには "dd" コマンドを使います。そうすると、次の行が上に移動して
隙間を埋めます:

        +---------------------------------------+
        |Found programming UNIX a hurdle        |
        |~                                      |
        |~                                      |
        |~                                      |
        |                                       |
        +---------------------------------------+


改行を削除する

Vim では 2 行を 1 つに連結でき、これは、それらの間の改行が削除されることを意味
します。"J" コマンドがこれを行います。
   これらの 2 行を取り上げます:

        A young intelligent
        turtle

カーソルを最初の行に移動して "J" を押します:

        A young intelligent turtle

02.5  undo と redo

削除しすぎたとします。まあ、それを再びタイプして入力することもできますが、もっ
と簡単な方法があります。"u" コマンドは最後の編集を undo します。これを実際に見
てみましょう: "dd" を使って最初の行を削除した後、"u" でそれが戻ります。
   もう 1 つ: カーソルを最初の行の A に移動します:

        A young intelligent turtle

ここで xxxxxxx をタイプして "A young" を削除します。結果は以下のとおりです:

         intelligent turtle

"u" をタイプして、最後の削除を undo します。その削除は g を削除したので、undo
はその文字を復元します。

        g intelligent turtle

次の "u" コマンドは、最後から 2 番目に削除された文字を復元します:

        ng intelligent turtle

次の "u" コマンドは u を戻し、以下同様です:

        ung intelligent turtle
        oung intelligent turtle
        young intelligent turtle
         young intelligent turtle
        A young intelligent turtle

        Note:
        "u" を 2 回タイプして、その結果同じテキストが戻ってくる場合、あなたの
        Vim は Vi 互換で動作するように設定されています。これを直すにはここを見
        てください: not-compatible。
           このテキストは、あなたが "Vim のやり方" で作業することを前提として
        います。古き良き Vi のやり方を使う方が好みかもしれませんが、そのときは
        テキスト中の小さな違いに気をつけなければならないでしょう。


REDO

undo しすぎた場合、CTRL-R (redo) を押して、直前のコマンドを逆にすることができ
ます。言い換えると、それは undo を undo します。これを実際に見るには、CTRL-R
を 2 回押します。文字 A およびその後の空白が消えます:

        young intelligent turtle

undo コマンドには特別なバージョンである、"U" (行 undo) コマンドがあります。行
undo コマンドは、最後に編集された行に加えられたすべての変更を undo します。こ
のコマンドを 2 回タイプすると、直前の "U" が取り消されます。

        A very intelligent turtle
          xxxx                          very を削除

        A intelligent turtle
                      xxxxxx            turtle を削除

        A intelligent
                                        "U" で行を復元
        A very intelligent turtle
                                        "u" で "U" を undo
        A intelligent

"U" コマンドはそれ自体が変更であり、それを "u" コマンドは undo し、CTRL-R は
redo します。これは少し混乱するかもしれません。心配しないでください、"u" およ
び CTRL-R で、あなたが持っていたどの状況にも行くことができます。それについては
セクション 32.2 で詳しく。

02.6  その他の編集コマンド

Vim にはテキストを変更するための多数のコマンドがあります。Q_in および以下を
参照してください。ここではよく使われるものをいくつか紹介します。


追加する

"i" コマンドは、カーソルの下の文字の前に文字を挿入します。それはうまく機能しま
す; しかし、行末に何かを追加したい場合、どうなるでしょう? そのためには、カーソ
ルの後にテキストを挿入する必要があります。これは "a" (append) コマンドで行いま
す。
   例えば、行

        and that's not saying much for the turtle.
を
        and that's not saying much for the turtle!!!

に変更するには、カーソルを行末のドットの上に移動します。それから "x" をタイプ
してピリオドを削除します。これでカーソルは行末の、turtle の e の上に位置してい
ます。ここで、こうタイプして

        a!!!<Esc>

turtle の e の後に 3 つの感嘆符を追加します:

        and that's not saying much for the turtle!!!


新しい行を開く

"o" コマンドは、カーソルの下に新しい空の行を作成し、Vim を挿入モードにします。
それから、新しい行のテキストをタイプできます。
   カーソルが、これらの 2 行のうちの最初の行のどこかにあるとします:

        A very intelligent turtle
        Found programming UNIX a hurdle

ここで "o" コマンドを使い、新しいテキストをタイプした場合:

        oThat liked using Vim<Esc>

結果は以下のとおりです:

        A very intelligent turtle
        That liked using Vim
        Found programming UNIX a hurdle

"O" コマンド (大文字) は、カーソルの上に行を開きます。


カウントを使う

9 行上に移動したいとします。"kkkkkkkkk" とタイプするか、またはコマンド "9k" を
入力できます。実際、多くのコマンドの前に数値を付けることができます。例えば、こ
の章の前の方で、あなたは "a!!!<Esc>" とタイプして行末に 3 つの感嘆符を追加しま
した。これを行う別の方法は、コマンド "3a!<Esc>" を使うことです。3 のカウント
は、後に続くコマンドに、その効果を 3 倍にするように伝えます。同様に、3 文字を
削除するには、コマンド "3x" を使います。カウントは常に、それが適用されるコマン
ドの前に来ます。

02.7  終了する

終了するには、"ZZ" コマンドを使います。このコマンドはファイルを書き込んで終了
します。

        Note:
        他の多くのエディタと異なり、Vim は自動的にバックアップファイルを作成し
        ません。"ZZ" をタイプした場合、あなたの変更は確定され、後戻りはできま
        せん。Vim エディタがバックアップファイルを作成するように設定できます;
        07.4 を参照してください。


変更を破棄する

時々、一連の変更を行った後で、始める前の方がよかったと突然気付くことがあるで
しょう。心配いりません; Vim には終了して物を捨てるコマンドがあります。それは:


        :q!

コマンドを終えるために <Enter> を押すのを忘れないでください。

詳細に興味がある方のために、このコマンドの 3 つの部分は、コマンドラインモード
に入るコロン (:)、エディタに終了するように伝える q コマンド、および上書きコマ
ンド修飾子 (!) です。
   上書きコマンド修飾子が必要なのは、Vim が変更を捨てることに消極的だからです。
単に ":q" とタイプしたとすると、Vim はエラーメッセージを表示して終了を拒否する
でしょう:

        E37: No write since last change (use ! to override)

上書きを指定することで、あなたは事実上、Vim に "自分がしていることが馬鹿げて見
えるのは分かっていますが、本当にこれをしたいのです。" と伝えています。

Vim で編集を続けたい場合: ":e!" コマンドは、ファイルの元のバージョンを再読み込
みします。

02.8  ヘルプを見つける

あなたがいつも知りたいと思っていたことはすべて、Vim のヘルプファイルで見つける
ことができます。恐れずに聞いてください!

探しているものが分かっている場合、通常は Google を使う代わりに、ヘルプシステム
を使ってそれを検索する方が簡単です。なぜなら、主題は特定のスタイルガイドに従っ
ているからです。

また、ヘルプには、あなたの特定の Vim バージョンに属しているという利点がありま
す。後で追加されたコマンドのヘルプは表示されません。それらはあなたには機能しな
いでしょう。

一般的なヘルプを得るには、このコマンドを使います:

        :help

最初のファンクションキー <F1> を使うこともできます。あなたのキーボードに
<Help> キーがある場合、それも機能するかもしれません。
   主題を指定しない場合、":help" は一般的なヘルプウィンドウを表示します。Vim
の作者たちはヘルプシステムでとても賢いこと (またはとても怠惰なこと) をしました:
彼らはヘルプウィンドウを通常の編集ウィンドウにしました。すべての通常の Vim コ
マンドを使って、ヘルプ情報の中を移動できます。したがって、h、j、k、および l
は、左、下、上、および右に移動します。
   ヘルプウィンドウから出るには、エディタから出るのに使うのと同じコマンド、
"ZZ" を使います。これはヘルプウィンドウを閉じるだけで、Vim は終了しません。

ヘルプテキストを読んでいると、縦棒で囲まれたテキスト (例えば help) があるこ
とに気付くでしょう。これはハイパーリンクを示します。棒の間のどこかにカーソルを
置いて CTRL-] (タグへジャンプ) を押した場合、ヘルプシステムは示された主題へあ
なたを連れて行きます。(ここでは議論しない理由により、ハイパーリンクに対する
Vim の用語はタグです。そのため、CTRL-] はカーソルの下の単語で与えられたタグの
位置へジャンプします。)
   何回かジャンプした後、戻りたくなるかもしれません。CTRL-T (タグをポップ) は
前の位置へあなたを戻します。CTRL-O (古い位置へジャンプ) も、ここでうまく機能し
ます。
   ヘルプ画面の一番上に、"*help.txt*" という表記があります。"*" 文字の間のこの
名前は、タグ (ハイパーリンクの行き先) を定義するために、ヘルプシステムによって
使われます。
   タグの使い方の詳細については 29.1 を参照してください。

特定の主題に関するヘルプを得るには、以下のコマンドを使います:

        :help {subject}

例えば、"x" コマンドに関するヘルプを得るには、以下を入力します:

        :help x

テキストを削除する方法を調べるには、このコマンドを使います:

        :help deleting

すべての Vim コマンドの完全な索引を得るには、以下のコマンドを使います:

        :help index

制御文字のコマンド (例えば CTRL-A) のヘルプを得る必要があるときは、プリフィッ
クス "CTRL-" を付けて綴る必要があります。

        :help CTRL-A

Vim エディタには多くの異なるモードがあります。既定では、ヘルプシステムはノーマ
ルモードのコマンドを表示します。例えば、以下のコマンドはノーマルモードの
CTRL-H コマンドのヘルプを表示します:

        :help CTRL-H

他のモードを識別するには、モードプリフィックスを使います。コマンドの挿入モード
版のヘルプが欲しい場合、"i_" を使います。CTRL-H の場合、これで以下のコマンドに
なります:

        :help i_CTRL-H

Vim エディタを起動するとき、いくつかのコマンドライン引数を使えます。これらはす
べてダッシュ (-) で始まります。例えば、-t 引数が何をするかを調べるには、このコ
マンドを使います:

        :help -t

Vim エディタには、エディタを設定し、カスタマイズできるようにする、多数のオプ
ションがあります。オプションのヘルプが欲しい場合、それを単一引用符で囲む必要が
あります。例えば、'number' オプションが何をするかを調べるには、以下のコマンド
を使います:

        :help 'number'

すべてのモードプリフィックスの表は、以下にあります: help-summary。

特殊キーは山括弧で囲まれています。例えば、挿入モードの上矢印キーのヘルプを見つ
けるには、このコマンドを使います:

        :help i_<Up>

理解できないエラーメッセージを見た場合、例えば:

        E37: No write since last change (use ! to override)

先頭のエラー ID を使って、それに関するヘルプを見つけることができます:

        :help E37


要約:                                           help-summary 

1) トピックをタイプした後で Ctrl-D を使い、Vim に使用可能なすべてのトピックを
   表示させます。
   または、Tab を押して補完します:
        :help some<Tab>
    ヘルプの使い方についての詳しい情報:
        :help helphelp

2) 関連するヘルプへは、棒で囲まれたリンクをたどります。詳細なヘルプから、特定
   のコマンドをよりユーザーの視点から、より詳細でなく説明しているユーザードキュ
   メントへ行くことができます。例えば、以下の後で:
        :help pattern.txt
    導入部で、ユーザーガイドのトピック 03.9 および usr_27.txt を見ることが
   できます。

3) オプションは単一アポストロフィで囲まれています。list オプションのヘルプト
   ピックへ行くには:
        :help 'list'
    特定のオプションを探していることだけが分かっている場合、こうすることもでき
   ます:
        :help options.txt
    で、すべてのオプションの扱いを説明しているヘルプページを開き、それから正規
   表現、例えば textwidth を使って検索します。
   特定のオプションには独自の名前空間があります。例えば:
        :help cpo-<letter>
    は 'cpoptions' 設定の対応するフラグのためのもので、<letter> を特定のフラグ
   で置き換えます。例えば:
        :help cpo-;
    そして 'guioptions' のフラグについては:
        :help go-<letter>

4) ノーマルモードのコマンドにはプリフィックスがありません。"gt" コマンドのヘル
   プページへ行くには:
        :help gt

5) 挿入モードのコマンドは i_ で始まります。単語を削除するためのヘルプ:
        :help i_CTRL-W

6) ビジュアルモードのコマンドは v_ で始まります。ビジュアル領域の反対側へジャ
   ンプするためのヘルプ:
        :help v_o

7) コマンドラインの編集および引数は c_ で始まります。コマンド引数 % を使うため
   のヘルプ:
        :help c_%

8) Ex コマンドは常に ":" で始まるので、":s" コマンドのヘルプへ行くには:
        :help :s

9) デバッグ専用のコマンドは ">" で始まります。"cont" デバッグコマンドのヘルプ
   へ行くには:
        :help >cont

10) キーの組み合わせ。それらは通常、それらが使えるモードを示す 1 文字で始まり
    ます。例えば:
        :help i_CTRL-X
     は、さまざまなものを自動補完するために使える、挿入モード用の CTRL-X コマ
    ンド群へあなたを連れて行きます。Note 特定のキーは常に同じように書かれる、
    例えば Control は常に CTRL になることに注意してください。
    ノーマルモードのコマンドにはプリフィックスがなく、トピックは :h
    CTRL-<Letter> にあります。例えば
        :help CTRL-W
     対照的に
        :help c_CTRL-R
     は、コマンドラインでコマンドを入力するときに CTRL-R が何をするかを説明し、
    そして
        :help v_CTRL-A
     はビジュアルモードで数値を増加させることについて述べ、そして
        :help g_CTRL-A
     は "g<C-A>" コマンドについて述べています (例えば、"g" を押してから
    <CTRL-A> を押さなければなりません)。ここで "g" はノーマルコマンド "g" を表
    し、これは "z" で始まるコマンドと同様の何かを行う前に、常に 2 つ目のキーを
    期待します。

11) 正規表現の項目は常に / で始まります。そのため、Vim の正規表現の "\+" 量指
    定子のヘルプを得るには:
        :help /\+
     正規表現についてすべてを知る必要がある場合、以下から読み始めてください:
        :help pattern.txt

12) レジスタは常に "quote" で始まります。特別な ":" レジスタについて調べるには:

        :help quote:

13) Vim script は以下にあります
        :help eval.txt
     言語の特定の側面は :h expr-X にあり、"X" は 1 文字です。例えば
        :help expr-!
     は、Vim script の "!" (Not) 演算子を説明しているトピックへあなたを連れて
    行きます。
    また重要なのは
        :help function-list
     で、使用可能なすべての関数の短い説明を見つけます。Vim script 関数のヘルプ
    トピックは常に "()" を含むので:
        :help append()
     は、カレントバッファにテキストを追加する方法ではなく、Vim script の
    append 関数について述べています。

14) マッピングについてはヘルプページ :h map.txt で述べられています。
        :help mapmode-i
     を使って、:imap コマンドについて調べます。また、マッピングに特有の特定
    のサブトピックについて調べるには、:map-topic を使います。例えば:
        :help :map-local
     でバッファローカルなマッピングについて、または
        :help map-bar
     でマッピングで '|' がどのように扱われるかについて。

15) コマンド定義については :h command-topic で述べられているので、
        :help command-bang
     を使って、カスタムコマンドの '!' 引数について調べます。

16) ウィンドウ管理コマンドは常に CTRL-W で始まるので、対応するヘルプは :h
    CTRL-W_letter で見つかります。例えば
        :help CTRL-W_p
     は、前にアクセスしたウィンドウへ移動するためのものです。以下にアクセスす
    ることもできます
        :help windows.txt
     そして、ウィンドウを扱うコマンドを探している場合、読み進めてください。

17) すべてのヘルプページ (およびインストールされた任意のプラグインのものも) を
    検索するには :helpgrep を使います。その使い方は :helpgrep を参照してく
    ださい。
    トピックを検索するには:
        :helpgrep topic
     これは最初のマッチへあなたを連れて行きます。次のマッチへ行くには:
        :cnext
     すべてのマッチは quickfix ウィンドウにあり、そのウィンドウは以下で開けま
    す:
        :copen
     好きなマッチへ移動して Enter を押し、そのヘルプへジャンプします。

18) ユーザーマニュアル。これは初心者向けのヘルプトピックを、かなり親しみやすい
    方法で説明しています。目次を見つけるには usr_toc.txt から始めてください
    (推測したかもしれませんが):
        :help usr_toc.txt
     内容にざっと目を通して、興味深いトピックを見つけてください。"ダイグラフ"
    および "特殊文字を入力する" の項目は 24 章にあるので、その特定のヘルプペー
    ジへ行くには:
        :help usr_24.txt
     また、ヘルプの特定の章にアクセスしたい場合、このように章番号に直接アクセ
    スできます:
        :help 10.1
     は usr_10.txt の 10.1 章へ行き、マクロの記録について述べています。

19) ハイライトグループ。常に hl-groupname で始まります。例えば
        :help hl-WarningMsg
     は WarningMsg ハイライトグループについて述べています。

20) 構文ハイライトは :syn-topic という名前空間にあります。例えば
        :help :syn-conceal
     は ":syn" コマンドの conceal 引数について述べています。

21) quickfix コマンドは通常 :c で始まり、一方 location リストのコマンドは通
    常 :l で始まります

22) 自動コマンドイベントは、その名前で見つけることができます:
        :help BufWinLeave
     すべての可能なイベントを見るには:
        :help autocommand-events

23) コマンドラインスイッチは常に "-" で始まります。そのため、Vim の -f コマン
    ドスイッチのヘルプには、以下を使います:
        :help -f

24) オプションの機能は常に "+" で始まります。conceal 機能について調べるには、
    以下を使います:
        :help +conceal

25) 同梱されているファイルタイプ固有の機能のドキュメントは、通常
    ft-<filetype>-<functionality> という形式で提供されています。そのため
        :help ft-c-syntax
     は C の構文ファイルおよびそれが提供するオプションについて述べています。
    時々、オムニ補完のための追加のセクション
        :help ft-php-omni
     またはファイルタイププラグイン
        :help ft-tex-plugin
     が提供されています。

26) エラーおよび警告のコードは、ヘルプで直接調べることができます。そのため
        :help E297
     はスワップのエラーメッセージの説明へ正確にあなたを連れて行き、そして
        :help W10
     は警告 "Changing a readonly file" について述べています。
    しかし、時々、それらのエラーコードは説明されておらず、むしろ通常それを引き
    起こす Vim コマンドのところに列挙されています。そのため:
        :help E128
     は :function コマンドへあなたを連れて行きます

27) Vim と共に配布されるパッケージのドキュメントは package-<name> という形式で
    す。そのため
        :help package-comment

    は、同梱されている comment プラグインのヘルプセクション、およびそれを有効
    にする方法へあなたを連れて行きます。
