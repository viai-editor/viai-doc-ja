                     VIAI ユーザーマニュアル


                              新しいメニューを追加する


ここまでで、Vim がとても柔軟であることはお分かりでしょう。これには GUI で使わ
れるメニューも含まれます。独自のメニュー項目を定義して、特定のコマンドに簡単に
アクセスできるようにすることができます。これはマウス好きのユーザーのためだけの
ものです。

42.1  はじめに

Vim が使うメニューは、ファイル "$VIMRUNTIME/menu.vim" で定義されています。独自
のメニューを書きたい場合は、まずそのファイルに目を通すとよいでしょう。
   メニュー項目を定義するには、":menu" コマンドを使います。このコマンドの基本
的な形式は以下のとおりです:

        :menu {menu-item} {keys}

{menu-item} は、メニューのどこに項目を置くかを記述します。典型的な {menu-item}
は "File.Save" で、これは "File" メニューの下の項目 "Save" を表します。名前を
区切るのにドットが使われます。例:

        :menu File.Save  :update<CR>

":update" コマンドは、ファイルが変更されていた場合にファイルを書き込みます。
   別の階層を追加できます: "Edit.Settings.Shiftwidth" は、項目 "Shiftwidth" を
持つサブメニュー "Settings" を "Edit" メニューの下に定義します。さらに深い階層
を使うこともできます。これを使いすぎないでください。そのような項目を使うにはマ
ウスをかなり動かす必要があります。
   ":menu" コマンドは ":map" コマンドにとてもよく似ています: 左側は項目がどの
ように起動されるかを指定し、右側は実行される文字を定義します。{keys} は文字で、
それらはあなたがタイプしたのとまったく同じように使われます。そのため、挿入モー
ドでは、{keys} が普通のテキストのとき、そのテキストが挿入されます。


アクセラレータ

アンパサンド文字 (&) は、アクセラレータを示すのに使われます。例えば、Alt-F を
使って "File" を選択し、S を使って "Save" を選択できます。(ただし、
'winaltkeys' オプションがこれを無効にするかもしれません!)。そのため、
{menu-item} は "&File.&Save" のようになります。アクセラレータの文字はメニュー
の中で下線付きで表示されます。
   各メニューの中で、それぞれのキーが 1 回だけ使われるように注意しなければなり
ません。そうしないと、2 つのうちのどちらが実際に使われるかが分からなくなりま
す。Vim はこれについて警告しません。


優先順位

File.Save メニュー項目の実際の定義は以下のとおりです:

        :menu 10.340 &File.&Save<Tab>:w  :confirm w<CR>

数値 10.340 は優先順位番号と呼ばれます。これは、エディタがメニュー項目をどこに
置くかを決めるのに使われます。最初の数値 (10) は、メニューバー上の位置を示しま
す。小さい番号のメニューは左に、大きい番号は右に配置されます。
   これらが標準のメニューに使われている優先順位です:

          10    20     40     50      60       70               9999

        +------------------------------------------------------------+
        | File  Edit  Tools  Syntax  Buffers  Window            Help |
        +------------------------------------------------------------+

Help メニューには、右端に表示されるように、とても大きな番号が与えられているこ
とに注目してください。
   2 番目の数値 (340) は、プルダウンメニューの中での項目の位置を決めます。小さ
い番号は上に、大きい番号は下に置かれます。これらが File メニューの中の優先順位
です:

                        +-----------------+
            10.310      |Open...          |
            10.320      |Split-Open...    |
            10.325      |New              |
            10.330      |Close            |
            10.335      |---------------- |
            10.340      |Save             |
            10.350      |Save As...       |
            10.400      |---------------- |
            10.410      |Split Diff with  |
            10.420      |Split Patched By |
            10.500      |---------------- |
            10.510      |Print            |
            10.600      |---------------- |
            10.610      |Save-Exit        |
            10.620      |Exit             |
                        +-----------------+

番号の間に空きがあることに注目してください。本当にそうしたい場合は、ここに独自
の項目を挿入できます (標準のメニューはそのままにして、独自の項目のために新しい
メニューを追加する方がよいことが多いです)。
   サブメニューを作るときは、優先順位にさらに ".number" を追加できます。そのた
め、{menu-item} の中の各名前はそれぞれの優先順位番号を持ちます。


特殊文字

この例の {menu-item} は "&File.&Save<Tab>:w" です。これは重要な点を提起します:
{menu-item} は 1 つの単語でなければなりません。名前にドット、スペースまたはタ
ブを入れたい場合は、<> 表記 (例えば、<Space> および <Tab>) を使うか、またはバッ
クスラッシュ (\) エスケープを使います。

        :menu 10.305 &File.&Do\ It\.\.\. :exit<CR>

この例では、メニュー項目の名前 "Do It..." はスペースを含んでいて、コマンドは
":exit<CR>" です。

メニュー名の中の <Tab> 文字は、メニュー名を定義する部分と、ユーザーにヒントを
与える部分を区切るのに使われます。<Tab> の後の部分は、メニューの中で右寄せで表
示されます。File.Save メニューでは、使われている名前は "&File.&Save<Tab>:w" で
す。そのため、メニュー名は "File.Save" で、ヒントは ":w" です。


セパレータ

関連するメニュー項目をまとめるのに使われるセパレータ行は、'-' で始まり、'-' で
終わる名前を使って定義できます。例えば "-sep-" です。複数のセパレータを使うと
きは、名前は異なっていなければなりません。それ以外では、名前は関係ありません。
   セパレータのコマンドは決して実行されませんが、それでも定義しなければなりま
せん。コロン 1 つで十分です。例:

        :amenu 20.510 Edit.-sep3- :

42.2  メニューコマンド

特定のモードにだけ存在するメニュー項目を定義できます。これは ":map" コマンドの
バリエーションとまったく同じように動作します:

        :menu           ノーマル、ビジュアルおよびオペレータ待機モード
        :nmenu          ノーマルモード
        :vmenu          ビジュアルモード
        :omenu          オペレータ待機モード
        :menu!          挿入およびコマンドラインモード
        :imenu          挿入モード
        :cmenu          コマンドラインモード
        :tlmenu         端末モード
        :amenu          すべてのモード (端末モードを除く)

メニュー項目のコマンドがマップされるのを避けるには、コマンド ":noremenu"、
":nnoremenu"、":anoremenu" などを使います。


:amenu を使う

":amenu" コマンドは少し異なります。これは、与えた {keys} がノーマルモードで実
行されるものと仮定します。メニューが使われたときに Vim がビジュアルモードまた
は挿入モードにある場合、Vim はまずノーマルモードに戻らなければなりません。
":amenu" は CTRL-C または CTRL-O を挿入してくれます。例えば、このコマンドを使
うと:
        :amenu  90.100 Mine.Find\ Word  *

そうすると、結果のメニューコマンドはこうなります:

        ノーマルモード:         *
        ビジュアルモード:               CTRL-C *
        オペレータ待機モード:   CTRL-C *
        挿入モード:             CTRL-O *
        コマンドラインモード:   CTRL-C *

コマンドラインモードのときは、CTRL-C はそれまでにタイプしたコマンドを破棄しま
す。ビジュアルモードおよびオペレータ待機モードでは、CTRL-C はそのモードを止め
ます。挿入モードの CTRL-O は、コマンドを実行してから挿入モードに戻ります。
   CTRL-O は 1 つのコマンドにだけ働きます。2 つ以上のコマンドを使う必要がある
場合は、それらを関数に入れて、その関数を呼び出します。例:

        :amenu  Mine.Next\ File  :call <SID>NextFile()<CR>
        :function <SID>NextFile()
        :  next
        :  1/^Code
        :endfunction

このメニュー項目は、":next" で引数リストの次のファイルに移動します。それから、
"Code" で始まる行を検索します。
   関数名の前の <SID> はスクリプト ID です。これにより、関数はカレントの Vim
script ファイルにローカルになります。これは、同じ名前の関数が別のスクリプトファ
イルで定義されているときの問題を避けます。<SID> を参照してください。


サイレントメニュー

メニューは、{keys} をあなたがタイプしたかのように実行します。":" コマンドの場
合、これはコマンドがコマンドラインにエコーされるのが見えることを意味します。長
いコマンドの場合は、hit-Enter プロンプトが表示されます。これはとても煩わしいこ
とがあります!
   これを避けるには、メニューをサイレントにします。これは <silent> 引数で行い
ます。例えば、前の例の NextFile() の呼び出しを考えます。このメニューを使うと、
コマンドラインにこれが表示されます:

        :call <SNR>34_NextFile()

コマンドラインのこのテキストを避けるには、最初の引数として "<silent>" を挿入し
ます:

        :amenu <silent> Mine.Next\ File :call <SID>NextFile()<CR>

"<silent>" を頻繁に使いすぎないでください。短いコマンドには必要ありません。誰
か他の人のためにメニューを作る場合は、実行されたコマンドが見えることで、その人
はマウスを使う代わりに何をタイプすればよかったかのヒントを得られます。


メニューの一覧表示

メニューコマンドが {keys} の部分なしで使われると、すでに定義されているメニュー
を一覧表示します。特定のメニューを一覧表示するために、{menu-item} またはその一
部を指定できます。例:

        :amenu

これはすべてのメニューを一覧表示します。長いリストです! 短いリストを得るには、
メニューの名前を指定した方がよいです:

        :amenu Edit

これは、すべてのモードの "Edit" メニュー項目だけを一覧表示します。挿入モードの
特定のメニュー項目 1 つだけを一覧表示するには:

        :imenu Edit.Undo

正確に正しい名前をタイプするように注意してください。ここでは大文字小文字が区別
されます。しかし、アクセラレータの '&' は省略できます。<Tab> およびその後に来
るものも省略できます。


メニューの削除

メニューを削除するには、一覧表示と同じコマンドを、"menu" を "unmenu" に変えて
使います。そのため、":menu" は ":unmenu" になり、":nmenu" は ":nunmenu" にな
る、などです。挿入モードの "Tools.Make" 項目を削除するには:

        :iunmenu Tools.Make

メニュー名を使って、メニュー全体をそのすべての項目と一緒に削除できます。例:

        :aunmenu Syntax

これは Syntax メニューおよびその中のすべての項目を削除します。

42.3  その他

'guioptions' のフラグで、メニューの外観を変更できます。デフォルト値では、"M"
を除いてすべて含まれています。このようなコマンドでフラグを取り除けます:

        :set guioptions-=m

        m               取り除くと、メニューバーが表示されません。

        M               追加すると、デフォルトのメニューが読み込まれません。

        g               取り除くと、無効なメニュー項目は灰色にされず、完全に取
                        り除かれます。(すべてのシステムで動作するわけではあり
                        ません。)

        t               取り除くと、切り離し機能は有効になりません。

メニューの一番上の点線はセパレータ行ではありません。この項目を選択すると、メ
ニューは "切り離され" ます: 別のウィンドウに表示されます。これは切り離しメ
ニューと呼ばれます。これは同じメニューを頻繁に使うときに便利です。

メニュー項目の翻訳については、:menutrans を参照してください。

メニュー項目を選択するにはマウスを使わなければならないので、ファイルを選択する
のに ":browse" コマンドを使うのはよい考えです。そして、例えばカレントバッファ
に変更があるときに、エラーメッセージの代わりにダイアログを得るには ":confirm"
です。これらの 2 つは組み合わせられます:

        :amenu File.Open  :browse confirm edit<CR>

":browse" は、編集するファイルを選択するためのファイルブラウザーを表示させま
す。":confirm" は、カレントバッファに変更があるときにダイアログをポップアップ
します。それから、変更を保存するか、破棄するか、またはコマンドを取り消すかを選
択できます。
   もっと複雑な項目には、confirm() および inputdialog() 関数を使えます。デフォ
ルトのメニューにはいくつかの例が含まれています。

42.4  ツールバーおよびポップアップメニュー

2 つの特別なメニューがあります: ToolBar および PopUp です。これらの名前で始ま
る項目は、通常のメニューバーには表示されません。


ツールバー

ツールバーは、'guioptions' オプションに "T" フラグが含まれているときにだけ表示
されます。
   ツールバーは、コマンドを表すのにテキストではなくアイコンを使います。例えば、
"ToolBar.New" という名前の {menu-item} は、ツールバーに "New" アイコンを表示さ
せます。
   Vim エディタには 28 個の組み込みアイコンがあります。その表はここにあります:
builtin-tools。そのほとんどはデフォルトのツールバーで使われています。これら
の項目が何をするかを (デフォルトのメニューが設定された後で) 再定義できます。
   ツールバー項目に別のビットマップを追加できます。または、ビットマップ付きの
新しいツールバー項目を定義できます。例えば、新しいツールバー項目をこれで定義し
ます:

        :tmenu ToolBar.Compile  Compile the current file
        :amenu ToolBar.Compile  :!cc %:S -o %:r:S<CR>

ここでアイコンを作る必要があります。MS-Windows では、それはビットマップ形式で、
名前は "Compile.bmp" でなければなりません。Unix では XPM 形式が使われ、ファイ
ル名は "Compile.xpm" です。サイズは 18 × 18 ピクセルでなければなりません。
MS-Windows では他のサイズも使えますが、見栄えが悪くなります。
   'runtimepath' のディレクトリの 1 つの中の "bitmaps" ディレクトリにビットマッ
プを置きます。例えば、Unix では "~/.vim/bitmaps/Compile.xpm" です。

ツールバーの項目にツールチップを定義できます。ツールチップは、ツールバー項目が
何をするかを説明する短いテキストです。例えば "Open file" です。これは、マウス
ポインタが項目の上にあって、しばらく動かないときに表示されます。これは、絵の意
味がそれほど明らかでない場合にとても便利です。例:

        :tmenu ToolBar.Make  Run make in the current directory

        Note:
        使われている大文字小文字に注意してください。"Toolbar" および "toolbar"
        は "ToolBar" とは異なります!

ツールチップを取り除くには、:tunmenu コマンドを使います。

'toolbar' オプションを使って、ビットマップの代わりにテキストを表示するか、また
はテキストおよびビットマップの両方を表示できます。テキストはかなりの場所を取る
ので、ほとんどの人はビットマップだけを使います。


ポップアップメニュー

ポップアップメニューは、マウスポインタがある場所にポップアップします。
MS-Windows では、マウスの右ボタンをクリックしてそれを有効にします。それから、
マウスの左ボタンで項目を選択できます。Unix では、ポップアップメニューは、マウ
スの右ボタンを押したままにすることで使われます。
   ポップアップメニューは、'mousemodel' が "popup" または "popup_setpos" に設
定されているときにだけ表示されます。2 つの違いは、"popup_setpos" はカーソルを
マウスポインタの位置に移動することです。選択範囲の内側をクリックしたときは、選
択範囲は変更されずに使われます。選択範囲があるが、その外側をクリックしたとき
は、選択範囲は取り除かれます。
   モードごとに別々のポップアップメニューがあります。そのため、通常のメニュー
のような灰色の項目は決してありません。
