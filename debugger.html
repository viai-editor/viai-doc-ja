デバッガサポート機能                                    debugger-support

これらの機能は、デバッガ、または統合プログラミング環境 (IPE) または統合開発環
境 (IDE) と統合するためのものである。Vim の端末ウィンドウで動くデバッガについ
ては terminal-debugger を参照。

1. デバッガ機能                 debugger-features
2. Vim のコンパイルオプション   debugger-compilation

==============================================================================
1. デバッガ機能                                         debugger-features

以下の機能が利用できる:

        代替コマンド入力                                alt-input
        デバッグ目印                                    debug-signs
        デバッグソースハイライト                        debug-highlight
        メッセージフッター                              gui-footer
        バルーン評価                                    balloon-eval

これらの機能は、特に Motif 版の gvim で使うために追加された。ただし、
alt-input および debug-highlight は vim および gvim の両方で使えるように書
かれた。他の機能のいくつかは、少し修正すれば GUI でない vim でも使えるだろう。
ただし、私はそれを行わなかったし、vim または Motif 以外の GUI 版向けにビルドし
た場合の信頼性もテストしなかった。


1.1 代替コマンド入力                                    alt-input

Vim がデバッガと連携するには、少なくともデバッガまたは外部ツールとの入力接続が
なければならない。多くの場合は出力接続もあるが、これは絶対に必要というわけでは
ない。

入力接続の目的は、外部のデバッガが Vim にコマンドを送れるようにすることである。
デバッガが送るコマンドは、現在のデバッグ環境および状態を表示するのに十分な制御
をデバッガに与えるべきである。

現在の実装は、X Toolkit のディスパッチループおよび XtAddInput() 関数の呼び出し
に基づいている。


1.2 デバッグ目印                                        debug-signs

多くのデバッガは、行に小さな目印または色ハイライトを置いて、特定の行に印を付け
る。:sign コマンドを使うと、デバッガがこのグラフィカルな印を設定できる。この
機能が使われる例としては、デバッグ中のプログラムのプログラムカウンタ (PC) を表
す矢印を表示するデバッガがある。別の例としては、ブレークポイントのある行の小さ
な停止目印がある。これらの目に見えるハイライトにより、ユーザーはデバッガの状態
の特定の部分を追跡できる。

この機能はデバッガ以外でも使える。IPE は、ビルドエラー、検索したテキスト、また
はその他のものをハイライトするために目印を使える。目印機能は、
debug-highlight と一緒に使って、印が確実によく目立つようにすることもできる。

デバッグ目印は :sign コマンドを使って定義し、配置する。


1.3 デバッグソースハイライト                            debug-highlight

この機能を使うと、行に優先的なハイライトを付けられる。このハイライトは、特定の
行を目立たせるためのものである。デバッグ目印はほとんどの場合 gvim に限られるの
に対して、このハイライトは vim および gvim の両方で動作するようにできる。これ
の唯一の例外は Sun Microsystem の dtterm である。Sun の dtterm には、目印を表
示するための "sign gutter" がある。


1.4 メッセージフッター                                  gui-footer

メッセージフッターは、デバッガまたは IPE からのメッセージを表示するのに使える。
メニューおよびツールバーのチップを表示するのにも使える。フッター領域は GUI ウィ
ンドウの最下部、コロンコマンドを表示するのに使う行の下にある。

フッターの表示は 'guioptions' の文字 'F' で制御される。


1.5 バルーン評価                                        balloon-eval

この機能を使うと、デバッガ、またはその他の外部ツールが、マウスが指している場所
に基づいた動的な情報を表示できる。この機能の目的は、Sun の Visual WorkShop デ
バッガが式評価を表示できるようにすることだった。ただし、この機能はできるだけ汎
用的な方法で実装されており、他の情報の表示にも使える。ただ、機能は限られてい
る。高度なポップアップについては popup-window を参照。

バルーンを使うもう 1 つの方法は 'balloonexpr' オプションである。これは完全に
ユーザーが定義できる。

バルーン評価には、設定できるパラメータもある。Motif では、フォントリストおよび
色を X リソース (XmNballoonEvalFontList、XmNballoonEvalBackground、および
XmNballoonEvalForeground) で設定できる。
'balloondelay' オプションは、バルーンを表示しようとするまでの遅延を設定する。
有効にするには、'ballooneval' および 'balloonevalterm' の一方または両方のオプ
ションを設定する必要がある。

バルーン評価は、+balloon_eval 機能付きでコンパイルされた場合に、GUI でのみ利
用できる。端末では  +balloon_eval_term 機能が関係する。

バルーン評価の関数は、ツールバーのツールチップを表示するのにも使われる。このた
めには 'ballooneval' オプションを設定する必要はない。ただし、他の設定は適用さ
れる。

==============================================================================
2. Vim のコンパイルオプション                           debugger-compilation

デバッガ機能は、Sun の Visual WorkShop 統合プログラミング環境 (ipe) で使うため
に追加された。ただし、他のデバッガとの統合でもこれらの機能を使えるように、でき
るだけ汎用的な方法で作られた。

以下のコンパイル時のプリプロセッサ変数が、機能を制御する:

    代替コマンド入力                            ALT_X_INPUT
    デバッググリフ                              FEAT_SIGNS
    デバッグハイライト                          FEAT_SIGNS
    メッセージフッター                          FEAT_FOOTER
    バルーン評価                                FEAT_BEVAL

Sun Visual WorkShop に特化したサポートは、製品がもう存在しないので削除された。

Sun NetBeans のサポートについては netbeans を参照。
