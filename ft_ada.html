1. 構文ハイライト
                                                               ft-ada-syntax

このモードは Ada の 2005 年版 ("Ada 2005") 向けに設計されており、これはオブジェ
クト指向プログラミング、protected 型などのサポートを含む。オリジナルの Ada 言
語 ("Ada83"、"Ada87"、"Ada95") 向けに書かれたコードも扱うが、Ada 2005 専用の
キーワードを使うコードは誤って色付けされる (そのようなコードはいずれにせよ修正
すべきである)。Ada についての詳しい情報は、http://www.adapower.com を参照。

Ada モードは多くの状況をきれいに扱う。

例えば、"-5" の中の "-" は数値だが、"A-5" の中の同じ文字は演算子であることを
知っている。通常、他のコンパイル単位を参照する "with" または "use" 節は、C の
"#include" が色付けされるのと同じように色付けされる。"Conditional" または
"Repeat" グループを異なる色にしている場合、"end if" および "end loop" はそれぞ
れのグループの一部として色付けされる。

vim の "highlight" コマンドを使って、これらを異なる色に設定できる (例えば、ルー
プの表示方法を変更するには、コマンド ":hi Repeat" に続けて色指定を入力する; 単
純な端末では色指定 ctermfg=White がよく見えることが多い)。

この Ada モードでは、選択できるオプションがいくつかある。完全な一覧は
ft-ada-options を参照。

それらを有効にするには、オプションに値を代入する。例えば、1 つをオンにするには:

        let g:ada_standard_types = 1

それらを無効にするには ":unlet" を使う。例:
        unlet g:ada_standard_types

Ada ファイルを読み込む前に、単に ":" を使ってこれらをコマンドラインにタイプし、
一時的に設定することができる。"let" コマンドをコロンなしであなたの "~/.vimrc"
ファイルに追加することで、これらのオプション設定を永続的にすることができる。

遅い (90Mhz) PC でもこのモードは速く動作するが、性能が許容できない場合、
g:ada_withuse_ordinary をオンにする。

g:ada_folding が設定されていると、構文折り畳みの指示 (fold-syntax) が追加
される。

2. ファイルタイププラグイン
                                               ft-ada-indent ft-ada-plugin

Ada プラグインは以下のサポートを提供する:

 - 自動インデント       (indent.txt)
 - 挿入補完             (i_CTRL-N)
 - ユーザー補完         (i_CTRL-X_CTRL-U)
 - タグ検索             (tagsrch.txt)
 - Quick Fix            (quickfix.txt)
 - バックスペース処理   ('backspace')
 - コメント処理         ('comments', 'commentstring')

このプラグインは、Ada ファイルが開かれたときにだけ Ada モードの機能を有効にし、
メインおよびポップアップメニューに Ada 関連の項目を追加する。

3. オムニ補完
                                                                 ft-ada-omni

Ada のオムニ補完 (i_CTRL-X_CTRL-O) は、"gnat xref -v" または
"Universal Ctags" (https://ctags.io) のどちらかで作成されたタグデータベースを
使う。補完関数は、タグファイルの作成にどのツールが使われたかを自動的に検出す
る。

------------------------------------------------------------------------------
3.1 "gnat xref" によるオムニ補完
                                                                   gnat-xref

GNAT XREF は、タグファイルを生成するためにコンパイラ内部の情報 (ali ファイル)
を使う。これには、100% 正確であるという利点、および深くネストした解析のオプショ
ンがある。しかし、コードはコンパイルできなければならず、生成器はかなり遅く、作
成されたタグファイルは各エントリについて基本的な Ctags 情報しか含まない - より
高度な Vim コードブラウザープラグインのいくつかには十分ではない。

NOTE: "gnat xref -v" は、診断出力がほとんどないので使うのが非常に厄介である -
       何も表示されない場合、通常はパラメータが間違っている。ここにいくつかの
       重要なヒントがある:

1)  最初にあなたのコードをコンパイルし、"-aO" オプションを使ってあなたの .ali
    ファイルを指す必要がある。
2)  "gnat xref -v ../Include/adacl.ads" は動作しない - 代わりに
    "gnat xref -v -aI../Include adacl.ads" を使う。
3)  "gnat xref -v -aI../Include *.ad?" は動作しない - "cd ../Include" を使い、
    それから "gnat xref -v *.ad?" を使う。
4)  プロジェクトマネージャーのサポートは完全に壊れている -
    "gnat xref -Padacl.gpr" を試すことすらしないこと。
5)  タグファイルがソートされていると Vim はより速い -
    "sort --unique --ignore-case --output=tags tags" を使う。
6)  ファイルをソート済みとしてマークするために、最初の行として
    "!_TAG_FILE_SORTED 2 %sort ui" を挿入することを忘れないこと。

------------------------------------------------------------------------------
3.2 "ctags" によるオムニ補完
                                                                   ada-ctags

Universal/Exuberant Ctags は、独自の多言語コードパーサーを使う。このパーサーは
かなり速く、多くの追加情報を生成し、現在コンパイルできないファイルに対しても実
行できる。

Universal/Exuberant Ctags を使う他の Vim ツールもたくさんある。Universal Ctags
が推奨され、Exuberant Ctags はもう開発されていない。

https://ctags.io から入手可能な Universal Ctags をインストールする必要がある。

Universal/Exuberant Ctags 用の Ada パーサーはかなり新しい - まだ完全なサポート
は期待しないこと。

==============================================================================
4. コンパイラサポート
                                                                ada-compiler

Ada モードは複数の Ada コンパイラをサポートし、Ada ソースが開かれるたびに
g:ada_default_compiler で設定されたコンパイラを自動的に読み込む。提供される
コンパイラプラグインは、実際のコンパイラプラグイン、およびサポート関数および変
数の集まりに分割されている。これにより、あなたの開発環境に合わせて細かく調整さ
れた専用のコンパイラプラグインを容易に開発できる。

------------------------------------------------------------------------------
4.1 GNAT
                                                               compiler-gnat

GNAT は、入手可能な唯一のフリー (ビールおよび言論) な Ada コンパイラである。使
われているライセンス条項が異なるいくつかのバージョンが入手可能である。

GNAT コンパイラプラグインは、<F7> を押すとコンパイルを実行し、すぐに結果を表示
する。使用するプロジェクトファイルは、以下を設定することで設定できる:
                call g:gnat.Set_Project_File ('my_project.gpr')

空白またはシェルの特殊文字を含むプロジェクトファイル名がサポートされている。

プロジェクトファイルを設定すると Vim セッション (views-sessions) も作成され
るので - GPS と同様に - 開いたファイル、ウィンドウ位置などがすべてのプロジェク
トについて別々に記憶される。

4.2 Dec Ada
                                            compiler-hpada compiler-decada
                                        compiler-vaxada compiler-compaqada

Dec Ada (- 年代順に - VAX Ada、Dec Ada、Compaq Ada、および HP Ada としても知ら
れる) は、かなり古い Ada 83 コンパイラである。サポートは基本的なものである:
<F7> で現在のユニットをコンパイルする。

Dec Ada コンパイラは、パラメータとしてファイル名ではなくパッケージ名が渡される
ことを期待する。コンパイラプラグインは、ファイルをユニット名に変換するための通
常のファイル名の規約をサポートしている。区切り文字として '-' および '__' の両
方が許される。

                ウ内に表示する。

                                                        g:decada.Unit_Name()
g:decada.Unit_Name()    関数
                カレントファイルのユニット名を取得する。

                                                       g:decada.Make_Command

5.1 オプション
                                                              ft-ada-options

                                                        g:ada_standard_types
g:ada_standard_types    真偽値 (存在するとき真)
                パッケージ Standard 内の型をハイライトする (例: "Float")。

                                                          g:ada_space_errors
                                                  g:ada_no_trail_space_error
                                                    g:ada_no_tab_space_error
                                                         g:ada_all_tab_usage
g:ada_space_errors       真偽値 (存在するとき真)
                空白内の余分なエラーをハイライトする ...
                g:ada_no_trail_space_error
                    - ただし行末の末尾の空白は無視する
                g:ada_no_tab_space_error
                    - ただしスペースの後のタブは無視する
                g:ada_all_tab_usage
                    - すべてのタブの使用をハイライトする

                                                           g:ada_line_errors
g:ada_line_errors         真偽値 (存在するとき真)
                長すぎる行をハイライトする。Note: このハイライトオプションはか
                なり CPU を消費する。

                                                         g:ada_rainbow_color
g:ada_rainbow_color       真偽値 (存在するとき真)
                '(' および ')' に虹色を使う。これを機能させるには
                rainbow_parenthesis が必要である。

                                                               g:ada_folding
g:ada_folding             集合 ('sigpft')
                Ada ソースに折り畳みを使う。
                    's':    読み込み時に構文折り畳みを有効にする
                        'p':    パッケージを折り畳む
                        'f':    関数およびプロシージャを折り畳む
                        't':    型を折り畳む
                        'c':    条件文を折り畳む
                    'g':    読み込み時に gnat pretty print 折り畳みを有効にする
                        'i':    単独の 'is' を上の行と一緒に折り畳む
                        'b':    単独の 'begin' を上の行と一緒に折り畳む
                        'p':    単独の 'private' を上の行と一緒に折り畳む
                        'x':    単独の 'exception' を上の行と一緒に折り畳む
                    'i':    読み込み時にインデント折り畳みを有効にする

                Note: 構文折り畳みは初期の (使用できない) 段階にあり、インデン
                      トまたは gnat pretty 折り畳みが推奨される。

                gnat pretty 折り畳みを機能させるには、以下の設定が推奨される:
                -cl3 -M79 -c2 -c3 -c4 -A1 -A2 -A3 -A4 -A5

                インデント折り畳みを機能させるには、以下の設定が推奨される:
                shiftwidth=3 softtabstop=3

                                                                g:ada_abbrev
g:ada_abbrev              真偽値 (存在するとき真)
                いくつかの短縮入力を追加する。この機能は、さまざまな補完方法に
                よって多かれ少なかれ取って代わられている。

                                                      g:ada_withuse_ordinary
g:ada_withuse_ordinary    真偽値 (存在するとき真)
                "with" および "use" を通常のキーワードとして表示する (他のコン
                パイル単位を参照するのに使われるとき、それらは通常特別にハイラ
                イトされる)。

                                                         g:ada_begin_preproc
g:ada_begin_preproc       真偽値 (存在するとき真)
                begin のようなすべてのキーワードを、C のプリプロセッサコマンド
                の色付けを使って表示する。

                                                    g:ada_omni_with_keywords
g:ada_omni_with_keywords
                キーワード、プラグマ、属性をオムニ補完 (compl-omni) に追加す
                る。Note: ユーザー補完 (i_CTRL-X_CTRL-U) でいつでもそれらを
                補完できる。

                                                      g:ada_extended_tagging
g:ada_extended_tagging    列挙 ('jump', 'list')
                拡張タグ付けを使う、2 つのオプションが使用可能である
                    'jump': tjump を使ってジャンプする。
                    'list': タグを quick fix リストに追加する。
                C ではこれらの機能が使用可能ではなく、タグ付けはもともと C 向
                けに開発されたので、通常のタグ付けは関数または演算子のオーバー
                ロードをサポートしない。

                                                   g:ada_extended_completion
g:ada_extended_completion
                <C-N> および <C-R> の補完に拡張補完を使う (i_CTRL-N)。この
                モードでは、'Object.Method' または 'Package.Procedure' が一緒
                に補完されるように、'.' が識別子の一部として使われる。

                                                       g:ada_gnat_extensions
g:ada_gnat_extensions     真偽値 (存在するとき真)
                 GNAT 拡張をサポートする。

                                               g:ada_with_gnat_project_files
g:ada_with_gnat_project_files    真偽値 (存在するとき真)
                 gnat プロジェクトファイルのキーワードおよび属性を追加する。

                                                      g:ada_default_compiler
g:ada_default_compiler    文字列
                既定のコンパイラを設定する。現在サポートされているのは 'gnat'
                および 'decada' である。

"exists" 型は、変数が定義されているとき真、変数が未定義のとき偽とみなされる真
偽値である。変数に設定される値は関係ない。

                Ctags を使ってタグファイルを作成する。オプションは、カレント
                ファイルに対する 'file'、カレントファイルのディレクトリに対す
                る 'dir'、またはファイル名のどれかにできる。

gnat#Insert_Tags_Header()                          gnat#Insert_Tags_Header()
                GNAT XREF の出力に欠けているタグファイルヘッダー (!_TAG_) 情報
                をカレントファイルに追加する。

ada#Switch_Syntax_Option ({option})               ada#Switch_Syntax_Option()
                ハイライトオプションをオンまたはオフに切り替える。Ada メニュー
                に使われる。

                                                                  gnat#New()
gnat#New ()
                新しい gnat オブジェクトを作成する。詳細は g:gnat を参照。

6. 追加プラグイン
                                                           ada-extra-plugins

以下の追加プラグインを任意でインストールできる。それらは Ada とうまく連携し、
Ada モードの能力を高める:

backup.vim
        http://www.vim.org/scripts/script.php?script_id=1537
        好きなだけ多くのバックアップを保持するので、あなたがする必要はない。

rainbow_parenthsis.vim
        http://www.vim.org/scripts/script.php?script_id=1561
        Ada は '(' および ')' だけを使うので、非常に役立つ。

nerd_comments.vim
        http://www.vim.org/scripts/script.php?script_id=1218
        ほとんどすべてのプログラミング言語に対する、優れたコメント化およびコメ
        ント解除のサポート。

matchit.vim
        http://www.vim.org/scripts/script.php?script_id=39
        任意の言語に対する '%' ジャンプ。通常の '%' ジャンプは '{}' スタイルの
        言語でだけ機能する。Ada モードは必要な検索パターンを設定する。

taglist.vim
        http://www.vim.org/scripts/script.php?script_id=273
        ソースコードエクスプローラーサイドバー。Ada 用のパッチが入手可能であ
        る。

Vim の GNU Ada Project ディストリビューション (http://gnuada.sourceforge.net)
には、上記のすべてが含まれている。
