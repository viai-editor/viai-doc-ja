Vim 用アラビア語サポート (オプションとマッピング)               Arabic


                                                                E800
右から左およびアラビア語マッピングのサポートを使用するには、Vim を +arabic
機能付きでコンパイルする必要がある。

これらの機能は Nadim Shaikli <nadim-at-arabeyes.org> によって作成された

このファイルは、Vim の GUI でこれらの設定で表示するのが最もよい:

        :set encoding=utf-8
        :set arabicshape


はじめに
--------
アラビア語は、いくつかの特別な機能が必要とされる、かなり要求の多い言語である。
文字は右から左に向かい、画面上でもそのように (つまり右から左に) 表示されるべき
である。
アラビア語はまた、文字のシェーピングを必要とする。これは、同じ文字が単語内での
相対的な位置 (語頭、語中、語末、または独立形) に基づいて異なる視覚的な形を持つ
ことを意味する。アラビア語はまた、2 つの異なる結合の形式、および、特定の場合
に、最大 2 つの文字を別の文字の上に重ねる (合成) か、または実際に 2 つの文字を
1 つに置き換える (結合) 能力を必要とする。最後に、アラビア語を正しく表示するに
は、ISO-8859-6 (U+0600-U+06FF) フォントだけでなく、Presentation Form-B
(U+FE70-U+FEFF) フォントも必要になり、そのどちらもいわゆる ISO-10646-1 フォン
ト内のサブセットである。

コマンド、プロンプト、およびヘルプファイルはアラビア語ではないので、ユーザーイ
ンターフェイスは標準の Vi インターフェイスのままである。


特徴
----
o  元の Vim のように左から右のファイルを編集することは変わっていない。

o  右から左のウィンドウでのファイルの表示および編集。ファイルの向きはウィンド
   ウごとなので、同じファイルを右から左モードおよび左から右モードで同時に表示
   することが可能である。

o  右から左の機能を持つ特別な端末は必要ない。
   右から左の変更は完全にハードウェアに依存しない。
   アラビア語フォントだけが必要である。

o  元の Vim と互換性がある。ほとんど全ての機能が右から左モードで動作する (バグ
   がある可能性がある)。

o  1 つのコマンドを使用したキーボードマッピングおよび逆挿入モードの変更。

o  1 つのコマンドによる完全なアラビア語サポートの切り替え。

o  アラビア語モードでは、数字は左から右に入力される。数字でない文字を入力する
   と、その文字は最後の数字のすぐ左に挿入される。

o  逆挿入モードでのコマンドライン上のアラビア語キーマッピング。

o  Vim が Bidi 対応の端末エミュレータ内で起動された場合、適切な双方向機能が可
   能である。


アラビア語フォント                                      arabicfonts
------------------

Vim は等幅フォントを必要とし、それは世の中にたくさんある。
アラビア語は ISO-8859-6 および Presentation Form-B フォントを必要とする
(Form-B が無いと、アラビア語は _使用できない_)。ユーザーがいわゆる
'ISO-10646-1' フォントを探すことを強く推奨する。
必要なアラビア語フォントの入手先に関するさらなる情報については、インターネット
で検索するか、または www.arabeyes.org を確認すること。


フォントインストール
--------------------

o  X Window システム (Unix/Linux) 用のフォントのインストール

   システムに応じて、your_ARABIC_FONT ファイルを好きなディレクトリにコピーす
   る。アラビア語フォントを含むディレクトリに移動し、以下のコマンドを実行する:

     %  mkfontdir
     %  xset +fp path_name_of_arabic_fonts_directory


使い方
------
Vim 内で実際にアラビア語を使用する前に、いくつかの設定を考慮し、実行する必要が
ある。

o  アラビア語フォントの設定

   +  Vim GUI では、'guifont' を your_ARABIC_FONT に設定する。これは Vim ウィ
      ンドウで以下のコマンドを入力することで行う。

                :set guifont=your_ARABIC_FONT

      NOTE: 文字列 'your_ARABIC_FONT' は、Linux/Unix システムで使われるものに
            似た完全なフォント名を表すために使われる。
            (例: -misc-fixed-medium-r-normal--20-200-75-75-c-100-iso10646-1)

      同じ上記の結果を得るために、'guifont' の set コマンドを .vimrc ファイル
      に追加することができる。言い換えると、':set guifont=your_ARABIC_FONT' を
      .vimrc ファイルに含めることができる。

   +  X Window 環境では、'-fn your_ARABIC_FONT' オプションで Vim を起動するこ
      ともできる。

o  適切な文字エンコーディングの設定
   正しいアラビア語エンコーディングを有効にするには、以下のコマンドを

                :set encoding=utf-8

   .vimrc ファイルに追加する必要がある (Vim ウィンドウに手動でコマンドを入力す
   ることは強く推奨されない)。要するに、':set encoding=utf-8' を .vimrc ファイ
   ルに含めること。

   UTF-8 無しでアラビア語を使用しようとすると、以下の警告メッセージになる、

                                                                W17 
     Arabic requires UTF-8, do ':set encoding=utf-8'

o  アラビア語設定を有効にする [ショートカット]

   物事を単純化および効率化するために、コマンドラインオプションで Vim を起動す
   るか、

     % vim -A my_utf8_arabic_file ...

   または Vim 内で以下のコマンドによって 'arabic' を有効にすることができる

                :set arabic

   上記の 2 つの可能な起動方法は、ユーザーが進めるよう指示される好ましい方法で
   ある。'termbidi' 設定が有効になっていない限り、どちらのコマンドオプションも
   以下を行う:

     1. 適切なキーマップを設定する
     2. 単一の結合ペア文字の削除を有効にする
     3. rightleft    モードを有効にする
     4. rightleftcmd モードを有効にする (コマンドラインに影響する)
     5. arabicshape  モードを有効にする (視覚的な文字の変更を行う)

   また、コマンドを .vimrc ファイルに追加して、単に ':set arabic' をそれに含め
   てもよい。

   以下によってアラビア語サポートを無効にすることもできる

                :set noarabic

   これは、グローバル設定は他の開いている可能性のあるバッファに影響することが
   あるので、それには触れずに、コマンドが有効にしたもの全てをリセットする。
   要するに、'noarabic' コマンドは、

     1. 代替キーマップにリセットする
     2. 単一の結合ペア文字の削除を無効にする
     3. rightleft モードを無効にする

   NOTE: 'arabic' コマンドは、端末からの外部の双方向 (bidi) サポートの可能性の
         ために 'termbidi' を考慮する (例えば "mlterm" はそのようなサポートを
         提供している)。
         'termbidi' は、使用可能な場合、rightleft サポートより優れており、その
         提供のレベルのためにそのサポートが好ましい。
         'termbidi' が有効な場合、'arabic' はキーマップだけを設定する。

         'termbidi' を設定している間の垂直ウィンドウの分離のために、"l" または
         "𝖨" のような LTR の垂直区切りを使用してもよい。それはまた、その色を前
         景色に変更することで隠すこともできる:
                :set fillchars=vert:l
                :hi VertSplit ctermbg=White
        Note これは回避策であり、適切な解決策ではないことに注意。

   一方、冗長かつ明示的にしたく、'arabic' ショートカットコマンドを使用しないこ
   とを選ぶ場合、必要なものは以下である (つまり、':set arabic' を使用する場合、
   この節は飛ばしてよい) -

   +  アラビア語キーマッピングの有効化

      アラビア語キーマップを有効にする (つまり、英語/ラテン文字のキーボードを
      標準のアラビア語キーボードのような見た目と操作感にマップし直す) には、
      'keymap' オプションを "arabic" に設定する。これは

                :set keymap=arabic

      を Vim ウィンドウで入力することで行う。また、'keymap' の set コマンド
      を .vimrc ファイルに追加することもできる。言い換えると、
      ':set keymap=arabic' を .vimrc ファイルに含めることができる。

      キーマッピングをアラビア語とデフォルトマッピング (英語) の間でトグルする
      (または切り替える) には、ユーザーは挿入 (または追加/置換) モードの間に
      'CTRL-^' キーを押すことが推奨される。コマンドラインは、現在のキーマップ
      を示す "Arabic" という文字列を挿入モードの隣に表示する (例: -- INSERT
      Arabic --) ことで、現在のマッピングを表示する。

   +  アラビア語の結合ペア文字の削除

      デフォルトでは、Vim は 'delcombine' オプションが無効になっている。このオ
      プションは、LAM_ALEF (LAA) 結合文字の中の ALEF を削除し、かつ LAM を残す
      ことを可能にする (つまり、結合文字をその本来の 2 文字の形として扱うよう
      に戻る -- これは harakat およびその結合形にも当てはまる)。このオプション
      は

                :set delcombine

      を私たちの Vim ウィンドウで入力することで有効にできる。また、
      'delcombine' の set コマンドを .vimrc ファイルに追加することもできる。言
      い換えると、':set delcombine' を .vimrc ファイルに含めることができる。

   +  アラビア語右から左モード

      デフォルトでは、Vim は左から右モードで起動する。'rightleft' はウィンドウ
      の向きを変更できるようにするコマンドであり、それは以下によって行うことが
      できる、

      - 左から右モードと右から左モードの間の切り替えは、':set rightleft' およ
        び ':set norightleft' によって行う。

      - 左から右モードの間に、コマンドラインで ':set rl' を入力する ('rl' は
        rightleft の短縮形である)。

      - Vim を常に右から左モードで起動するには、':set rl' の行を '.vimrc' ファ
        イルに入れる。

   +  アラビア語右から左コマンドラインモード

      特定のコマンドでは、編集を右から左モードで行うことができる。現在、これは
      検索コマンドにのみ適用できる。

      これは 'rightleftcmd' オプションで制御される。デフォルトは "search" で、
      これは 'rightleft' が設定されたウィンドウでは、検索コマンドを右左モード
      で編集することを意味する。この動作を無効にするには、

                :set rightleftcmd=

      検索コマンドの右左編集を再び有効にするには、

                :set rightleftcmd&

   +  アラビア語シェーピングモード

      アラビア語が要求する、必要な視覚的な文字の変更 (シェーピング、合成、結合)
      を有効にするには、'arabicshape' コマンドを有効にする。これは

                :set arabicshape

      を私たちの Vim ウィンドウで入力することで行う。また、'arabicshape' の
      set コマンドを .vimrc ファイルに追加することもできる。言い換えると、
      ':set arabicshape' を .vimrc ファイルに含めることができる。


キーマップ/キーボード                                   arabickeymap
---------------------

Vim で使用される文字/字のエンコーディングは標準の UTF-8 である。
他のエンコーディングを使用すること、または試みることさえ、広く推奨されない。

Note: UTF-8 は全てを包括するエンコーディングであり、そのため、アラビア語に関し
      て唯一サポートされる (および推奨される) エンコーディングである (他の全て
      の独自エンコーディングは推奨されず、嫌われるべきである)。

o  キーボード

   +  挿入/置換モードの CTRL-^ は、アラビア語/ラテン文字モードを切り替える

   +  キーボードマッピングは Microsoft のアラビア語キーマップ (アラブ世界にお
      ける事実上の標準) に基づいている:

  +---------------------------------------------------------------------+
  |!   |@   |#   |$   |%   |^   |&   |*   |(   |)   |_   |+   ||   |~ ّ |

  +---------------------------------------------------------------------+
       |Q َ |W ً |E ُ |R ٌ |T لإ |Y إ |U ` |I ÷ |O x |P ؛ |{ < |} > |
       |q ض |w ص |e ث |r ق |t ف |y غ |u ع |i ه |o خ |p ح |[ ج |] د |
       +-----------------------------------------------------------+
         |A ِ |S ٍ |D [ |F ] |G لأ |H أ |J ـ |K ، |L / |:   |"   |
         |a ش |s س |d ي |f ب |g ل |h ا |j ت |k ن |l م |; ك |' ط |
         +------------------------------------------------------+
           |Z ~ |X ْ |C { |V } |B لآ |N آ |M ' |< , |> . |? ؟ |
           |z ئ |x ء |c ؤ |v ر |b لا |n ى |m ة |, و |. ز |/ ظ |
           +-------------------------------------------------+

制限
----

o  GUI 形式の Vim は、現在、双方向性 (つまり、同じ行の中でアラビア語およびラテ
   ン文字の両方が混在したものを見る能力) をサポートしていない。


既知のバグ
----------

既知の小さなバグが 1 つある。

 1. LAM (U+0644) の後に haraka (例: Fatha (U+064E)) を挿入し、それから ALEF
    (U+0627) を挿入した場合、挟まれた haraka のために適切な結合が行われず、正
    しく表示されないものになる。

    回避策: LAM と ALEF の組み合わせの間に harakat を含めないこと。
            一般に、harakat および LAM+ALEF 結合文字に関して (両方の文字の後に
            入力されたものでさえ)、正しい視覚的表現を見ることを期待しないこと。
            指摘された問題は厳密に視覚的なものであり、つまり、そのようなファイ
            ルを保存すると、全ての適切な情報/エンコーディングが含まれる - 何も
            失われない。

他に既知のバグは存在しない。
