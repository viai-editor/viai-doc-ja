はじめに                                               ft-hare-intro

このプラグインは、Hare プログラミング言語のための、シンタックスハイライト、イ
ンデント、およびその他のサポート機能を提供する。


ファイルタイププラグイン                               ft-hare-plugin

このプラグインには、動作を調整するために vimrc の中で定義できるいくつかの異
なる変数がある。

                                                        hare-folding
このプラグインは { } ブロックの折り畳みをサポートしている。折り畳みを有効に
するには、after-directory の中のファイル (例: ~/.vim/after/ftplugin/hare.vim)
に以下を追加する:

        setlocal foldmethod=syntax

シンタックスに基づく折り畳みは多くの小さな折り畳みを作りがちなので、
'foldminlines' または 'foldnestmax' など、いくつかの関連するオプションを設定す
ることを検討すること。

                                                hare-symbol-operators
ほとんどの記号の演算子は、デフォルトではハイライトされない ("?"、"!"、および
"::" を除く)。すべての演算子をハイライトしたい場合は、vimrc の中で、それらを
好みのハイライトグループにリンクできる。例:

        hi def link hareCast hareSymbolOperator
        hi def link hareSymbolOperator hareOperator

                                                g:hare_recommended_style
Hare の公式のスタイルガイドに従って、デフォルトで以下のオプションが設定される:


        setlocal noexpandtab
        setlocal shiftwidth=8
        setlocal softtabstop=0
        setlocal tabstop=8
        setlocal textwidth=80

この動作を無効にするには、vimrc に以下を追加する:

        let g:hare_recommended_style = 0

                                                        g:hare_space_error
デフォルトでは、行末の空白、および <Tab> 文字が後に続くスペースは、エラーとし
てハイライトされる。これは挿入モードの間は自動的に無効になる。このハイライトを
完全にオフにするには、vimrc に以下を追加する:

        let g:hare_space_error = 0


Haredoc ファイルタイプ                         ft-haredoc-plugin

このプラグインは、再帰的なディレクトリ検索を使って Hare モジュールの中の
README ファイルを自動的に検出し、それに "haredoc" ファイルタイプを与える。これ
は非常によくあるファイル名なので、このプラグインはデフォルトでは、同じディレク
トリの中の Hare のソースファイルだけを検索する。

                                                        g:filetype_haredoc
g:filetype_haredoc 変数を使うと、この検索の深さを調整するか、または Hare の
ドキュメントファイルの検出をまったく行わないようにできる:

        値              効果
        0               検索は無効
        1               カレントディレクトリだけを検索 (これがデフォルト)
        2               1 階層のサブディレクトリを検索

検索の深さには任意の正の整数を指定できるが、2 より大きい値が目に見える利点をも
たらす可能性は非常に低く、パフォーマンスに影響することがある。


インデント設定                                 ft-hare-indent

他の設定と異なり、インデント設定はバッファごとに設定でき、既存のグローバルな設
定を上書きできる。そうするには、変数に g: の代わりに b: のプリフィックスを
付けるだけでよい。

                g:hare_indent_match_switch b:hare_indent_match_switch
デフォルトでは、"match" および "switch" の条件の継続行は、1 レベルだけインデン
トされる:

        const file = match (os::create(path, 0o644,
                flag::WRONLY | flag::TRUNC)) {
        case let file: io::file =>
                yield file;
        // ...

2 レベルでインデントして、"if" および "for" の条件により近くしたい場合は、
vimrc に以下の行を追加する:

        let g:hare_indent_match_switch = 2

                                g:hare_indent_case b:hare_indent_case
デフォルトでは、"match" および "switch" の case の継続行は、case の本体と見た
目で区別するために 2 レベルでインデントされる:

        case ltok::I8, ltok::I16, ltok::I32,
                        ltok::I64, ltok::INT =>
                // ...

異なるレベルのインデントにしたい場合は、g:hare_indent_case を使って調整でき
る。指定できる値は 0、1、および 2 である。


コンパイラサポート                                     compiler-hare

カレントディレクトリに Makefile が検出された場合、このプラグインはビルドシステ
ムに "make" を使っているとみなし、'makeprg' をそのままにする。それ以外の場合
は、"hare build" が使われる。

                                                g:hare_makeprg_params
"hare build" を使う場合、g:hare_makeprg_params を使って 'makeprg' に追加のコ
ンパイラオプションを付け加えられる。デフォルトは "-q" で、ビルドの際に stdout
への出力を抑止する。
