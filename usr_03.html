03.1  単語単位の移動

カーソルを 1 単語前方に移動するには、"w" コマンドを使います。ほとんどの Vim コ
マンドと同様に、数値のプリフィックスを使って複数の単語を越えて移動できます。例
えば、"3w" は 3 単語移動します。この図は、それがどのように機能するかを示してい
ます ("x" でマークされた位置から開始します):

        This is a line with example text
          x-->-->->----------------->
           w  w  w    3w

すでに単語の先頭にいる場合、"w" は次の単語の先頭に移動することに注意してくださ
い。
   "b" コマンドは、前の単語の先頭へ後方に移動します:

        This is a line with example text
        <----<--<-<---------<--x
           b   b b    2b      b

次の単語の末尾に移動する "e" コマンド、および前の単語の末尾に移動する "ge" も
あります:

        This is a line with example text
           <----<----x---->------------>
           2ge   ge     e       2e

行の最後の単語にいる場合、"w" コマンドは次の行の最初の単語に移動します。した
がって、これを使って段落の中を移動することができ、"l" を使うよりずっと速いで
す。"b" は逆方向に同じことをします。

単語は、"."、"-"、または ")" のような、単語でない文字で終わります。Vim が何を
単語とみなすかを変更するには、'iskeyword' オプションを参照してください。これを
ヘルプの中で直接試す場合、例が機能するためには 'iskeyword' をリセットする必要
があります:
        :set iskeyword&
空白で区切られた WORD 単位で移動することもできます。これは通常の意味での単語で
はないので、大文字が使われています。この図が示すように、WORD 単位で移動するコ
マンドも大文字です:

               ge      b          w                             e
               <-     <-         --->                          --->
        This is-a line, with special/separated/words (and some more).
           <----- <-----         -------------------->         ----->
             gE      B                   W                       E

小文字および大文字のコマンドをこのように組み合わせると、段落の中を素早く前方お
よび後方に移動できます。

03.2  行の先頭または末尾への移動

"$" コマンドは、カーソルを行の末尾に移動します。あなたのキーボードに <End> キー
がある場合、それも同じことをします。

"^" コマンドは、行の最初の空白でない文字に移動します。"0" コマンド (ゼロ) は行
のまさに最初の文字に移動し、<Home> キーも同じことをします。図で示すと ("." は
空白を示します):

                  ^
             <-----------x
        .....This is a line with example text
        <----------------x   x-------------->
                0                  $

(ここでは "....." は空白を示します)

   "$" コマンドは、ほとんどの移動コマンドと同様に、カウントを受け付けます。し
かし、行の末尾に何回も移動することは意味がありません。したがって、それはエディ
タを別の行の末尾に移動させます。例えば、"1$" は最初の行 (今いる行) の末尾に、
"2$" は次の行の末尾に移動し、以下同様です。
   "0" コマンドは、"0" がカウントの一部になってしまうので、カウント引数を受け
付けません。意外なことに、"^" にカウントを付けて使っても何の効果もありません。

03.3  文字への移動

最も便利な移動コマンドの 1 つは、1 文字検索コマンドです。"fx" コマンドは、行の
中で 1 文字の x を前方に検索します。ヒント: "f" は "Find" を表します。
   例えば、以下の行の先頭にいます。human の h に移動したいとします。"fh" コマ
ンドを実行するだけで、カーソルは h の上に置かれます:

        To err is human.  To really foul up you need a computer.
        ---------->--------------->
            fh           fy

これは、"fy" コマンドが単語 really の末尾に移動することも示しています。
   カウントを指定できます。したがって、"3fl" で "foul" の "l" に移動できます:

        To err is human.  To really foul up you need a computer.
                  --------------------->
                           3fl

"F" コマンドは左に向かって検索します:

        To err is human.  To really foul up you need a computer.
                  <---------------------
                            Fh

"tx" コマンドは、検索した文字の 1 文字手前で止まることを除いて、"fx" コマンド
のように機能します。ヒント: "t" は "To" を表します。このコマンドの後方版は
"Tx" です。

        To err is human.  To really foul up you need a computer.
                   <------------  ------------->
                        Th              tn

これら 4 つのコマンドは ";" で繰り返すことができます。"," は逆方向に繰り返しま
す。カーソルが別の行に移動することは決してありません。文が続いているときでもで
す。

検索を開始してから、間違ったコマンドをタイプしたことに気付くことがあるでしょ
う。例えば、後方に検索するために "f" をタイプしてから、本当は "F" のつもりだっ
たことに気付きます。検索を中止するには、<Esc> を押します。したがって、"f<Esc>"
は中止された前方検索であり、何もしません。Note: <Esc> は、検索だけでなく、ほと
んどの操作をキャンセルします。

03.4  対応する括弧

プログラムを書いていると、入れ子になった () の構造ができることがよくあります。
そのとき、"%" コマンドがとても便利です: それは対応する括弧に移動します。カーソ
ルが "(" の上にある場合、対応する ")" に移動します。")" の上にある場合、対応す
る "(" に移動します。

                            %
                         <----->
                if (a == (b * c) / d)
                   <---------------->
                            %

これは [] および {} のペアでも機能します。(これは 'matchpairs' オプションで定
義できます。)

カーソルが有用な文字の上にないとき、"%" は前方を検索してそれを見つけます。した
がって、カーソルが前の例の行の先頭にある場合、"%" は前方を検索して最初の "("
を見つけます。それから、それに対応するものに移動します:

                if (a == (b * c) / d)
                ---+---------------->
                           %

コードの中を移動する他の方法は usr_29.txt にあります。

03.5  特定の行への移動

C または C++ のプログラマの場合、以下のようなエラーメッセージに見覚えがあるで
しょう:

        prog.c:33: j   undeclared (first use in this function)

これは、33 行目の何かを修正したほうがよいかもしれないことを伝えています。では、
どうやって 33 行目を見つけるのでしょうか? 1 つの方法は、"9999k" を実行してファ
イルの先頭に行き、"32j" で 32 行下に移動することです。良い方法ではありません
が、機能します。もっとずっと良い方法は、"G" コマンドを使うことです。カウントを
付けると、このコマンドは指定された行番号に移動します。例えば、"33G" は 33 行目
に移動します。(コンパイラのエラーリストをたどるより良い方法については、
usr_30.txt の :make コマンドについての情報を参照してください。)
   引数なしでは、"G" はファイルの末尾に移動します。ファイルの先頭に行く素早い
方法は "gg" を使うことです。"1G" も同じことをしますが、ほんの少しタイプが多く
なります。

            |   first line of a file   ^
            |   text text text text    |
            |   text text text text    |  gg
        7G  |   text text text text    |
            |   text text text text
            |   text text text text
            V   text text text text    |
                text text text text    |  G
                text text text text    |
                last line of a file    V

行に移動する別の方法は、"%" コマンドにカウントを付けて使うことです。例えば、
"50%" はファイルの中ほどに移動します。"90%" は末尾近くに移動します。

前述のことは、ファイル内の行に、それが現在見えているかどうかに関係なく移動した
いことを前提としています。見えている行の 1 つに移動したい場合はどうでしょうか?
この図は、使用できる 3 つのコマンドを示しています:

                        +---------------------------+
                H -->   | text sample text          |
                        | sample text               |
                        | text sample text          |
                        | sample text               |
                M -->   | text sample text          |
                        | sample text               |
                        | text sample text          |
                        | sample text               |
                L -->   | text sample text          |
                        +---------------------------+

ヒント: "H" は Home、"M" は Middle、および "L" は Last を表します。あるいは、
"H" は High、"M" は Middle、および "L" は Low を表します。

03.6  どこにいるかを知る

ファイルの中のどこにいるかを知るには、3 つの方法があります:

1.  CTRL-G コマンドを使います。次のようなメッセージが表示されます ('ruler' オ
    プションがオフであると仮定します):

        "usr_03.txt" line 233 of 650 --35%-- col 45-52

    これは、編集しているファイルの名前、カーソルのある行番号、総行数、ファイル
    全体の中での割合、およびカーソルのカラムを表示します。
       時々、分割されたカラム番号が表示されます。例えば、"col 2-9" です。これ
    は、カーソルが 2 番目の文字の上にあることを示していますが、1 番目の文字が
    タブで、8 個分のスペースのカラムを占めているので、画面上のカラムは 9 です。

2.  'number' オプションを設定します。これにより、すべての行の前に行番号が表示
    されます:

        :set number

    これを再びオフにするには:

        :set nonumber

    'number' は切替オプションなので、その名前の前に "no" を付けると、それをオ
    フにする効果があります。切替オプションは、この 2 つの値しか持たず、オンま
    たはオフのどちらかです。
       Vim にはたくさんのオプションがあります。切替オプションの他に、数値の値
    を持つオプションおよび文字列オプションがあります。これらの例は、それらが使
    われるところで見ることになるでしょう。

3.  'ruler' オプションを設定します。これにより、Vim ウィンドウの右下隅にカーソ
    ル位置が表示されます:

        :set ruler

'ruler' オプションを使うことには、あまり場所を取らないので、あなたのテキストの
ためのスペースが多くなるという利点があります。

03.7  あちこちスクロールする

CTRL-U コマンドは、テキストを半画面下にスクロールします。表示用の窓を通してテ
キストを見ていて、この窓をウィンドウの高さの半分だけ上に動かすことを考えてくだ
さい。したがって、窓はテキストの上を上に移動し、これはファイルの中では後方で
す。どちらが上なのかを覚えるのに少し苦労する場合でも、心配しないでください。ほ
とんどのユーザーが同じ問題を抱えています。
   CTRL-D コマンドは、表示用の窓をファイルの中で半画面下に動かし、したがってテ
キストを半画面上にスクロールします。

                                       +----------------+
                                       | some text      |
                                       | some text      |
                                       | some text      |
        +---------------+              | some text      |
        | some text     |  CTRL-U  --> |                |
        |               |              | 123456         |
        | 123456        |              +----------------+
        | 7890          |
        |               |              +----------------+
        | example       |  CTRL-D -->  | 7890           |
        +---------------+              |                |
                                       | example        |
                                       | example        |
                                       | example        |
                                       | example        |
                                       +----------------+

1 行ずつスクロールするには、CTRL-E (上にスクロール) および CTRL-Y (下にスクロー
ル) を使います。CTRL-E は、1 行 Extra をくれるものと考えてください。
(MS-Windows 互換のキーマッピングを使っている場合、CTRL-Y はスクロールする代わ
りに変更を redo します。)

画面全体 (2 行を除く) 分前方にスクロールするには、CTRL-F を使います。後方にス
クロールするには、CTRL-B を使います。これらは覚えやすいはずです: F は
Forwards、および B は Backwards です。

よくある問題は、"j" で何行も下に移動した後、あなたのカーソルが画面の一番下にあ
ることです。カーソルのある行のコンテキストを見たいでしょう。それは "zz" コマン
ドで行います。

        +------------------+             +------------------+
        | earlier text     |             | earlier text     |
        | earlier text     |             | earlier text     |
        | earlier text     |             | earlier text     |
        | earlier text     |   zz  -->   | line with cursor |
        | earlier text     |             | later text       |
        | earlier text     |             | later text       |
        | line with cursor |             | later text       |
        +------------------+             +------------------+

"zt" コマンドはカーソル行を一番上に置き、"zb" は一番下に置きます。スクロールコ
マンドは他にもいくつかあります。Q_sc を参照してください。カーソルの周りに常
に数行のコンテキストを保つには、'scrolloff' オプションを使います。

03.8  簡単な検索

文字列を検索するには、"/string" コマンドを使います。例えば、単語 include を見
つけるには、このコマンドを使います:

        /include

"/" をタイプすると、コロンコマンドと同様に、カーソルが Vim ウィンドウの最終行
にジャンプすることに気付くでしょう。そこで単語をタイプします。修正するには、
バックスペースキー (後ろ向きの矢印または <BS>) を押すことができます。必要なと
きは、<Left> および <Right> カーソルキーを使います。
   <Enter> を押すと、コマンドが実行されます。

        Note:
        文字 .*[]^%/\?~$ には特別な意味があります。検索でそれらを使いたい場合、
        それらの前に \ を置かなければなりません。以下を参照してください。

同じ文字列の次の出現を見つけるには、"n" コマンドを使います。カーソルの後の最初
の #include を見つけるには、これを使います:

        /#include

そして、"n" を何回かタイプします。テキスト内の各 #include に移動します。どの
マッチが欲しいか分かっている場合、カウントを使うこともできます。したがって、
"3n" は 3 番目のマッチを見つけます。"/" にカウントを使うこともできます:
"4/the" は "the" の 4 番目のマッチに移動します。

"?" コマンドは "/" のように機能しますが、後方に検索します:

        ?word

"N" コマンドは、最後の検索を逆方向に繰り返します。したがって、"/" コマンドの後
に "N" を使うと後方に検索し、"?" の後に "N" を使うと前方に検索します。


大文字小文字を無視する

通常は、見つけたいものを正確にタイプしなければなりません。単語の大文字または小
文字を気にしない場合、'ignorecase' オプションを設定します:

        :set ignorecase

ここで "word" を検索すると、"Word" および "WORD" にもマッチします。再び大文字
小文字を一致させるには:

        :set noignorecase


履歴

3 回検索をしたとします:

        /one
        /two
        /three

では、<Enter> を押さずに単純な "/" をタイプして検索を始めてみましょう。<Up>
(カーソルキー) を押すと、Vim はコマンドラインに "/three" を置きます。この時点
で <Enter> を押すと、three を検索します。<Enter> を押さずに、代わりに <Up> を
押した場合、Vim はプロンプトを "/two" に変更します。もう 1 回 <Up> を押すと、
"/one" に移動します。
   <Down> カーソルキーを使って、検索コマンドの履歴を逆方向に移動することもでき
ます。

以前に使ったパターンが何で始まるかを知っていて、それを再び使いたい場合、<Up>
を押す前にその文字をタイプします。前の例では、"/o<Up>" とタイプすると、Vim は
コマンドラインに "/one" を置きます。

":" で始まるコマンドにも履歴があります。これにより、以前のコマンドを呼び戻し
て、再び実行することができます。この 2 つの履歴は別々です。


テキスト中の単語を検索する

テキストの中に単語 "TheLongFunctionName" があり、その次の出現を見つけたいとし
ます。"/TheLongFunctionName" とタイプすることもできますが、それはタイプ量が多
いです。そして、間違えると Vim はそれを見つけられません。
   もっと簡単な方法があります: カーソルを単語の上に置いて、"*" コマンドを使い
ます。Vim はカーソルの下の単語をつかみ、それを検索文字列として使います。
   "#" コマンドは、逆方向に同じことをします。カウントを前に付けることができま
す: "3*" は、カーソルの下の単語の 3 番目の出現を検索します。


単語全体を検索する

"/the" とタイプすると、"there" にもマッチします。"the" で終わる単語だけを見つ
けるには、以下を使います:

        /the\>

"\>" という項目は、単語の末尾にだけマッチする特別なマーカーです。同様に、"\<"
は単語の先頭にだけマッチします。したがって、単語 "the" だけを検索するには:

        /\<the\>

これは "there" または "soothe" にはマッチしません。"*" および "#" コマンドは、
単語全体だけを見つけるために、これらの単語の先頭および単語の末尾のマーカーを使
うことに注意してください (部分的な単語にマッチさせるには、"g*" および "g#" を
使えます)。


マッチをハイライトする

プログラムを編集していて、"nr" という変数を見かけます。それがどこで使われてい
るかを確認したいです。カーソルを "nr" に移動して "*" コマンドを使い、"n" を押
してすべてのマッチをたどることもできます。
   別の方法があります。このコマンドをタイプします:

        :set hlsearch

ここで "nr" を検索すると、Vim はすべてのマッチをハイライトします。これは、コマ
ンドをタイプする必要なしに、変数がどこで使われているかを見るのにとても良い方法
です。
   これをオフにするには:

        :set nohlsearch

そうすると、次の検索コマンドでそれを使いたい場合、再びオンにする必要がありま
す。ハイライトを取り除きたいだけの場合、このコマンドを使います:

        :nohlsearch

これはオプションをリセットしません。代わりに、ハイライトを無効にします。検索コ
マンドを実行するとすぐに、ハイライトが再び使われます。"n" および "N" コマンド
でもです。


検索を調整する

検索の動作を変更するオプションがいくつかあります。これらが必須のものです:

        :set incsearch

これにより、文字列をまだタイプしている間に、Vim がその文字列のマッチを表示しま
す。正しいマッチが見つかるかどうかを確認するために、これを使います。それから、
<Enter> を押して実際にその場所にジャンプします。または、さらにタイプして検索文
字列を変更します。

        :set nowrapscan

これは、ファイルの末尾で検索を止めます。または、後方に検索しているときは、ファ
イルの先頭で検索を止めます。'wrapscan' オプションは既定でオンなので、検索はファ
イルの末尾で折り返します。


間奏

前に述べたオプションの 1 つが気に入って、Vim を使うたびにそれを設定する場合、
そのコマンドをあなたの Vim の起動ファイルに入れることができます。
   not-compatible で述べたように、そのファイルを編集します。または、それがど
こにあるかを調べるために、このコマンドを使います:

        :scriptnames

例えば以下で、ファイルを編集します:

        :edit ~/.vimrc

それから、Vim でタイプしたのとまったく同じように、オプションを設定するコマンド
を含む行を追加します。例:

        Go:set hlsearch<Esc>

"G" はファイルの末尾に移動します。"o" は新しい行を開始し、そこで ":set" コマン
ドをタイプします。<Esc> で挿入モードを終了します。それから、ファイルを書き込ん
で閉じます:

        ZZ

ここで Vim を再び起動する場合、'hlsearch' オプションはすでに設定されています。

03.9  簡単な検索パターン

Vim エディタは、何を検索するかを指定するのに正規表現を使います。正規表現は、検
索パターンを指定するための、非常に強力で、かつ簡潔な方法です。残念ながら、正規
表現は指定するのが少し難しいので、この力には代償が伴います。
   このセクションでは、必須のものをいくつかだけ述べます。検索パターンおよびコ
マンドについての詳細は、第 27 章 usr_27.txt にあります。完全な説明はここにあ
ります: pattern。


行の先頭と末尾

^ 文字は行の先頭にマッチします。English-US キーボードでは、それは 6 の上にあり
ます。パターン "include" は、行のどこにある単語 include にもマッチします。しか
し、パターン "^include" は、単語 include が行の先頭にある場合だけマッチします。
   $ 文字は行の末尾にマッチします。したがって、"was$" は、単語 was が行の末尾
にある場合だけマッチします。

この例の行で "/the" がマッチする場所を "x" でマークしてみましょう:

        the solder holding one of the chips melted and the
        xxx                       xxx                  xxx

"/the$" を使うと、このマッチが見つかります:

        the solder holding one of the chips melted and the
                                                       xxx

"/^the" ではこれが見つかります:
        the solder holding one of the chips melted and the
        xxx

"/^the$" で検索してみることができます。これは、"the" だけからなる 1 行にだけ
マッチします。ここでは空白が問題になるので、行が "the " のように単語の後に空白
を含んでいる場合、パターンはマッチしません。


任意の 1 文字にマッチする

. (ドット) 文字は、存在する任意の文字にマッチします。例えば、パターン "c.m"
は、最初の文字が c で、2 番目の文字が何でもよく、3 番目の文字が m である文字列
にマッチします。例:

        We use a computer that became the cummin winter.
                 xxx             xxx      xxx


特殊文字にマッチする

本当にドットにマッチさせたい場合、その前にバックスラッシュを置くことで、その特
別な意味を回避しなければなりません。
   "ter." を検索すると、これらのマッチが見つかります:

        We use a computer that became the cummin winter.
                      xxxx                          xxxx

"ter\." を検索すると、2 番目のマッチだけが見つかります。

03.10 マークを使う

"G" コマンドである位置にジャンプすると、Vim はこのジャンプの前の位置を記憶しま
す。この位置はマークと呼ばれます。元いた場所に戻るには、このコマンドを使います:


        ``

この ` は、バックティックまたは開きシングルクォート文字です。
   同じコマンドをもう 1 回使うと、再び戻ってジャンプします。これは、"`" コマン
ド自体がジャンプであり、このジャンプの前の位置が記憶されるからです。

一般的に、同じ行の中よりも遠くにカーソルを移動できるコマンドを実行するたびに、
これはジャンプと呼ばれます。これには、検索コマンド "/" および "n" が含まれます
(マッチがどれだけ離れているかは関係ありません)。しかし、"fx" および "tx" によ
る文字検索、または単語移動 "w" および "e" は含まれません。
   また、"j" および "k" は、カウントを使ってカーソルをかなり遠くまで移動させる
ときでも、ジャンプとはみなされません。

"``" コマンドは、2 つの地点の間を行ったり来たりジャンプします。CTRL-O コマンド
は、より古い位置にジャンプします (ヒント: older の O)。そして CTRL-I は、より
新しい位置に戻ってジャンプします (ヒント: 多くの一般的なキーボードレイアウトで
は、I は O のすぐ隣にあります)。このコマンドの並びを考えてみてください:

        33G
        /^The
        CTRL-O

まず 33 行目にジャンプし、それから "The" で始まる行を検索します。それから、
CTRL-O で 33 行目に戻ってジャンプします。もう 1 回 CTRL-O を使うと、開始した場
所に戻ります。ここで CTRL-I を使うと、再び 33 行目にジャンプします。そして、も
う 1 回 CTRL-I を使うと、"The" のマッチにジャンプします。


             |  example text   ^             |
        33G  |  example text   |  CTRL-O     | CTRL-I
             |  example text   |             |
             V  line 33 text   ^             V
             |  example text   |             |
       /^The |  example text   |  CTRL-O     | CTRL-I
             V  There you are  |             V
                example text

        Note:
        CTRL-I は <Tab> と同じです。

":jumps" コマンドは、ジャンプした位置のリストを表示します。最後に使ったエント
リは ">" でマークされます。


名前付きマーク                                         bookmark

Vim では、テキストの中にあなた自身のマークを置くことができます。"ma" コマンド
は、カーソルの下の場所をマーク a としてマークします。あなたのテキストには 26
個のマーク (a から z) を置くことができます。それらは見えません。それは Vim が
記憶している単なる位置です。
   マークに移動するには、コマンド `{mark} を使います。ここで {mark} はマークの
文字です。したがって、マーク a に移動するには:

        `a

"'mark" コマンド (シングルクォーテーションマーク、またはアポストロフィ) は、
マークを含む行の先頭に移動します。これは、マークされたカラムにも移動する
"`mark" コマンドとは異なります。

マークは、ファイル内の関連する 2 つの部分で作業するときにとても便利です。ファ
イルの末尾近くのテキストで作業している間に、ファイルの先頭近くにある見る必要の
あるテキストがあるとします。
   先頭のテキストに移動し、そこに s (start) マークを置きます:

        ms

それから、作業したいテキストに移動し、そこに e (end) マークを置きます:

        me

これで、あちこち移動でき、ファイルの先頭を見たいときは、これを使ってそこにジャ
ンプします:

        's

それから、'' を使って元いた場所に戻ってジャンプするか、または 'e を使って末尾
で作業していたテキストにジャンプできます。
   s を start に、e を end に使うことに特別なことは何もありません。それらは単
に覚えやすいだけです。

このコマンドを使って、マークのリストを得ることができます:

        :marks

いくつかの特別なマークに気付くでしょう。これらには以下が含まれます:

        '       ジャンプする前のカーソル位置
        "       最後にファイルを編集していたときのカーソル位置
        [       最後の変更の開始
        ]       最後の変更の終了
