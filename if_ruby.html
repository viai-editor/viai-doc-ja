1. コマンド                                             ruby-commands

                                                        :ruby :rub
:rub[y] {cmd}           Ruby コマンド {cmd} を実行する。試してみるためのコマン
                        ド:
                                :ruby print "Hello"

:rub[y] << [trim] [{endmarker}]
{script}
{endmarker}
                        Ruby スクリプト {script} を実行する。

                        [endmarker] が省略された場合、:append および
                        :insert コマンドと同様に、デフォルトはドット '.' に
                        なる。さらなる情報については :let-heredoc を参照。


                        この形式の :ruby コマンドは、主に vim script に ruby
                        コードを含めるのに便利である。

                        Note: このコマンドは、Ruby 機能がコンパイルに含まれて
                        いない場合は動作しない。エラーを避けるには、
                        script-here を参照。

Vim script の例:

        function! RedGem()
        ruby << EOF
        class Garnet
                def initialize(s)
                        @buffer = Vim::Buffer.current
                        vimputs(s)
                end
                def vimputs(s)
                        @buffer.append(@buffer.count,s)
                end
        end
        gem = Garnet.new("pretty")
        EOF
        endfunction

どのバージョンの Ruby を持っているかを見るには:
        :ruby print RUBY_VERSION


                                                :rubydo :rubyd E265
:[range]rubyd[o] {cmd}  [range] 内の各行に対して、$_ に各行のテキストを末尾の
                        <EOL> なしで順に設定しながら、Ruby コマンド {cmd} を評
                        価する。$_ を設定するとテキストが変更されるが、このコ
                        マンドを使って行を追加または削除することはできないこと
                        に注意。
                        [range] のデフォルトはファイル全体: "1,$"。

                                                        :rubyfile :rubyf
:rubyf[ile] {file}      {file} 内の Ruby スクリプトを実行する。これは
                        :ruby load 'file' と同じだが、ファイル名補完を可能に
                        する。

sandbox の中では Ruby コマンドを実行することはできない。

2. Vim モジュール                                       ruby-vim

Ruby コードは、vim へのすべてのアクセスを "Vim" モジュール経由で得る。

概要:
        print "Hello"                         # メッセージを表示する
        Vim.command(cmd)                      # Ex コマンドを実行する
        num = Vim::Window.count               # ウィンドウの数を取得する
        w = Vim::Window[n]                    # ウィンドウ "n" を取得する
        cw = Vim::Window.current              # カレントウィンドウを取得する
        num = Vim::Buffer.count               # バッファの数を取得する
        b = Vim::Buffer[n]                    # バッファ "n" を取得する
        cb = Vim::Buffer.current              # カレントバッファを取得する
        w.height = lines                      # ウィンドウの高さを設定する
        w.cursor = [row, col]                 # ウィンドウのカーソル位置を
                                              # 設定する
        pos = w.cursor                        # 配列 [row, col] を取得する
        name = b.name                         # バッファのファイル名を取得する
        line = b[n]                           # バッファから行を取得する
        num = b.count                         # 行数を取得する
        b[n] = str                            # バッファに行を設定する
        b.delete(n)                           # 行を削除する
        b.append(n, str)                      # n の後に行を追加する
        line = Vim::Buffer.current.line       # カレント行を取得する
        num = Vim::Buffer.current.line_number # カレント行番号を取得する
        Vim::Buffer.current.line = "test"     # カレント行番号を設定する


モジュール関数:

                                                        ruby-message
Vim::message({msg})
        メッセージ {msg} を表示する。

                                                        ruby-blob
Vim::blob({arg})
        {arg} から Blob リテラル文字列を返す。

                                                        ruby-set_option
Vim::set_option({arg})
        vim オプションを設定する。{arg} は ":set" コマンドが受け付ける任意の引
        数にできる。Note これは引数の中で空白が許されないことを意味することに
        注意! :set を参照。

                                                        ruby-command
Vim::command({cmd})
        Ex コマンド {cmd} を実行する。

                                                        ruby-evaluate
Vim::evaluate({expr})
        vim の内部の式評価器を使って {expr} を評価する (expression を参照)。
        式の結果を次として返す:
        - Vim の式が数値に評価される場合は Integer
        - Vim の式が浮動小数点数に評価される場合は Float
        - Vim の式が文字列に評価される場合は String
        - Vim の式が Vim のリストに評価される場合は Array
        - Vim の式が Vim の辞書に評価される場合は Hash
        辞書およびリストは再帰的に展開される。

3. Vim::Buffer オブジェクト                             ruby-buffer

Vim::Buffer オブジェクトは vim のバッファを表す。

クラスメソッド:

current         カレントバッファオブジェクトを返す。
count           バッファの数を返す。
self[{n}]       番号 {n} のバッファオブジェクトを返す。最初の番号は 0 である。

メソッド:

name            バッファの完全な名前を返す。
number          バッファの番号を返す。
count           行数を返す。
length          行数を返す。
self[{n}]       バッファから行を返す。{n} は行番号である。
self[{n}] = {str}
                バッファの行を設定する。{n} は行番号である。
delete({n})     バッファから行を削除する。{n} は行番号である。
append({n}, {str})
                行 {n} の後に行を追加する。
line            バッファがアクティブな場合、バッファのカレント行を返す。
line = {str}    バッファがアクティブな場合、バッファのカレント行を設定する。
line_number     バッファがアクティブな場合、カレント行の番号を返す。

==============================================================================
4. Vim::Window オブジェクト                             ruby-window

Vim::Window オブジェクトは vim のウィンドウを表す。

クラスメソッド:

current         カレントウィンドウオブジェクトを返す。
count           ウィンドウの数を返す。
self[{n}]       番号 {n} のウィンドウオブジェクトを返す。最初の番号は 0 であ
                る。

メソッド:

buffer          ウィンドウに表示されているバッファを返す。
height          ウィンドウの高さを返す。
height = {n}    ウィンドウの高さを {n} に設定する。
width           ウィンドウの幅を返す。
width = {n}     ウィンドウの幅を {n} に設定する。
cursor          カーソル位置の [row, col] 配列を返す。
                最初の行番号は 1 で、最初の桁番号は 0 である。
cursor = [{row}, {col}]
                カーソル位置を {row} および {col} に設定する。

$curbuf         カレントバッファオブジェクト。

6. rubyeval() Vim 関数                                  ruby-rubyeval

双方向インターフェイスを容易にするため、rubyeval() 関数を使って Ruby の式を
評価し、その値を Vim script に渡すことができる。

Ruby の値 "true"、"false" および "nil" は、それぞれ v:true、v:false および
v:null に変換される。

7. 動的ロード                                           ruby-dynamic

MS-Windows および Unix では、Ruby ライブラリを動的にロードできる。そのとき、
:version の出力に +ruby/dyn が含まれる。

これは、Vim が必要なときにだけ Ruby の DLL ファイルまたは共有ライブラリを検索
することを意味する。Ruby インターフェイスを使わない場合はそれは必要ないので、
このライブラリファイルがシステムに無くても Vim を使うことができる。


MS-Windows

これを動作させるには、正しいバージョンの Ruby をインストールする必要がある。ダ
ウンロードするパッケージは以下から見つけられる:
http://rubyinstaller.org/downloads/
現在それは rubyinstaller-2.2.5.exe である

Ruby インターフェイスを使うには、Ruby の DLL が検索パス内に無ければならない。
コンソールウィンドウで "path" とタイプすると、どのディレクトリが使われるかを見
ることができる。'rubydll' オプションを使って Ruby の DLL を指定することもでき
る。

DLL の名前は、Vim がコンパイルされたときの Ruby のバージョンと一致しなければな
らない。現在その名前は "msvcrt-ruby220.dll" である。これは Ruby 2.2.X 用であ
る。確実に知るには、"gviai.exe" を編集して "ruby\d*.dll\c" を検索する。

RubyInstaller 1.9 または 2.X を使って MSVC で Vim をビルドしたい場合は、いくつ
かのトリックが必要である。詳細は src/INSTALLpc.txt を参照。

Vim が RubyInstaller 2.4 以降でビルドされている場合、環境変数 PATH に
"C:\Ruby<version>\bin\ruby_builtin_dlls" を追加する必要があるかもしれない。


Unix

'rubydll' オプションを使って、コンパイル時に指定された DYNAMIC_RUBY_DLL ファイ
ルの代わりに、Ruby の共有ライブラリファイルを指定できる。共有ライブラリのバー
ジョンは、Vim がコンパイルされたときの Ruby のバージョンと一致しなければならな
い。
