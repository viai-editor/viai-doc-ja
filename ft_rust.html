はじめに                                       rust-intro

このプラグインは、Rust ファイルタイプのためのシンタックスおよびサポート機能を
提供する。

設定                                           rust-settings

このプラグインには、あなたの vimrc で定義してプラグインの動作を変更できる変数
がいくつかある。

一部の変数はバッファローカル (b: プリフィックス) に設定でき、バッファローカ
ルのものはグローバルの g: の対応物よりも優先される。

                                                g:rustc_path
g:rustc_path
        このオプションに、:RustRun および :RustExpand コマンドで使う rustc
        へのパスを設定する。設定されていない場合、"rustc" は $PATH 内から探さ
        れる:
                let g:rustc_path = $HOME."/bin/rustc"

                                                g:rustc_makeprg_no_percent
g:rustc_makeprg_no_percent
        'makeprg' の既定値を "rustc %" ではなく "rustc" にするには、このオプ
        ションを 1 に設定する:
                let g:rustc_makeprg_no_percent = 1

                                                g:rust_conceal
g:rust_conceal
        基本的な conceal サポートを有効にするには、このオプションを設定する:

                let g:rust_conceal = 1

                                                g:rust_conceal_mod_path
g:rust_conceal_mod_path
        パスを連結するトークン "::" に対して conceal を有効にするには、この
        オプションを設定する:
                let g:rust_conceal_mod_path = 1

                                                g:rust_conceal_pub
g:rust_conceal_pub
        "pub" トークンに対して conceal を有効にするには、このオプションを設
        定する:
                let g:rust_conceal_pub = 1

                                                g:rust_recommended_style
g:rust_recommended_style
        このオプションを設定すると、Rust スタイルガイドのスタイル規約に従うた
        めの vim のインデントおよびテキスト幅の設定が有効になる (つまり、イン
        デントに 4 つの空白を使い、'textwidth' を 100 に設定する)。このオプショ
        ンは既定で有効である。無効にするには:
                let g:rust_recommended_style = 0

                                                g:rust_fold
g:rust_fold
        folding を有効にするには、このオプションを設定する:
                let g:rust_fold = 1

        値      効果
        0       折り畳みなし
        1       中括弧ブロックが折り畳まれる。既定ではすべての折り畳みが開いて
                いる。
        2       中括弧ブロックが折り畳まれる。'foldlevel' はグローバル値のまま
                になる (既定ではすべての折り畳みが閉じている)。

                                                g:rust_bang_comment_leader
g:rust_bang_comment_leader
        /*! 構文を使う複数行の doc コメントでリーダーを保持するには、このオプ
        ションを 1 に設定する:
                let g:rust_bang_comment_leader = 1

                                                g:rust_use_custom_ctags_defs
g:rust_use_custom_ctags_defs
        Rust 用の ctags 定義をカスタマイズしていて、rust.vim に含まれているも
        のを使いたくない場合、このオプションを 1 に設定する:
                let g:rust_use_custom_ctags_defs = 1


        NOTE: rust.vim の組み込みの定義は、Tagbar Vim プラグインに対して、それ
        がインストールされている場合、かつ Universal Ctags が検出されない場合
        にのみ使われる。これは、Universal Ctags が Tagbar と一緒に使われるとき
        に、すでに Rust の組み込みサポートを持っているからである。

        また、Universal Ctags 以外の ctags を使うとき、Vim が異なるソースファ
        イル間で定義にナビゲートするのに使える tags ファイルを生成する際に、
        それは自動的には使われないことに注意。tags ファイルを生成したい場合、
        rust.vim/ctags/rust.ctags をあなた自身の ~/.ctags に自由にコピーし
        てよい。

                                                g:ftplugin_rust_source_path
g:ftplugin_rust_source_path
        このオプションに、Rust のソースファイルに対して 'path' の前に追加すべ
        きパスを設定する:
                let g:ftplugin_rust_source_path = $HOME.'/dev/rust'

                                                g:rustfmt_command
g:rustfmt_command
        このオプションに、あなたの $PATH 内の "rustfmt" 実行可能ファイルの名前
        を設定する。指定されていない場合、既定値は "rustfmt" である:
                let g:rustfmt_command = 'rustfmt'

                                                g:rustfmt_autosave
                                                b:rustfmt_autosave
g:rustfmt_autosave
        バッファの保存時に :RustFmt を自動的に実行するには、このオプションを
        1 に設定する。指定されていない場合、既定値は 0 である:
                let g:rustfmt_autosave = 0

        同じ目的のために設定でき、グローバル設定を上書きできる、バッファローカ
        ルな b:rustfmt_autosave もある。

                                        g:rustfmt_autosave_if_config_present
                                        b:rustfmt_autosave_if_config_present
g:rustfmt_autosave_if_config_present
        編集されているファイルに至るいずれかの親ディレクトリに rustfmt.toml
        ファイルが存在する場合に b:rustfmt_autosave が自動的に設定されるよう
        にするには、このオプションを 1 に設定する。設定されていない場合、0 が
        既定になる:
                let g:rustfmt_autosave_if_config_present = 0

        これは、rustfmt.toml の設定があるプロジェクトで、保存時にのみ
        rustfmt を実行させるのに便利である。

        同じ目的のために設定でき、グローバル設定を上書きできる、バッファローカ
        ルな b:rustfmt_autosave_if_config_present もある。
                                                g:rustfmt_fail_silently
g:rustfmt_fail_silently
        "rustfmt" が location-list にエラーを入れないようにするには、このオ
        プションを 1 に設定する。指定されていない場合、既定値は 0 である:
                let g:rustfmt_fail_silently = 0

                                                g:rustfmt_options
g:rustfmt_options
        このオプションに、"rustfmt" に渡すオプションの文字列を設定する。
        write-mode はすでに "overwrite" に設定されている。指定されていない場
        合、既定値は '' である:
                let g:rustfmt_options = ''

                                                g:rustfmt_emit_files
g:rustfmt_emit_files
        指定されていない場合、rust.vim は、報告されたバージョンに基づいて
        rustfmt に渡す正しいパラメータを検出しようとする。そうでない場合、
        rustfmt を "--write-mode=overwrite" の代わりに "--emit=files" で実行す
        る (1 が指定されたとき) かどうかを決める。
                let g:rustfmt_emit_files = 0

                                                g:rustfmt_detect_version
g:rustfmt_detect_version
        1 に設定されたとき、"rustfmt" からのバージョン出力を解析しようとする。
        パフォーマンス上の理由から、既定では無効である。
                let g:rustfmt_detect_version = 1

                                                g:rustfmt_find_toml
g:rustfmt_find_toml
        1 に設定されたとき、現在のパスから上方向に検索して rustfmt.toml ファ
        イルを見つけようとする。パフォーマンス上の理由から、既定では無効であ
        る。
                let g:rustfmt_find_toml = 1

                                                g:rust_playpen_url
g:rust_playpen_url
        使う playpen の url を上書きするには、このオプションを設定する:
                let g:rust_playpen_url = 'https://play.rust-lang.org/'

                                                g:rust_shortener_url
g:rust_shortener_url
        url 短縮サービスの url を上書きするには、このオプションを設定する:
                let g:rust_shortener_url = 'https://is.gd/'

                                                g:rust_clip_command
g:rust_clip_command
        このオプションに、Rust Play の url をクリップボードにコピーするために
        あなたの OS で使われるコマンドを設定する:
                let g:rust_clip_command = 'xclip -selection clipboard'

                                                g:cargo_makeprg_params
g:cargo_makeprg_params
        このオプションに、cargo に渡すパラメータの文字列を設定する。指定されて
        いない場合、既定値は "$*" である:
                let g:cargo_makeprg_params = 'build'

                                                g:cargo_shell_command_runner
g:cargo_shell_command_runner
        cargo コマンド :Cargo、:Cbuild、:Crun など、のためにシェルコマン
        ドをどのように実行するかを変更するには、このオプションを設定する -
        rust-commands を参照。
        既定では、:terminal を使って、シェルコマンドを端末ウィンドウで非同期
        に実行する。しかし、コマンドの実行に :! を好む場合、それを指定できる:

                let g:cargo_shell_command_runner = '!'

Syntastic との統合                              rust-syntastic
------------------

このプラグインは自動的に Syntastic チェッカーと統合される。2 つのチェッカーが
提供されている: "rustc"、および "cargo"。後者はコードをビルドするために
"cargo" を呼び出し、前者は編集中の単一の ".rs" ファイルをコンパイル対象として
直接 Rust コンパイラ rustc に渡す。

最近では Cargo がほぼ専ら Rust コードのビルドに使われているため、"cargo" が既
定のチェッカーである。

        let g:syntastic_rust_checkers = ['cargo']

それを変更したい場合、g:syntastic_rust_checkers に別の値を設定できる。
                                        g:rust_cargo_avoid_whole_workspace
                                        b:rust_cargo_avoid_whole_workspace
g:rust_cargo_avoid_whole_workspace
        Cargo ワークスペースの一部であるクレートを編集していて、このオプション
        が 1 (既定値) に設定されているとき、"cargo" はワークスペースのディレク
        トリではなく、そのクレートのディレクトリで直接実行される。0 に設定する
        とこの動作が抑止される - ただし、大きなワークスペースで作業している場
        合、Cargo コマンドにより多くの時間がかかるかもしれず、さらに Syntastic
        のエラーリストにワークスペース内のすべてのクレートが含まれるかもしれな
        いことに注意すること。
                let g:rust_cargo_avoid_whole_workspace = 0

                                        g:rust_cargo_check_all_targets
                                        b:rust_cargo_check_all_targets
g:rust_cargo_check_all_targets
        1 に設定されたとき、Syntastic が cargo を実行するときに
        --all-targets オプションが渡され、パッケージ配下のすべてのターゲット
        の lint が可能になる。
        既定値は 0 である。
                                        g:rust_cargo_check_all_features
                                        b:rust_cargo_check_all_features
g:rust_cargo_check_all_features
        1 に設定されたとき、Syntastic が cargo を実行するときに
        --all-features オプションが渡され、パッケージのすべての機能の lint
        が可能になる。
        既定値は 0 である。
                                        g:rust_cargo_check_examples
                                        b:rust_cargo_check_examples
g:rust_cargo_check_examples
        1 に設定されたとき、Syntastic が cargo を実行するときに --examples
        オプションが渡され、例が lint から除外されるのを防ぐ。例は通常、クレー
        トの examples/ ディレクトリの下にある。
        既定値は 0 である。
                                        g:rust_cargo_check_tests
                                        b:rust_cargo_check_tests
g:rust_cargo_check_tests
        1 に設定されたとき、Syntastic が cargo を実行するときに --tests オプ
        ションが渡され、テストが lint から除外されるのを防ぐ。テストは通常、ク
        レートの tests/ ディレクトリの下にある。
        既定値は 0 である。
                                        g:rust_cargo_check_benches
                                        b:rust_cargo_check_benches
g:rust_cargo_check_benches
        1 に設定されたとき、Syntastic が cargo を実行するときに --benches オ
        プションが渡される。ベンチは通常、クレートの benches/ ディレクトリの
        下にある。
        既定値は 0 である。

auto-pairs との統合                     rust-auto-pairs
-------------------

このプラグインは、1 文字のリテラルよりもライフタイム注釈に多く使われるシングル
クォートを重複させないように、auto-pairs プラグインを自動的に設定する。

                                        g:rust_keep_autopairs_default
g:rust_keep_autopairs_default
        Rust ファイルタイプに対して auto-pairs の既定を上書きしない。既定値は
        0 である。

コマンド                                               rust-commands

Cargo の呼び出し
----------------

このプラグインは、Vim の中から Cargo を呼び出すためのとても単純なショートカッ
トを定義する。

:Cargo <args>                                           :Cargo
                与えられた引数で "cargo" を実行する。

:Cbuild <args>                                          :Cbuild
                "cargo build" のショートカット。

:Cclean <args>                                          :Cclean
                "cargo clean" のショートカット。

:Cdoc <args>                                            :Cdoc
                "cargo doc" のショートカット。

:Cinit <args>                                           :Cinit
                "cargo init" のショートカット。

:Crun <args>                                            :Crun
                "cargo run" のショートカット。

:Ctest <args>                                           :Ctest
                "cargo test" のショートカット。

:Cupdate <args>                                         :Cupdate
                "cargo update" のショートカット。

:Cbench <args>                                          :Cbench
                "cargo bench" のショートカット。

:Csearch <args>                                         :Csearch
                "cargo search" のショートカット。

:Cpublish <args>                                        :Cpublish
                "cargo publish" のショートカット。

:Cinstall <args>                                        :Cinstall
                "cargo install" のショートカット。

:Cruntarget <args>                                      :Cruntarget
                現在開いているバッファに応じて、"cargo run --bin" または
                "cargo run --example" のショートカット。

フォーマット
------------

:RustFmt                                                :RustFmt
                カレントバッファに対して g:rustfmt_command を実行する。
                g:rustfmt_options が設定されている場合、それらが実行可能ファ
                イルに渡される。

                g:rustfmt_fail_silently が 0 (既定値) の場合、
                g:rustfmt_command からのエラーを location-list に入れる。
                g:rustfmt_fail_silently が 1 に設定されている場合、
                location-list には入れない。

:RustFmtRange                                           :RustFmtRange
                選択された範囲で g:rustfmt_command を実行する。その他の情報
                については :RustFmt を参照。

Playpen 統合
------------

:RustPlay                                               :RustPlay
                このコマンドは、web-api.vim
                (https://github.com/mattn/webapi-vim で入手可能) がインストー
                ルされている場合にのみ動作する。現在の選択範囲を、または何も選
                択されていない場合はカレントバッファ全体を、Rust playpen に送
                り、playpen への短縮 URL を含むメッセージを出力する。

                g:rust_playpen_url は playpen へのベース URL で、既定では
                "https://play.rust-lang.org/" である。

                g:rust_shortener_url は短縮サービスのベース url で、既定では
                "https://is.gd/" である

                g:rust_clip_command は、playpen の url をあなたのシステムの
                クリップボードにコピーするために実行するコマンドである。

単一の Rust ファイルの評価
--------------------------

NOTE: これらのコマンドは、スタンドアロンの Rust ファイルで作業するときにのみ便
利であり、一般的な Rust 開発ではたいていそうではない。Vim の中から Rust クレー
トをビルドしたい場合、Vim の make、Syntastic、または他のプラグインの機能を使う
こと。

:RustRun  [args]                                        :RustRun
:RustRun! [rustc-args] [--] [args]
                カレントファイルをコンパイルして実行する。保存されていない変更
                がある場合、まず :update を使って保存される。カレントファイ
                ルが無名バッファの場合、まず一時ファイルに書き込まれる。コンパ
                イルされたバイナリは常に一時ディレクトリに置かれるが、カレント
                ディレクトリから実行される。

                :RustRun に与えられた引数は、コンパイルされたバイナリに渡さ
                れる。

                ! が指定された場合、引数は代わりに rustc に渡される。"--" 引数
                は、rustc の引数とバイナリに渡される引数を分離する。

                g:rustc_path が定義されている場合、それが rustc へのパスとし
                て使われる。そうでない場合、rustc は $PATH 内で見つかると仮定
                される。

:RustExpand  [args]                                     :RustExpand
:RustExpand! [TYPE] [args]
                --pretty を使ってカレントファイルを展開し、結果を新しい分割ウィ
                ンドウに表示する。カレントファイルに保存されていない変更がある
                場合、まず :update を使って保存される。カレントファイルが無
                名バッファの場合、まず一時ファイルに書き込まれる。

                :RustExpand に与えられた引数は rustc に渡される。これは主に、
                さまざまな --cfg 設定を指定することを意図している。

                ! が指定された場合、最初の引数は rustc --pretty に渡す展開タイ
                プである。そうでない場合、既定は "expanded" になる。

                g:rustc_path が定義されている場合、それが rustc へのパスとし
                て使われる。そうでない場合、rustc は $PATH 内で見つかると仮定
                される。

:RustEmitIr [args]                                      :RustEmitIr
                カレントファイルを LLVM IR にコンパイルし、結果を新しい分割ウィ
                ンドウに表示する。カレントファイルに保存されていない変更がある
                場合、まず :update を使って保存される。カレントファイルが無
                名バッファの場合、まず一時ファイルに書き込まれる。

                :RustEmitIr に与えられた引数は rustc に渡される。

                g:rustc_path が定義されている場合、それが rustc へのパスとし
                て使われる。そうでない場合、rustc は $PATH 内で見つかると仮定
                される。

:RustEmitAsm [args]                                     :RustEmitAsm
                カレントファイルをアセンブリにコンパイルし、結果を新しい分割
                ウィンドウに表示する。カレントファイルに保存されていない変更が
                ある場合、まず :update を使って保存される。カレントファイル
                が無名バッファの場合、まず一時ファイルに書き込まれる。

                :RustEmitAsm に与えられた引数は rustc に渡される。

                g:rustc_path が定義されている場合、それが rustc へのパスとし
                て使われる。そうでない場合、rustc は $PATH 内で見つかると仮定
                される。

テストの実行
------------

:[N]RustTest[!] [options]                               :RustTest
                カレントバッファが cargo プロジェクト内にあるとき、
                "cargo test" コマンドでカーソルの下のテストを実行する。コマン
                ドがカーソルの下にテスト関数を見つけられなかった場合、エラー
                メッセージを出して停止する。

                N が指定されたとき、新しいウィンドウのサイズを N 行または列に
                調整する。

                ! が指定されたとき、現在のカーソル位置に関係なく、すべてのテス
                トを実行する。

                [options] が指定されたとき、それは "cargo" コマンドの引数に渡
                される。

                カレントバッファが cargo プロジェクトの外にあるとき、このコマ
                ンドはフォールバックとして "cargo test" の代わりに
                "rustc --test" コマンドを実行する。rustc で特定のテスト関数を
                実行する方法はないので、! を付けるかどうかに関係なくすべてのテ
                ストが実行される。その場合、[options] は "rustc" コマンドの引
                数に渡される。

                省略可能な修飾子を取る (<mods> を参照):
                        :tab RustTest
                        :belowright 16RustTest
                        :leftabove vert 80RustTest

rust.vim のデバッグ
-------------------

:RustInfo                                               :RustInfo
                Vim Rust プラグインのデバッグ情報を出力する。

:RustInfoToClipboard                                    :RustInfoClipboard
                Vim Rust プラグインのデバッグ情報を既定のレジスタに保存する。

:RustInfoToFile [filename]                              :RustInfoToFile
                Vim Rust プラグインのデバッグ情報を指定されたファイルに保存し、
                上書きする。
