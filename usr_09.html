                     VIAI ユーザーマニュアル


                                GUI を使う


Vim は普通の端末で動作しますが、gVim にはグラフィカルユーザーインターフェイス
(GUI) があります。それは同じことができ、さらにいくつかのことができます。GUI
は、メニュー、ツールバー、スクロールバー、およびその他の項目を提供します。この
章は、GUI が提供するこれらの追加のものについてです。

09.1  GUI の各部

デスクトップに gvim を起動するアイコンがあるかもしれません。そうでなければ、こ
れらのコマンドのうちの 1 つでそれができるはずです:

        gvim file.txt
        vim -g file.txt

これがうまくいかない場合、GUI サポート付きの Vim のバージョンを持っていません。
まずそれをインストールする必要があります。
   Vim はウィンドウを開き、その中に "file.txt" を表示します。ウィンドウがどの
ように見えるかは、Vim のバージョンによります。以下の絵に似ているはずです
(ASCII で示せる限りにおいて!)。

        +----------------------------------------------------+
        | file.txt + (~/dir) - VIM                         X |  <- ウィンドウタイトル
        +----------------------------------------------------+
        | File  Edit  Tools  Syntax  Buffers  Window  Help   |  <- メニューバー
        +----------------------------------------------------+
        | aaa  bbb  ccc  ddd  eee  fff  ggg  hhh  iii  jjj   |  <- ツールバー
        | aaa  bbb  ccc  ddd  eee  fff  ggg  hhh  iii  jjj   |
        +----------------------------------------------------+
        | file text                                      | ^ |
        | ~                                              | # |
        | ~                                              | # |  <- スクロールバー
        | ~                                              | # |
        | ~                                              | # |
        | ~                                              | # |
        |                                                | V |
        +----------------------------------------------------+

最も大きな領域は、ファイルのテキストによって占められています。これは、端末と同
じ方法でファイルを表示します。おそらく、いくらか異なる色および別のフォントで。


ウィンドウタイトル

一番上にはウィンドウタイトルがあります。これはウィンドウシステムによって描画さ
れます。Vim は、カレントファイルの名前を表示するようにタイトルを設定します。ま
ずファイルの名前が来ます。次に、いくつかの特殊文字、および括弧で囲まれたファイ
ルのディレクトリが来ます。これらの特殊文字が存在することがあります:

        -       ファイルは変更できない (例えば、ヘルプファイル)
        +       ファイルは変更を含んでいる
        =       ファイルは読み込み専用である
        =+      ファイルは読み込み専用だが、それでも変更を含んでいる

何も表示されていない場合は、普通の、変更されていないファイルです。


メニューバー

メニューがどう動作するかは知っていますよね? Vim には通常の項目に加えて、いくつ
かの項目があります。それらを眺めて、何に使えるかの見当をつけてください。関連す
るサブメニューは Edit/Global Settings です。これらの項目が見つかるでしょう:

        Toggle Toolbar          ツールバーを表示/非表示にする
        Toggle Bottom Scrollbar 下部のスクロールバーを表示/非表示にする
        Toggle Left Scrollbar   左側のスクロールバーを表示/非表示にする
        Toggle Right Scrollbar  右側のスクロールバーを表示/非表示にする

ほとんどのシステムでは、メニューを切り離すことができます。メニューの一番上の項
目、破線のように見えるものを選択します。メニューの項目を持つ別のウィンドウが得
られます。それは、そのウィンドウを閉じるまで残ります。


ツールバー

これには、最もよく使われる操作のためのアイコンが含まれています。アイコンが見た
だけで分かるものであることを願います。追加のヒントを得るためのツールチップがあ
ります (クリックせずにマウスポインタをアイコンに移動し、1 秒間動かさないでくだ
さい)。

"Edit/Global Settings/Toggle Toolbar" メニュー項目を使って、ツールバーを消すこ
とができます。ツールバーが決して要らない場合は、vimrc ファイルでこのコマンドを
使います:

        :set guioptions-=T

これは 'guioptions' オプションから 'T' フラグを取り除きます。GUI の他の部分も、
このオプションで有効または無効にできます。それについてのヘルプを参照してくださ
い。


スクロールバー

デフォルトでは、右側に 1 つのスクロールバーがあります。それは見てのとおりのこ
とをします。ウィンドウを分割すると、各ウィンドウはそれぞれ自身のスクロールバー
を持ちます。
   メニュー項目 Edit/Global Settings/Toggle Bottom Scrollbar で、水平スクロー
ルバーを表示させることができます。これは diff モードで、または 'wrap' オプショ
ンがオフにされているときに便利です (これについては後で詳しく)。

垂直分割されたウィンドウがあるときは、右側のウィンドウだけがスクロールバーを持
ちます。しかし、カーソルを左のウィンドウに移動すると、スクロールバーが制御する
のはそのウィンドウになります。これは慣れるのに少し時間がかかります。
   垂直分割されたウィンドウで作業するときは、左側にスクロールバーを追加するこ
とを検討してください。これはメニュー項目で、または 'guioptions' オプションで行
えます:

        :set guioptions+=l

これは 'guioptions' に 'l' フラグを追加します。

09.2  マウスを使う

標準というのは素晴らしいものです。Microsoft Windows では、標準的な方法でマウス
を使ってテキストを選択できます。X Window システムにも、マウスを使うための標準
的なシステムがあります。残念ながら、これら 2 つの標準は同じではありません。
   幸い、Vim はカスタマイズできます。マウスの振る舞いを、X Window システムのマ
ウスまたは Microsoft Windows のマウスのように動作させることができます。以下の
コマンドは、マウスを X Window のマウスのように振る舞わせます:

        :behave xterm

以下のコマンドは、マウスを Microsoft Windows のマウスのように動作させます:

        :behave mswin

UNIX システムでのマウスのデフォルトの振る舞いは xterm です。Microsoft Windows
システムでのデフォルトの振る舞いは、インストール処理の間に選択されます。2 つの
振る舞いが何であるかの詳細については、:behave を参照してください。ここに要約
を示します。


xterm マウスの振る舞い

マウス左クリック                カーソルを置く
マウス左ドラッグ                        ビジュアルモードでテキストを選択する
マウス中クリック                クリップボードからテキストを貼り付ける
マウス右クリック                選択されたテキストをマウスポインタまで拡張する


mswin マウスの振る舞い

マウス左クリック                カーソルを置く
マウス左ドラッグ                        選択モードでテキストを選択する (09.4 を参照)
マウス左クリック、Shift 付き    選択されたテキストをマウスポインタまで拡張する
マウス中クリック                クリップボードからテキストを貼り付ける
マウス右クリック                ポップアップメニューを表示する


マウスはさらに調整できます。マウスの動作の仕方を変更したい場合は、これらのオプ
ションを調べてください:

        'mouse'                 Vim がどのモードでマウスを使うか
        'mousemodel'            マウスクリックがどんな効果を持つか
        'mousetime'             ダブルクリックのためのクリック間の時間
        'mousehide'             タイプ中にマウスを隠す
        'selectmode'            マウスがビジュアルモードまたは選択モードを開始するかどうか

09.3  クリップボード

セクション 04.7 で、クリップボードの基本的な使い方が説明されました。
X-windows について説明すべき重要なことが 1 つあります: プログラム間でテキスト
を交換する場所は、実際には 2 つあります。MS-Windows にはこれがありません。

X-Windows には "カレントセレクション" があります。これは現在ハイライトされてい
るテキストです。Vim では、これはビジュアル領域です (これは、デフォルトのオプ
ション設定を使っていることを前提としています)。それ以上何も操作せずに、この選
択範囲を別のアプリケーションに貼り付けることができます。
   例えば、このテキストで、マウスを使っていくつかの単語を選択してください。Vim
はビジュアルモードに切り替わり、テキストをハイライトします。では、ファイル名の
引数なしで別の gvim を起動し、空のウィンドウが表示されるようにします。マウスの
中ボタンをクリックします。選択されたテキストが挿入されます。

"カレントセレクション" は、他のテキストが選択されるまでの間だけ有効なままです。
もう一方の gvim で貼り付けを行った後、そのウィンドウでいくつかの文字を選択して
ください。もう一方の gvim ウィンドウで以前に選択されていた単語が、異なる表示に
なっていることに気づくでしょう。これは、それがもはやカレントセレクションではな
いことを意味します。

テキストをマウスで選択する必要はありません。ビジュアルモードのキーボードコマン
ドを使っても同じように動作します。


真のクリップボード

さて、テキストを交換できるもう一方の場所についてです。混乱を避けるため、これを
"真のクリップボード" と呼びます。"カレントセレクション" および
"真のクリップボード" の両方がクリップボードと呼ばれることがよくあります。それ
には慣れる必要があるでしょう。
   テキストを真のクリップボードに置くには、実行中の gvim の 1 つで、いくつかの
異なる単語を選択します。それから Edit/Copy メニュー項目を使います。これでテキ
ストが真のクリップボードにコピーされました。クリップボードの内容を表示するアプ
リケーション (例えば、KDE の Klipper) がない限り、これを見ることはできません。
   では、もう一方の gvim を選択し、カーソルをどこかに置いて、Edit/Paste メ
ニューを使います。真のクリップボードからのテキストが挿入されるのが分かるでしょ
う。


両方を使う

"カレントセレクション" および "真のクリップボード" の両方をこのように使うのは、
少し混乱するように聞こえるかもしれません。しかし、これはとても便利です。例でこ
れを示しましょう。テキストファイルで 1 つの gvim を使い、これらの操作を行いま
す:

-  ビジュアルモードで 2 つの単語を選択する。
-  Edit/Copy メニューを使って、これらの単語をクリップボードに入れる。
-  ビジュアルモードで別の 1 つの単語を選択する。
-  Edit/Paste メニュー項目を使う。起こることは、選択された 1 つの単語が、クリッ
   プボードからの 2 つの単語で置き換えられるということである。
-  マウスポインタをどこか別の場所に移動し、中ボタンをクリックする。クリップボー
   ドで上書きしたばかりの単語が、ここに挿入されるのが分かるだろう。

"カレントセレクション" および "真のクリップボード" を注意して使えば、それらを
使って多くの便利な編集を行うことができます。


キーボードを使う

マウスを使うのが好きでない場合は、2 つのレジスタを使って、カレントセレクション
および真のクリップボードにアクセスできます。"* レジスタはカレントセレクション
用です。
   テキストをカレントセレクションにするには、ビジュアルモードを使います。例え
ば、行全体を選択するには、"V" を押すだけです。
   カレントセレクションをカーソルの前に挿入するには:

        "*P

大文字の "P" に注意してください。小文字の "p" はテキストをカーソルの後に置きま
す。

"+ レジスタは真のクリップボードに使われます。例えば、カーソル位置から行末まで
のテキストをクリップボードにコピーするには:

        "+y$

覚えておいてください、"y" はヤンクで、これは Vim のコピーコマンドです。
   真のクリップボードの内容をカーソルの前に挿入するには:

        "+P

これはカレントセレクションの場合と同じですが、スター (*) レジスタの代わりにプ
ラス (+) レジスタを使います。

09.4  選択モード

そして次は、X-Windows よりも MS-Windows でよく使われるものです。しかし、どちら
でもそれができます。ビジュアルモードについては既に知っています。選択モードは、
それもテキストを選択するのに使われるので、ビジュアルモードに似ています。しか
し、明らかな違いがあります: テキストをタイプすると、選択されたテキストが削除さ
れ、タイプされたテキストがそれを置き換えます。

選択モードで作業を始めるには、まずそれを有効にしなければなりません (MS-Windows
では、おそらく既に有効になっていますが、とにかくこれを実行してもかまいません):


        :set selectmode+=mouse

では、マウスを使っていくつかのテキストを選択してください。それはビジュアルモー
ドのようにハイライトされます。では、文字を 1 つ押してください。選択されたテキ
ストが削除され、その 1 文字がそれを置き換えます。今は挿入モードなので、タイプ
し続けることができます。

通常のテキストをタイプすると選択されたテキストが削除されるので、通常の移動コマ
ンド "hjkl"、"w" などは使えません。代わりに、Shift 付きのファンクションキーを
使います。<S-Left> (Shift 付きの左カーソルキー) はカーソルを左に移動します。選
択されたテキストはビジュアルモードのように変更されます。他の Shift 付きのカー
ソルキーは期待どおりのことをします。<S-End> および <S-Home> も動作します。

'selectmode' オプションで、選択モードの動作の仕方を調整できます。
