1. コマンド                             tcl-ex-commands E571 E572

                                                        :tcl
:[range]tcl {cmd}       Tcl コマンド {cmd} を実行する。:tcl が動作しているか
                        どうかの簡単な確認:
                                :tcl puts "Hello"

:[range]tcl << [trim] [{endmarker}]
{script}
{endmarker}
                        Tcl スクリプト {script} を実行する。
                        Note: このコマンドは、Tcl 機能がコンパイルされていない
                        ときは動作しない。エラーを避けるには、script-here を
                        参照。

[endmarker] が "<<" の後から省略された場合、:append および :insert コマン
ドと同様に、{script} の後にドット '.' を使わなければならない。詳しい情報は
:let-heredoc を参照。

この形式の :tcl コマンドは、主に Vim script に tcl コードを含めるのに便利で
ある。

例:
        function! DefineDate()
            tcl << EOF
            proc date {} {
                return [clock format [clock seconds]]
            }
        EOF
        endfunction

持っている Tcl のバージョンを見るには:
        :tcl puts [info patchlevel]


                                                        :tcldo :tcld
:[range]tcld[o] {cmd}   [range] 内の各行に対して、変数 "line" に各行のテキスト
                        を順に設定し、"lnum" に行番号を設定して、Tcl コマンド
                        {cmd} を実行する。"line" を設定するとテキストが変更さ
                        れるが、このコマンドを使って行を追加または削除すること
                        はできないことに注意。{cmd} がエラーを返した場合、コマ
                        ンドは中断される。[range] の既定値はファイル全体:
                        "1,$"。
                        tcl-var-line および tcl-var-lnum を参照。

                                                        :tclfile :tclf
:[range]tclf[ile] {file}
                        {file} 内の Tcl スクリプトを実行する。これは
                        ":tcl source {file}" と同じだが、ファイル名補完ができ
                        る。


Note Tcl オブジェクト (変数など) は、Tcl シェルと同様に、あるコマンドから次の
コマンドへと持続することに注意。

sandbox 内では Tcl コマンドの実行はできない。

2. Tcl コマンド                                         tcl-commands

Tcl コードは、vim へのすべてのアクセスを "::vim" 名前空間内のコマンドを介して
得る。以下のコマンドが実装されている:

        ::vim::beep                     # 推測せよ。
        ::vim::buffer {n}               # 1 つのバッファに対する Tcl コマンドを作成する。
        ::vim::buffer list              # すべてのバッファに対する Tcl コマンドを作成する。
        ::vim::command [-quiet] {cmd}   # Ex コマンドを実行する。
        ::vim::expr {expr}              # Vim の式評価器を使う。
        ::vim::option {opt}             # vim オプションを取得する。
        ::vim::option {opt} {val}       # vim オプションを設定する。
        ::vim::window list              # すべてのウィンドウに対する Tcl コマンドを作成する。

コマンド:
        ::vim::beep                                     tcl-beep
        ブーと鳴らす。結果を返さない。

        ::vim::buffer {n}                               tcl-buffer
        ::vim::buffer exists {n}
        ::vim::buffer list
        vim バッファへのアクセスを提供する。整数の引数を指定すると、その番号の
        バッファに対するバッファコマンド (tcl-buffer-cmds を参照) を作成し、
        その名前を結果として返す。無効なバッファ番号は標準の Tcl エラーになる。
        有効なバッファ番号かどうかを調べるには、vim の内部関数を使える:
                set nbufs [::vim::expr bufnr("$")]
                set isvalid [::vim::expr "bufexists($n)"]
        "list" オプションは、有効な各バッファに対するバッファコマンドを作成し、
        コマンド名のリストを結果として返す。
        例:
                set bufs [::vim::buffer list]
                foreach b $bufs { $b append end "The End!" }
        "exists" オプションは、指定された番号のバッファが存在するかどうかを調
        べる。
        例:
                if { [::vim::buffer exists $n] } { ::vim::command ":e #$n" }
        このコマンドは将来のバージョンで変数に置き換えられるかもしれない。
        カレントバッファについては tcl-var-current も参照。

        ::vim::command {cmd}                            tcl-command
        ::vim::command -quiet {cmd}
        vim (Ex モード) コマンド {cmd} を実行する。バッファまたはウィンドウに
        影響する Ex コマンドはすべて、カレントバッファ/カレントウィンドウを使
        う。標準の Tcl エラーコード以外の結果は返さない。このコマンドが完了し
        た後、"::vim::current" 変数が更新される。
        "-quiet" フラグは、vim からのすべてのエラーメッセージを抑制する。
        例:
                ::vim::command "set ts=8"
                ::vim::command "%s/foo/bar/g"
        ノーマルモードのコマンドを実行するには、"normal" を使う (:normal を
        参照):
                set cmd "jj"
                ::vim::command "normal $cmd"
        tcl-window-command および tcl-buffer-command も参照。

        ::vim::expr {expr}                              tcl-expr
        vim の内部の式評価器 (expression を参照) を使って式 {expr} を評価す
        る。バッファまたはウィンドウのプロパティを問い合わせる式はすべて、カレ
        ントバッファ/カレントウィンドウを使う。結果を文字列として返す。List
        は、要素を連結して改行を挿入することで文字列に変換される。
        例:
                set perl_available [::vim::expr has("perl")]
        tcl-window-expr および tcl-buffer-expr も参照。

        ::vim::option {opt}                             tcl-option
        ::vim::option {opt} {value}
        2 番目の引数がない場合、vim オプションの値を問い合わせる。この引数があ
        る場合、vim オプションを {value} に設定し、以前の値を結果として返す。
        'local to buffer' または 'local to window' とマークされているオプショ
        ンはすべて、カレントバッファ/カレントウィンドウに影響する。グローバル
        値は変更されず、それには ":set" コマンドを使う。ブール値オプションの場
        合、{value} は "0" または "1"、またはキーワード "on"、"off"、または
        "toggle" のいずれかであるべきである。オプションの一覧は
        option-summary を参照。
        例:
                ::vim::option ts 8
        tcl-window-option および tcl-buffer-option も参照。

        ::vim::window {option}                          tcl-window
        vim ウィンドウへのアクセスを提供する。現在は "list" オプションだけが実
        装されている。これは各ウィンドウに対するウィンドウコマンド
        (tcl-window-cmds を参照) を作成し、コマンド名のリストを結果として返
        す。
        例:
                set wins [::vim::window list]
                foreach w $wins { $w height 4 }
        このコマンドは将来のバージョンで変数に置き換えられるかもしれない。
        カレントウィンドウについては tcl-var-current も参照。

3. Tcl 変数                                             tcl-variables

::vim 名前空間にはいくつかの変数が含まれている。これらは、Tcl インタープリター
が vim から呼ばれたときに作成され、現在の値に設定される。

        ::vim::current          # "current" オブジェクトを含む配列
        ::vim::lbase            # 最初の行の番号
        ::vim::range            # 現在の範囲の番号を含む配列
        line                    # 文字列としての現在行 (:tcldo のみ)
        lnum                    # 現在の行番号 (:tcldo のみ)

変数:
        ::vim::current                                  tcl-var-current
        これは、vim で使用可能なさまざまな "current" オブジェクトへのアクセス
        を提供する配列である。"::vim::command" は vim の現在の設定を変更するか
        もしれない (例えば、カレントバッファを削除することによって) ので、この
        配列の内容は "::vim::command" が呼ばれた後に更新される。
        "buffer" 要素には、カレントバッファに対するバッファコマンドの名前が含
        まれている。これは、バッファコマンド (tcl-buffer-cmds を参照) を呼び
        出すのに直接使える。この要素は読み取り専用である。
        例:
                $::vim::current(buffer) insert begin "Hello world"
        "window" 要素には、カレントウィンドウに対するウィンドウコマンドの名前
        が含まれている。これは、ウィンドウコマンド (tcl-window-cmds を参照)
        を呼び出すのに直接使える。この要素は読み取り専用である。
        例:
                $::vim::current(window) height 10

        ::vim::lbase                                    tcl-var-lbase
        この変数は、Tcl が行番号をどう扱うかを制御する。'1' に設定されている場
        合、行および列は 1 から始まる。こうすると、Tcl コマンドおよび vim の式
        からの行番号は互換性がある。この変数が '0' に設定されている場合、Tcl
        では行番号および列は 0 から始まる。これは、バッファを Tcl リストとし
        て、または行を Tcl 文字列として扱い、インデックスを返す標準の Tcl コマ
        ンド (例えば "lsort" または "string first") を使いたい場合に便利であ
        る。既定値は '1' である。現在のところ、0 以外の値はすべて '1' として扱
        われるが、あなたのスクリプトはこれに依存すべきではない。
        tcl-linenumbers も参照。

        ::vim::range                                    tcl-var-range
        これは、"start"、"begin"、および "end" の 3 つの要素を持つ配列である。
        これには現在の範囲の開始行および終了行の行番号が含まれている。"begin"
        は "start" と同じである。この変数は読み取り専用である。tcl-examples
        を参照。

        line                                            tcl-var-line
        lnum                                            tcl-var-lnum
        これらのグローバル変数は、":tcldo" Ex コマンドが実行されている場合にの
        み使用可能である。これらには現在行のテキストおよび行番号が含まれてい
        る。":tcldo" によって呼び出された Tcl コマンドが完了すると、Tcl コマン
        ドによって変数が unset されていない限り、現在行は "line" 変数の内容に
        設定される。"lnum" 変数は読み取り専用である。これらの変数は "::vim" 名
        前空間にないので、":tcldo" 内であまりタイプせずに使える (これは将来の
        バージョンで変更されるかもしれない)。tcl-linenumbers も参照。

4. Tcl ウィンドウコマンド                               tcl-window-cmds

ウィンドウコマンドは vim ウィンドウを表す。これらはいくつかのコマンドによって
作成される:
        ::vim::window list                      tcl-window
        バッファコマンドの "windows" オプション tcl-buffer-windows
::vim::current(window) 変数には、カレントウィンドウに対するウィンドウコマンド
の名前が含まれている。ウィンドウコマンドは、対応する vim ウィンドウが閉じられ
ると自動的に削除される。

ウィンドウコマンドの名前が Tcl 変数 "win" に格納されている、つまり "$win" がコ
マンドを呼び出すと仮定しよう。以下のオプションが使用可能である:

        $win buffer             # ウィンドウのバッファに対する Tcl コマンドを作成する。
        $win command {cmd}      # ウィンドウのコンテキストで Ex コマンドを実行する。
        $win cursor             # 現在のカーソル位置を取得する。
        $win cursor {var}       # 配列変数からカーソル位置を設定する。
        $win cursor {row} {col} # カーソル位置を設定する。
        $win delcmd {cmd}       # ウィンドウが閉じられたときに Tcl コマンドを呼ぶ。
        $win expr {expr}        # ウィンドウのコンテキストで vim の式を評価する。
        $win height             # ウィンドウの高さを報告する。
        $win height {n}         # ウィンドウの高さを設定する。
        $win option {opt} [val] # ウィンドウのコンテキストで vim オプションを取得/設定する。

オプション:
        $win buffer                                     tcl-window-buffer
        ウィンドウのバッファに対する Tcl コマンドを作成し、その名前を結果とし
        て返す。名前は変数に格納すべきである:
                set buf [$win buffer]
        これで $buf は有効な Tcl コマンドである。使用可能なオプションについて
        は tcl-buffer-cmds を参照。

        $win cursor                                     tcl-window-cursor
        $win cursor {var}
        $win cursor {row} {col}
        引数がない場合、現在のカーソル位置を文字列として報告する。これは Tcl
        配列変数に変換できる:
                array set here [$win cursor]
        これで "here(row)" および "here(column)" にカーソル位置が含まれる。
        引数が 1 つの場合、その引数は Tcl 配列変数の名前として解釈され、その配
        列変数は 2 つの要素 "row" および "column" を含まなければならない。
        これらはカーソルを新しい位置に設定するのに使われる:
                $win cursor here        ;# $here ではない!
        引数が 2 つの場合、カーソルを指定された行および列に設定する:
                $win cursor $here(row) $here(column)
        無効な位置は標準の Tcl エラーになり、それは "catch" で捕捉できる。行お
        よび列の値は "::vim::lbase" 変数に依存する。tcl-var-lbase を参照。

        $win delcmd {cmd}                               tcl-window-delcmd
        Tcl コマンド {cmd} をウィンドウの削除コールバックとして登録する。この
        コマンドは、ウィンドウが閉じられる直前に (グローバルスコープで) 実行さ
        れる。複雑なコマンドは "list" で組み立てるべきである:
                $win delcmd [list puts vimerr "window deleted"]
        tcl-buffer-delcmd も参照。

        $win height                                     tcl-window-height
        $win height {n}
        引数がない場合、ウィンドウの現在の高さを報告する。引数がある場合、ウィ
        ンドウの高さを {n} に設定しようとし、それから新しい高さ ({n} とは異な
        るかもしれない) を報告する。

        $win command [-quiet] {cmd}                     tcl-window-command
        $win expr {expr}                                tcl-window-expr
        $win option {opt} [val]                         tcl-window-option
        これらは "::vim::command" などと似ているが、すべてがカレントウィンドウ
        ではなく $win によって表されるウィンドウのコンテキストで行われる点が異
        なる。例えば、'local to window' とマークされているオプションを設定する
        と、ウィンドウ $win に影響する。バッファに影響するか、またはバッファを
        問い合わせるものはすべて、このウィンドウに表示されているバッファ (つま
        り "$win buffer" によって表されるバッファ) を使う。詳しい情報は
        tcl-command、tcl-expr、および tcl-option を参照。
        例:
                $win option number on

5. Tcl バッファコマンド                                 tcl-buffer-cmds

バッファコマンドは vim バッファを表す。これらはいくつかのコマンドによって作成
される:
        ::vim::buffer {N}                       tcl-buffer
        ::vim::buffer list                      tcl-buffer
        ウィンドウコマンドの "buffer" オプション        tcl-window-buffer
::vim::current(buffer) 変数には、カレントバッファに対するバッファコマンドの名
前が含まれている。バッファコマンドは、対応する vim バッファが破棄されると自動
的に削除される。バッファの内容が変更されるたびに、バッファ内のすべてのマークは
自動的に調整される。Tcl コマンドによって行われたバッファの内容への変更はすべ
て、"undo" vim コマンド (undo を参照) で取り消すことができる。

バッファコマンドの名前が Tcl 変数 "buf" に格納されている、つまり "$buf" がコマ
ンドを呼び出すと仮定しよう。以下のオプションが使用可能である:

        $buf append {n} {str}   # 行 {n} の後に、バッファに行を追加する。
        $buf command {cmd}      # バッファのコンテキストで Ex コマンドを実行する。
        $buf count              # バッファ内の行数を報告する。
        $buf delcmd {cmd}       # バッファが削除されたときに Tcl コマンドを呼ぶ。
        $buf delete {n}         # 1 行を削除する。
        $buf delete {n} {m}     # 複数行を削除する。
        $buf expr {expr}        # バッファのコンテキストで vim の式を評価する。
        $buf get {n}            # 1 行を文字列として取得する。
        $buf get {n} {m}        # 複数行をリストとして取得する。
        $buf insert {n} {str}   # 行 {n} として、バッファに行を挿入する。
        $buf last               # バッファ内の最終行の行番号を報告する。
        $buf mark {mark}        # バッファマークの位置を報告する。
        $buf name               # バッファ内のファイルの名前を報告する。
        $buf number             # このバッファの番号を報告する。
        $buf option {opt} [val] # バッファのコンテキストで vim オプションを取得/設定する。
        $buf set {n} {text}     # 1 行を置き換える。
        $buf set {n} {m} {list} # 複数行を置き換える。
        $buf windows            # バッファのウィンドウに対する Tcl コマンドを作成する。

                                                        tcl-linenumbers
ほとんどのバッファコマンドは引数として行番号を取る。Tcl がこれらの番号をどう扱
うかは "::vim::lbase" 変数 (tcl-var-lbase を参照) に依存する。行番号の代わり
に、いくつかのキーワードも使える: "top"、"start"、"begin"、"first"、"bottom"、
"end"、および "last"。

オプション:
        $buf append {n} {str}                           tcl-buffer-append
        $buf insert {n} {str}                           tcl-buffer-insert
        バッファに行を追加する。"insert" オプションでは、文字列は新しい行 {n}
        になり、"append" では行 {n} の後に挿入される。
        例:
                $buf insert top "This is the beginning."
                $buf append end "This is the end."
        バッファに行のリストを追加するには、ループを使う:
                foreach line $list { $buf append $num $line ; incr num }

        $buf count                                      tcl-buffer-count
        バッファ内の行の総数を報告する。

        $buf delcmd {cmd}                               tcl-buffer-delcmd
        Tcl コマンド {cmd} をバッファの削除コールバックとして登録する。このコ
        マンドは、バッファが削除される直前に (グローバルスコープで) 実行され
        る。複雑なコマンドは "list" で組み立てるべきである:
                $buf delcmd [list puts vimerr "buffer [$buf number] gone"]
        tcl-window-delcmd も参照。

        $buf delete {n}                                 tcl-buffer-delete
        $buf delete {n} {m}
        行 {n}、または行 {n} から {m} までをバッファから削除する。
        この例は最終行以外のすべてを削除する:
                $buf delete first [expr [$buf last] - 1]

        $buf get {n}                                    tcl-buffer-get
        $buf get {n} {m}
        バッファから 1 行以上を取得する。1 行の場合、結果は文字列であり、複数
        行の場合、文字列のリストである。
        例:
                set topline [$buf get top]

        $buf last                                       tcl-buffer-last
        最終行の行番号を報告する。この値は "::vim::lbase" 変数に依存する。
        tcl-var-lbase を参照。

        $buf mark {mark}                                tcl-buffer-mark
        名前付きマークの位置を、ウィンドウコマンドの "cursor" オプションのカー
        ソル位置 (tcl-window-cursor を参照) と同様に、文字列として報告する。
        これは Tcl 配列変数に変換できる:
                array set mpos [$buf mark "a"]
        これで "mpos(column)" および "mpos(row)" にマークの位置が含まれる。マー
        クが設定されていない場合、標準の Tcl エラーになる。

        $buf name
        バッファ内のファイルの名前を報告する。ファイルのないバッファでは、これ
        は空文字列である。

        $buf number
        このバッファの番号を報告する。:buffers を参照。
        この例は vim からバッファを削除する:
                ::vim::command "bdelete [$buf number]"

        $buf set {n} {string}                           tcl-buffer-set
        $buf set {n} {m} {list}
        バッファ内の 1 行または複数行を置き換える。置き換える行よりもリストの
        要素の方が多い場合、それらはバッファに挿入される。リストの要素の方が少
        ない場合、置き換えられなかった行はすべてバッファから削除される。

        $buf windows                                    tcl-buffer-windows
        このバッファを表示している各ウィンドウに対するウィンドウコマンドを作成
        し、コマンド名のリストを結果として返す。
        例:
                set winlist [$buf windows]
                foreach win $winlist { $win height 4 }
        使用可能なオプションについては tcl-window-cmds を参照。

        $buf command [-quiet] {cmd}                     tcl-buffer-command
        $buf expr {expr}                                tcl-buffer-expr
        $buf option {opt} [val]                         tcl-buffer-option
        これらは "::vim::command" などと似ているが、すべてがカレントバッファで
        はなく $buf によって表されるバッファのコンテキストで行われる点が異な
        る。例えば、'local to buffer' とマークされているオプションを設定する
        と、バッファ $buf に影響する。ウィンドウに影響するか、またはウィンドウ
        を問い合わせるものはすべて、vim のウィンドウリストのうちこのバッファを
        表示している最初のウィンドウ (つまり "$buf windows" によって返されるリ
        ストの最初のエントリ) を使う。詳しい情報は tcl-command、tcl-expr、
        および tcl-option を参照。
        例:
                if { [$buf option modified] } { $buf command "w" }

6. その他; Tcl からの出力                       tcl-misc tcl-output

標準の Tcl コマンド "exit" および "catch" は独自のバージョンに置き換えられてい
る。"exit" は現在の Tcl スクリプトを終了して vim に戻り、vim は Tcl インタープ
リターを削除する。その後 ":tcl" を再び呼ぶと、新しい Tcl インタープリターが作
成される。"exit" は vim を終了しない! "catch" は以前と同様に動作するが、"exit"
によるスクリプトの終了を妨げない点が異なる。!= 0 の終了コードは、Tcl スクリプ
トを呼び出した Ex コマンドがエラーを返す原因となる。

Tcl では 2 つの新しい I/O ストリーム "vimout" および "vimerr" が使用可能であ
る。それらに向けられたすべての出力は、vim のメッセージ領域に、それぞれ情報メッ
セージおよびエラーメッセージとして表示される。標準の Tcl 出力ストリーム stdout
および stderr は vimout および vimerr にマップされているので、通常の "puts" コ
マンドを使って vim にメッセージを表示できる。

7. 既知のバグおよび問題                                 tcl-bugs

Tcl の内部から ("::vim::command" を介して) Tcl Ex コマンドの 1 つを呼ぶと、予
期しない副作用が起こるかもしれない。そのコマンドは新しいインタープリターを作成
し、それは標準のインタープリターと同じ能力を持つ - したがって、安全な子インター
プリターで "::vim::command" を使用可能にすると、その子は安全でなくなる。(入れ
子になった :tcl* の呼び出しをブロックするか、または安全なインタープリターから
のそのような呼び出しが新しい安全なインタープリターだけを作成するようにするのは
簡単だが、まったく無意味である - vim の構成によっては、"::vim::command" は任意
の数の他のスクリプト言語で任意のコードを実行するかもしれない。) この新しいイン
タープリター内での "exit" の呼び出しは古いインタープリターに影響しない; それは
新しいインタープリターを終了するだけで、その後スクリプトの処理は古いインタープ
リターで通常どおり続行される。

stdin からの入力は現在サポートされていない。

8. 例:                                                  tcl-examples

ここにいくつかの小さな (そしておそらく有用な) Tcl スクリプトがある。

このスクリプトは、バッファ全体の行をソートする (それには名前のリストまたはそれ
に類するものが含まれていると仮定する):
        set buf $::vim::current(buffer)
        set lines [$buf get top bottom]
        set lines [lsort -dictionary $lines]
        $buf set top bottom $lines

このスクリプトはバッファ内の行を反転する。Note どんな行番号の設定でも動作する
ように "::vim::lbase" および "$buf last" を使っていることに注意:
        set buf $::vim::current(buffer)
        set t $::vim::lbase
        set b [$buf last]
        while { $t < $b } {
                set tl [$buf get $t]
                set bl [$buf get $b]
                $buf set $t $bl
                $buf set $b $tl
                incr t
                incr b -1
        }

このスクリプトは、現在の範囲内の各行に連番を追加する:
        set buf $::vim::current(buffer)
        set i $::vim::range(start)
        set n 1
        while { $i <= $::vim::range(end) } {
                set line [$buf get $i]
                $buf set $i "$n\t$line"
                incr i ; incr n
        }

同じことは、":tcldo" を使って 2 つの Ex コマンドで素早く行うこともできる:
        :tcl set n 1
        :[range]tcldo set line "$n\t$line" ; incr n

この手続きは各バッファ上で Ex コマンドを実行する (アイデアは Ron Aaron から盗
んだ):
        proc eachbuf { cmd } {
                foreach b [::vim::buffer list] {
                        $b command $cmd
                }
        }
このように使う:
        :tcl eachbuf %s/foo/bar/g
ただし、Tcl の文字列およびバックスラッシュの置換には注意すること。疑わしい場
合、Ex コマンドを波括弧で囲むこと。


いくつかの Tcl の手続きを vim に恒久的に追加したい場合、それらをファイル (例え
ば Unix マシンでは "~/.vimrc.tcl") に置き、これらの行をあなたのスタートアップ
ファイル (Unix では通常 "~/.vimrc") に追加するだけでよい:
        if has("tcl")
                tclfile ~/.vimrc.tcl
        endif

9. 動的ロード                                           tcl-dynamic

MS-Windows および Unix では、Tcl ライブラリを動的にロードできる。そのとき
:version の出力には +tcl/dyn が含まれる。

これは、Vim が必要なときにだけ Tcl の DLL または共有ライブラリファイルを探すこ
とを意味する。Tcl インターフェイスを使わないときはそれは必要ないので、このファ
イルなしで Vim を使える。


MS-Windows

Tcl インターフェイスを使うには、Tcl の DLL があなたの検索パス内になければなら
ない。コンソールウィンドウで "path" とタイプすると、どのディレクトリが使われる
かがわかる。'tcldll' オプションも Tcl の DLL を指定するのに使える。

DLL の名前は、Vim がコンパイルされたときの Tcl のバージョンと一致しなければな
らない。現在、名前は "tcl86.dll" である。これは Tcl 8.6 用である。確実に知るに
は、"gviai.exe" を編集して "tcl\d*.dll\c" を検索する。


Unix

'tcldll' オプションを使うと、コンパイル時に指定された DYNAMIC_TCL_DLL ファイル
の代わりに Tcl 共有ライブラリファイルを指定できる。共有ライブラリのバージョン
は、Vim がコンパイルされたときの Tcl のバージョンと一致しなければならない。
