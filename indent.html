==============================================================================
1. C スタイルのプログラムをインデントする               C-indenting

C スタイルのインデントの基本は、ユーザーマニュアルの 30.2 節で説明されてい
る。

Vim には C スタイルのプログラムファイルを自動的にインデントするためのオプショ
ンがある。Java および C++ を含む多くのプログラミング言語は、C で確立された整形
慣習に非常に忠実に従っている。これらのオプションはインデントだけに影響し、その
他の整形は行わない。インデントに加えて他の種類の整形にも影響する追加のオプショ
ンがある。主なものについては format-comments、fo-table、gq および
formatting を参照。

実際には、インデントに使用可能な主要な方法は 4 つあり、それぞれ、有効な場合、
または 'indentexpr' については空でない場合に、前のものを上書きする:
'autoindent'    前の行のインデントを使う。
'smartindent'   'autoindent' と同様だが、いくつかの C の構文も認識して、適切な
                場所でインデントを増やす/減らす。
'cindent'       他の 2 つより賢く動作し、異なるインデントスタイルに設定できる。
'indentexpr'    すべての中で最も柔軟: 式を評価して行のインデントを計算する。空
                でない場合、この方法は他の方法を上書きする。
                indent-expression を参照。
この節の残りでは 'cindent' オプションについて説明する。

Note 'cindent' によるインデントは、すべてのコード状況でうまく働くわけではない
ことに注意。Vim は C コンパイラではない: すべての構文を認識するわけではない。
要件の 1 つは、トップレベルの関数の '{' が 1 桁目にあることである。そうでない
と、それらは宣言と混同されやすい。

これらの 5 つのオプションが C プログラムのインデントを制御する:
'cindent'       Vim が C プログラムのインデントを自動的に行うようにする。
'cinkeys'       挿入モードでどのキーが再インデントを引き起こすかを指定する。
'cinoptions'    好みのインデントスタイルを設定する。
'cinwords'      次の行で追加のインデントを開始するキーワードを定義する。
'cinscopedecls' C++ のスコープ宣言として認識される文字列を定義する。

'lisp' がオンでなく、'equalprg' が空の場合、"=" オペレータは外部プログラムを呼
び出すのではなく、Vim の組み込みのアルゴリズムを使ってインデントする。

C コードのファイルに対して 'cindent' オプションを自動的に設定し、その他のファ
イルに対してはリセットする方法については autocommand を参照。

                                        cinkeys-format indentkeys-format
'cinkeys' オプションは、特定の状況で特定の文字またはコマンドをタイプしたことに
反応して、Vim のインデントを制御する文字列である。Note これは C のインデントだ
けを引き起こすのではないことに注意。'indentexpr' が空でない場合、代わりに
'indentkeys' が使われる。'cinkeys' および 'indentkeys' の書式は同じである。

既定値は "0{,0},0),0],:,0#,!^F,o,O,e" で、これは以下のようにインデントが行われ
ることを指定する:

        "0{"    行の最初の文字として '{' をタイプした場合
        "0}"    行の最初の文字として '}' をタイプした場合
        "0)"    行の最初の文字として ')' をタイプした場合
        "0]"    行の最初の文字として ']' をタイプした場合
        ":"     ラベルまたは case 文の後で ':' をタイプした場合
        "0#"    行の最初の文字として '#' をタイプした場合
        "!^F"   CTRL-F をタイプした場合 (これは挿入されない)
        "o"     どこかで <CR> をタイプするか、または "o" コマンドを使った場合
                (挿入モードではない!)
        "O"     "O" コマンドを使った場合 (挿入モードではない!)
        "e"     行頭の "else" の 2 つ目の 'e' をタイプした場合

各キーの前に置くことができる文字:                               i_CTRL-F
!       '!' がキーの前にある場合、Vim はそのキーを挿入せず、代わりにカレント行
        を再インデントする。これにより、カレント行を再インデントするためのコマ
        ンドキーを定義できる。CTRL-F がこのためのデフォルトのキーである。
        CTRL-I は <Tab> の ASCII コードなので、これに CTRL-I を定義する場合は
        注意すること。
*       '*' がキーの前にある場合、Vim はキーを挿入する前にその行を再インデント
        する。'cinkeys' が "*<Return>" を含む場合、Vim は新しい行を開く前にカ
        レント行を再インデントする。
0       ゼロがキーの前にある場合 (ただし '!' または '*' の後に置く)、Vim は、
        そのキーがその行でタイプする最初の文字である場合だけ、その行を再インデ
        ントする。"=" の前で使われた場合、Vim は、その単語の前に空白しかない場
        合だけ、その行を再インデントする。

'!' も '*' もキーの前にない場合、Vim はキーをタイプした後にその行を再インデン
トする。したがって ';' は、';' を含む行のインデントを設定する。

特殊なキー名:
<>      山括弧は、キーの名前を綴ったものを意味する。例えば: "<Up>"、"<Ins>"
        (key-notation を参照)。
^       キャレット (^) が前に付いた文字はコントロール文字である。例えば: "^F"
        は CTRL-F である。
o       "o" コマンドを使った時、または Vim がカレント行の下に新しい行を開いた
        時 (例えば、挿入モードで <Enter> をタイプした時) に、行を再インデント
        する。
O       "O" コマンドを使った時に、行を再インデントする。
e       2 つ目の 'e' をタイプした時に、"else" で始まる行を再インデントする。
:       ラベルまたは case 文の後にある ':' がタイプされた時に、行を再インデン
        トする。C++ の "class::method" の中の ":" では再インデントしない。どん
        な ":" でも再インデントするには、"<:>" を使う。
=word   "word" の最後の文字をタイプした時に再インデントする。"word" は実際には
        他の単語の一部であってもよい。したがって "=end" は、"endif" または
        "endwhile" の "d" をタイプした時に再インデントを引き起こす。しかし
        "bend" をタイプした時には引き起こさない。補完が "word" で始まる単語を
        生成した時にも再インデントする。"0=word" は、その単語の前に空白しかな
        い場合に再インデントする。
=~word  =word と同様だが、大文字小文字を無視する。

本当に 'o'、'O'、'e'、'0'、'<'、'>'、'*'、':' または '!' をタイプした時に再イ
ンデントしたい場合、それらのキーには、それぞれ "<o>"、"<O>"、"<e>"、"<0>"、
"<<>"、"<>>"、"<*>"、"<:>" または "<!>" を使う。

<Enter> を押すたびに行がインデントされるのではなく、<Tab> を押した場合だけイン
デントされる emacs スタイルのインデントモードには、以下を提案する:
        :set cinkeys=0{,0},:,0#,!<Tab>,!^F
その時は 'autoindent' もオフにしたいかもしれない。

Note: カレント行のインデントを手動で変更した場合、Vim はその行の cindent の設
定を無視する。これにより、インデントの中で <BS>、<Tab>、または <Space> をタイ
プするか、または CTRL-T または CTRL-D を使ってインデントを変更した後に、vim が
再インデントするのを防ぐ。

                                                cinoptions-values
'cinoptions' オプションは、Vim がどのようにインデントを行うかを設定する。オプ
ション文字の後の値は、これらのいずれかにできる (N は任意の数):
        N       N 個の空白をインデントする
        -N      N 個の空白を左にインデントする
        Ns      'shiftwidth' の N 倍の空白
        -Ns     'shiftwidth' の N 倍の空白を左に

以下のリストでは、"N" は選択した数を表す (数は負でもよい)。数の後に 's' がある
場合、Vim はその数に 'shiftwidth' を掛ける: "1s" は 'shiftwidth'、"2s" は
'shiftwidth' の 2 倍、などである。小数点も使用できる: "-0.5s" はマイナス
'shiftwidth' の半分である。
以下の例では、'shiftwidth' が 4 であると仮定する。
                                                        cino->
        >N    "通常の" インデントで追加される量。インデントを増やすべき行
              ("if"、開き波括弧などで始まる行) の後で使われる。(既定値
              'shiftwidth')。

                cino=               cino=>2             cino=>2s
                  if (cond)           if (cond)           if (cond)
                  {                   {                   {
                      foo;              foo;                      foo;
                  }                   }                   }

                                                        cino-e
        eN    開き波括弧が行末にある場合 (より正確には: 行の最初の文字でない場
              合)、波括弧の組の内側の現在のインデントに N を加える。これは、
              '{' が行頭にある時と、'{' が行末にある時とで、異なるインデントに
              したい場合に便利である。(既定値 0)。

                cino=               cino=e2             cino=e-2
                  if (cond) {         if (cond) {         if (cond) {
                      foo;                  foo;            foo;
                  }                   }                   }
                  else                else                else
                  {                   {                   {
                      bar;                bar;                bar;
                  }                   }                   }

                                                        cino-n
        nN    "if"、"while" などの後の文が波括弧の組の内側にない場合、その文に
              対して現在のインデントに N を加える。これは、文の前に '{' がない
              時と、文の前に '{' がある時とで、異なるインデントにしたい場合に
              便利である。(既定値 0)。

                cino=               cino=n2             cino=n-2
                  if (cond)           if (cond)           if (cond)
                      foo;                  foo;            foo;
                  else                else                else
                  {                   {                   {
                      bar;                bar;                bar;
                  }                   }                   }

                                                        cino-f
        fN    関数またはその他のブロックの最初の開き波括弧を N 桁目に置く。こ
              れは、他の波括弧の内側になく、行頭にある開き波括弧だけに適用され
              る。波括弧の後に来るものは、この波括弧に対して相対的に置かれる。
              (既定値 0)。

                cino=               cino=f.5s           cino=f1s
                  func()              func()              func()
                  {                     {                     {
                      int foo;              int foo;              int foo;

                                                        cino-{
        {N    開き波括弧を、現在のインデントから N 文字の位置に置く。これは、
              他の波括弧の内側にある開き波括弧だけに適用される。(既定値 0)。

                cino=               cino={.5s           cino={1s
                  if (cond)           if (cond)           if (cond)
                  {                     {                     {
                      foo;                foo;                foo;

                                                        cino-}
        }N    閉じ波括弧を、対応する開き波括弧から N 文字の位置に置く。(既定値
              0)。

                cino=               cino={2,}-0.5s      cino=}2
                  if (cond)           if (cond)           if (cond)
                  {                     {                 {
                      foo;                foo;                foo;
                  }                   }                     }

                                                        cino-^
        ^N    開き波括弧が 0 桁目にある場合、波括弧の組の内側の現在のインデン
              トに N を加える。これにより、関数全体に対して異なるインデントを
              指定できる (負の数に設定したい人もいるだろう)。(既定値 0)。

                cino=               cino=^-2            cino=^-s
                  func()              func()              func()
                  {                   {                   {
                      if (cond)         if (cond)         if (cond)
                      {                 {                 {
                          a = b;            a = b;            a = b;
                      }                 }                 }
                  }                   }                   }

                                                        cino-L
        LN    ジャンプラベルの配置を制御する。N が負の場合、ラベルは 1 桁目に
              置かれる。N が負でない場合、ラベルのインデントは、現在のインデン
              トから N を引いたものになる。(既定値 -1)。

                cino=               cino=L2             cino=Ls
                  func()              func()              func()
                  {                   {                   {
                      {                   {                   {
                          stmt;               stmt;               stmt;
                  LABEL:                    LABEL:            LABEL:
                      }                   }                   }
                  }                   }                   }

                                                        cino-:
        :N    case ラベルを、switch() のインデントから N 文字の位置に置く。(既
              定値 'shiftwidth')。

                cino=               cino=:0
                  switch (x)          switch(x)
                  {                   {
                      case 1:         case 1:
                          a = b;          a = b;
                      default:        default:
                  }                   }

                                                        cino-=
        =N    case ラベルの後に現れる文を、ラベルのインデントから N 文字の位置
              に置く。(既定値 'shiftwidth')。

                cino=               cino==10
                   case 11:             case 11:  a = a + 1;
                       a = a + 1;                 b = b + 1;

                                                        cino-l
        lN    N != 0 の場合、Vim は、同じ行にあるその後の文ではなく、case ラベ
              ルに揃える。

                cino=                       cino=l1
                    switch (a) {              switch (a) {
                        case 1: {                 case 1: {
                                    break;            break;
                                }                 }

                                                        cino-b
        bN    N != 0 の場合、Vim は最後の "break" を case ラベルに揃え、
              case..break が一種のブロックのように見えるようにする。(既定値:
              0)。1 を使う場合は、'cinkeys' に "0=break" を追加することを検討
              すること。

                cino=               cino=b1
                  switch (x)          switch(x)
                  {                   {
                      case 1:             case 1:
                          a = b;              a = b;
                          break;          break;

                      default:            default:
                          a = 0;              a = 0;
                          break;          break;
                  }                   }

                                                        cino-g
        gN    C++ のスコープ宣言を、それがあるブロックのインデントから N 文字
              の位置に置く。(既定値 'shiftwidth')。デフォルトでは、スコープ宣
              言は "public:"、"protected:" または "private:" である。これは
              'cinscopedecls' オプションで調整できる。

                cino=               cino=g0
                  {                   {
                      public:         public:
                          a = b;          a = b;
                      private:        private:
                  }                   }

                                                        cino-h
        hN    C++ のスコープ宣言の後に現れる文を、ラベルのインデントから N 文
              字の位置に置く。(既定値 'shiftwidth')。

                cino=               cino=h10
                   public:              public:   a = a + 1;
                       a = a + 1;                 b = b + 1;

                                                        cino-N
        NN    C++ の namespace の内側を、通常のブロックと比べて N 文字余分にイ
              ンデントする。(既定値 0)。

                cino=                      cino=N-s
                  namespace {                namespace {
                      void function();       void function();
                  }                          }

                  namespace my               namespace my
                  {                          {
                      void function();       void function();
                  }                          }

                                                        cino-E
        EN    C++ のリンケージ指定 (extern "C" または extern "C++") の内側を、
              通常のブロックと比べて N 文字余分にインデントする。(既定値 0)。

                cino=                      cino=E-s
                  extern "C" {               extern "C" {
                      void function();       void function();
                  }                          }

                  extern "C"                 extern "C"
                  {                          {
                      void function();       void function();
                  }                          }

                                                        cino-p
        pN    K&R スタイルの関数宣言のパラメーター宣言は、余白から N 文字イン
              デントされる。(既定値 'shiftwidth')。

                cino=               cino=p0             cino=p2s
                  func(a, b)          func(a, b)          func(a, b)
                      int a;          int a;                      int a;
                      char b;         char b;                     char b;

                                                        cino-t
        tN    関数の戻り値の型の宣言を、余白から N 文字インデントする。(既定値
              'shiftwidth')。

                cino=               cino=t0             cino=t7
                      int             int                        int
                  func()              func()              func()

                                                        cino-i
        iN    C++ の基底クラスの宣言およびコンストラクタ初期化が新しい行で始ま
              る場合、それらをインデントする (そうでない場合、それらは ':' の
              右側に揃えられる)。
              (既定値 'shiftwidth')。

                cino=                     cino=i0
                  class MyClass :           class MyClass :
                      public BaseClass      public BaseClass
                  {}                        {}
                  MyClass::MyClass() :      MyClass::MyClass() :
                      BaseClass(3)          BaseClass(3)
                  {}                        {}

                                                        cino-+
        +N    継続行 (次の行にあふれ出た行) を、関数の内側では N 文字追加でイ
              ンデントする。(既定値 'shiftwidth')。
              関数の外側では、前の行がバックスラッシュで終わっている場合、2 *
              N が使われる。

                cino=                     cino=+10
                  a = b + 9 *               a = b + 9 *
                      c;                              c;

                                                        cino-c
        cN    コメント開始記号の後のコメント行を、揃えるべき他のテキストがない
              場合、コメント開始記号から N 文字インデントする。(既定値 3)。
              format-comments も参照。

                cino=                     cino=c5
                  /*                        /*
                     text.                       text.
                   */                        */

                                                        cino-C
        CN    N が 0 でない場合、コメント開始記号の後ろに他のテキストがあって
              も、コメント行を上記の c フラグで指定された量でインデントする。
              (既定値 0)。

                cino=c0                   cino=c0,C1
                  /********                 /********
                    text.                   text.
                  ********/                 ********/
              (例では ":set comments& comments-=s1:/* comments^=s0:/*" を使っ
              ている)

                                                        cino-/
        /N    コメント行を N 文字余分にインデントする。(既定値 0)。
                cino=                     cino=/4
                  a = b;                    a = b;
                  /* comment */                 /* comment */
                  c = d;                    c = d;

                                                        cino-(
        (N    閉じていない括弧の中にある場合、閉じていない括弧のある行から N
              文字インデントする。余分な閉じていない括弧ごとに 'shiftwidth' を
              1 つ追加する。N が 0 であるか、または閉じていない括弧がその行の

CLOJURE                                 ft-clojure-indent clojure-indent

Clojure インデントは、一部は角括弧および波括弧の使用のため、その他はコミュニ
ティ慣習によって、伝統的な Lisp とはいくらか異なる。これらの慣習は普遍的に従わ
れているわけではないので、Clojure インデントスクリプトはいくつかの設定オプショ
ンを提供している。

(現在の Vim が searchpairpos() を含まない場合、インデントスクリプトは通常の
'lisp' のインデントにフォールバックし、以下のオプションは無視される。)


                                                        g:clojure_maxlines

searchpairpos() の最大走査距離を設定する。大きな値は、非常に長いフォームを扱
う時に、パフォーマンスと引き換えに正確さを得る。0 の値は制限なしで走査する。既
定値は 300 である。


                                                g:clojure_fuzzy_indent
                                        g:clojure_fuzzy_indent_patterns
                                        g:clojure_fuzzy_indent_blacklist

'lispwords' オプションは、サブフォームが 2 つの空白でインデントされるべき特殊
フォームを示す、コンマ区切りの単語のリストである。

例えば:

        (defn bad []
              "Incorrect indentation")

        (defn good []
          "Correct indentation")

代わりに pattern で 'lispwords' を指定したい場合、ファジーインデント機能を使
うことができる:

        " 既定値
        let g:clojure_fuzzy_indent = 1
        let g:clojure_fuzzy_indent_patterns = ['^with', '^def', '^let']
        let g:clojure_fuzzy_indent_blacklist =
                \ ['-fn$', '\v^with-%(meta|out-str|loading-context)$']

g:clojure_fuzzy_indent_patterns および g:clojure_fuzzy_indent_blacklist
は、リストの先頭の修飾されていないシンボルに対してマッチされるパターンのリスト
である。これは、"^foo" のようなパターンが、これらすべての候補にマッチするこ
とを意味する: foobar、my.ns/foobar、および #'foobar。

各候補単語は、この順序で特別な扱いについてテストされる:

        1. 単語が文字どおり 'lispwords' にある場合、true を返す
        2. 単語が g:clojure_fuzzy_indent_blacklist のパターンにマッチする場
           合、false を返す
        3. 単語が g:clojure_fuzzy_indent_patterns のパターンにマッチする場
           合、true を返す
        4. それ以外の場合、false を返し、通常どおりインデントする


                                        g:clojure_special_indent_words

Clojure のいくつかのフォームは、'lispwords' に関係なく、すべてのサブフォームが
2 つの空白だけでインデントされるようにインデントされる。この特異な方法でインデ
ントされるべき独自の構文がある場合、以下の既定のリストに自分のシンボルを追加で
きる。

        " 既定値
        let g:clojure_special_indent_words =
           \ 'deftype,defrecord,reify,proxy,extend-type,extend-protocol,letfn'


                                        g:clojure_align_multiline_strings

複数行の文字列の後続の行を、同じ桁ではなく、開きの引用符の後の桁に揃える。

例えば:

        (def default
          "Lorem ipsum dolor sit amet, consectetur adipisicing elit, sed do
          eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut
          enim ad minim veniam, quis nostrud exercitation ullamco laboris
          nisi ut aliquip ex ea commodo consequat.")

        (def aligned
          "Lorem ipsum dolor sit amet, consectetur adipisicing elit, sed do
           eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut
           enim ad minim veniam, quis nostrud exercitation ullamco laboris
           nisi ut aliquip ex ea commodo consequat.")


                                                g:clojure_align_subforms

デフォルトでは、関数呼び出しのように見え、先頭のサブフォームがそれ自身の行にあ
る括弧付きの複合フォームでは、後続のサブフォームが開き括弧に対して 2 つの空白
でインデントされる:

        (foo
          bar
          baz)

このオプションを 1 に設定すると、この動作が変わり、すべてのサブフォームが同
じ桁に揃えられ、clojure-mode.el のデフォルトの動作をエミュレートする:

        (foo
         bar
         baz)


FORTRAN                                                 ft-fortran-indent

ブロック if、select case、select type、select rank、where、forall、type、
interface、associate、block、enum、critical、および change team 構文はインデン
トされる。サブルーチン、関数、モジュール、およびプログラムブロックのインデント
はオプションである。コメント、ラベル付きの文、および継続行は、自由形式ソースで
はインデントされるが、固定形式ソースでは左マージンの要件のためにインデントされ
ない。したがって、固定形式ソースが使われている時は、ラベル付きの文および継続行
に対して手動のインデント修正が必要になる。ソース形式の検出に使われる方法につい
てのさらなる議論は ft-fortran-syntax を参照。

Do ループ
すべての do ループは、デフォルトではインデントされないままになる。Fortran で
は、do ループは、(場合によっては複数の) ループがほぼ任意の型のラベル付き実行文
で終わるという形で、構造化されていないことがある。正しいインデントには、コンパ
イラ品質の構文解析が必要である。任意の型のラベル付きの文で終わる do ループを持
つ古いコードは、Tidy のような精巧なプログラムでインデントできる。構造化された
do/continue ループも、continue 文が do ループを終える以外の目的で使われるため、
インデントされないままになる。Tidy のようなプログラムは、構造化された
do/continue ループを do/enddo 形式に変換できる。do/enddo 種類の do ループはイ
ンデントできる。構造化された do/enddo 形式のループだけを使う場合、.vimrc で以
下のように fortran_do_enddo 変数を設定することによって、これを宣言するべきであ
る

   let fortran_do_enddo=1

その場合、do ループはインデントされる。すべてのループが、例えば .f90 ファイル
でだけ do/enddo 型である場合、以下のような自動コマンドでバッファフラグを設定す
るべきである

  au! BufRead,BufNewFile *.f90 let b:fortran_do_enddo=1

そうすると、.f90 ファイルでは do ループがインデントされ、.for のような他の拡張
子の Fortran ファイルではそのままにされる。

プログラム単位
プログラム単位 (サブルーチン、関数、モジュール、およびプログラムブロック) のイ
ンデントは、変数 fortran_indent_more を設定することによって増やすことができ、
変数 fortran_indent_less を設定することによって減らすことができる。これらの変
数は、.vimrc で以下のように、すべての fortran ファイルに対して設定できる

  let fortran_indent_less=1

対応するバッファローカル変数を以下のように設定することによって、より細かいレベ
ルの制御ができる

  let b:fortran_indent_less=1


HTML                            ft-html-indent html-indent html-indenting

これは、HTML インデントをカスタマイズするために vimrc で設定できる変数について
である。

<script> および <style> の "blocktags" の後の最初の行のインデントを設定できる
(既定値 "zero"):

      :let g:html_indent_script1 = "inc"
      :let g:html_indent_style1 = "inc"

      値        意味
      "zero"    ゼロインデント
      "auto"    自動インデント (blocktag と同じインデント)
      "inc"     自動インデント + 1 インデントステップ

開いた <tag の行の後の属性に対するインデントを設定できる:

      :let g:html_indent_attribute = 1

      値        意味
      1         自動インデント、<tag より 1 インデントステップ多い
      2         自動インデント、2 インデントステップ (既定値)
      > 2       自動インデント、より多くのインデントステップ

多くのタグは、デフォルトで後に続くものに対してインデントを増やす (スクリプトの
"Add Indent Tags" を参照)。以下で、さらにタグを追加できる:

      :let g:html_indent_inctags = "html,body,head,tbody"

以下で、そのようなタグを削除することもできる:

      :let g:html_indent_autotags = "th,td,tr,tfoot,thead"

両方の変数の既定値は空である。Note: 最初の "inctags" は、Vim セッションごとに
1 回だけ定義される。

ユーザー変数は、スクリプトが読み込まれた時にだけ読まれる。セッション中に、HTML
ファイルを再読み込みせずに変更を有効にするには、手動で以下を実行できる:

      :call HtmlIndent_CheckUserSettings()

詳細:
  "異質な" 内容を持つ "blocktags" の内側のインデントの計算:
      BLOCKTAG   インデント式       適用される場合
      <script> : {customizable}     ブロックの最初の行の場合
               : cindent(v:lnum)    属性が空であるか、または "java" を含む場合
               : -1                 それ以外 (vbscript、tcl、...)
      <style>  : {customizable}     ブロックの最初の行の場合
               : GetCSSIndent()     それ以外
      <!-- --> : -1

IDRIS2                                                  ft-idris2-indent

Idris 2 インデントは、異なる言語構文のインデントレベルを制御するいくつかの変数
で設定できる:

"g:idris2_indent_if" 変数は、if 文の後の then および else ブロックのイン
デントを制御する。既定値は 3 である。

"g:idris2_indent_case" 変数は、case 式の中のパターンのインデントを制御する。
既定値は 5 である。

"g:idris2_indent_let" 変数は、let 束縛の後のインデントを制御する。既定値は 4
である。

"g:idris2_indent_rewrite" 変数は、rewrite 式の後のインデントを制御する。既定
値は 8 である。

"g:idris2_indent_where" 変数は、where ブロックのインデントを制御する。既定値
は 6 である。

"g:idris2_indent_do" 変数は、do ブロックの中のインデントを制御する。既定値は
3 である。

設定例:

        let g:idris2_indent_if = 2
        let g:idris2_indent_case = 4
        let g:idris2_indent_let = 4
        let g:idris2_indent_rewrite = 8
        let g:idris2_indent_where = 6
        let g:idris2_indent_do = 3


MATLAB                  ft-matlab-indent matlab-indent matlab-indenting

MATLAB Editor/Debugger Language Preferences の Function indenting format の設
定は、以下に対応する:
    :let g:MATLAB_function_indent = {0, 1 or 2 (default)}

ここで 0 は Classic、1 は Indent nested functions、および 2 は Indent all
functions に対応する。


PHP                             ft-php-indent php-indent php-indenting

NOTE:   PHP ファイルは、PHP の syntax が有効な場合だけ正しくインデントされ
        る。

Unix の 'fileformat' のファイルを編集していて、改行の前に '\r' 文字がある場合、
インデントは正しく進まない ; 最初に、以下のようなコマンドでそれらの不要な文字
を削除する必要がある:

    :%s /\r$//g

または、単に変数 PHP_removeCRwhenUnix を 1 に :let するだけで、Vim が PHP
ファイルを読み込む時に (各 BufRead で)、スクリプトがそれらを黙って削除する。

オプション: ~

PHP インデントは、いくつかのグローバル変数の値を変更することによって、いくつか
の方法で変更できる:

                                        php-comment PHP_autoformatcomment
デフォルトでコメントの自動整形を有効にしないためには (独自の 'formatoptions'
を使いたい場合):
    :let g:PHP_autoformatcomment = 0

そうでない場合、'formatoptions' 文字列から 't' が削除され、"qrowcb" が追加され
る。詳細については fo-table を参照。

N は追加する 'shiftwidth' の数とする。

    /* コメント */

例えば、N = 1 の場合、以下のようになる:

    <?php

                                                        PHP_BracesAtCodeLevel
波括弧を、それらが含むコードと同じレベルにインデントするには:
    :let g:PHP_BracesAtCodeLevel = 1

これは以下の結果になる:

                                        PHP_vintage_case_default_indent

                                                        PHP_noArrowMatching

    :let g:PHP_noArrowMatching = 1

    $user_name_very_long->name()

PYTHON                                                  ft-python-indent

インデントの量は g:python_indent Dictionary で設定できる。これは項目を追加
する前に作成する必要がある:
        let g:python_indent = {}
示された例は既定値である。Note 辞書の値は式に設定されているので、後でこれらの
値を更新することなく 'shiftwidth' の値を変更できることに注意。

開き括弧の後のインデント:
        let g:python_indent.open_paren = 'shiftwidth() * 2'
ネストした括弧の後のインデント:
        let g:python_indent.nested_paren = 'shiftwidth()'
継続行のインデント:
        let g:python_indent.continue = 'shiftwidth() * 2'

デフォルトでは、複数行の構文の閉じ括弧は、前の行の最初の非空白文字の下に揃う。
それを、複数行の構文を開始する行の最初の文字の下に揃えたい場合、このキーをリ
セットする:
        let g:python_indent.closed_paren_align_last_line = v:false

この方法は、閉じていない括弧を後ろ向きに探すために searchpair() を使う。これ
は時々遅くなることがあるので、150 ミリ秒後にタイムアウトする。インデントが正し
くないことに気付いた場合、ミリ秒単位でより大きなタイムアウトを設定できる:
        let g:python_indent.searchpair_timeout = 500

閉じていない括弧を後ろ向きに探すのがまだ遅すぎる場合、特にコピー&ペースト操作
の間、または複数行の括弧の中のインデントが必要ない場合、この機能を完全に無効に
できる:
        let g:python_indent.disable_parentheses_indenting = 1

後方互換性のために、これらの変数もサポートされている:
        g:pyindent_open_paren
        g:pyindent_nested_paren
        g:pyindent_continue
        g:pyindent_searchpair_timeout
        g:pyindent_disable_parentheses_indenting


R                                                               ft-r-indent

関数の引数は、複数行にわたる場合に揃えられる。関数の引数を揃えたくない場合、
vimrc に以下を入れる:

   let r_indent_align_args = 0

コメント文字 # で始まるすべての行は、通常の R コードと同じインデントレベルにな
る。Emacs/ESS のユーザーは、1 つの # で始まる行が 40 桁目にインデントされ、##
が R コードとしてインデントされ、### がインデントされないことに慣れているかも
しれない。コメント文字で始まる行を Emacs/ESS と同じように揃えたい場合、vimrc
に以下を入れる:

   let r_indent_ess_comments = 1

1 つの # で始まる行を 40 桁目とは異なる桁に揃えたい場合、以下の例のように、変
数 r_indent_comment_column に新しい値を設定するべきである:

   let r_indent_comment_column = 30

"<-" で終わる行の後のコードはインデントされる。Emacs/ESS は、それがトップレベ
ルの関数の場合、コードをインデントしない。この点で Emacs/ESS のような動作を好
む場合、vimrc に以下を入れる:

   let r_indent_ess_compatible = 1

以下は、このオプションを有効にした場合および有効にしない場合のインデントの例で
ある:

   ### r_indent_ess_compatible = 1           ### r_indent_ess_compatible = 0
   foo <-                                    foo <-
       function(x)                               function(x)
   {                                             {
       paste(x)                                      paste(x)
   }                                             }

パターン '\(&\||\|+\|-\|\*\|/\|=\|\~\|%\|->\)\s*$' にマッチする行の後で、コー
ドはインデントされる。異なるパターンにマッチする行の後でインデントしたい場合、
vimrc で r_indent_op_pattern に適切な値を設定するべきである。

VERILOG                                                 ft-verilog-indent

if、for、case、always、initial、function、specify および begin などの一般的な
ブロック文はインデントされる。module ブロック文 (第 1 レベルのブロック) は、デ
フォルトではインデントされない。.vimrc で以下のように変数を設定することで、イ
ンデントをオンにできる:

  let b:verilog_indent_modules = 1

そうすると、module ブロックがインデントされる。これを止めるには、変数を削除す
る:

  :unlet b:verilog_indent_modules

変数を Verilog ファイルに対してだけ設定するには。以下の文を使うことができる:

  au BufReadPost * if exists("b:current_syntax")
  au BufReadPost *   if b:current_syntax == "verilog"
  au BufReadPost *     let b:verilog_indent_modules = 1
  au BufReadPost *   endif
  au BufReadPost * endif

さらに、インデント幅を変更するための変数 b:verilog_indent_width の設定 (既定値
は 'shiftwidth'):

  let b:verilog_indent_width = 4
  let b:verilog_indent_width = shiftwidth() * 2

加えて、デバッグ問題のために詳細モードを切り替えることができる:

  let b:verilog_indent_verbose = 1

メッセージの表示を可能にするために、最初に ":set cmdheight=2" を実行しておくこ
と。

generic/port のマッピング文の整列は、デフォルトで行われる。これにより、以下の
整列例のようになる:

  ENTITY sync IS
  PORT (
         clk        : IN  STD_LOGIC;
         reset_n    : IN  STD_LOGIC;
         data_input : IN  STD_LOGIC;

右辺の代入 "<=" 文の整列は、デフォルトで行われる。これにより、以下の整列例のよ

  sig_out <= (bus_a(1) AND
             (sig_b OR sig_c)) OR
             (bus_a(0) AND sig_d);

これをオフにするには、以下を

.vimrc ファイルに追加する。これにより、前の整列例が以下のように変わる:

  sig_out <= (bus_a(1) AND
    (sig_b OR sig_c)) OR
    (bus_a(0) AND sig_d);

----------------------------------------

全行コメント ("--" で始まる行) は、"--" の後に空白が続く場合に限り、すぐ前の行
のコメントに揃うようにインデントされる。

例えば:

  sig_a <= sig_b; -- コメントの開始
                  -- コメントの続き
                  -- 同じコメントのさらに続き

挿入モードで、"-- " をタイプした後 (空白 " " に注意)、CTRL-F を押すと、カレン
トの "-- " が前の行の "--" に揃えられる。

すぐ前の行が "--" を含まない場合、全行コメントは、全行コメントではない次の非空
行の開始に揃えられる。

以下のコードをインデントすると:

  sig_c <= sig_d; -- comment 0
         -- comment 1
               -- comment 2
    --debug_code:
    --PROCESS(debug_in)
         --BEGIN
            --  FOR i IN 15 DOWNTO 0 LOOP
             --    debug_out(8*i+7 DOWNTO 8*i) <= debug_in(15-i);
            --  END LOOP;
     --END PROCESS debug_code;

      -- comment 3
  sig_e <= sig_f; -- comment 4
           -- comment 5

以下の結果になる:

  sig_c <= sig_d; -- comment 0
                  -- comment 1
                  -- comment 2
  --debug_code:
  --PROCESS(debug_in)
  --BEGIN
  --  FOR i IN 15 DOWNTO 0 LOOP
  --    debug_out(8*i+7 DOWNTO 8*i) <= debug_in(15-i);
  --  END LOOP;
  --END PROCESS debug_code;

  -- comment 3
  sig_e <= sig_f; -- comment 4
                  -- comment 5

"--debug_code:" の中の "--" の後に続く空白がないので、"--debug_code:" は
"-- comment 2" に揃わないことに注目。

コメントのインデントの動的な性質のため、インデントは 2 回行うべきである。最初
のパスでは、コードがインデントされる。2 回目のパスでは、全行コメントが、正しく
インデントされたコードに従ってインデントされる。


VIM                                                     ft-vim-indent
                                                        g:vim_indent
Vim script インデントは、g:vim_indent 辞書変数で設定できる。これは 3 つの
キー、line_continuation、more_in_bracket_block、および
searchpair_timeout をサポートする。
line_continuation は、バックスラッシュで始まる継続行のインデントレベルに加え
られる数値を期待し、既定値は shiftwidth() * 3 である。文字列も受け付け、それ
は実行時に評価される。
more_in_bracket_block は真偽値を期待する; オンの場合、括弧で囲まれたブロック
の内側で余分な shiftwidth() が加えられる。既定値は v:false である。
searchpair_timeout は、タイムアウトとして searchpair() に渡される数値を期
待する。値を増やすと、より正確な結果が得られるかもしれないが、インデントにより
多くの時間がかかるようにもなる。既定値は 100 (ミリ秒) である。

設定の例:

        let g:vim_indent = #{
            \ line_continuation: shiftwidth() * 3,
            \ more_in_bracket_block: v:false,
            \ searchpair_timeout: 100,
            \ }

                                                        g:vim_indent_cont
この変数は g:vim_indent.line_continuation と同等である。
後方互換性のためにサポートされている。
