                          言語を選択する (ロケール)


Vim のメッセージは、いくつかの言語で表示できます。この章では、どれを使うかを変
更する方法を説明します。また、さまざまな言語のファイルを扱うためのいろいろな方
法を説明します。

45.1  メッセージの言語

Vim を起動すると、使っている言語を調べるために環境をチェックします。ほとんどの
場合、これはうまく動作するはずで、あなたの言語でメッセージが表示されます (それ
らが使用可能な場合)。現在の言語が何かを見るには、このコマンドを使います:

        :language

"C" と返ってきた場合、これは既定値が使われていることを意味し、それは英語です。

        Note:
        異なる言語を使うことは、Vim がそれを扱えるようにコンパイルされていると
        きにだけ動作します。動作するかどうかを調べるには、":version" コマンド
        を使い、出力に "+gettext" および "+multi_lang" があるかをチェックして
        ください。それらがある場合、OK です。"-gettext" または "-multi_lang"
        が表示される場合、別の Vim を見つける必要があります。

あなたのメッセージを別の言語にしたい場合はどうでしょうか? いくつかの方法があり
ます。どれを使うべきかは、あなたのシステムの能力によります。
   1 つ目の方法は、Vim を起動する前に、環境を望みの言語に設定することです。
Unix での例:

        env LANG=de_DE.ISO_8859-1  vim

これは、その言語があなたのシステムで使用可能な場合にだけ動作します。利点は、す
べての GUI メッセージおよびライブラリ内のものも正しい言語を使うことです。欠点
は、Vim を起動する前にこれを行わなければならないことです。Vim の実行中に言語を
変更したい場合、2 つ目の方法を使えます:

        :language fr_FR.ISO_8859-1

この方法では、あなたの言語のいくつかの名前を試すことができます。それがあなたの
システムでサポートされていないときは、エラーメッセージが表示されます。翻訳され
たメッセージが使用可能でないときは、エラーは表示されません。Vim は黙って英語を
使うことにフォールバックします。
   どの言語があなたのシステムでサポートされているかを調べるには、それらが一覧
されているディレクトリを見つけてください。私のシステムでは "/usr/share/locale"
です。いくつかのシステムでは "/usr/lib/locale" にあります。"setlocale" のマニュ
アルページに、あなたのシステムのどこにあるかのヒントがあるはずです。
   名前は、正確にあるべきとおりにタイプするように注意してください。大文字およ
び小文字は区別され、'-' および '_' 文字は混同しやすいです。

メッセージ、編集されるテキスト、および時刻の書式に対して、別々に言語を設定する
こともできます。:language を参照してください。


自分でメッセージを翻訳する

あなたの言語の翻訳されたメッセージが使用可能でない場合、自分で書くこともできま
す。これを行うには、Vim のソースコードおよび GNU gettext パッケージを入手して
ください。ソースを展開した後、ディレクトリ src/po/README.txt に説明があります。
   翻訳を行うのはそれほど難しくありません。プログラマである必要はありません。
もちろん、英語および翻訳先の言語の両方を知っている必要があります。
   翻訳に満足したときは、それを他の人が利用できるようにすることを検討してくだ
さい。vim-online (http://vim.sf.net) にアップロードするか、または Vim メンテ
ナー <maintainer@vim.org> にメールで送ってください。または両方を。

45.2  メニューの言語

既定のメニューは英語です。あなたの地域の言語を使えるようにするには、それらを翻
訳する必要があります。通常、メッセージの場合とちょうど同じように、環境があなた
の言語に設定されている場合、これは自動的に行われます。このために何か追加で行う
必要はありません。しかし、それはその言語の翻訳が使用可能な場合にだけ動作しま
す。
   ドイツにいて、言語がドイツ語に設定されているが、"Datei" の代わりに "File"
を使いたいとします。この方法で、英語のメニューを使うように戻すことができます:


        :set langmenu=none

言語を指定することもできます:

        :set langmenu=nl_NL.ISO_8859-1

上と同様に、"-" と "_" の間の違いは区別されます。しかし、ここでは大文字/小文字
の違いは無視されます。
   'langmenu' オプションは、メニューが読み込まれる前に設定する必要があります。
メニューが定義されてしまうと、'langmenu' を変更しても直接の効果はありません。
したがって、'langmenu' を設定するコマンドはあなたの vimrc ファイルに入れてくだ
さい。
   Vim の実行中にどうしてもメニューの言語を切り替えたい場合、この方法でできま
す:

        :source $VIMRUNTIME/delmenu.vim
        :set langmenu=de_DE.ISO_8859-1
        :source $VIMRUNTIME/menu.vim

1 つ欠点があります: 自分で定義したすべてのメニューがなくなってしまいます。それ
らも定義し直す必要があります。


自分でメニューを翻訳する

どのメニューの翻訳が使用可能かを見るには、このディレクトリを見てください:

        $VIMRUNTIME/lang

ファイルは menu_{language}.vim と呼ばれます。使いたい言語が見当たらない場合、
あなた自身の翻訳を行うことができます。これを行う最も簡単な方法は、既存の言語
ファイルの 1 つをコピーし、それを変更することです。
   まず、":language" コマンドであなたの言語の名前を調べてください。この名前を、
ただしすべての文字を小文字にして使います。それから、そのファイルを、
'runtimepath' の早いほうで見つかるあなた自身のランタイムディレクトリにコピーし
ます。例えば、Unix では次のようにします:

        :!cp $VIMRUNTIME/lang/menu_ko_kr.euckr.vim ~/.vim/lang/menu_nl_be.iso_8859-1.vim

翻訳のヒントは "$VIMRUNTIME/lang/README.txt" にあります。

45.3  別のエンコーディングを使う

Vim は、編集しようとしているファイルがあなたの言語用にエンコードされていると推
測します。多くのヨーロッパの言語では、これは "latin1" です。その場合、各バイト
が 1 文字です。つまり、256 個の異なる文字が可能です。アジアの言語では、これで
は十分ではありません。これらはたいてい 2 バイトのエンコーディングを使い、1 万
を超える文字を可能にしています。テキストがいくつかの異なる言語を含むときは、こ
れでもまだ十分ではありません。ここで Unicode の出番です。それは、一般的に使わ
れる言語で使われるすべての文字を含むように設計されました。これは
"他のすべてを置き換える超エンコーディング" です。しかし、まだそれほど多くは使
われていません。
   幸い、Vim はこれら 3 種類のエンコーディングをサポートしています。そして、い
くつかの制限はありますが、あなたの環境がテキストとは別の言語を使っているときで
も、それらを使うことができます。
   それでも、あなたの言語のエンコーディングのファイルだけを編集するときは、既
定値でうまく動作するはずで、何もする必要はありません。以下は、異なる言語を編集
したいときにだけ関係があります。


GUI で Unicode を使う

Unicode のよいところは、他のエンコーディングを情報を失わずにそれに変換し、また
戻すことができる点です。Vim に内部で Unicode を使わせると、任意のエンコーディ
ングのファイルを編集できるようになります。
   残念ながら、Unicode をサポートしているシステムの数はまだ限られています。し
たがって、あなたの言語がそれを使っている可能性は低いです。Unicode を使いたいこ
と、およびシステムの残りの部分とのインターフェイスをどう扱うかを Vim に伝える
必要があります。
   Unicode 文字を表示できる、GUI 版の Vim から始めましょう。これで動作するはず
です:

        :set encoding=utf-8
        :set guifont=-misc-fixed-medium-r-normal--18-120-100-100-c-90-iso10646-1

'encoding' オプションは、使う文字のエンコーディングを Vim に伝えます。これは
バッファ内のテキスト (編集しているファイル)、レジスタ、Vim script ファイルなど
に適用されます。'encoding' は Vim の内部のための設定とみなすことができます。
   この例は、あなたのシステムにこのフォントがあることを前提としています。例の
中の名前は X Window System 用です。このフォントは、xterm を Unicode サポートで
拡張するために使われるパッケージに入っています。このフォントがない場合、ここで
見つかるかもしれません:

        http://www.cl.cam.ac.uk/~mgk25/download/ucs-fonts.tar.gz

MS-Windows では、いくつかのフォントは限られた数の Unicode 文字を持っています。
"Courier New" フォントを使ってみてください。Edit/Select Font... メニューを使っ
て、使用可能なフォントを選択して試すことができます。ただし、固定幅フォントだけ
が使えます。例:

        :set guifont=courier_new:h12

うまく動作しない場合、fontpack を入手してみてください。Microsoft がそれを移動
していない場合、ここで見つけられます:

        http://www.microsoft.com/typography/fonts/default.aspx

これで、内部で Unicode を使い、Unicode フォントでテキストを表示するように Vim
に伝えました。タイプした文字は、まだあなたの元の言語のエンコーディングで届きま
す。これには、それらを Unicode に変換する必要があります。'termencoding' オプ
ションで、どの言語から変換するかを Vim に伝えてください。次のようにできます:

        :let &termencoding = &encoding
        :set encoding=utf-8

これは、'encoding' を utf-8 に設定する前に、'encoding' の古い値を
'termencoding' に代入します。これがあなたのセットアップで本当に動作するかは、
試してみる必要があります。アジアの言語のインプットメソッドを使っていて、
Unicode テキストを編集したいときに、特にうまく動作するはずです。


Unicode 端末で Unicode を使う

Unicode を直接サポートしている端末があります。XFree86 に付属する標準の xterm
はその 1 つです。それを例として使いましょう。
   まず第一に、xterm は Unicode サポート付きでコンパイルされている必要がありま
す。それをチェックする方法、および必要なときにそれをコンパイルする方法について
は、UTF8-xterm を参照してください。
   "-u8" 引数を付けて xterm を起動してください。フォントも指定する必要があるか
もしれません。例:

   xterm -u8 -fn -misc-fixed-medium-r-normal--18-120-100-100-c-90-iso10646-1

これで、この端末の中で Vim を実行できます。前と同じように、'encoding' を
"utf-8" に設定してください。それで全部です。


通常の端末で Unicode を使う

Unicode ファイルを扱いたいが、Unicode をサポートしている端末を持っていないとし
ます。端末でサポートされていない文字は表示されませんが、Vim でこれを行うことが
できます。テキストのレイアウトは保たれます。

        :let &termencoding = &encoding
        :set encoding=utf-8

これは GUI で使ったのと同じです。しかし、動作は異なります: Vim は、表示される
テキストを端末に送る前に変換します。それにより、表示がおかしな文字で乱れるのを
避けます。
   これが動作するには、'termencoding' と 'encoding' の間の変換が可能である必要
があります。Vim は latin1 から Unicode に変換するので、それは常に動作します。
他の変換には +iconv 機能が必要です。
   Unicode 文字を含むファイルを編集してみてください。端末が表示できない文字が
あるべき場所に、Vim が疑問符 (またはアンダースコア、または何か他の文字) を置く
ことに気付くでしょう。カーソルを疑問符に移動し、このコマンドを使ってください:


        ga

Vim はその文字のコードを含む行を表示します。これにより、それが何の文字かのヒン
トが得られます。Unicode の表でそれを調べることができます。時間がたくさんある場
合、実際にその方法でファイルを見ることもできます。

        Note:
        'encoding' は Vim の内部のすべてのテキストに使われるので、それを変更す
        ると、すべての非 ASCII テキストが無効になります。レジスタおよび
        'viminfo' ファイル (例えば、記憶された検索パターン) を使うときに、これ
        に気付くでしょう。'encoding' はあなたの vimrc ファイルで設定し、それに
        は手を触れないことをお勧めします。

45.4  異なるエンコーディングのファイルを編集する

Vim を Unicode を使うように設定していて、16-bit Unicode のファイルを編集したい
とします。簡単そうですよね? さて、Vim は実際には内部で utf-8 エンコーディング
を使っているので、16-bit エンコーディングは変換する必要があります。文字セット
(Unicode) とエンコーディング (utf-8 または 16-bit) の間には違いがあるからです。
   Vim は、どんな種類のファイルを編集しているかを検出しようとします。それには
'fileencodings' オプションのエンコーディング名を使います。Unicode を使っている
ときは、既定値は "ucs-bom,utf-8,latin1" です。これは、Vim がファイルをチェック
して、これらのエンコーディングのどれかであるかを調べることを意味します:

        ucs-bom         ファイルはバイトオーダーマーク (BOM) で始まらなければ
                        ならない。これにより、16-bit、32-bit、および utf-8 の
                        Unicode エンコーディングを検出できる。
        utf-8           utf-8 Unicode。バイトの並びが utf-8 として不正なとき
                        は、これは拒否される。
        latin1          古き良き 8-bit エンコーディング。常に動作する。

その 16-bit Unicode ファイルの編集を開始し、それに BOM がある場合、Vim はこれ
を検出し、読み込むときにファイルを utf-8 に変換します。'fileencoding' オプショ
ン (末尾に s なし) は検出された値に設定されます。この場合、それは "utf-16le"
です。これは、Unicode、16-bit、およびリトルエンディアンであることを意味します。
このファイル形式は MS-Windows では一般的です (例えば、レジストリファイル)。
   ファイルを書き込むとき、Vim は 'fileencoding' を 'encoding' と比較します。
それらが異なる場合、テキストは変換されます。
   'fileencoding' の空の値は、変換が行われないことを意味します。したがって、テ
キストは 'encoding' でエンコードされているとみなされます。

既定の 'fileencodings' の値が合わない場合、Vim に試してほしいエンコーディング
に設定してください。ある値が無効であるとわかったときにだけ、次のものが使われま
す。"latin1" を最初に置くのはうまくいきません。それは決して不正にならないから
です。ファイルに BOM がなく、utf-8 でもないときに日本語にフォールバックする例:


        :set fileencodings=ucs-bom,utf-8,sjis

推奨される値については encoding-values を参照してください。他の値も動作する
かもしれません。これは使用可能な変換によります。


エンコーディングを強制する

自動検出がうまくいかない場合、ファイルがどのエンコーディングであるかを Vim に
伝える必要があります。例:

        :edit ++enc=koi8-r russian.txt

"++enc" の部分は、このファイルに対してだけ使うエンコーディングの名前を指定しま
す。Vim はファイルを、指定されたエンコーディング、この例ではロシア語から、
'encoding' に変換します。'fileencoding' も指定されたエンコーディングに設定され
るので、ファイルを書き込むときに逆の変換を行うことができます。
   ファイルを書き込むときにも同じ引数を使えます。この方法で、実際に Vim を使っ
てファイルを変換できます。例:

        :write ++enc=utf-8 russian.txt

        Note:
        変換により文字が失われることがあります。あるエンコーディングから
        Unicode に変換して戻すことは、不正な文字がない限り、たいていこの問題は
        ありません。ファイルに 2 つ以上の言語があったときは、Unicode から他の
        エンコーディングへの変換では、しばしば情報が失われます。

45.5  言語のテキストを入力する

コンピューターのキーボードには、100 個を大きく超えるキーはありません。数千の文
字を持つ言語もあり、Unicode には 10 万を超える文字があります。では、これらの文
字をどうやってタイプするのでしょうか?
   まず第一に、特殊文字をそれほど多く使わないときは、ダイグラフを使うことがで
きます。これは 24.9 ですでに説明しました。
   あなたのキーボードのキーよりもずっと多くの文字を使う言語を使うときは、イン
プットメソッド (IM) を使いたくなるでしょう。これには、タイプしたキーから結果の
文字への変換を覚える必要があります。IM が必要なときは、おそらくすでにあなたの
システムにあるでしょう。他のプログラムと同じように Vim でも動作するはずです。
詳しくは、X Window system については mbyte-XIM を、MS-Windows については
mbyte-IME を参照してください。


キーマップ

いくつかの言語では、文字セットはラテン文字とは異なりますが、同じくらいの数の文
字を使います。キーを文字にマップすることが可能です。Vim はこのためにキーマップ
を使います。
   ヘブライ語をタイプしたいとします。次のようにキーマップを読み込むことができ
ます:

        :set keymap=hebrew

Vim はキーマップファイルを探そうとします。これは 'encoding' の値によります。一
致するファイルが見つからなかった場合、エラーメッセージが表示されます。

これで、挿入モードでヘブライ語をタイプできます。ノーマルモード、および ":" コ
マンドをタイプするときは、Vim は自動的に英語に切り替えます。ヘブライ語と英語の
間で切り替えるには、このコマンドを使えます:

        CTRL-^

これは挿入モードおよびコマンドラインモードでだけ動作します。ノーマルモードで
は、まったく異なること (代替ファイルへのジャンプ) をします。
   'showmode' オプションが設定されている場合、キーマップの使用はモードメッセー
ジで示されます。GUI では、Vim はキーマップの使用を異なるカーソルの色で示しま
す。
   'iminsert' および 'imsearch' オプションでキーマップの使用を変更することもで
きます。

マッピングの一覧を見るには、このコマンドを使います:

        :lmap

どのキーマップファイルが使用可能かを調べるには、GUI では Edit/Keymap メニュー
を使えます。それ以外では、このコマンドを使えます:

        :echo globpath(&rtp, "keymap/*.vim")


自分でキーマップを作る

あなた自身のキーマップファイルを作ることができます。それほど難しくありません。
使いたい言語に似たキーマップファイルから始めてください。それをあなたのランタイ
ムディレクトリ内の "keymap" ディレクトリにコピーします。例えば、Unix では、ディ
レクトリ "~/.vim/keymap" を使います。
   キーマップファイルの名前は、次のようでなければなりません:

        keymap/{name}.vim
または
        keymap/{name}_{encoding}.vim

{name} はキーマップの名前です。わかりやすいが、既存のキーマップとは異なる名前
を選んでください (既存のキーマップファイルを置き換えたいのでない限り)。{name}
はアンダースコアを含むことができません。必要に応じて、アンダースコアの後に、使
われるエンコーディングを追加してください。例:

        keymap/hebrew.vim
        keymap/hebrew_utf-8.vim

ファイルの内容は見ればわかるはずです。Vim と一緒に配布されているキーマップのい
くつかを見てください。詳しくは mbyte-keymap を参照してください。


最後の手段

他のすべての方法が失敗した場合、CTRL-V で任意の文字を入力できます:

        エンコード タイプ               範囲
        8-bit      CTRL-V 123           10 進数 0-255
        8-bit      CTRL-V x a1          16 進数 00-ff
        16-bit     CTRL-V u 013b        16 進数 0000-ffff
        31-bit     CTRL-V U 001303a4    16 進数 00000000-7fffffff

スペースはタイプしないでください。詳しくは i_CTRL-V_digit を参照してくださ
い。
