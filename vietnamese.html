1. はじめに
                                                        vietnamese-intro
Vim は以下の方法でベトナム語をサポートしている:

- 組み込みの vietnamese-keymap。US キーボード配列を使って、Insert-mode と
  search-commands でベトナム語の文字を入力できる。
- ベトナム語へのローカライゼーション。vietnamese-l10n を参照

==============================================================================
2. ベトナム語のキーマップ
                                                        vietnamese-keymap
言語を切り替えるには、システムネイティブのキーボード切り替え機能を使うか、以下
のように、Vim の配布物に含まれているベトナム語のキーマップのどれかを使える
    :set keymap=vietnamese-telex_utf-8

詳細は 'keymap' を参照。

後者の場合は、ベトナム語の入力メソッドエンジン (IME) が無い場合や、Vim をシス
テム全体のキーボード設定から独立させたい場合 ('imdisable' が設定されているとき)
でも、ベトナム語を入力できる。キーボードを切り替えるキーを :map することもで
きる。

Vim には以下のベトナム語のキーマップが付属している:
- vietnamese-telex_utf-8      Telex 入力メソッド、UTF-8 エンコーディング。
- vietnamese-viqr_utf-8       VIQR 入力メソッド、UTF-8 エンコーディング。
- vietnamese-vni_utf-8        VNI 入力メソッド、UTF-8 エンコーディング。

                                                   vietnamese-ime_diff
これらのキーマップは最小限になるように設計されたので、対応する入力メソッドのす
べての機能をサポートしてはいない。違いは以下で説明する:

- 各文字は 1 つずつしか入力できず、基本の文字を先に、分音記号を後に入力する。
  例えば、vietnamese-vni_utf-8 を使って単語 nến を入力するには、nen61 や
  ne6n1 ではなく ne61n とタイプしなければならない
- 2 つ以上の分音記号を持つ文字は、声調記号の前に母音記号をタイプする必要があ
  る。例えば、vietnamese-telex_utf-8 を使って ồ を入力するには、ofo では
  なく oof とタイプする必要がある。
- vietnamese-telex_utf-8 では、分音記号付きの大文字を出すには、すべて大文字
  でタイプする必要がある。例えば、Ừ は UWF とタイプしなければならない。
- vietnamese-telex_utf-8 では VNI のエスケープ文字 \ が追加されている。そ
  のため、oo を入力するための、曖昧さにつながりうる紛らわしい ooo という入
  力は削除されている。例えば、単語 Đoòng を入力するには DDo\ofng とタイプ
  する。
- w[]{} 形式を含む Simple Telex (v1 と v2 の両方) はサポートされていない。
- Telex の z や、VNI と VIQR の 0 を使って分音記号を取り除くことはサポート
  されていない。

==============================================================================
3. ローカライゼーション
                                                        vietnamese-l10n
Vim の messages はベトナム語でも使用できる。メッセージをベトナム語で見たい場
合は、ベトナム語のロケールの名前を引数にして、コマンド :language を実行すれ
ばよい。例えば、
        :language vi_VN
  または
        :language vi_VN.utf-8

Note ベトナム語のロケールの名前はシステムによって異なる場合があることに注意。
詳細は mbyte-first を参照。

tutor のプレーンテキスト版もベトナム語で使用できる。そこで説明されているよう
に、ファイル "tutor1.vi" を使うこと。
