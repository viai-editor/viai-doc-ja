Wayland プロトコルのサポート                            wayland

1. 役に立つ Wayland 情報        wayland-useful
2. Wayland セレクション         wayland-selections

==============================================================================
1. 役に立つ Wayland 情報                                wayland-useful

                                                        wayland-seat
Wayland のクリップボードなどの機能は、使うシートを必要とする。Wayland シート
は、キーボード、ポインタ、およびタッチデバイスから成ることがある。使うシートは
'wlseat' オプションで設定できる。同じ Wayland セッションで複数の Wayland シー
トを使う場合にだけ役に立つ。これが何であるのか分からない場合は、おそらくあなた
には関係ない。

                                                        wayland-gui
gui-wayland を参照。Note GUI を使うとき、Vim は GTK などのツールキットを使っ
てクリップボードにアクセスし、Wayland を通してはクリップボードにアクセスしない
ことに注意。これは v:clipmethod 変数で確認できる。GUI を実行しているときは
"none" に等しくなるはずである。

Wayland コマンド:
                                                        :wlrestore :wl
:wl[restore] [display]  Wayland コンポジタへの接続を再初期化する。
                        Vim を screen/tmux セッションで実行していて、Wayland
                        コンポジタが再起動した後もそのセッションが実行され続け
                        る場合に役に立つ。

                        [display] は $WAYLAND_DISPLAY 環境変数の形式 (例:
                        "wayland-0") でなければならない。[display] を省略する
                        と、このコマンドの前回の実行で使われたのと同じ値を使っ
                        て接続を再初期化する。値が一度も指定されていなければ、
                        $WAYLAND_DISPLAY 環境変数の値を使う。これは
                        v:clipmethod も更新する。
                        {+wayland 機能付きでコンパイルされたときのみ有効}

Wayland エラー:
                                                        E1548
Vim は Wayland コンポジタとの通信に失敗した。これはおそらく、Wayland コンポジ
タのプロセスが kill されたためである。もう一度接続を試みるには、:wlrestore
コマンドを試すこと。

2. Wayland セレクション                                 wayland-selections

Vim は、現在の Wayland セレクションにアクセスするために、
wlr-data-control-unstable-v1 および ext-data-control-v1 プロトコルをサポートし
ている。この場合のセレクションは、本質的に "クリップボード." を意味する。
Wayland コンポジタがこれらのプロトコルのどちらかをサポートしているかは、
wayland-info コマンドを実行して確認できる。このコマンドはシステムの libwayland
に同梱されているはずである:
        wayland-info | grep -E '(ext_data_control|zwlr_data_control)'
grep がマッチを見つけたら、システムにどちらかまたは両方のプロトコルがある。

どちらかまたは両方のプロトコルをサポートしていることが知られているコンポジタ:
    1. KWin (KDE)
    2. wlroots ベース (Sway, Labwc)
    3. Niri
    4. Hyprland
    5. Wayfire

X11 から来た場合、通常の Wayland セレクションは X11 の CLIPBOARD セレクション
に相当し、プライマリの Wayland セレクションは X11 の PRIMARY セレクションに相
当する。これらのセレクションへのアクセスは Vim の X11 と同じで、+ レジスタが通
常のセレクション、* レジスタがプライマリセレクションである。Note コンポジタが
プライマリセレクションをサポートしていないかもしれないことに注意。詳細は
wayland-primary-selection を参照。

                                                        wayland-persist
X11 のカットバッファを使っている場合、Wayland にはそのようなものは存在しない。
代わりに、そのような機能を模倣するには、Wayland クライアントが終了したときにセ
レクションデータを保持するために、別のクリップボードマネージャーを使わなければ
ならない。

                                                        wayland-and-x11
使っている Vim が X11 および Wayland の両方のサポート付きでコンパイルされてい
る場合、クリップボードにアクセスするときにどちらを使うかは、Vim が
'clipmethod' オプションを使って決める。

                                                wayland-primary-selection
X11 スタイルのプライマリセレクションが便利だと思う場合、Wayland も Vim がサポー
トするプロトコルを使ってこの機能を実装している。ただし、wlr-data-control プロ
トコルのバージョン 1 (プロトコル名の 'v1' とは別物) を使っている場合はこの限り
ではなく、その場合プライマリセレクションはサポートされない。これは次を使って確
認できる
        wayland-info | grep -E '(ext_data_control|zwlr_data_control)'
"zwlr_data_control_manager_v1" の "version:" エントリが "2" 以上なら、プライマ
リセレクションはサポートされている。"ext_data_control_manager_v1" も得られた場
合は、Vim は代わりにそのプロトコルを使う。そのプロトコルにはプライマリセレク
ションのサポートが組み込まれている。

Wayland コンポジタが wlr-data-control-v1 または ext-data-control-v1 プロトコル
をサポートしていない場合、Vim は Wayland プロトコルを通してクリップボードに直
接アクセスできない。代わりに、ユーザー定義の clipboard-providers を通して、
wl-clipboard などの外部ツールを使える。

例: wl-copy および wl-paste をシェルで実行するプロバイダを定義する:

    vim9script

    def Available(): bool
        return executable('wl-copy') && executable('wl-paste')
    enddef

    def Copy(reg: string, type: string, str: list<string>)
        var args = "wl-copy"

        if reg == "*"
            args ..= " -p"
        endif

        silent system(args, str)
    enddef

    def Paste(reg: string): tuple<string, list<string>>
        var args = "wl-paste --type text/plain;charset=utf-8"

        if reg == "*"
            args ..= " -p"
        endif

        silent return ("", systemlist(args))
    enddef

    v:clipproviders["wl_clipboard"] = {
        available: Available,
        copy: {
            "+": Copy,
            "*": Copy
        },
        paste: {
            "+": Paste,
            "*": Paste
        }
    }

    set clipmethod=wl_clipboard


これは wl-clipboard パッケージがインストールされていることに依存する
(https://github.com/bugaevc/wl-clipboard)。
