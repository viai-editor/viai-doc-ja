                                                hangul
Vim には XIM (X Input Method) を使っていないユーザー向けにハングル (韓国語) の
サポートがあった。しかし、うまく動かずメンテナンスもされていなかったため Vim
8.1.2327 で削除された。

もしこのハングルインプットメソッドを使いたい場合は Vim 8.1.2326 かそれ以前に戻
ること。もしあなたが、このコードは有用でメンテナンスしたいと考えるならそれを元
に戻すパッチを作ること。しかし、それが UTF-8 エンコーディングで動くようにする
のが最良だろう。
