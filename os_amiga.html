                  VIAI リファレンスマニュアル


                                                        Amiga
このファイルには Amiga 版 Vim の特記事項が書かれている。
以下に MorphOS 専用の節もある。

NOTE: Amiga コードはまだ含まれているが、メンテナンスまたはテストされていない。

Amiga へのインストール:
- "VIM:" を、Vim の "doc" ディレクトリがあるディレクトリに割り当てる。Vim は
  ファイル "VIM:doc/help.txt" を探す (help コマンドのため)。
  環境変数 $VIM を設定しても動作する。逆も同じで、$VIM が使われ、それが定義さ
  れていない場合は "VIM:" が使われる。
- DOS 1.3 以前の場合: "arp.library" を "libs:" に置く。Vim は +ARP 機能を有
  効にしてコンパイルされていなければならない。newcli および run が "C:" にある
  ことを確かめること (外部コマンドを実行するため)。
- "-c" 付きのコマンドを受け付けるシェル (例えば Fish disk 624 の "Csh") を、
  "c:"、または検索パスにある他のディレクトリに置く (外部コマンドを実行するた
  め)。

メモリが十分にあれば、コマンド "rez csh vim" で Vim および csh を常駐させるこ
とで、起動の遅れを避けられる。"rezlib.library" を "libs:" ディレクトリに置く必
要がある。2.0 では rez のバージョン 0.5 が必要である。

ダイグラフを使わない場合は、+digraphs 機能を無効にして再コンパイルすると、メ
モリをいくらか節約できる。Vim を他の端末で使いたい場合は、TERMCAP オプション付
きで再コンパイルできる。Vim は Manx 5.x および SAS 6.x でコンパイルできる。
makefile および feature.h を参照。

構文ハイライトがオンのとき、または入れ子のワイルドカードを含む検索パターンを
使ったときに、Vim がいくつかのファイルでクラッシュすることに気付いた場合は、ス
タックが小さすぎるのかもしれない。スタックサイズを増やしてみること。シェルで
は、Vim を起動する前に Stack コマンドを使う。Workbench では、Vim アイコンを選
択し、workbench の "Info" メニューを使って、フォームの Stack フィールドを変更
する。

別の色を使いたい場合は、termcap コードを設定する:
        t_mr (反転したテキスト用)
        t_md (太字のテキスト用)
        t_me (t_mr および t_md の後の通常のテキスト用)
        t_so (強調モード用)
        t_se (t_so の後の通常のテキスト用)
        t_us (下線付きのテキスト用)
        t_ue (t_us の後の通常のテキスト用)
        t_ZH (イタリックのテキスト用)
        t_ZR (t_ZH の後の通常のテキスト用)

標準の ANSI エスケープシーケンスが使われる。コードは:
30 grey char   40 grey cell   >0 grey background    0 all attributes off
31 black char  41 black cell  >1 black background   1 boldface
32 white char  42 white cell  >2 white background   2 faint
33 blue char   43 blue cell   >3 blue background    3 italic
34 grey char   44 grey cell   >4 grey background    4 underscore
35 black char  45 black cell  >5 black background   7 reverse video
36 white char  46 white cell  >6 white background   8 invisible
37 blue char   47 blue cell   >7 blue background

'>' の付いたコードは最後でなければならない。cell および background の色は同じ
にするべきである。コードはセミコロンで区切って組み合わせられる。例えば、青い背
景に白いテキストにするには:
  :set t_me=^V<Esc>[0;32;43;>3m
  :set t_se=^V<Esc>[0;32;43;>3m
  :set t_ue=^V<Esc>[0;32;43;>3m
  :set t_ZR=^V<Esc>[0;32;43;>3m
  :set t_md=^V<Esc>[1;32;43;>3m
  :set t_mr=^V<Esc>[7;32;43;>3m
  :set t_so=^V<Esc>[0;31;43;>3m
  :set t_us=^V<Esc>[4;32;43;>3m
  :set t_ZH=^V<Esc>[3;32;43;>3m

フィルタコマンドで複数のコマンドを使う場合、例えば:
  :r! echo this; echo that
最後のコマンドの出力だけが使われる。これを直すには、コマンドをグループにする必
要がある。これは使っているシェルによって異なる (そのため Vim では自動的に行わ
れない)。例:
  :r! (echo this; echo that)
  :r! {echo this; echo that}

ファイル名を 1 つ受け付けるコマンドでは、ファイル名に空白を含められる。しかし、
複数のファイル名を受け付けるコマンドを使う場合は、含まれる空白をバックスラッ
シュでエスケープする必要がある。

問題

MorphOS ではなく、むしろ Vim および UN*X に関係する問題がいくつかある。ram: で
Vim を起動すると、MorphOS からの nag requester で文句を言われるが、単に無視す
ること。もう 1 つの問題は、Vim をそのまま実行すると、いくつかのプラグインがい
くつかの問題を起こすことで、これも無視してよい。いずれ誰かが直してくれることを
期待している。

今のところこれらの問題を回避するには、どちらかを実行できる:

        vim <編集するファイル>

または、Vim を素の状態で実行し、ヘルプファイルなどの動きを楽しみたい場合は、入
力する方がよいだろう:

        vim --noplugins <もちろんファイルを追加できる>


バイナリアーカイブのインストール

1) バイナリの 'VIM' ファイルを c: にコピーすること
2) Vim のランタイムパッケージを入手する (Note: そのサーバーはもう更新されてい
   ない):

        https://ftp.nluug.nl/pub/vim/amiga/vim90src.tgz

   そして、MorphOS インストールの 'Apps' ディレクトリに展開する。私の場合、以
   下のディレクトリ階層ができる:

        MorphOS:Apps/Vim/Vim62/...

3) 以下の行を s:shell-startup に追加する (重要!)。

        ;Begin VIM
        Set VIM=MorphOS:Apps/Vim/Vim62
        Assign HOME: ""
        ;End VIM

4) '.vimrc' ファイルを s: にコピーする

5) このアーカイブには 'color-sequence' というファイルも含まれている。これは
   MorphOS シェルで ANSI カラーを表示するように設定する。このファイルを s: に
   コピーし、s:shell-startup を変更すること:

        ;Begin VIM
        Set VIM=MorphOS:Apps/Vim/Vim62
        Assign HOME: ""
        Execute S:Color-Sequence
        Cls
        ;End VIM
