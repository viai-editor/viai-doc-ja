41.1  はじめに                                vim-script-intro script

いくつかの用語から始めましょう。Vim script とは、Vim が解釈して実行できる任意
のファイルです。これには、例えば .vim ファイルのような Vim のスクリプト言語で
書かれたファイル、または .vimrc および .gvimrc のような設定ファイルが含まれま
す。これらのスクリプトは、Vim がその動作をカスタマイズし、拡張するために使う関
数、コマンド、および設定を定義することがあります。

                                                vim-script-notation
正しい表記は "Vim script" (または、新しい Vim9 言語 Vim9-script を指す場合は
"Vim9 script") なので、このドキュメント全体を通して、Vim のスクリプト言語を指
すのに "Vim script" を使います。この略記は、Vim でのスクリプト作成についての説
明および議論を簡潔にするのに役立ちます。

Vim プラグインは、1 つ以上の Vim script に、ヘルプドキュメント、設定ファイル、
およびその他のリソースのような追加のファイルを合わせたコレクションで、特定の機
能または機能性を Vim に追加するように設計されています。プラグインは、新しいコ
マンドを提供し、既存の機能を強化し、外部のツールまたはサービスを Vim 環境に統
合することができます。

あなたの Vim script での最初の経験は vimrc ファイルです。Vim は起動時にそれを
読み込み、そのコマンドを実行します。オプションを好みの値に設定し、マッピングを
定義し、プラグインを選択し、さらに多くのことができます。その中では任意のコロン
コマンドを使えます (":" で始まるコマンド; これらは Ex コマンドまたはコマンドラ
インコマンドと呼ばれることもあります)。

構文ファイルも Vim script です。特定のファイルタイプ用にオプションを設定する
ファイルもそうです。複雑なマクロは、別の Vim script ファイルで定義できます。他
の用途はあなた自身で考えることができます。

Vim script には 2 つの種類があります: 旧来のものおよび Vim9 です。このヘルプ
ファイルは新しいユーザー向けなので、より新しく、より便利な Vim9 構文を教えま
す。旧来の script は特に Vim 用のものですが、Vim9 script は JavaScript およ
び TypeScript のような他の言語により似ています。

Vim script を試すには、スクリプトファイルを編集して読み込むのが最良の方法です。
基本的には:
        :edit test.vim
        [望むスクリプトの行を挿入する]
        :w
        :source %

簡単な例から始めましょう:

        vim9script
        var i = 1
        while i < 5
          echo "count is" i
          i += 1
        endwhile

例のコードの出力は:

        count is 1
        count is 2
        count is 3
        count is 4

最初の行では、vim9script コマンドが、これが新しい、Vim9 script ファイルで
あることを明らかにしています。それは、ファイルの残りがどのように使われるかに関
わります。それを一番最初の行、どのコメントよりも前に置くことが推奨されます。
                                                        vim9-declarations
var i = 1 コマンドは "i" 変数を宣言し、それを初期化します。一般的な形式は:

        var {name} = {expression}

この場合、変数名は "i" で、式は単純な値、数値の 1 です。

while コマンドはループを開始します。一般的な形式は:

        while {condition}
          {statements}
        endwhile

対応する endwhile までの文は、条件が真である間ずっと実行されます。ここで使わ
れている条件は式 "i < 5" です。これは変数 i が 5 より小さいときに真です。
        Note:
        実行され続ける while ループをたまたま書いてしまった場合、CTRL-C
        (MS-Windows では CTRL-Break) を押すことでそれを中断できます。

echo コマンドはその引数を表示します。この場合、文字列 "count is" および変数
i の値。i は 1 なので、これが表示するのは:

        count is 1

次に i += 1 コマンドがあります。これは "i = i + 1" と同じことを行い、変数 i
に 1 を加え、新しい値を同じ変数に代入します。

この例はコマンドを説明するために示したものですが、本当にそのようなループを作り
たい場合、ずっとコンパクトに書けます:

        for i in range(1, 4)
          echo $"count is {i}"
        endfor

for、range()、および $"string" がどのように動作するかは、後になるまで説
明しません。待ちきれない場合はリンクをたどってください。


例を試す

これらのヘルプファイルのほとんどの例は、コマンドをファイルに保存せずに簡単に試
すことができます。例えば、上の "for" ループを試すには、これを行います:
1. カーソルを "for" の上に置きます
2. "v" でビジュアルモードを開始します
3. "endfor" まで下に移動します
4. コロン、次に "so" および Enter を押します

コロンを押した後、ビジュアル選択されたテキストの範囲である ":'<,'>" が見えま
す。

一部のコマンドでは、それらが Vim9 script のように実行されることが重要です。
しかし、タイプしたコマンドは通常、以下の E1004 エラーを起こす例のように、旧来
の script 構文を使います。そのためには、この 4 番目の手順を使ってください:
4. コロン、次に "vim9 so" および Enter を押します

"vim9" は vim9cmd の短縮形で、これは後に続くコマンドを Vim9 構文で実行する
ためのコマンド修飾子です。

Note これはスクリプトコンテキストを必要とする例では動作しないことに注意してく
ださい。


4 種類の数値

数値は 10 進数、16 進数、8 進数、および 2 進数にできます。

16 進数は "0x" または "0X" で始まります。例えば、"0x1f" は 10 進数の 31 で、
"0x1234" は 10 進数の 4660 です。

8 進数は "0o"、"0O" で始まります。"0o17" は 10 進数の 15 です。

2 進数は "0b" または "0B" で始まります。例えば、"0b101" は 10 進数の 5 です。

10 進数は単なる数字です。注意: 旧来の script では、10 進数の前にゼロを置かない
でください、8 進数として解釈されます! それが Vim9 script を使う理由の 1 つで
す。

echo コマンドはその引数を評価し、それが数値の場合は常に 10 進数の形式で表示
します。例:

        echo 0x7f 0o36
        127 30

数値はマイナス記号で負になります。これは 16 進数、8 進数、および 2 進数でも機
能します:

        echo -0x7f
        -127

マイナス記号は減算にも使われます。これは時々混乱を招くことがあります。両方の数
値の前にマイナス記号を置いた場合、エラーになります:

        echo -0x7f -0o36
        E1004: White space required before and after '-' at "-0o36"

Note: これらのコマンドを試すのに Vim9 script を使っておらず、直接タイプして
いる場合、それらは旧来の script として実行されます。そうすると、echo コマンド
は 2 つ目のマイナス記号を減算とみなします。エラーを得るには、コマンドの前に
vim9cmd を付けてください:

        vim9cmd echo -0x7f -0o36
        E1004: White space required before and after '-' at "-0o36"

式の中の空白は、読みやすくし、エラーを避けるために、しばしば必要とされます。上
の "-0o36" が、実際には減算とみなされるのに、数値を負にすると考えるようなこと。

マイナス記号を実際に符号反転に使わせるには、2 つ目の式を括弧で囲むことができま
す:

        echo -0x7f (-0o36)
        -127 -30

41.2  変数

変数名は ASCII 文字、数字、およびアンダースコアから成ります。数字で始めること
はできません。有効な変数名は:

        counter
        _aap3
        very_long_variable_name_with_underscores
        CamelCaseName
        LENGTH

無効な名前は "foo.bar" および "6var" です。

いくつかの変数はグローバルです。現在定義されているグローバル変数の一覧を見るに
は、このコマンドをタイプします:

        :let

グローバル変数はどこでも使えます。しかし、関係のない 2 つのスクリプトで同じ名
前を使うことは、あまりにも簡単です。そのため、スクリプト内で宣言された変数は、
そのスクリプトにローカルです。例えば、"script1.vim" にこれがある場合:

        vim9script
        var counter = 5
        echo counter
        5

そして、"script2.vim" でその変数を使おうとする場合:

        vim9script
        echo counter
        E121: Undefined variable: counter

スクリプトローカル変数を使うということは、それがそのスクリプト内でのみ変更さ
れ、他の場所では変更されないと確信できることを意味します。

スクリプト間で変数を共有したい場合は、"g:" プリフィックスを使って値を直接代入
してください、var は使わないでください。そして、間違いを避けるために特定の名
前を使ってください。したがって、"script1.vim" では:

        vim9script
        g:mash_counter = 5
        echo g:mash_counter
        5

そして次に、"script2.vim" では:

        vim9script
        echo g:mash_counter
        5

グローバル変数にはコマンドラインでもアクセスできます、例えばこれをタイプして:

        echo g:mash_counter
それはスクリプトローカル変数では機能しません。

スクリプトローカル変数についてさらに詳しくはここ: script-variable。

さらに多くの種類の変数があります、internal-variables を参照してください。最
もよく使われるものは:

        b:name          バッファにローカルな変数
        w:name          ウィンドウにローカルな変数
        g:name          グローバル変数 (関数の中でも)
        v:name          Vim によって定義済みの変数


変数を削除する

変数はメモリを消費し、let コマンドの出力に現れます。グローバル変数を削除する
には、unlet コマンドを使います。例:

        unlet g:counter

これはグローバル変数 "g:counter" を削除し、それが使っているメモリを解放します。
変数が存在するかどうか確かでなく、存在しないときにエラーメッセージが欲しくない
場合、! を付け加えてください:

        unlet! g:counter

Vim9 script ではスクリプトローカル変数を unlet することはできず、旧来の
script でのみできます。

スクリプトが最後まで処理されたとき、そこで宣言されたローカル変数は削除されませ
ん。スクリプト内で定義された関数はそれらを使えます。例:

        vim9script
        var counter = 0
        def g:GetCount(): number
          counter += 1
          return counter
        enddef

関数を呼び出すたびに、次のカウントを返します:
        :echo g:GetCount()
        1

        :echo g:GetCount()
        2

スクリプトローカル変数がメモリを消費しすぎていることが心配な場合、もう必要がな
くなった後に、それを空または null の値に設定してください。例:
        var lines = readfile(...)
        ...
        lines = []

Note: 以下では、関連するコマンドに集中できるように、例から vim9script の行を
省きますが、それでもあなたのスクリプトファイルの先頭にそれを置く必要がありま
す。


文字列変数および定数

ここまでは変数の値に数値だけが使われました。文字列も同様に使えます。数値および
文字列は、Vim がサポートする変数の基本的な型です。例:

        var name = "Peter"
        echo name
        Peter

すべての変数には型があります。非常に多くの場合、この例のように、型は値を代入す
ることによって定義されます。これは型推論と呼ばれます。変数にまだ値を与えたくな
い場合、型を指定する必要があります:

        var name: string
        var age: number
        if male
           name = "Peter"
           age = 42
        else
           name = "Elisa"
           age = 45
        endif

間違えて、誤った型の値を代入しようとした場合、エラーになります:

        age = "Peter"
        E1012: Type mismatch; expected number but got string

型についてさらに詳しくは 41.8 で。

変数に文字列の値を代入するには、文字列定数を使えます。これには 2 つの種類があ
ります。まず、すでに使ったように、ダブルクォートで囲まれた文字列。文字列の中に
ダブルクォートを含めたい場合、その前にバックスラッシュを置いてください:

        var name = "he is \"Peter\""
        echo name
        he is "Peter"

バックスラッシュが必要になるのを避けるには、シングルクォートで囲まれた文字列を
使えます:

        var name = 'he is "Peter"'
        echo name
        he is "Peter"

シングルクォート文字列の中では、すべての文字はそのままです。シングルクォート自
体だけが特別です: 1 つを得るには 2 つ使う必要があります。バックスラッシュは文
字どおりに解釈されるので、その後の文字の意味を変えるためにそれを使うことはでき
ません:

        var name = 'P\e''ter'''
        echo name
        P\e'ter'

ダブルクォート文字列では、特殊文字を使うことができます。ここにいくつかの便利な
ものがあります:

        \t              <Tab>
        \n              <NL>、改行
        \r              <CR>, <Enter>
        \e              <Esc>
        \b              <BS>、バックスペース
        \"              "
        \\              \、バックスラッシュ
        \<Esc>          <Esc>
        \<C-W>          CTRL-W

最後の 2 つは単なる例です。"\<name>" 形式は、特殊キー "name" を含めるのに使え
ます。

文字列内の特殊な項目の完全なリストは expr-quote を参照してください。

41.3  式

Vim には、式を扱うかなり標準的な方法があります。定義はここで読めます:
expression-syntax。ここでは最も一般的な項目を示します。

上で述べた数値、文字列、および変数は、それ自体が式です。したがって、式が期待さ
れるところではどこでも、数値、文字列、または変数を使えます。式の中のその他の基
本的な項目は:

        $NAME           環境変数
        &name           オプションの値
        @r              レジスタの内容

例:

        echo "The value of 'tabstop' is" &ts
        echo "Your home directory is" $HOME
        if @a == 'text'

&name 形式は、オプションの値を設定し、何かを行い、古い値を復元するためにも使え
ます。例:

        var save_ic = &ic
        set noic
        s/The Start/The Beginning/
        &ic = save_ic

これにより、"The Start" パターンが 'ignorecase' オプションをオフにした状態で使
われることが確実になります。それでも、ユーザーが設定していた値は保持されます。
(これを行う別の方法は、パターンに "\C" を追加することでしょう、/\C を参照し
てください。)


算術

これらの基本的な項目を組み合わせると、もっと面白くなります。数値に対する算術か
ら始めましょう:

        a + b           足す
        a - b           引く
        a * b           掛ける
        a / b           割る
        a % b           剰余

通常の優先順位が使われます。例:

        echo 10 + 5 * 2
        20

グループ化は括弧で行います。ここに驚きはありません。例:

        echo (10 + 5) * 2
        30


その他

文字列は ".." で連結できます (expr6 を参照)。例:

        echo "Name: " .. name
        Name: Peter

"echo" コマンドは複数の引数を受け取ると、それらを空白で区切ります。この例では
引数は 1 つの式なので、空白は挿入されません。

連結が好きでない場合、波括弧の中の式を受け付ける $"string" 形式を使えます:
        echo $"Name: {name}"

詳しい情報は interpolated-string を参照してください。

C 言語から借用したのが条件式です:

        a ? b : c

"a" が真と評価された場合、"b" が使われ、そうでなければ "c" が使われます。例:

        var nr = 4
        echo nr > 5 ? "nr is big" : "nr is small"
        nr is small

この構文の 3 つの部分は常に最初に評価されるので、それが以下のように動作すると
みなすことができます:

        (a) ? (b) : (c)

falsy 演算子もあります:
        echo name ?? "No name given"
?? を参照してください。

41.4  条件文

if コマンドは、条件が満たされたときにだけ、対応する endif までの、後に続く
文を実行します。一般的な形式は:

        if {condition}
           {statements}
        endif

式 {condition} が真または 1 と評価されたときにだけ、{statements} が実行されま
す。それらが実行されない場合でも、それらは有効なコマンドでなければなりません。
それらがゴミを含んでいる場合、Vim は対応する endif を見つけることができませ
ん。

else も使えます。このための一般的な形式は:

        if {condition}
           {statements}
        else
           {statements}
        endif

2 つ目の {statements} ブロックは、1 つ目が実行されない場合にだけ実行されます。

最後に、elseif があります

        if {condition}
           {statements}
        elseif {condition}
           {statements}
        endif

これは else の後に if を使うのとまったく同じように機能しますが、余分な
endif を必要としません。

あなたの vimrc ファイルにとって便利な例は、'term' オプションをチェックして、そ
の値に応じて何かを行うことです:

        if &term == "xterm"
          # xterm 用の処理をする
        elseif &term == "vt100"
          # vt100 端末用の処理をする
        else
          # 他の端末用に何かをする
        endif

これはコメントを開始するのに "#" を使っています、これについては後で詳しく。


論理演算

例の中ですでにそのいくつかを使いました。これらが最もよく使われるものです:

        a == b          等しい
        a != b          等しくない
        a >  b          より大きい
        a >= b          より大きいか、または等しい
        a <  b          より小さい
        a <= b          より小さいか、または等しい

条件が満たされた場合、結果は真で、そうでなければ偽です。例:

        if v:version >= 800
          echo "congratulations"
        else
          echo "you are using an old version, upgrade!"
        endif

ここで "v:version" は Vim によって定義された変数で、Vim のバージョンの値を持ち
ます。800 はバージョン 8.0 用で、バージョン 8.1 は値 801 を持ちます。これは、
Vim の複数のバージョンで動作するスクリプトを書くのに便利です。
v:version を参照してください。has() で特定の機能を、または特定のパッチを
チェックすることもできます、has-patch を参照してください。

論理演算子は数値および文字列の両方に機能します。2 つの文字列を比較するとき、数
学的な差が使われます。これはバイト値を比較するもので、一部の言語にとっては正し
くないかもしれません。

文字列を数値と比較しようとした場合、エラーになります。

文字列には、さらに 2 つの便利な項目があります:

        str =~ pat              マッチする
        str !~ pat              マッチしない

左の項目 "str" は文字列として使われます。右の項目 "pat" は、検索に使われるもの
のように、パターンとして使われます。例:

        if str =~ " "
          echo "str contains a space"
        endif
        if str !~ '\.$'
          echo "str does not end in a full stop"
        endif

パターンにシングルクォート文字列を使っていることに注意してください。これは便利
です、パターンは多くのバックスラッシュを含む傾向があり、ダブルクォート文字列で
はバックスラッシュを二重にする必要があるからです。

マッチは固定されていません、文字列全体にマッチさせたい場合は、"^" で始めて "$"
で終わらせてください。

文字列を比較するときは、'ignorecase' オプションは使われません。大文字小文字を
無視したいときは、"?" を付け加えてください。したがって、"==?" は大文字小文字を
無視して 2 つの文字列が等しいかを比較します。完全な表は expr-== を参照してく
ださい。


さらなるループ

while コマンドはすでに述べました。while と endwhile の間で、さらに 2 つ
の文を使えます:

        continue                while ループの先頭に戻る; ループは継続する。
        break                   endwhile へ前方にジャンプする; ループは中止
                                される。

例:

        var counter = 1
        while counter < 40
          if skip_number(counter)
            continue
          endif
          if last_number(counter)
            break
          endif
          sleep 50m
          ++counter
        endwhile

sleep コマンドは Vim に昼寝をさせます。"50m" は 50 ミリ秒を指定します。別の
例は sleep 4 で、これは 4 秒間スリープします。

continue および break は、for と endfor の間でも使えます。
for コマンドを使うと、さらに多くのループを行うことができます、以下の 41.8
を参照してください。

41.5  式を実行する

ここまで、スクリプト内のコマンドは Vim によって直接実行されました。execute
コマンドは、式の結果を実行することを可能にします。これは、コマンドを組み立てて
実行する非常に強力な方法です。

例は、変数に含まれているタグへジャンプすることです:

        execute "tag " .. tag_name

".." は、文字列 "tag " を変数 "tag_name" の値と連結するのに使われます。
"tag_name" が値 "get_cmd" を持っているとすると、実行されるコマンドは:

        tag get_cmd

execute コマンドは Ex コマンドだけを実行できます。normal コマンドはノーマ
ルモードのコマンドを実行します。しかし、その引数は式ではなく、文字どおりのコマ
ンド文字です。例:

        normal gg=G

これは "gg" で最初の行へジャンプし、"=" オペレータおよび "G" 移動ですべての行
を整形します。

normal を式で機能させるには、execute をそれと組み合わせます。
例:

        execute "normal " .. count .. "j"

これはカーソルを "count" 行下に移動します。

normal の引数が完全なコマンドであることを確認してください。そうでないと、Vim
は引数の終わりに行き当たり、コマンドを黙って中止します。例えば、削除オペレータ
を開始した場合、移動コマンドも与えなければなりません。これは機能します:

        normal d$

これは何もしません:

        normal d

挿入モードを開始して Esc で終了しなかった場合、それはいずれにしても終了します。
これは "new text" を挿入するのに機能します:

        execute "normal inew text"

テキストを挿入した後に何かをしたい場合は、挿入モードを終了する必要があります:


        execute "normal inew text\<Esc>b"

これは "new text" を挿入し、カーソルを "text" の最初の文字の上に置きます。特殊
キー "\<Esc>" の使用に注意してください。これにより、あなたのスクリプトに実際の
<Esc> 文字を入力する必要がなくなります。そこが、ダブルクォート文字列を伴う
execute が役に立つところです。

文字列をコマンドとして実行するのではなく、式の結果を得るためにそれを評価したい
場合、eval() 関数を使えます:

        var optname = "path"
        var optvalue = eval('&' .. optname)

"&" 文字が "path" の前に付け加えられるので、eval() への引数は "&path" になりま
す。その結果は 'path' オプションの値になります。

41.6  関数を使う

Vim は多くの関数を定義し、その方法で大量の機能を提供します。このセクションでは
いくつかの例を示します。全体のリストは以下にあります: function-list。

関数は、括弧の中にコンマで区切られたパラメーターを付けて呼び出されます。例:

        search("Date: ", "W")

これは、引数 "Date: " および "W" で search() 関数を呼び出します。search() 関数
は、1 つ目の引数を検索パターンとして、2 つ目をフラグとして使います。"W" フラグ
は、検索がファイルの末尾で折り返さないことを意味します。

Vim9 script では call コマンドの使用は任意です。旧来の script およびコマン
ドラインでは必須です:

        call search("Date: ", "W")

関数は式の中で呼び出せます。例:

        var line = getline(".")
        var repl = substitute(line, '\a', "*", "g")
        setline(".", repl)

getline() 関数は、カレントバッファから 1 行を取得します。その引数は行番号の指
定です。この場合は "." が使われており、これはカーソルがある行を意味します。

substitute() 関数は、:substitute コマンドと似たことを行います。1 つ目の引数
"line" は、置換を実行する対象の文字列です。2 つ目の引数 '\a' はパターンで、3
つ目の "*" は置換文字列です。最後に、最後の引数 "g" はフラグです。

setline() 関数は、1 つ目の引数で指定された行を、新しい文字列、2 つ目の引数に設
定します。この例では、カーソルの下の行が substitute() の結果で置き換えられま
す。したがって、3 つの文の効果は以下と同じです:

        :substitute/\a/*/g

substitute() の呼び出しの前および後でさらに多くの作業を行うとき、関数を使うこ
とが面白くなります。

41.7  関数を定義する

Vim では、あなた自身の関数を定義できます。基本的な関数宣言は以下のように始まり
ます:

        def {name}({var1}, {var2}, ...): return-type
          {body}
        enddef

        Note:
        関数名は大文字で始めなければなりません。

2 つの数値のうち小さい方を返す短い関数を定義しましょう。それはこの行で始まりま
す:

        def Min(num1: number, num2: number): number

これは Vim に、関数の名前は "Min" で、数値である 2 つの引数: "num1" および
"num2" を取り、数値を返すことを伝えます。

最初に行う必要があることは、どちらの数値が小さいかを確認するためにチェックする
ことです:
  
        if num1 < num2

変数 "smaller" に、最小の数値の値を代入しましょう:

        var smaller: number
        if num1 < num2
          smaller = num1
        else
          smaller = num2
        endif

変数 "smaller" はローカル変数です。それは数値として宣言されており、そうするこ
とで Vim はどんな間違いについてもあなたに警告できます。関数の中で使われる変数
は、"g:"、"w:"、または "b:" のようなものが前に付いていない限り、ローカルです。

        Note:
        関数の内部からグローバル変数にアクセスするには、その前に "g:" を付けな
        ければなりません。したがって、関数の内部の "g:today" はグローバル変数
        "today" に使われ、"today" は別の変数で、関数またはスクリプトにローカル
        です。

ここで、return 文を使って最小の数値をユーザーに返します。最後に、関数を終了
します:

          return smaller
        enddef

完全な関数定義は以下のとおりです:

        def Min(num1: number, num2: number): number
          var smaller: number
          if num1 < num2
            smaller = num1
          else
            smaller = num2
          endif
          return smaller
        enddef

明らかにこれは冗長な例です。2 つの return コマンドを使うことで、もっと短くでき
ます:

        def Min(num1: number, num2: number): number
          if num1 < num2
            return num1
          endif
          return num2
        enddef

そして、条件式を覚えている場合、1 行だけで済みます:

        def Min(num1: number, num2: number): number
          return num1 < num2 ? num1 : num2
        enddef

ユーザー定義関数は、組み込み関数とまったく同じ方法で呼び出されます。名前だけが
異なります。Min 関数はこのように使えます:

        echo Min(5, 8)

今になって初めて、関数が実行され、行が Vim によって解析されます。
未定義の変数または関数を使うような間違いがある場合、ここでエラーメッセージが出
ます。関数を定義するときには、これらのエラーは検出されません。エラーをもっと早
く得るには、スクリプト内のすべての関数をコンパイルするように Vim に指示できま
す:

        defcompile

関数のコンパイルには少し時間がかかりますが、エラーを早く報告します。あなたのス
クリプトに取り組んでいる間はその末尾で :defcompile を使い、すべて問題なくなっ
たらそれをコメントアウトすることができます。

何も返さない関数の場合は、単に戻り値の型を省いてください:

        def SayIt(text: string)
          echo text
        enddef

任意の種類の値を返したい場合、"any" 戻り値型を使えます:
        def GetValue(): any
これは戻り値の型チェックを無効にします、必要なときだけ使ってください。

function および endfunction で旧来の関数を定義することもできます。これらは
型を持たず、コンパイルされません。そのため、ずっと遅く実行されます。


範囲を使う

行範囲は関数呼び出しと一緒に使えます。関数は、範囲内のすべての行に対して 1 回
ずつ、カーソルをその行に置いて呼び出されます。例:

        def Number()
          echo "line " .. line(".") .. " contains: " .. getline(".")
        enddef

この関数を以下で呼び出した場合:

        :10,15call Number()

関数は 6 回呼び出され、10 行目から始まり 15 行目で終わります。


関数を一覧表示する

function コマンドは、すべてのユーザー定義関数の名前および引数を一覧表示しま
す:

        :function
        def <SNR>86_Show(start: string, ...items: list<string>)
        function GetVimIndent()
        function SetSyn(name)

"<SNR>" プリフィックスは、関数がスクリプトローカルであることを意味します。
Vim9 関数は "def" で始まり、引数および戻り値の型を含みます。旧来の関数は
"function" とともに一覧表示されます。

関数が何をするかを見るには、その名前を function の引数として使います:

        :function SetSyn
        1     if &syntax == ''
        2       let &syntax = a:name
        3     endif
           endfunction

複数の "Show" 関数が異なるスクリプトで定義されうるので、"Show" 関数を見るには
スクリプトプリフィックスを含める必要があります。正確な名前を見つけるには
function を使えますが、結果は非常に長いリストになるかもしれません。パターン
にマッチする関数だけを得るには、filter プリフィックスを使えます:

        :filter Show function
        def <SNR>86_Show(start: string, ...items: list<string>)

        :function <SNR>86_Show
        1    echohl Title
        2    echo "start is " .. start
        など。


デバッグ

行番号は、エラーメッセージが出たとき、またはデバッグするときに役に立ちます。デ
バッグモードについては debug-scripts を参照してください。

'verbose' オプションを 12 以上に設定して、すべての関数呼び出しを見ることもでき
ます。15 以上に設定すると、実行されたすべての行を見ることができます。


関数を削除する

SetSyn() 関数を削除するには:

        :delfunction SetSyn

削除は、グローバル関数および旧来の script 内の関数に対してのみ機能し、Vim9
script で定義された関数に対しては機能しません。

関数が存在しないか、または削除できないとき、エラーが出ます。


関数参照

変数がある関数または別の関数を指すようにすると便利な場合があります。関数参照変
数でそれを行えます。しばしば "funcref" と短縮されます。例:

        def Right(): string
          return 'Right!'
        enddef
        def Wrong(): string
          return 'Wrong!'
        enddef

        var Afunc = g:result == 1 ? Right : Wrong
        echo Afunc()
        Wrong!

これは "g:result" が 1 でないことを前提としています。詳細は Funcref を参照し
てください。

Note 関数参照を保持する変数の名前は大文字で始めなければならないことに注意して
ください。そうでないと、組み込み関数の名前と混同される可能性があります。

41.8  リストおよび辞書

ここまで、基本的な型である文字列および数値を使ってきました。Vim は 3 つの複合
型もサポートしています: リスト、タプル、および辞書。

リストは項目の順序付きシーケンスです。項目はどんな種類の値でもよいので、数値の
リスト、リストのリスト、さらには混在した項目のリストを作れます。3 つの文字列を
持つリストを作るには:

        var alist = ['aap', 'noot', 'mies']

リストの項目は角括弧で囲まれ、コンマで区切られます。空のリストを作るには:

        var alist = []

add() 関数でリストに項目を追加できます:

        var alist = []
        add(alist, 'foo')
        add(alist, 'bar')
        echo alist
        ['foo', 'bar']

リストの連結は + で行います:

        var alist = ['foo', 'bar']
        alist = alist + ['and', 'more']
        echo alist
        ['foo', 'bar', 'and', 'more']

または、関数でリストを拡張したい場合、extend() を使います:

        var alist = ['one']
        extend(alist, ['two', 'three'])
        echo alist
        ['one', 'two', 'three']

add() を使うと extend() とは異なる効果になることに注意してください:

        var alist = ['one']
        add(alist, ['two', 'three'])
        echo alist
        ['one', ['two', 'three']]

add() の 2 つ目の引数は 1 つの項目として追加され、これで入れ子のリストができま
す。


for ループ

リストでできる素晴らしいことの 1 つは、それを反復処理することです:

        var alist = ['one', 'two', 'three']
        for n in alist
          echo n
        endfor
        one
        two
        three

これはリスト "alist" の各要素をループし、各値を変数 "n" に代入します。for ルー
プの一般的な形式は:

        for {varname} in {list-expression}
          {commands}
        endfor

ある回数だけループするには、特定の長さのリストが必要です。range() 関数がそれを
作成してくれます:

        for a in range(3)
          echo a
        endfor
        0
        1
        2

range() が生成するリストの最初の項目は 0 なので、最後の項目はリストの長さより
1 小さいことに注意してください。詳細: 内部的には range() は実際にはリストを作
成しないので、for ループで使われる大きな範囲は効率的に動作します。他の場所で使
われるときは、範囲は実際のリストに変換され、長いリストではより多くの時間がかか
ります。

最大値およびステップ幅を指定することも、さらには逆方向に進むこともできます:

        for a in range(8, 4, -2)
          echo a
        endfor
        8
        6
        4

もっと便利な例、バッファ内のすべての行をループする:

        for line in getline(1, 50)
          if line =~ "Date: "
            echo line
          endif
        endfor

これは 1 から 50 行目 (両端を含む) を調べ、そこで見つかった日付を echo します。

さらに読むには Lists を参照してください。

タプル

タプルは、項目の不変の順序付きシーケンスです。項目はどんな型でもかまいません。
項目にはそのインデックス番号でアクセスできます。3 つの文字列を持つタプルを作る
には:

        var atuple = ('one', 'two', 'three')

タプルの項目は括弧で囲まれ、コンマで区切られます。空のタプルを作るには:

        var atuple = ()

:for ループは、リストと同様に、タプルの項目を反復処理するのに使えます。

さらに読むには Tuples を参照してください。

辞書

辞書はキーと値のペアを格納します。キーを知っている場合、値を素早く検索できま
す。辞書は波括弧で作成されます:

        var uk2nl = {one: 'een', two: 'twee', three: 'drie'}

これで、角括弧の中にキーを置いて単語を検索できます:

        echo uk2nl['two']
        twee

キーが特殊文字を含まない場合、ドット表記を使えます:

        echo uk2nl.two
        twee

辞書を定義する一般的な形式は:

        {<key> : <value>, ...}

空の辞書は、キーを 1 つも持たないものです:

        {}

辞書でできることは多数あります。それらのためのさまざまな関数もあります。例え
ば、キーのリストを取得して、それをループできます:

        for key in keys(uk2nl)
          echo key
        endfor
        three
        one
        two

キーが順序付けられていないことに気付くでしょう。特定の順序を得るために、リスト
をソートできます:

        for key in sort(keys(uk2nl))
          echo key
        endfor
        one
        three
        two

しかし、項目が定義された順序を取り戻すことは決してできません。そのためにはリス
トを使う必要があります、リストは項目を順序付きシーケンスで格納します。

さらに読むには Dictionaries を参照してください。

41.9  空白

空行はスクリプト内で許可され、無視されます。

先頭の空白文字 (ブランクおよびタブ) は、"trim" なしで :let-heredoc を使う場
合を除き、無視されます。

末尾の空白はしばしば無視されますが、常にではありません。それを含むコマンドの 1
つが map です。それには注意しなければなりません、理解しにくい間違いを引き起
こすことがあります。一般的な解決策は、本当に必要でない限り、末尾の空白を決して
使わないことです。

オプションの値に空白文字を含めるには、以下の例のように "\" (バックスラッシュ)
でエスケープしなければなりません:

        :set tags=my\ nice\ file

それが以下のように書かれた場合:

        :set tags=my nice file

これはエラーを出します、なぜならそれは以下のように解釈されるからです:

        :set tags=my
        :set nice
        :set file

Vim9 script は、空白に関しては非常にうるさいです。これは、スクリプトを読みや
すくし、間違いを避けるために、意図的に行われました。
空白を賢明に使う場合、問題なく動作します。そうでないときは、どこで空白が欠けて
いるか、または削除すべきかを伝えるエラーメッセージが出ます。

41.10 行継続

旧来の Vim script では、継続行の前にバックスラッシュを置くことで行継続が行われ
ます:
        let mylist = [
                        \ 'one',
                        \ 'two',
                        \ ]

これには、'cpo' オプションが "C" フラグを含まないことが必要です。通常、これは
スクリプトの先頭にこれを置くことで行われます:
        let s:save_cpo = &cpo
        set cpo&vim

そして、スクリプトの末尾でオプションを復元します:
        let &cpo = s:save_cpo
        unlet s:save_cpo

さらにいくつかの詳細はここにあります: line-continuation。

Vim9 script では、バックスラッシュはまだ使えますが、ほとんどの場所では必要あ
りません:
        var mylist = [
                        'one',
                        'two',
                        ]

また、'cpo' オプションを変更する必要もありません。詳細は
vim9-line-continuation を参照してください。

41.11 コメント

Vim9 script では、文字 # がコメントを開始します。その文字および行末までのそ
の後のすべてはコメントとみなされて無視されます、ただし以下の例で示すように、コ
メントを考慮しないコマンドは除きます。コメントは行のどの文字位置からでも開始で
きますが、それがコマンドの一部であるとき、例えば文字列の中では、そうではありま
せん。

文字 " (ダブルクォート記号) は、旧来の script でコメントを開始します。これに
は、ダブルクォートで囲まれた文字列がコメントとして認識されないようにするため
の、ある程度の巧妙さが伴います (Vim9 script を好む理由の 1 つにすぎません)。

一部のコマンドでは、コメントにちょっとした "落とし穴" があります。例:

        abbrev dev development  # 略記
        map <F3> o#include      # include を挿入する
        execute cmd             # それを行う
        !ls *.c                 # C ファイルを一覧表示する

- 短縮形 'dev' は 'development  # 略記' に展開される。
- <F3> のマッピングは、実際には '# include を挿入する' を含む、'o# ....' の後
  の行全体になる。
- execute コマンドはエラーを出す。
- ! コマンドはその後のすべてをシェルに送り、おそらくエラーを引き起こす。

map、abbreviate、execute、および ! コマンドの後にはコメントを置けませ
ん (この制限を持つコマンドは他にもいくつかあります)。map、abbreviate、およ
び execute コマンドには技があります:

        abbrev dev development|# 略記
        map <F3> o#include|# include を挿入する
        execute '!ls *.c'       |# それを行う

'|' 文字でコマンドは次のコマンドから区切られます。そして、その次のコマンドはコ
メントだけです。最後のコマンド、execute を使うものは汎用的な解決策で、コメン
トまたは次のコマンドを区切る '|' を受け付けないすべてのコマンドで機能します。

短縮形およびマッピングでは、'|' の前に空白がないことに注意してください。これら
のコマンドでは、行末または '|' までのすべての文字が含まれます。この動作の結果
として、末尾の空白が含まれていることが常に見えるわけではありません:

        map <F4> o#include  

ここでは意図的ですが、他の場合には偶発的かもしれません。これらの問題を見つける
ために、末尾の空白をハイライトできます:
        match Search /\s\+$/

Unix には、行をコメントにする特別な方法が 1 つあり、それによって Vim script を
実行可能にでき、旧来の script でも機能します:
        #!/usr/bin/env vim -S
        echo "this is a Vim script"
        quit

41.12 ファイルフォーマット

行末文字はシステムに依存します。Vim script では、常に Unix のファイルフォーマッ
トを使うことが推奨されます。そうすると、行は改行文字で区切られます。これは他の
どのシステムでも機能します。そうすることで、あなたの Vim script を MS-Windows
から Unix にコピーでき、それらは依然として機能します。:source_crnl を参照し
てください。それが正しく設定されていることを確かめるには、ファイルを書き込む前
にこれを行ってください:

        :setlocal fileformat=unix

"dos" ファイルフォーマットを使うとき、行は CR-NL、2 文字で区切られます。CR 文
字はさまざまな問題を引き起こします、これは避けた方がよいです。
