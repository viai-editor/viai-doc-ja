多言語機能                                      multilang multi-lang

これは、さまざまな言語でのメッセージおよびメニューの使用に関するものである。マ
ルチバイトテキストの編集については multibyte を参照。

基本はユーザーマニュアルで説明されている: usr_45.txt。

1. メッセージ                   multilang-messages
2. メニュー                     multilang-menus
3. スクリプト                   multilang-scripts

多言語のヘルプについては help-translated も参照。

{+multi_lang 機能なしでコンパイルされたときは使えない}

==============================================================================
1. メッセージ                                           multilang-messages

Vim はロケールを環境から取得する。ほとんどの場合、これは、使えない場合を除い
て、Vim があなたの好む言語を使うということである。

システムでサポートされているロケール名の一覧を見るには、これらのディレクトリの
どれかを見ること (Unix の場合):
        /usr/lib/locale
        /usr/share/locale
残念ながら、大文字と小文字の違いは区別される。また、"-" および "_" の使い方に
も気をつけること。

                                            :lan :lang :language E197
:lan[guage]
:lan[guage] mes[sages]
:lan[guage] cty[pe]
:lan[guage] tim[e]
:lan[guage] col[late]
                        現在の言語 (別名ロケール) を表示する。
                        "messages" 引数を付けると、メッセージに使われる言語が
                        表示される。技術的には: LC_MESSAGES。
                        "ctype" 引数を付けると、文字エンコーディングに使われる
                        言語が表示される。技術的には: LC_CTYPE。"time" 引数を
                        付けると、strftime() に使われる言語が表示される。技術
                        的には: LC_TIME。
                        "collate" 引数を付けると、照合順序に使われる言語が表示
                        される。技術的には: LC_COLLATE。引数なしの場合は、ロ
                        ケールのすべての部分が表示される (これはシステムに依存
                        する)。
                        現在の言語は、v:lang、v:ctype、v:collate、および
                        v:lc_time 変数でも取得できる。

:lan[guage] {name}
:lan[guage] mes[sages] {name}
:lan[guage] cty[pe] {name}
:lan[guage] tim[e] {name}
:lan[guage] col[late] {name}
                        現在の言語 (別名ロケール) を {name} に設定する。
                        {name} の POSIX の形式は:
                                language[_territory][.encoding]
                        ロケール {name} は、システムで有効なロケールでなければ
                        ならない。"en" または "en_US" のような別名を受け付ける
                        システムもあるが、"en_US.ISO_8859-1" のような完全な指
                        定しか受け付けないシステムもある。Unix システムでは、
                        このコマンドを使って、どのロケールがサポートされている
                        かを見ることができる:
                                :!locale -a
                        "messages" 引数を付けると、メッセージに使われる言語が
                        設定される。これは、例えば日本語のテキストを編集しなが
                        ら英語のメッセージを使いたいときに、違うものにできる。
                        これは $LC_MESSAGES を設定する。
                        "ctype" 引数を付けると、文字エンコーディングに使われる
                        言語が設定される。これは、Vim がリンクしているライブラ
                        リに影響する。これを 'encoding' または "C" と違う値に
                        設定するのは普通ではない。これは $LC_CTYPE を設定する。
                        "time" 引数を付けると、時刻および日付のメッセージに使
                        われる言語が設定される。これは strftime() に影響する。
                        これは $LC_TIME を設定する。
                        "collate" 引数を付けると、照合順序に使われる言語が設定
                        される。これは文字のソートに影響する。これは
                        $LC_COLLATE を設定する。
                        引数なしの場合は、すべてが設定され、さらに $LANG が設
                        定される。
                        使えるなら、浮動小数点数が小数点として '.' を使うよう
                        に、LC_NUMERIC の値は常に "C" に設定される。
                        これは、言語に依存する項目 (一部のメッセージ、時刻およ
                        び日付の書式) に違いをもたらす。すべてのシステムで完全
                        にサポートされているわけではない
                        これが失敗するとエラーメッセージが出る。成功した場合は
                        メッセージは出ない。例:
                                :language
                                Current language: C
                                :language de_DE.ISO_8859-1
                                :language mes
                                Current messages language: de_DE.ISO_8859-1
                                :lang mes en


MS-Windows のメッセージ翻訳                            win32-gettext

自己インストール形式の .exe ファイルを使った場合は、メッセージ翻訳はすでに動作
するはずである。そうでなければ、libintl.dll ファイルをまだ持っていない場合は入
手すること:

        http://sourceforge.net/projects/gettext
または:
        https://mlocati.github.io/gettext-iconv-windows/

これには xgettext、msgformat、およびその他のツールも含まれている。

libintl.dll は、(g)viai.exe と同じディレクトリ、または PATH 環境変数に列挙され
たディレクトリのどれかに置くこと。Vim は別名の "libintl-8.dll" および
"intl.dll" も探す。

メッセージファイル (viai.mo) は "$VIMRUNTIME/lang/xx/LC_MESSAGES" に置かなけれ
ばならない。"xx" は言語の略称 (たいていは 2 文字) である。

自分で翻訳を書く場合は、.po ファイルを生成して、それを .mo ファイルに変換する
必要がある。ソース配布物を入手して、"src/po/README.txt" ファイルを読む必要があ
る。

メッセージの言語は、地域の書式ではなく、Windows の表示言語から決まる。その他の
ロケールカテゴリ、例えば strftime() に使われるものは、地域の書式に従う。

言語の自動選択を上書きするには、$LANG 変数を好きな言語に設定する。翻訳を無効に
するには "en" を使う。

  :let $LANG = 'ja'

(Windows についての記述は Muraoka Taro による)

2. メニュー                                             multilang-menus

基本については 45.2 を参照。特に 'langmenu' の使い方。

Note 翻訳が行われた後にメニューが変更された場合、一部のメニューは英語で表示さ
れるかもしれないことに注意。翻訳のメンテナーに連絡を取って、更新するように頼ん
でみてほしい。翻訳者の名前およびメールアドレスは
"$VIMRUNTIME/lang/menu_<lang>.vim" で見つけられる。

メニューに使うフォント (またはフォントセット) を設定するには、:highlight コ
マンドを使う。例:

        :highlight Menu font=k12,r12


ロケール名の別名

残念ながら、ロケール名は、同じ言語およびエンコーディングのものでも、システムに
よって違う。期待したメニュー翻訳が得られない場合は、このコマンドの出力を確認す
ること:

        echo v:lang

次に、"$VIMRUNTIME/lang" ディレクトリで、似た言語を使うメニューの翻訳ファイル
を確認する。"-" が "_" になっているという違いだけで、ファイルは見つからなくな
る!  ほかに気をつけるべきよくある違いは、"iso8859-1" と "iso_8859-1" である。
幸い、Vim はすべての名前を小文字にするので、大文字と小文字の違いを気にする必要
はない。空白は、エスケープしなくて済むように、アンダースコアに変えられる。

自分の言語のメニューの翻訳ファイルが別の名前で見つかったら、それを読み込むファ
イルを自分のランタイムディレクトリに作ること。そのファイルの名前はこうできる:


        ~/.vim/lang/menu_<v:lang>.vim

検索されるディレクトリについては 'runtimepath' オプションを確認すること。その
ファイルには、別の名前のメニューファイルを読み込むコマンドを書く:

        runtime lang/menu_<other_lang>.vim


メニューの翻訳

自分で翻訳したい場合は、以下で説明する :menutrans コマンドを使える。1 つの言
語の翻訳は Vim script に書くことを推奨する。まだ翻訳が無い言語の場合は、メンテ
ナーになって、翻訳をすべての Vim ユーザーが使えるようにすることを検討してほし
い。Vim のメンテナー <maintainer@vim.org> にメールを送ること。

                                        :menut :menutrans :menutranslate
:menut[ranslate] clear
                        メニュー翻訳をすべて消去する。

:menut[ranslate] {english} {mylang}
                        メニュー名 {english} を {mylang} に翻訳する。"&" およ
                        び "<Tab>" のような特殊文字はすべて含める必要がある。
                        空白およびドットは、他の :menu コマンドと同様に、バッ
                        クスラッシュでエスケープする必要がある。{english} の大
                        文字と小文字は無視される。

例については $VIMRUNTIME/lang ディレクトリを参照。

翻訳を試すには、まずすべてのメニューを削除する必要がある。Vim を再起動せずにそ
れを行う方法はこうである:
        :source $VIMRUNTIME/delmenu.vim
        :source <your-new-menu-file>
        :source $VIMRUNTIME/menu.vim

メニューパスの各部分は別々に翻訳される。その結果、"Help" が "Hilfe" に、および
"Overview" が "Überblick" に翻訳されると、"Help.Overview" は "Hilfe.Überblick"
に翻訳される。

3. スクリプト                                           multilang-scripts

Vim script では、v:lang 変数を使って現在の言語 (ロケール) を取得できる。デ
フォルト値は "C" であるか、または $LANG 環境変数から取られる。

以下の例は、この変数を簡単な方法で使って、メッセージをユーザーの言語の好みに合
わせる方法を示す、

        :if v:lang =~ "de_DE"
        :  echo "Guten Morgen"
        :else
        :  echo "Good morning"
        :endif
