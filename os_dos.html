1. ファイル位置                                         dos-locations

Vim の実行可能ファイルを help および syntax サブディレクトリを含むディレクトリ
に置いておけば、Vim が動作するために特別なことをする必要は無い。レジストリエン
トリまたは環境変数を設定する必要は無い。単にそのディレクトリが検索パスにあるこ
とを確かめるか、またはデスクトップ上のショートカットを使うこと。

vimrc ファイル ("_vimrc" および "_gvimrc") は、通常ランタイムファイルの 1 つ上
のディレクトリに置かれる。それらを他のどこかに置きたい場合は、環境変数 $VIM を
それらを置いているディレクトリに設定すること。例:
        set VIM=C:\user\piet
"c:\user\piet\_vimrc" を見つける。
Note: これはコンピューターが複数の人に使われる場合にのみ必要になる。そうでなけ
れば、_vimrc ファイルをデフォルトの場所に置いておく方が簡単である。

実行可能ファイルを別の場所に移動する場合は、$VIM 環境変数も設定する必要がある。
ランタイムファイルは "$VIM/viai{version}" で見つけられる。例:
        set VIM=E:\viai
"e:\viai\viai10" にあるバージョン 1.0 のランタイムファイルを見つける。
Note: これは推奨_されない_。望ましい方法は、実行可能ファイルをランタイムディレ
クトリに置いておくことである。

実行可能ファイルを移動し、かつ "_vimrc" および "_gvimrc" ファイルを他のどこか
に置きたい場合は、$VIM を vimrc ファイルのある場所に設定し、$VIMRUNTIME をラン
タイムファイルに設定しなければならない。例:
        set VIM=C:\usr\piet
        set VIMRUNTIME=E:\viai\viai10
"c:\user\piet\_vimrc" および "e:\viai\viai10" にあるランタイムファイルを見つけ
る。

詳細は $VIM および $VIMRUNTIME を参照。

System Properties ダイアログボックスを通して、ユーザーごとに別々に環境変数を設
定できる。そうする手順:
1. Windows キー + R を入力して "Run" ダイアログボックスを開く。
2. "sysdm.cpl" を入力して "OK" ボタンを押す。"System Properties" ダイアログボッ
   クスが開く。
3. "Advanced" タブを選択して "Environment Variables..." ボタンを押す。
   "Environment Variables" ダイアログボックスが開く。
4. "User variables" リストで既存の変数を選択し、"Edit..." ボタンを押してそれを
   編集する。または "New..." ボタンを押して新しい変数を追加する。
5. 変数の編集を終えた後、"OK" ボタンを押して変更を保存する。

2. バックスラッシュの使用                               dos-backslash

ファイル名でバックスラッシュを使うことは問題になり得る。Vi はいくつかのコマン
ドでバックスラッシュの数を半分にする。Vim はもう少し寛容で、ファイル名からバッ
クスラッシュを削除しないので、":e c:\foo\bar" は期待どおりに動作する。しかし、
特殊文字 (スペース、コンマ、バックスラッシュなど) の前にバックスラッシュがある
場合は、Vim はそのバックスラッシュを削除する。問題を避けるにはスラッシュを使う
こと: ":e c:/foo/bar" はうまく動作する。Vim は、いくつかの MS-DOS プログラムお
よび Win32 プログラムでの問題を避けるために、内部でスラッシュをバックスラッシュ
に置き換える。

スラッシュを使う方が好みの場合は、'shellslash' オプションを設定すること。そう
すると、Vim はファイル名を展開する時にバックスラッシュをスラッシュに置き換え
る。これは Unix 風の 'shell' を使う場合に特に便利である。

3. 標準のマッピング                             dos-standard-mappings

CTRL-PageUp および CTRL-PageDown のマッピングは削除された。それらは現在、次ま
たは前のタブページにジャンプする <C-PageUp> <C-PageDown>

それらで最初および最後の画面行に移動したい場合は、これらのマッピングを使える:

キー            キーコード   ノーマル/ビジュアルモード      挿入モード
CTRL-PageUp     <M-N><M-C-D>        H               <C-O>H
CTRL-PageDown   <M-N>v              L$              <C-O>L<C-O>$

さらに、これらのキーがコピー/カット/ペーストに使用できる。Win32 および DJGPP
版では、それらはクリップボードも使う。

Shift-Insert    テキストをペースト (クリップボードから)         <S-Insert>
CTRL-Insert     ビジュアルテキストをコピー (クリップボードへ)   <C-Insert>
CTRL-Del        ビジュアルテキストをカット (クリップボードへ)   <C-Del>
Shift-Del       ビジュアルテキストをカット (クリップボードへ)   <S-Del>
CTRL-X          ビジュアルテキストをカット (クリップボードへ)

これらのマッピングがこれを実現する (Vim の Win32 および DJGPP 版):

キー            キーコード   ノーマル   ビジュアル          挿入
Shift-Insert    <M-N><M-T>   "*P        "-d"*P      <C-R><C-O>*
CTRL-Insert     <M-N><M-U>              "*y
Shift-Del       <M-N><M-W>              "*d
CTRL-Del        <M-N><M-X>              "*d
CTRL-X          <C-X>                   "*d

またはこれらのマッピング (Vim の非 Win32 版):

キー            キーコード   ノーマル   ビジュアル          挿入
Shift-Insert    <M-N><M-T>   P          "-dP        <C-R><C-O>"
CTRL-Insert     <M-N><M-U>              y
Shift-Del       <M-N><M-W>              d
CTRL-Del        <M-N><M-X>              d

クリップボードがサポートされている場合は、"* レジスタが使われる。

4. 画面出力および色                                     dos-colors

画面のデフォルトの出力方法は bios コールを使うことである。これはほとんどのシス
テムですぐに動作する。ansi.sys は必要無い。":mode" を使って現在の画面モードを
設定できる。:mode を参照。

Vim が使う画面の色を変更するには、:highlight コマンドを使える。Normal ハイラ
イトグループは、Vim が通常のテキストに使う色を指定する。例えば、青い背景に灰色
のテキストを得るには:
        :hi Normal ctermbg=Blue ctermfg=grey
使用可能な他のグループについては highlight-groups を参照。

DOS コンソールは太字および下線のような属性をサポートしない。9 つの端末オプショ
ンで、5 つのモードで使われる色を設定できる。Note ":highlight" コマンドで色を直
接設定できるので、これは必要無いことに注意。これらのオプションは古い Vim バー
ジョンとの後方互換性のためのものである。'highlight' オプションは、5 つのモード
のどれがどの動作に使われるかを指定する。

        :set t_mr=^V^[\|xxm             反転モードの開始
        :set t_md=^V^[\|xxm             太字モードの開始
        :set t_me=^V^[\|xxm             通常のテキストに戻る

        :set t_so=^V^[\|xxm             standout モードの開始
        :set t_se=^V^[\|xxm             通常のテキストに戻る

        :set t_us=^V^[\|xxm             下線モードの開始
        :set t_ue=^V^[\|xxm             通常のテキストに戻る

        :set t_ZH=^V^[\|xxm             イタリックモードの開始
        :set t_ZR=^V^[\|xxm             通常のテキストに戻る

^V は CTRL-V
^[ は <Esc>
xx を 10 進コードに置き換えなければならない。それは前景色の番号および背景色の
番号を足し合わせたものである:

色                      前景色  背景色
Black                       0               0
DarkBlue                    1              16
DarkGreen                   2              32
DarkCyan                    3              48
DarkRed                     4              64
DarkMagenta                 5              80
Brown, DarkYellow           6              96
LightGray                   7             112
DarkGray                    8             128 *
Blue, LightBlue             9             144 *
Green, LightGreen          10             160 *
Cyan, LightCyan            11             176 *
Red, LightRed              12             192 *
Magenta, LightMagenta      13             208 *
Yellow, LightYellow        14             224 *
White                      15             240 *

* ディスプレイモードによっては、128 以上のカラーコードが使用できないことがあ
  り、コード 128 はテキストを点滅させる。

0 を使うと、色は Vim を開始した時に使われていたものにリセットされる (通常は 7、
黒地に lightgray だが、これは上書きできる。コマンドプロンプトでデフォルトの色
を上書きしている場合は、vimrc でいくつかのハイライト色を調整する必要があるかも
しれない---以下を参照)。
これは t_me のデフォルトである。

さまざまなハイライトモードのデフォルトは:
        t_mr    112      反転モード: LightGray (112) の上に Black のテキスト (0)
        t_md     15      太字モード: Black (0) の上に White のテキスト (15)
        t_me      0      通常モード (デフォルトに戻す)

        t_so     31      standout モード: DarkBlue (16) の上に White (15) のテキスト
        t_se      0      standout モードの終了 (デフォルトに戻す)

        t_ZH    225      イタリックモード: Yellow (224) の上に DarkBlue のテキスト (1)
        t_ZR      0      イタリックモードの終了 (デフォルトに戻す)

        t_us     67      下線モード: DarkRed (64) の上に DarkCyan のテキスト (3)
        t_ue      0      下線モードの終了 (デフォルトに戻す)

これらの色は、反転したディスプレイを使う時にも見栄えが良いので選ばれたが、好み
に合わせて変更できる。

例:
  :set t_mr=^V^[\|97m   " 反転モードの開始: Brown (96) の上に DarkBlue (1)
  :set t_md=^V^[\|67m   " 太字モードの開始: DarkRed (64) の上に DarkCyan (3)
  :set t_me=^V^[\|112m  " 通常モードに戻る: LightGray (112) の上に Black (0)

  :set t_so=^V^[\|37m   " standout モードの開始: DarkGreen (32) の上に
                                                                        DarkMagenta (5)
  :set t_se=^V^[\|112m  " 通常モードに戻る: LightGray (112) の上に Black (0)

5. ファイル形式                                         dos-file-formats

'fileformat' オプションが "dos" (これがデフォルト) に設定されている場合、Vim
は行末 (<EOL>) として単一の <NL> または <CR><NL> の組を受け付ける。ファイルを
書き込む時は、Vim は <CR><NL> を使う。したがって、ファイルを編集して書き込む
と、Vim は <NL> を <CR><NL> に置き換える。

'fileformat' オプションが "unix" に設定されている場合、Vim は <EOL> として単一
の <NL> を使い、<CR> を ^M として表示する。

任意のモードで読み込み、Dos モード (":se ff=dos") で書き込むことで、Vim を使っ
て <NL> を <CR><NL> に置き換えられる。
Dos モードで読み込み、Unix モード (":se ff=unix") で書き込むことで、Vim を使っ
て <CR><NL> を <NL> に置き換えられる。

'fileformats' が空でない (これがデフォルト) 場合、Vim は 'fileformat' を自動的
に設定するので、自分が何をしているかを実際に心配する必要は無い。

スクリプトファイルまたはバイナリファイルを編集したい場合は、ファイルを読み込む
前に 'binary' オプションを設定するべきである。スクリプトファイルおよびバイナリ
ファイルは、Vim が <CR><NL> に置き換えてしまう単一の <NL> 文字を含んでいること
がある。"-b" (binary) オプション付きで Vim を起動することで、'binary' を自動的
に設定できる。

6. :cd コマンド                                         dos-:cd

":cd" コマンドはドライブ指定子を認識し、カレントドライブを変更する。":cd c:"
を使うとドライブ C がアクティブなドライブになる。":cd d:\foo" を使うとドライブ
D のルートにあるディレクトリ "foo" に移動する。システムがサポートしていれば、
Vim は UNC 名も認識する。例えば、":cd \\server\share\dir"。:cd

7. 割り込み                                             dos-CTRL-Break

検索を中断するには、CTRL-C の代わりに CTRL-Break を使うこと。Vim はキーを読も
うとするまで CTRL-C を検出しない。

8. 一時ファイル                                         dos-temp-files

16 ビットおよび 32 ビット DOS 版のみ:
Vim は一時ファイル (フィルタリング用) を、これらのディレクトリのうち、存在し、
かつ Vim がファイルを作成できる最初のものに置く:
        $TMP
        $TEMP
        C:\TMP
        C:\TEMP
        カレントディレクトリ

Win32 版 (コンソールおよび GUI の両方) の場合:
Vim は一時ファイル名 (フィルタリング用) を得るために標準の Windows 関数を使う。
これらのディレクトリのうち、存在し、かつ Vim がファイルを作成できる最初のもの
が使われる:
        $TMP
        $TEMP
        カレントディレクトリ

9. shell オプションのデフォルト                         dos-shell

'sh' ('shell') オプションのデフォルトは、Windows 95 では "command.com"、
Windows NT では "cmd.exe" である。SHELL が定義されている場合は、Vim は代わりに
SHELL を使い、SHELL が定義されていないが COMSPEC が定義されている場合は、Vim
は COMSPEC を使う。Vim は外部コマンドを "<shell> /c <command_name>" で開始す
る。CTRL-Z を入力すると新しいコマンドサブシェルが開始される。"exit" で Vim に
戻る。  'shell' CTRL-Z

サードパーティのシェルを実行している場合は、'shellcmdflag' ('shcf') および
'shellquote' ('shq') または 'shellxquote' ('sxq') オプションを設定する必要があ
るかもしれない。残念ながら、これは使われる Vim のバージョンにも依存する。例え
ば、MKS Korn シェルまたは bash では、オプションの値は以下のようになるべきであ
る:

                DOS 16 ビット       DOS 32 ビット               Win32 
'shellcmdflag'     -c                   -c               -c
'shellquote'       "
'shellxquote'                                            "

Dos 16 ビットでは、これはシェルを次のように開始する:
        <shell> -c "command name" >file
Win32 では:
        <shell> -c "command name >file"
DOS 32 ビットでは、DJGPP がこれを何らかの方法で内部的に行う。

起動時に、Vim が標準の Windows シェルを認識しない場合、'shell' オプションのど
こかに "sh" が存在するかを確認する。存在する場合、Vim は 'shellcmdflag' および
'shellquote' または 'shellxquote' オプションを設定し、上記のとおりに設定される
だろう。

10. PowerShell                                  dos-powershell dos-pwsh

Vim は PowerShell Desktop および PowerShell Core をサポートする。PowerShell
Desktop は Windows と一緒にインストールされる PowerShell のバージョンであり、
一方 PowerShell Core はクロスプラットフォームで動作する別途ダウンロード可能な
バージョンである。使っているバージョンを確認するには、PowerShell プロンプトで
以下を入力する -
$PSVersionTable.PSEdition

起動時に 'shell' のファイル名に "powershell" が含まれている場合、VIM は
'shellcmdflag'、'shellxquote'、'shellpipe'、および 'shellredir' オプションを以
下の値に設定する:

'shellcmdflag'  -Command
'shellxquote'   "
'shellpipe'     2>&1 | Out-File -Encoding default
'shellredir'    2>&1 | Out-File -Encoding default

起動時に 'shell' のファイル名に "pwsh" が含まれている場合、VIM は
'shellcmdflag'、'shellxquote'、'shellpipe'、および 'shellredir' オプションを以
下の値に設定する:

'shellcmdflag'  -c
'shellxquote'   "
'shellpipe'     >%s 2>&1
'shellredir'    >%s 2>&1

Note: これらのオプションは .vimrc ファイルを読み込んだ後にのみ設定される。特
に、-c で 'shell' オプションを設定するのは、他のシェル関連の設定に反映される
には遅すぎる。コマンドラインからこのオプションを上書きするには --cmd を使う
ことを検討すること。

PowerShell コマンドの実行に長い時間がかかっていると分かった場合は、
'shellcmdflag' の先頭に "-NoProfile" を付けて試すこと。Note これはプロファイル
による PowerShell 環境のセットアップが行われるのを妨げることに注意。

'shell' を通して PowerShell スクリプトを実行するのに問題がある場合は、
'shellcmdflag' の先頭に "-ExecutionPolicy RemoteSigned -Command" を付けて試す
こと。PowerShell の実行ポリシー設定に関する詳細はオンラインの Windows ドキュメ
ントを参照。

複数のフラグを使う時に 'shellcmdflag' に空白を含めることについては
option-backslash を参照。

'shellpipe' および 'shellredir' オプションの値は、PowerShell Desktop からの
UTF-16LE 出力を、現在設定されているコンソールのコードページに再エンコードする。
"default" を以下のどれかに変更することで、出力を別のエンコーディングに強制でき
る:

        unicode          - UTF-16LE (PowerShell 5.1 からのデフォルト出力)
        bigendianunicode - UTF-16
        utf8             - UTF-8
        utf7             - UTF-7 (BOM 無し)
        utf32            - UTF-32
        ascii            - 7-bit ASCII 文字セット
        default          - システムのアクティブなコードページ (通常は ANSI)
        oem              - システムの現在の OEM コードページ

Note 上記のマルチバイト Unicode エンコーディングは、特に示されていない限り、先
頭に BOM を含む。

デフォルトでは、PowerShell Core の出力は BOM 無しの UTF-8 でエンコードされる。
PowerShell Core の出力を別のエンコーディングに強制したい場合は、'shellredir'
および 'shellpipe' を "2>&1 | Out-File -Encoding encoding" に設定すること。こ
こで encoding は以下のどれかである:

        ascii            - 7-bit ASCII 文字セット
        bigendianunicode - UTF-16BE
        bigendianutf32   - UTF-32BE
        oem              - システムの現在の OEM コードページ
        unicode          - UTF-16LE
        utf7             - UTF-7
        utf8             - UTF-8
        utf8BOM          - UTF-8、BOM 付き
        utf8NoBOM        - UTF-8、BOM 無し (PowerShell Core からのデフォルト出力)
        utf32            - UTF-32

PowerShell Core 6.2 以降、Encoding パラメーターは、登録されたコードページの数
値 ID (-Encoding 1251) または登録されたコードページの文字列名 (-Encoding
"windows-1251") の指定もサポートする。.NET の Encoding.CodePage のドキュメント
にさらに情報がある

 vim:tw=78:ts=8:noet:ft=help:norl:
