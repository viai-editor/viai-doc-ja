1. Raku ファイルで Unicode を使う                             raku-unicode

Unicode の記号を使って新しい演算子を定義するのは、Raku のプログラムを読みやす
くする良い方法である。参照:
https://perl6advent.wordpress.com/2012/12/18/day-18-formulas-resistance-is-futile/

Raku はいくつかの一般的な演算子に ASCII の代替を定義しているが
(https://docs.raku.org/language/unicode_ascii を参照)、Unicode の演算子をすべ
て使うことが強く望まれる。オペレーティングシステムは入力の機能を提供している
が、Vim に組み込まれた機能を使う方が好ましいかもしれない。

Vim でこれらの記号を生成する自然な方法は、ダイグラフのショートカットを使うこと
である (:help digraphs-use)。それらの多くは定義されている。一覧を得るには
:digraphs とタイプする。ダイグラフの一覧を読む便利な方法は、それをファイルに
保存することである。シェルから:
        vim +'redir >/tmp/vim-digraphs-listing.txt' +digraphs +'redir END' +q

それらのいくつかは、Vim の標準のダイグラフで使える:
        << «    /0 ∅    !< ≮ 
        >> »    Ob ∘    !> ≯ 
        ., …    00 ∞    (C ⊂ 
        (U ∩    -: ÷    )C ⊃ 
        )U ∪    (_ ⊆    >= ≥ 
        ?= ≅    )_ ⊇    =< ≤ 
        (- ∈    ?= ≅    != ≠ 
        -) ∋    ?- ≃ 

ギリシャ文字は、'*' の後に似たラテン文字を続けると使える:
        *p π 
        *t τ 
        *X × 

数字、下付き文字、上付き文字は 's' と 'S' で使える:
        0s ₀    0S ⁰ 
        1s ₁    1S ¹ 
        2s ₂    9S ⁹ 

しかし、デフォルトでは定義されていないものもある。これらが、~/.vimrc ファイル
に追加できるダイグラフの定義である。
        exec 'digraph \\ ' .. char2nr('∖')
        exec 'digraph \< ' .. char2nr('≼')
        exec 'digraph \> ' .. char2nr('≽')
        exec 'digraph (L ' .. char2nr('⊈')
        exec 'digraph )L ' .. char2nr('⊉')
        exec 'digraph (/ ' .. char2nr('⊄')
        exec 'digraph )/ ' .. char2nr('⊅')
        exec 'digraph )/ ' .. char2nr('⊅')
        exec 'digraph U+ ' .. char2nr('⊎')
        exec 'digraph 0- ' .. char2nr('⊖')
        " オイラーの定数
        exec 'digraph ne ' .. char2nr('𝑒')
        " Raku のアトミック操作の記号
        exec 'digraph @@ ' .. char2nr('⚛')

入モードの短縮入力を書くこともできる。
