これは METAFONT および MetaPost のファイルタイププラグインのドキュメントであ
る。特に明記しない限り、以下で定義されるコマンド、設定、およびマッピングは、両
方のファイルタイプに等しく適用される。

NOTE: このプラグインは +vim9script を必要とする。

                                                        ft-metapost-intro
                                                        ft-metafont-intro
はじめに
このファイルタイププラグインは、構文の色付け、インデント、および補完など、
METAFONT および MetaPost のドキュメントの編集のための広範なサポートを提供する。

METAFONT および MetaPost のコードのインデント規則を定義するのは難しく、やや主
観的である。構文がかなり自由だからである。プラグインは、ほとんどの場合にうまく
動作するいくつかの経験則を使うが、特定の場合には、自動の規則を上書きして、手動
で定義したインデントが gg=G のようなコマンドで保たれるようにしたいかもしれな
い。

これは、行に %>、%<、%=、または %! を付け足して、次の行のインデントを
明示的に制御することで実現できる。< および > の記号は何回でも繰り返してよ
い: 例えば、%>> は次の行を 2 回インデントする。もちろん、%< は次の行のイン
デントを戻すことを意味し、%= は次の行のインデントを現在の行のインデントと同
じにし、%! は次の行のインデントを、手動で設定されたものから変えないことを意
味する。

例えば、これは単純なマクロのデフォルトのインデントである:

        def foo =
            makepen(
                subpath(T-n,t) of r
                shifted .5down
                --subpath(t,T) of r shifted .5up -- cycle
            )
            withcolor black
        enddef

特別なコメントを付け足すと、インデントを任意に調整できる:

        def foo =
            makepen(
                subpath(T-n,t) of r  %>
                    shifted .5down   %>
                        --subpath(t,T) of r shifted .5up -- cycle   %<<<
            )
            withcolor black
        enddef

                                                        ft-metapost-commands
コマンド
                                        :FixBeginfigs
現在のバッファの beginfig() ブロックの番号を、n 番目の図が番号 n を持つように
振り直す。MetaPost のみ。

                                                        ft-metapost-settings
                                                        ft-metafont-settings
設定
                                        'g:mf_other_macros'
その他のいくつかの基本的なマクロ名、例えば cmbase、logo などのものをハイライト
する。これは METAFONT バッファではデフォルトで 1 に設定され、MetaPost バッファ
ではデフォルトで 0 に設定される。

                                        'g:mf_plain_macros'
plain.mf で定義されたキーワードをハイライトする。これは METAFONT バッファでは
デフォルトで 1 に設定され、MetaPost バッファではデフォルトで 0 に設定される。

                                        'g:mf_plain_modes'
modes.mf で定義されたキーワードをハイライトする。これは METAFONT バッファでは
デフォルトで 1 に設定され、MetaPost バッファではデフォルトで 0 に設定される。

                                        'g:mp_close_tag'
インデントされたブロックを終わらせる追加のキーワードを定義する。例えば、定義す
ると:

        g:mp_close_tag = ['\<endfoo\>']

endfoo で始まる行はすべて、その前の行と比べてインデントが戻される。

        g:mp_close_tag = []

                                        'b:mp_metafun'
                                        'g:mp_metafun'
1 に設定すると、ConTeXt の MetaFun キーワードをハイライトする。MetaPost のみ。

        g:mp_metafun = 0

                                        'g:mp_mfplain_macros'
mfplain.mp で定義されたキーワードをハイライトする。MetaPost のみ。

        g:mp_mfplain_macros = 1

                                        'g:mp_open_tag'
インデントされたブロックを始める追加のキーワードを定義する。例えば、定義すると:

        g:mp_open_tag = ['\<beginfoo\>']

beginfoo の次の行がインデントされる。

        g:mp_open_tag = []

                                        'g:mp_other_macros'
すべてのベースマクロパッケージ (boxes, rboxes, format, graph, marith, sarith,
string, TEX) で定義されたキーワードをハイライトする。このオプションは MetaPost
バッファにだけ影響する。

        g:mp_other_macros = 1

                                        'g:mp_plain_macros'
plain.mp で定義されたキーワードをハイライトする。MetaPost のみ。

        g:mp_plain_macros = 1

                                        'g:no_mp_maps'
                                        'g:no_mf_maps'
設定すると、対応するファイルタイプのバッファでは、マッピングを一切定義しない。

        g:no_mp_maps = 0
        g:no_mf_maps = 0

                                                        ft-metapost-mappings
                                                        ft-metafont-mappings
マッピング

]]                      [count] 個の vardef、マクロ、または図だけ前方へ。

[[                      [count] 個の vardef、マクロ、または図だけ後方へ。

][                      [count] 個の vardef、マクロ、または図の終わりだけ前方
                        へ。

[]                      [count] 個の vardef、マクロ、または図の終わりだけ後方
                        へ。

]}                      [count] 個のブロック (fi, endfor, endgroup) の終わりだ
                        け前方へ。

[{                      [count] 個のブロック (if, for, begingroup) の始まりだ
                        け後方へ。
