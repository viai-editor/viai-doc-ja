ICCF オランダと Kuwasha

Bram Moolenaar 氏の慈善団体である ICCF オランダは、Kibaale Children's Centre
を通じて長年にわたりウガンダの子どもたちの教育を支援してきた。2023 年に Bram
氏が亡くなった後、ICCF オランダはすべての活動をカナダの姉妹慈善団体である
Kuwasha に移管し、2025 年末に解散した。

Vim ユーザーからの寄付は引き続き歓迎しており、引き続きウガンダに直接送られる。
この活動を継続して支援するには、Kuwasha まで寄付を送ること。

VIM ライセンス

I)  Vim のコピーを変更せずに配布することは、このライセンス文を含めなければな
    らないこと以外に制限されない。また、変更を加えていない Vim の一部分だけを
    配布することも同様に、このライセンス文を含めなければならないこと以外に制限
    されない。配布物には、変更を加えていない Vim のソースから作成した実行可能
    ファイルや、あなた独自の説明書や Vim script を含めることもできる。

II) 以下の 4 つの条件を満たす場合に限り、Vim に変更 (または拡張) を加えた物
    を、実行可能ファイルやソースコードも含めて配布することが認められている:
    1) このライセンス文を変更せずに配布物に含めること。
    2) 変更された Vim は以下の 5 つの方法のどれかで配布しなければならない。
       a) Vim に独自の変更を加えた場合、配布物にあなたの連絡先を明確に示すこ
          と。メンテナーがあなたが配布した変更された Vim のコピーについて (何
          かを) 尋ねたときに、あなたが加えた変更を、ソースコードも含めて、無償
          で、メンテナーが利用できるようにしなければならない。メンテナーは公式
          なバージョンの Vim にあなたの変更を取り込むための権利を保有する。メ
          ンテナーがあなたの変更をどのようにし、どういったライセンスで配布する
          かを交渉することができる。交渉が行われなければ、このライセンス、もし
          くはこれの新しいバージョンのライセンスがあなたの変更に適用される。現
          在のメンテナーはここにリストされている:
              https://github.com/orgs/vim/people
          これが変更されるときは適切な場所で告知される (おそらく vim.sf.net や
          www.vim.org そして comp.editors)。もし本当にメンテナーと連絡が取れな
          い場合には、あなたの変更を提出する義務はない。一旦、メンテナーがあな
          たの変更を受け取ったことを確認できたなら、再度提出する必要はない。
       b) a) に基づいて配布された変更された Vim を受け取った場合、それを変更す
          ることなしに、I) に基づいて再配布できる。さらなる変更を加えた場合、
          その変更には a) が適用される。
       c) 変更された Vim の配布物全てに、ソースコードも含めて、全ての変更点を
          提供すること。これは context diff の形式で行うことができる。あなた
          は、あなたが加えた新しいコードに対してどのライセンスを適用するか選択
          できる。その変更とライセンスは、公式なバージョンの Vim に取り込むこ
          とで、他のものを制限してはいけない。
       d) c) に基づいて配布された変更された Vim があるとき、次の条件を満たす場
          合に限り、そのソースコードを含めずに配布することができる:
          - その変更に適用されているライセンスが、その変更を無償で制限なしに
            Vim のメンテナーに提供することを認め、そして、Vim のメンテナーが
            その変更を公式なバージョンの Vim に取り込むことを無償で制限なしに
            認めている。
          - その変更された Vim の変更点を、最後に配布したときから少なくとも 3
            年は保持すること。その期間内に、メンテナーや誰かがその変更について
            (何かを) 尋ねた場合、彼らがその変更を利用できるようにしなければな
            らない。
          - その配布物にあなたの連絡先を明確に示すこと。その連絡方法は、その変
            更された Vim に相当する配布物が最後に提供されてから、少なくとも 3
            年、そして可能な限り長く、有効でなければならない。
       e) その変更に GNU General Public License (GPL) が適用されている場合、
          GNU GPL バージョン 2、またはそれより新しいバージョンに基づいて、その
          変更された Vim を配布することができる。
    3) その変更された Vim を利用しているユーザーが、それが変更されていると確認
       できるように、少なくとも、":version" コマンドや起動時の挨拶メッセージ
       に、変更されている旨を表示しなければならない。その配布物が 2)e) による
       ものである場合、そのライセンスが変更前のものと矛盾していない、という旨
       のメッセージだけが必要である。
    4) 2)a) と 2)d) により要求されている連絡方法を、その本人が訂正する以外に、
       変更したり削除してはいけない。

III) 変更された Vim を配布する場合、あなたの変更に Vim のライセンスを使い、
     その変更を、ソースコードも含めて、メンテナーが利用できるようにすることが
     奨励されている。そのためには電子メールで送るか、サーバーにアップロードし
     てその URL を電子メールで知らせるのが望ましい。少しの変更なら (例えば
     Makefile の変更など) context diff を電子メールで送るのがいいだろう。
     電子メールの送り先は <maintainer@vim.org> である。

IV)  Vim のソースや、その一部、または変更された Vim、の配布物からこのライセン
     スを削除することは認められていない。望むなら、以前の Vim リリースに、その
     時点のライセンスではなく、このライセンスを適用することができる。

Kibaale Children's Centre               kcc Kibaale  charity

Kibaale Children's Centre (KCC) はウガンダの南部にある小さな町 Kibaale にある。
ウガンダは東アフリカのタンザニアの近くに位置している。その地域はRakai 地区とし
て知られている。人口の大部分は農民で、貧乏ではあるが通常食料は十分にある。しか
しこの地域は世界のほかの場所よりも AIDS で苦しんでいる。AIDS はここから始まっ
たという人もいる。過去の推定ではウガンダ人の 10-30% が HIV に感染しているとさ
れている。両親が死んでしまうので孤児がたくさんいる。この地域では人口 350,000
人のうちの 60,000 人の子供が親をどちらか、または両方をなくしている。AIDS は現
在おおむね管理下にはあるが、問題はまだ続いている。

子供たちは多くの援助を必要としている。KCC は食料、医療、教育を彼らに提供するた
めに懸命に働いている。食料と医療は彼らの健康を保つために、そして教育は彼らの将
来を手助けするためである。KCC はキリスト教の教えに基づいて活動しているが、子供
たちの宗教にかかわらず援助が行われている。

この地域の問題を解決する鍵は教育である。過去数年にわたる Idi Amin 大統領の時代
とそれに続く市民戦争により、教育は軽視されてきた。今は政府が再び安定したし、子
供と親は自分自身の健康をどうやって保つか、そしてどうすれば感染を避けられるかを
学ぶ必要がある。病気にかかっている人々や空腹を抱えている人々への援助もなされて
いるが、第一の目標は人々を病気から遠ざけることであり、そして体によい食料を育て
る方法を彼らに教えることである。

ほとんどの孤児は拡大家族の中で生活している。叔父や姉が彼らの世話をしている。こ
のような家庭は大家族でありながら収入は少ないので、子供が体によい食料を得られる
のは希である。まして衣類、医療、学校に通うことなどは無理なのである。このような
貧しい子供たちを助けるために資金援助制度が設けられた。子供は経済的に養子になる
のである。KCC は、月に数ドルのお金で、子供たちに必要なもの、健康や学校に通うこ
となどを手配する。また KCC はその他にも、子供とその世話をしている家族が必要と
するものの面倒を見ている。

子供を直接援助するほかに、子供が育つ環境を改善する必要がある。KCC は学校の教育
方法が改善されるよう援助を行っている。センターには実地教育をする学校
(demonstration school) があり、教師を指導している。保健に従事する人の育成もさ
れており、衛生教育も行われている。そして、各家庭が適切なトイレを作れるように支
援している。私はセメントの厚い板を作る現場を設立する手伝いをした。その板はよい
トイレを作るのに使われ、そしてコスト以下の値段で売られている。

プロジェクトには診療所があり、子供たちとその家族が医療を受けられるようにしてい
る。2020年以降、産科病棟が追加され、24時間年中無休のサービスが可能になった。そ
して必要あれば病院へ移ることが提供される。病気の予防プログラムが実行されてお
り、伝染病 (風疹とコレラは悩みの種である) が発生した場合は援助が行われる。

1994 年の夏から 1995 年の夏にかけて、Bram 氏は丸 1 年間、ボランティアとしてセ
ンターで活動した。センターの拡張に尽力し、水と衛生の分野で活動した。Bram 氏は
KCC が提供する支援が本当に役立つことを知った。オランダに戻った後も、Bram 氏は
KCC への支援を継続したいと考えた。そのため、彼は資金集めとスポンサーシッププロ
グラムの運営に尽力してきた。

資金が適切に使われると、どのようにして確信できるのだろうか？まず、Vim の作者で
ある Bram 氏 (センターで働く人々を個人的に知っている) の個人的な保証がある。さ
らに、センターは World Vision と Save the Children ファンドの共同スポンサーと
視察を受けており、現在は Pacific Academy Outreach Society の監督下にある。Bram
氏は 1993 年以来、何度もセンターを訪問している。訪問報告書は ICCF のウェブサイ
トで公開されている (現在は閲覧できない可能性がある)。

不明な点があれば、info@kuwasha.net までメールで問い合わせること。
