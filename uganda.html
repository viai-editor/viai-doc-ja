Vim はチャリティウェアである。好きなだけ使用およびコピーできるが、ウガンダの貧
しい子供たちのために寄付することが奨励されている。以下の kcc を参照するか、
または以下の URL で利用できる Kuwasha のウェブサイトを訪れること:

        https://www.kuwasha.net

Vim の開発のスポンサーになることもできる。sponsor を参照。いずれにせよ、その
お金はウガンダへ送られる。

                                                        iccf ICCF
ICCF Holland および Kuwasha

Bram Moolenaar の慈善団体である ICCF Holland は、Kibaale Children's Centre
を通じて、長い間ウガンダの子供たちの教育を支援してきた。2023 年の Bram の逝去
に続いて、ICCF Holland はすべての活動をカナダの姉妹慈善団体 Kuwasha に移管し、
2025 年末に解散した。

Vim ユーザーからの寄付は今でも歓迎され、引き続き直接ウガンダへ送られる。この活
動を引き続き支援するには、Kuwasha へ寄付を送ること。

Vim ライセンス

I)  Vim の変更されていないコピーを配布することには、このライセンス文を含めなけ
    ればならないことを除いて、制限は無い。Vim の変更されていない部分を配布する
    こともでき、同様に、このライセンス文を含めなければならないことを除いて制限
    は無い。変更されていない Vim のソースから作成した実行可能ファイルに加えて、
    あなた自身の使用例および Vim script を含めることも認められている。

II) 以下の 4 つの条件が満たされる場合、実行可能ファイルおよび/またはソースコー
    ドを含めて、Vim の変更 (または拡張) 版を配布することが認められている:
    1) このライセンス文を変更せずに含めなければならない。
    2) 変更された Vim は、以下の 5 つの方法のうちの 1 つで配布しなければならな
       い:
       a) Vim に自分で変更を加える場合、配布物の中で、あなたへの連絡方法を明確
          に記述しなければならない。あなたが配布した変更された Vim のコピーを
          メンテナーが (何らかの方法で) 求めた場合、あなたは、ソースコードを含
          めて、あなたの変更を無償でメンテナーが利用できるようにしなければなら
          ない。メンテナーは、あなたの変更を Vim の公式版に含める権利を保有す
          る。メンテナーがあなたの変更をどうするか、およびそれらがどのライセン
          スの下で配布されるかは、交渉可能である。交渉が無かった場合は、このラ
          イセンス、またはより新しい版が、あなたの変更にも適用される。現在のメ
          ンテナーはここに列挙されている:
              https://github.com/orgs/vim/people
          これが変わる場合は、適切な場所 (おそらく vim.sf.net、www.vim.org お
          よび/または comp.editors) で告知される。メンテナーへの連絡が完全に不
          可能な場合、彼にあなたの変更を送る義務は無くなる。あなたの変更を受け
          取ったことをメンテナーが確認したら、それらを再び送る必要は無い。
       b) a) で述べたように配布された変更された Vim を受け取った場合、I) で述
          べたように、それを変更せずにさらに配布することが認められている。追加
          の変更を加える場合、a) の下の文がそれらの変更に適用される。
       c) あなたが配布する変更された Vim のすべてのコピーに、ソースコードを含
          めて、すべての変更を提供する。これは context diff の形式で行ってもよ
          い。あなたが追加する新しいコードにどのライセンスを使うかは選ぶことが
          できる。変更およびそのライセンスは、他者が Vim の公式版に自分の変更
          を加えることを制限してはならない。
       d) c) で述べたような変更を含む変更された Vim を持っている場合、以下の 3

Note:

- Vim に満足しているなら、このファイルの残りを読み、ウガンダの貧しい子供たちを
  援助することを検討することで、それを表してほしい。

- Vim のさらなる開発を支援したいなら、sponsor になることを検討すること。いず
  れにせよ、そのお金はウガンダへ送られる。

- Richard Stallman によれば、Vim のライセンスは GNU GPL 互換である。
  彼がそれを確認してからいくつかの小さな変更が加えられたが、それは違いを生まな
  いはずである。

- GNU GPL の下にあるライブラリと Vim をリンクすると、それ以降の配布は GNU GPL
  に制限される。実際には Vim の何も変更しなかった場合もそうである。

- GNU GPL の下にある変更がいったん取り込まれると、それ以降のすべての変更も GNU
  GPL または互換ライセンスの下で行うことが強制される。

- Vim の改変版を配布する場合、"--with-modified-by" configure 引数または
  MODIFIED_BY define で、あなたの名前および連絡先情報を含めることができる。

- このライセンスは Vim のソースコードに適用される。ただし、Vim に含まれる一部
  のランタイムファイルには異なるライセンス条件が適用される場合がある。それらは
  各ファイルのヘッダーで指定される。

Kibaale Children's Centre               kcc Kibaale  charity

Kibaale Children's Centre (KCC) は、東アフリカの、タンザニアの近くの、ウガンダ
の南部にある小さな町 Kibaale にある。この地域は Rakai District として知られて
いる。住民の大部分は農民である。人々は貧しいが、通常は十分な食料がある。しか
し、この地区は世界の他のどの地域よりも AIDS に苦しんでいる。そこで始まったと言
う人もいる。推定では、過去にウガンダ人の 10 から 30% が HIV に感染している。親
が死ぬので、多くの孤児がいる。この地区では、人口 350,000 人のうち約 60,000 人
の子供が片親または両親を失っている。AIDS は現在ほぼ抑えられているが、問題はま
だ続いている。

子供たちは多くの援助を必要としている。KCC は、貧しい人々に食料、医療、および教
育を提供するために懸命に働いている。食料および医療は彼らを今健康に保つため、そ
して教育は彼らが将来自分自身の面倒を見られるようにするためである。KCC はキリス
ト教を基盤として活動しているが、援助はどの宗教の子供にも与えられる。

この地域の問題を解決する鍵は教育である。これは、過去の Idi Amin 大統領の時代、
およびそれに続く内戦の間、なおざりにされてきた。政府が再び安定した今、子供たち
および親たちは、自分自身の面倒を見る方法、および感染を避ける方法を学ばなければ
ならない。病気で飢えている人々への援助もあるが、第一の目標は人々が病気になるの
を防ぎ、健康な食料を育てる方法を彼らに教えることである。

孤児のほとんどは拡大家族の中で暮らしている。叔父または姉が彼らの面倒を見てい
る。これらの家族は大きく、収入は (あったとしても) 少ないので、子供は健康な食料
を得られれば幸運である。衣服、医療、および学校教育は手の届かないものである。こ
れらの貧しい子供たちを助けるために、スポンサー制度が設けられた。子供を経済的に
養子にできる。月に数ドルで、KCC は子供が欠かせない品物を得て、健康で、学校に通
えるよう取り計らい、そして KCC はその子供およびその子供を支える家族のために必
要なその他のことの面倒を見る。

子供を直接助けることに加え、子供が育つ環境を改善する必要がある。KCC は学校が教
育方法を改善するのを手助けしている。センターにはモデル校があり、教員研修が行わ
れている。保健従事者が育成され、衛生教育が実施され、そして各家庭は適切なトイレ
を建てるよう促されている。私はセメント板の製造所を立ち上げるのを手伝った。これ
らは良いトイレを建てるのに使われる。これらは原価以下で売られている。

プロジェクトには診療所があり、子供たちおよびその家族に医療援助を提供している。
2020 年から産科病棟が追加され、24/7 のサービスが利用できる。必要な場合は、病院
への移送が提供される。予防接種プログラムが実施され、伝染病が発生している時には
援助が提供される (はしかおよびコレラが問題になってきた)。

1994 年の夏から 1995 年の夏まで、Bram はセンターで丸 1 年を過ごし、ボランティ
アとして働いた。Bram はセンターの拡張を手伝い、水および衛生の分野で働いた。
Bram は KCC が提供する援助が本当に役立つことを知った。Bram はオランダに戻った
時、KCC の支援を続けたいと思った。そうするために、彼は資金を集め、スポンサー制
度を運営してきた。

資金が正しく使われることをどうやって知ることができるか? まず、センターで働く
人々を個人的に知っていた、Vim の作者としての Bram の個人的な保証がある。さら
に、センターは World Vision、Save the Children Fund の共同スポンサーおよび視察
を受けてきており、現在は Pacific Academy Outreach Society の監督下にある。Bram
は 1993 年から何度もセンターを訪れた。訪問報告は ICCF のウェブサイトで共有され
てきた (もう利用できないかもしれない)。

さらに質問がある場合は、e-mail を送ること: info@kuwasha.net。
