1. コマンド                                             lua-commands

                                                        :lua
:[range]lua {chunk}
                        Lua チャンク {chunk} を実行する。

例:

        :lua print("Hello, Vim!")
        :lua local curbuf = vim.buffer() curbuf[7] = "line #7"


:[range]lua << [trim] [{endmarker}]
{script}
{endmarker}
                        Lua スクリプト {script} を実行する。
                        Note: このコマンドは、Lua 機能がコンパイルされていない
                        ときは機能しない。エラーを避けるには、script-here を
                        参照。

"<<" の後から [endmarker] が省略された場合、:append および :insert コマン
ドと同様に、{script} の後にドット '.' を使わなければならない。詳しい情報は
:let-heredoc を参照。

:lua コマンドのこの形式は、主に Vim script に Lua コードを含めるのに便利であ
る。

例:

        function! CurrentLineInfo()
        lua << EOF
        local linenr = vim.window().line
        local curline = vim.buffer()[linenr]
        print(string.format("Current line [%d] has %d chars",
                linenr, #curline))
        EOF
        endfunction

使っている Lua のバージョンを確認するには:
        :lua print(_VERSION)

LuaJIT を使っている場合、これも使える:
        :lua print(jit.version)


                                                        :luado
:[range]luado {body}    [range] 内の各行に対して、関数の引数に各行のテキストを
                        末尾の <EOL> なしで順に、および現在の行番号を設定して、
                        Lua 関数 "function (line, linenr) {body} end" を実行す
                        る。関数によって返された値が文字列の場合、それは現在の
                        順番の行のテキストになる。[range] の既定値はファイル全
                        体: "1,$"。

例:

        :luado return string.format("%s\t%d", line:reverse(), #line)

        :lua require"lpeg"
        :lua -- 釣り合った括弧の文法:
        :lua bp = lpeg.P{ "(" * ((1 - lpeg.S"()") + lpeg.V(1))^0 * ")" }
        :luado if bp:match(line) then return "-->\t" .. line end


                                                        :luafile
:[range]luafile {file}
                        {file} 内の Lua スクリプトを実行する。
                        引数全体が 1 つのファイル名として使われる。

例:

        :luafile script.lua
        :luafile %


これらのコマンドはすべて、指定された行範囲 [range] で、コマンドライン (:lua お
よび :luado) またはファイル (:luafile) のどちらかから Lua チャンクを実行する。
Lua インタープリターと同様に、各チャンクはそれ自身のスコープを持つので、コマン
ド呼び出しの間で共有されるのはグローバル変数だけである。Lua の既定のライブラリ
はすべて使用可能である。さらに、Lua の "print" 関数はその出力が Vim のメッセー
ジ領域にリダイレクトされ、引数はタブの代わりに空白で区切られる。

Lua は "vim" モジュール (lua-vim を参照) を使って、Vim にコマンドを発行し、
バッファ (lua-buffer) およびウィンドウ (lua-window) を管理する。しかし、コ
マンドが sandbox 内で実行されるときは、バッファの内容を変更する、新しいバッ
ファを開く、およびカーソル位置を変更する手続きは制限される。

2. vim モジュール                                       lua-vim

Lua は "vim" モジュールを通して Vim とインターフェイスする。入力範囲の最初およ
び最後の行は、それぞれ "vim.firstline" および "vim.lastline" に格納される。こ
のモジュールには、バッファ、ウィンドウ、およびカレント行の問い合わせ、Vim の評
価およびコマンド実行、その他のためのルーチンも含まれる。

        vim.list([arg])         空のリストを返すか、または "arg" が数値キー 1,
                                ..., n を持つ Lua テーブル ("sequence") の場
                                合、i = 1, ..., n について l[i] = arg[i] とな
                                るようなリスト l を返す (List を参照)。数値
                                でないキーはリストの初期化に使われない。変換規
                                則については lua-eval も参照。例:
                                    :lua t = {math.pi, false, say = 'hi'}
                                    :echo luaeval('vim.list(t)')
                                    :" [3.141593, v:false]、'say' は無視される

        vim.dict([arg])         空の辞書を返すか、または "arg" が Lua テーブル
                                の場合、"arg" 内のすべての文字列キー k につい
                                て d[k] = arg[k] となるような辞書 d を返す
                                (Dictionary を参照)。数値キーは文字列に変換
                                される。文字列でないキーは辞書の初期化に使われ
                                ない。変換規則については lua-eval も参照。例:

                                    :lua t = {math.pi, false, say = 'hi'}
                                    :echo luaeval('vim.dict(t)')
                                    :" {'1': 3.141593, '2': v:false,
                                    :" 'say': 'hi'}

        vim.blob([arg])         空の blob を返すか、または "arg" が Lua 文字列
                                の場合、b がバイト文字列として "arg" と等価で
                                あるような blob b を返す。例:
                                    :lua s = "12ab\x00\x80\xfe\xff"
                                    :echo luaeval('vim.blob(s)')
                                    :" 0z31326162.0080FEFF

        vim.funcref({name})     関数 {name} への Funcref を返す (Funcref を
                                参照)。これは Vim の function() と等価である。

        vim.buffer([arg])       "arg" が数値の場合、バッファリスト内の番号
                                "arg" のバッファを返すか、または "arg" が文字
                                列の場合、フルネームまたは短い名前が "arg" で
                                あるバッファを返す。どちらの場合も、バッファが
                                見つからないときは 'nil' (文字列ではなく nil
                                値) を返す。それ以外の場合、"toboolean(arg)"
                                が 'true' のときはバッファリスト内の最初のバッ
                                ファを返し、それ以外のときはカレントバッファを
                                返す。

        vim.window([arg])       "arg" が数値の場合、番号 "arg" のウィンドウを
                                返すか、または見つからないときは 'nil' (文字列
                                ではなく nil 値) を返す。それ以外の場合、
                                "toboolean(arg)" が 'true' のときは最初のウィ
                                ンドウを返し、それ以外のときはカレントウィンド
                                ウを返す。

        vim.type({arg})         {arg} の型を返す。これは Lua の "type" 関数と
                                等価だが、{arg} がリスト、辞書、funcref、バッ
                                ファ、またはウィンドウの場合、それぞれ "list"、
                                "dict"、"funcref"、"buffer"、または "window"
                                を返す。例:
                                        :lua l = vim.list()
                                        :lua print(type(l), vim.type(l))
                                        :" list

        vim.command({cmds})     {cmds} 内の 1 行以上の Ex モードのコマンドを実
                                行する。
                                例:
                                        :lua vim.command"set tw=60"
                                        :lua vim.command"normal ddp"
                                        lua << trim END
                                          vim.command([[
                                              new Myfile.js
                                              call search('start')
                                          ]])
                                        END

        vim.eval({expr})        式 {expr} を評価し (expression を参照)、結果
                                を Lua に変換して、それを返す。Vim の文字列お
                                よび数値は、それぞれ Lua の文字列および数値に
                                直接変換される。Vim のリストおよび辞書は Lua
                                の userdata に変換される (lua-list および
                                lua-dict を参照)。例:
                                        :lua tw = vim.eval"&tw"
                                        :lua print(vim.eval"{'a': 'one'}".a)

        vim.line()              カレント行 (末尾の <EOL> なし) を Lua 文字列で
                                返す。

        vim.beep()              ビープを鳴らす。

        vim.open({fname})       ファイル {fname} の新しいバッファを開き、それ
                                を返す。Note そのバッファはカレントに設定され
                                ないことに注意。

        vim.call({name} [, {args}])
                                名前が {name} の Vim 関数を引数 {args} で呼び
                                出すプロキシ。例:
                                        :lua print(vim.call('has', 'timers'))

        vim.fn                  Vim 関数を呼び出すプロキシ。プロキシメソッドは
                                要求に応じて作成される。例:
                                        :lua print(vim.fn.has('timers'))

        vim.lua_version         Vim がコンパイルされた Lua のバージョンで、
                                {major}.{minor}.{patch} の形式、例えば
                                "5.1.4"。

        vim.version()           Vim のバージョンを持つ Lua テーブルを返す。
                                テーブルは以下のキーを持つ:
                                        major - Vim のメジャーバージョン。
                                        minor - Vim のマイナーバージョン。
                                        patch - 含まれている最新のパッチ。

                                                        lua-vim-variables
Vim エディタのグローバル辞書 g: w: b: t: v: には、以下で説明する
vim.* Lua テーブルを参照することで、Lua から便利かつ慣用的にアクセスできる。
この方法で、Lua から Vim script のグローバル変数を簡単に読み取りおよび変更でき
る。

例:

    vim.g.foo = 5     -- Vim script 変数 g:foo を設定する。
    print(vim.g.foo)  -- Vim script 変数 g:foo を取得して表示する。
    vim.g.foo = nil   -- Vim script 変数を削除 (:unlet) する。

vim.g                                                   vim.g
        グローバル (g:) エディタ変数。
        値のないキーは nil を返す。

vim.b                                                   vim.b
        カレントバッファのバッファスコープ (b:) 変数。
        無効または未設定のキーは nil を返す。

vim.w                                                   vim.w
        カレントウィンドウのウィンドウスコープ (w:) 変数。
        無効または未設定のキーは nil を返す。

vim.t                                                   vim.t
        カレントタブページのタブページスコープ (t:) 変数。
        無効または未設定のキーは nil を返す。

vim.v                                                   vim.v
        v: 変数。
        無効または未設定のキーは nil を返す。

3. リスト userdata                                      lua-list

リスト userdata は vim のリストを表し、そのインターフェイスはリストに対する
Vim の構文に密接に従おうとしている。リストはオブジェクトなので、Lua でのリスト
参照の変更は Vim に反映され、その逆も同様である。リスト "l" は以下のプロパティ
およびメソッドを持つ:

NOTE: パッチ 8.2.1066 で、配列のインデックスは 0 始まりから 1 始まりに変更され
た。以下で確認できる:
            if has("patch-8.2.1066")

プロパティ
----------
        o "#l" はリスト "l" 内の要素数で、Vim の "len(l)" と等価である。
        o "l[k]" は "l" 内の k 番目の要素を返す; "l" は Lua と同様に 1 始ま
            りである。k 番目の要素を変更するには、単に "l[k] = newitem" とする;
            特に、"l[k] = nil" は "l" から k 番目の要素を削除する。要素は
            "l[#l + 1] = newitem" でリストの末尾に追加できる
        o "l()" は "l" のイテレータを返す。
        o "table.insert(l, newitem)" はリストの末尾に要素を挿入する。(Lua
            5.3 以降のみ)
        o "table.insert(l, position, newitem)" は指定された位置に要素を挿入
            する。"position" は 1 始まりである。(Lua 5.3 以降のみ)
        o "table.remove(l, position)" は指定された位置の要素を削除する。
            "position" は 1 始まりである。


メソッド
--------
        o "l:add(item)" は "item" を "l" の末尾に追加する。
        o "l:insert(item[, pos])" は "item" をリスト内の (省略可能な) 位置
            "pos" に挿入する。"pos" の既定値は 0 である。

例:

        :let l = [1, 'item']
        :lua l = vim.eval('l') -- 同じ 'l'
        :lua l:add(vim.list())
        :lua l[1] = math.pi
        :echo l[0] " 3.141593
        :lua l[1] = nil -- 最初の要素を削除
        :lua l:insert(true, 1)
        :lua print(l, #l, l[1], l[2])
        :lua l[#l + 1] = 'value'
        :lua table.insert(l, 100)
        :lua table.insert(l, 2, 200)
        :lua table.remove(l, 1)
        :lua for item in l() do print(item) end

4. 辞書 userdata                                        lua-dict

リスト userdata と同様に、辞書 userdata は vim の辞書を表す; 辞書もオブジェク
トなので、Lua と Vim の間で参照が保持される。辞書 "d" は以下のプロパティを持つ:

プロパティ
----------
        o "#d" は辞書 "d" 内の要素数で、Vim の "len(d)" と等価である。
        o "d.key" または "d['key']" は "d" 内のエントリ "key" の値を返す。
            このキーのエントリを変更するには、単に "d.key = newvalue" とする;
            特に、"d.key = nil" は "d" からエントリを削除する。
        o "d()" は "d" のイテレータを返し、Vim の "items(d)" と等価である。

例:

        :let d = {'n':10}
        :lua d = vim.eval('d') -- 同じ 'd'
        :lua print(d, d.n, #d)
        :let d.self = d
        :lua for k, v in d() do print(d, k, v) end
        :lua d.x = math.pi
        :lua d.self = nil -- エントリを削除
        :echo d


==============================================================================
5. Blob userdata                                        lua-blob

Blob userdata は vim の blob を表す。blob "b" は以下のプロパティを持つ:

プロパティ
----------
        o "#b" は blob "b" の長さで、Vim の "len(b)" と等価である。
        o "b[k]" は "b" 内の k 番目の要素を返す; "b" は Vim と同様に 0 始ま
            りである。負の "k" は、これも Vim と同様に末尾から数えるので、
            "b[-1]" は最後の要素である。k 番目の要素を変更するには、単に
            "b[k] = number" とする; "b[#b] = number" で末尾にバイトを追加でき
            る。

メソッド
--------
        o "b:add(bytes)" は "bytes" を "b" の末尾に追加する。

例:

        :let b = 0z001122
        :lua b = vim.eval('b') -- 同じ 'b'
        :lua print(b, b[0], #b)
        :lua b[1] = 32
        :lua b[#b] = 0x33 -- 末尾にバイトを追加
        :lua b:add("\x80\x81\xfe\xff")
        :echo b

6. Funcref userdata                                     lua-funcref

Funcref userdata は Vim の funcref 変数を表す。"dict" 属性付きで定義された
Funcref は、"self" が辞書に適切に割り当てられるようにするために、辞書のキーと
して取得する必要がある (以下の例を参照。) funcref "f" は以下のプロパティを持つ:

プロパティ
----------
        o "#f" は "f" が参照する関数の名前
        o "f(...)" は "f" が参照する関数を呼び出す (引数付きで)

例:

        :function I(x)
        :  return a:x
        :  endfunction
        :let R = function('I')
        :lua i1 = vim.funcref('I')
        :lua i2 = vim.eval('R')
        :lua print(#i1, #i2) -- どちらも 'I'
        :lua print(i1, i2, #i2(i1) == #i1(i2))
        :function Mylen() dict
        :  return len(self.data)
        :  endfunction
        :let mydict = {'data': [0, 1, 2, 3]}
        :lua d = vim.eval('mydict'); d.len = vim.funcref('Mylen')
        :echo mydict.len()
        :lua l = d.len -- d を 'self' として割り当てる
        :lua print(l())

Lua の関数およびクロージャは自動的に Vim の Funcref に変換され、Vim script
でアクセスできる。例:

        lua <<EOF
        vim.fn.timer_start(1000, function(timer)
            print('timer callback')
        end)
        EOF

7. バッファ userdata                                    lua-buffer

バッファ userdata は vim のバッファを表す。バッファ userdata "b" は以下のプロ
パティおよびメソッドを持つ:

プロパティ
----------
        o "b()" は "b" をカレントバッファに設定する。
        o "#b" はバッファ "b" 内の行数である。
        o "b[k]" は行番号 k を表す: "b[k] = newline" は行 k を文字列
            "newline" で置き換え、"b[k] = nil" は行 k を削除する。
        o "b.name" はバッファ "b" の短い名前を含む (読み取り専用)。
        o "b.fname" はバッファ "b" のフルネームを含む (読み取り専用)。
        o "b.number" はバッファリスト内のバッファ "b" の位置を含む (読み取り
            専用)。

メソッド
--------
        o "b:insert(newline[, pos])" は文字列 "newline" をバッファ内の (省略
            可能な) 位置 "pos" に挿入する。"pos" の既定値は "#b + 1" である。
            "pos == 0" の場合、"newline" はバッファの最初の行になる。
        o "b:next()" はバッファリスト内で "b" の次のバッファを返す。
        o "b:previous()" はバッファリスト内で "b" の前のバッファを返す。
        o "b:isvalid()" は、バッファ "b" が "本物の" (メモリから解放されてい
            ない) Vim バッファに対応する場合、'true' (boolean) を返す。

例:

        :lua b = vim.buffer() -- カレントバッファ
        :lua print(b.name, b.number)
        :lua b[1] = "first line"
        :lua b:insert("FIRST!", 0)
        :lua b[1] = nil -- 先頭行を削除
        :lua for i=1,3 do b:insert(math.random()) end
        :3,4lua for i=vim.lastline,vim.firstline,-1 do b[i] = nil end
        :lua vim.open"myfile"() -- バッファを開いてカレントに設定する

        function! ListBuffers()
        lua << EOF
        local b = vim.buffer(true) -- リスト内の最初のバッファ
        while b ~= nil do
                print(b.number, b.name, #b)
                b = b:next()
        end
        vim.beep()
        EOF
        endfunction

8. ウィンドウ userdata                                  lua-window

ウィンドウオブジェクトは vim のウィンドウを表す。ウィンドウ userdata "w" は以
下のプロパティおよびメソッドを持つ:

プロパティ
----------
        o "w()" は "w" をカレントウィンドウに設定する。
        o "w.buffer" はウィンドウ "w" のバッファを含む (読み取り専用)。
        o "w.line" はウィンドウ "w" 内のカーソル行の位置を表す。
        o "w.col" はウィンドウ "w" 内のカーソル桁の位置を表す。
        o "w.width" はウィンドウ "w" の幅を表す。
        o "w.height" はウィンドウ "w" の高さを表す。

メソッド
--------
        o "w:next()" は "w" の次のウィンドウを返す。
        o "w:previous()" は "w" の前のウィンドウを返す。
        o "w:isvalid()" は、ウィンドウ "w" が "本物の" (メモリから解放されて
            いない) Vim ウィンドウに対応する場合、'true' (boolean) を返す。

例:

        :lua w = vim.window() -- カレントウィンドウ
        :lua print(w.buffer.name, w.line, w.col)
        :lua w.width = w.width + math.random(10)
        :lua w.height = 2 * math.random() * w.height
        :lua n,w = 0,vim.window(true) while w~=nil do n,w = n + 1,w:next() end
        :lua print("There are " .. n .. " windows")

9. luaeval() Vim 関数                                   lua-luaeval lua-eval

Lua の値を Vim に渡すための、"vim.eval" に (双対的に) 相当するものは "luaeval"
である。"luaeval" は式の文字列および省略可能な引数を取り、式の結果を返す。これ
は意味的には Lua での以下と等価である:

        local chunkheader = "local _A = select(1, ...) return "
        function luaeval (expstr, arg)
            local chunk = assert(loadstring(chunkheader .. expstr, "luaeval"))
            return chunk(arg) -- typval を返す
        end

Note "_A" は "luaeval" への引数を受け取ることに注意。Lua の数値、文字列、およ
び list、dict、blob、および funcref の userdata は、それぞれ対応する Vim の型
に変換され、一方 Lua のブール値は数値に変換される。list、dict、blob、および
funcref 以外の userdata を含む、残りの Lua の型のいずれかの変換が試みられた場
合、エラーが投げられる。

例:

        :echo luaeval('math.pi')
        :lua a = vim.list():add('newlist')
        :let a = luaeval('a')
        :echo a[0] " 'newlist'
        :function Rand(x,y) " x と y の間の一様乱数
        :  return luaeval('(_A.y-_A.x)*math.random()+_A.x', {'x':a:x,'y':a:y})
        :  endfunction
        :echo Rand(1,10)

10. 動的ロード                                      lua-dynamic

MS-Windows および Unix では、Lua ライブラリを動的にロードできる。そのとき、
:version の出力には +lua/dyn が含まれる。

これは、Vim が必要なときだけ Lua の DLL または共有ライブラリファイルを探すこと
を意味する。Lua インターフェイスを使わないときはそれは必要ないので、このファイ
ルなしで Vim を使える。


MS-Windows

Lua インターフェイスを使うには、Lua の DLL があなたの検索パス内になければなら
ない。どのディレクトリが使われるかを確認するには、コンソールウィンドウで
"path" とタイプする。'luadll' オプションを使って Lua の DLL を指定することもで
きる。DLL のバージョンは、Vim がコンパイルされた Lua のバージョンと一致しなけ
ればならない。


Unix

'luadll' オプションを使って、コンパイル時に指定された DYNAMIC_LUA_DLL ファイル
の代わりに Lua 共有ライブラリファイルを指定できる。共有ライブラリのバージョン
は、Vim がコンパイルされた Lua のバージョンと一致しなければならない。
