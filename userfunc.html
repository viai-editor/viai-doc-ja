関数の定義および使用。

これはユーザーマニュアルの 41.7 節で紹介されている。

1. 関数の定義                           define-function
2. 関数の呼び出し                       :call
3. 関数内でのクリーンアップ             :defer
4. 関数を自動的に読み込む               autoload-functions

==============================================================================

1. 関数の定義
                                                define-function
新しい関数を定義できる。これらは組み込み関数とまったく同じように呼び出せる。関
数は一連の Ex コマンドを実行する。ノーマルモードのコマンドは :normal コマン
ドで実行できる。

関数名は、組み込み関数との混同を避けるため、大文字で始まらなければならない。異
なるスクリプトで同じ名前を使うのを防ぐには、それらをスクリプトローカルにするこ
と。グローバル関数を使う場合は、明白な、短い名前を避けること。よい習慣は、関数
名をスクリプトの名前で始めることである。例えば "HTMLcolor()"。

旧来の Vim script では、波括弧を使うこともできる。curly-braces-names を参照。

autoload 機能は、関数をそれが呼び出されたときにだけ定義するのに便利である。

                                                        local-function
旧来の Vim script にローカルな関数は "s:" で始まらなければならない。ローカルな
スクリプト関数は、そのスクリプト内から、およびそのスクリプト内で定義された関
数、ユーザーコマンド、および自動コマンドからのみ呼び出せる。そのスクリプト内で
定義されたマッピングから関数を呼び出すこともできるが、その場合、マッピングがス
クリプトの外で展開されるときは "s:" の代わりに <SID> を使わなければならない。
スクリプトローカル関数だけがあり、バッファローカルまたはウィンドウローカルの関
数はない。

Vim9 script では、関数は既定でスクリプトにローカルである。グローバル関数を定
義するには "g:" を前に付ける。

                                :fu :function E128 E129 E123 E454
:fu[nction]             すべての関数およびその引数を一覧表示する。

:fu[nction] {name}      関数 {name} を一覧表示する。
                        {name} は Funcref である Dictionary のエントリにす
                        ることもできる:
                                :function dict.init
                        Note {name} は式ではなく、関数参照である変数を使うこと
                        はできないことに注意。変数 "Funcref" で参照される関数
                        を一覧表示するには、この汚いトリックを使える:
                                let g:MyFuncref = Funcref
                                func g:MyFuncref
                                unlet g:MyFuncref

:fu[nction] /{pattern}  名前が {pattern} にマッチする関数を一覧表示する。
                        "File" で終わるすべての関数を一覧表示する例:
                                :function /File$

                                                        :function-verbose
'verbose' が 0 でない場合、関数を一覧表示すると、それが最後に定義された場所も
表示される。例:

    :verbose function SetFileTypeSH
        function SetFileTypeSH(name)
            Last set from /usr/share/vim/vim-7.0/filetype.vim

詳細は :verbose-cmd を参照。

                                                E124 E125 E853 E884
:fu[nction][!] {name}([arguments]) [range] [abort] [dict] [closure]
                        {name} という名前の新しい関数を定義する。関数の本体は、
                        対応する :endfunction まで、次の行以降に続く。
                                                                E1267
                        名前は英数字および '_' で構成され、大文字または "s:"
                        で始まらなければならない (上記参照)。Note "b:"、"l:"
                        などを使うことは許されない (パッチ 7.4.260 以降、関数
                        名にコロンがある場合、例えば "foo:bar()" に対しては
                        E884 が出る) が、先頭の "g:" はスキップされ、それでも
                        その後に大文字が必要であることに注意。

                        {name} は Funcref である Dictionary のエントリにす
                        ることもできる:
                                :function dict.init(arg)
                        "dict" は既存の辞書でなければならない。エントリ "init"
                        は、まだ存在しない場合は追加される。そうでない場合、既
                        存の関数を上書きするには [!] が必要である。結果は番号
                        付き関数への Funcref である。その関数は Funcref で
                        のみ使用でき、それへの参照がなくなると削除される。
                                                                E127 E122
                        この名前の関数がすでに存在し、かつ [!] が使われていな
                        い場合、エラーメッセージが出る。例外が 1 つある: スク
                        リプトを再び読み込むとき、そのスクリプト内で以前に定義
                        された関数は黙って置き換えられる。
                        [!] が使われた場合、既存の関数は黙って置き換えられる。
                        それが現在実行中でない限り、それはエラーである。
                        NOTE: ! は賢く使うこと。不注意に使うと、既存の関数が予
                        期せず置き換えられる原因になることがあり、それはデバッ
                        グが難しい。
                        NOTE: Vim9 script では、スクリプトローカル関数は削除ま
                        たは再定義できない。

                        {arguments} については function-argument を参照。

                                        :func-range a:firstline a:lastline
                        [range] 引数が追加された場合、関数は範囲を自分で扱うこ
                        とが期待される。範囲は "a:firstline" および
                        "a:lastline" として渡される。[range] が除外された場合、
                        ":{range}call" は範囲内の各行に対して、カーソルを各行
                        の先頭に置いて関数を呼び出す。function-range-example
                        を参照。
                        すべての Ex コマンドの場合と同様に、カーソルはそれでも
                        範囲の最初の行に移動される。
                                                                :func-abort
                        [abort] 引数が追加された場合、関数はエラーが検出される
                        とすぐに中断する。
                                                                :func-dict
                        [dict] 引数が追加された場合、関数は Dictionary のエ
                        ントリを通して呼び出されなければならない。そのとき、
                        ローカル変数 "self" がその辞書に設定される。
                        Dictionary-function を参照。
                                                :func-closure E932
                        [closure] 引数が追加された場合、関数は外側のスコープの
                        変数および引数にアクセスできる。これは通常クロージャと
                        呼ばれる。この例では、Bar() は Foo() のスコープの "x"
                        を使う。それは Foo() が戻った後でも参照されたままであ
                        る:
                                :function! Foo()
                                :  let x = 0
                                :  function! Bar() closure
                                :    let x += 1
                                :    return x
                                :  endfunction
                                :  return funcref('Bar')
                                :endfunction

                                :let F = Foo()
                                :echo F()
                                1
                                :echo F()
                                2
                                :echo F()
                                3

                                                function-search-undo
                        最後に使われた検索パターンおよび redo コマンド "." は、
                        関数によって変更されない。これはまた、関数から戻るとき
                        に :nohlsearch の効果が取り消されることも意味する。

                        :endf :endfunction E126 E193 W22 E1151
:endf[unction] [argument]
                        関数定義の終わり。[argument] なしで、それ自体だけの行
                        に置くのが最もよい。

                        [argument] には次を指定できる:
                                | command       次に実行するコマンド
                                \n command      次に実行するコマンド
                                " comment       常に無視される
                                それ以外        無視される、'verbose' が 0 で
                                                ない場合は警告が出る
                        後続のコマンドのサポートは Vim 8.0.0654 で追加された。
                        それ以前は、引数はすべて黙って無視されていた。

                        :execute コマンドの中で関数を定義できるようにするに
                        は、:bar の代わりに改行を使う:
                                :exe "func Foo()\necho 'foo'\nendfunc"

                                :delf :delfunction E131 E933
:delf[unction][!] {name}
                        関数 {name} を削除する。
                        {name} は Funcref である Dictionary のエントリにす
                        ることもできる:
                                :delfunc dict.init
                        これは "dict" から "init" エントリを削除する。関数は、
                        それへの参照がなくなると削除される。
                        ! を付けた場合、関数が存在しなくてもエラーにならない。
                        Vim9 script では、スクリプトローカル関数を削除しようと
                        すると E1084 が出る。

                                                        :retu :return E133
:retu[rn] [expr]        関数から戻る。[expr] が与えられた場合、それが評価され、
                        関数の結果として返される。[expr] が与えられない場合、
                        数値 0 が返される。関数が明示的な ":return" なしで終
                        わった場合、数値 0 が返される。

                        Vim9 script では:
                        - :return は短縮できず、
                        - E1095 は、無条件の :return または :throw の後
                          にコマンドが続く場合に出る。完全な
                          :if/:elseif/:else も、すべての分岐が :return
                          または :throw で終わる場合、終了するとみなされる。
                          :else のない :if、または通常どおり続行できる分岐
                          は、後続のコマンドを到達不能にしない。例えば:

                          vim9script
                          var L: func = (): bool => {
                            return false
                            echo 'no'  # E1095: Unreachable code after :return
                          }
                          echo L()

                          同じチェックは :try にも適用される: :try 本体お
                          よびすべての :catch ブロックは終了しなければならな
                          い。ただし、終了する :finally ブロックがそれらを上
                          書きする場合を除く。ループ内では、:break および
                          :continue はループ本体内のその後のコマンドを到達不
                          能にするが、ループの後のコマンドは到達不能にしない。
                          例えば、:if/:else のすべての分岐が戻る場合、
                          :endif の後のコマンドは到達不能である:

                          vim9script
                          def AllBranchesReturn(n: number): number
                            if n > 0
                              return 1
                            else
                              return 0
                            endif
                            echo 'no'  # E1095: Unreachable code after :return
                          enddef

                        旧来の Vim script では到達不能な行のチェックはなく、し
                        たがって :return の後にコマンドが続いても警告はない。
                        また、次の行が有効なコマンドを含んでいるかどうかの
                        チェックもない。行継続のバックスラッシュを忘れても気付
                        かれないことがある:
                                return 'some text'
                                       .. ' some more text'
                        これはエラーなしで "some text" を喜んで返す。本来はこ
                        うあるべきだった:
                                return 'some text'
                                       \ .. ' some more text'

                        ":return" が :try の後、かつ対応する :finally (存
                        在する場合) の前で使われた場合、":finally" に続く、対
                        応する :endtry までのコマンドが先に実行される。この
                        処理は関数内のネストしたすべての ":try" に適用される。
                        関数は最も外側の ":endtry" で戻る。

                                                function-argument a:var
引数は、その名前を与えることで定義できる。そうすると関数内では、これは
"a:name" ("a:" は argument を表す) として使える (:def 関数内では "a:" は使わ
れない)。
                                        a:0 a:1 a:000 E740 ...
コンマで区切って、最大 20 個の引数を与えることができる。名前付き引数の後に、引
数 "..." を指定できる。これは、さらに引数が任意に続くことがあることを意味する。
関数内では、追加の引数は "a:1"、"a:2" などとして使える。"a:0" は追加の引数の数
(0 にもなりうる) に設定される。"a:000" はこれらの引数を含む List に設定され
る。Note "a:1" は "a:000[0]" と同じであることに注意。
                                                        E742 E1090
a: スコープおよびその中の変数は変更できず、固定されている。しかし、List また
は Dictionary のような複合型が使われている場合、その内容は変更できる。した
がって、List を関数に渡し、関数にそれへ項目を追加させることができる。関数が
List または Dictionary を変更できないことを確実にしたい場合、:lockvar を
使う。

引数なしで関数を定義することもできる。その場合でも () を与えなければならない。

関数本体の中で別の関数を定義することは許されている。

                                                optional-function-argument
位置指定の名前付き引数には既定値を与えることができる。これにより、それらは関数
呼び出しにおいて省略可能になる。位置指定の引数が呼び出し時に指定されない場合、
それを初期化するのに既定の式が使われる。
これは :function または :def で宣言された関数でのみ機能し、ラムダ式
expr-lambda では機能しない。

例:
  function Something(key, value = 10)
     echo a:key .. ": " .. a:value
  endfunction
  call Something('empty')       "empty: 10"
  call Something('key', 20)     "key: 20"

引数の既定の式は、関数が定義されたときではなく、関数呼び出しの時点で評価され
る。したがって、関数が定義された時点では無効な式を使うことが可能である。また、
式は呼び出し時に引数が指定されなかった場合にのみ評価される。
                                                none-function_argument
既定の式を使うために v:none を渡すことができる。Note これは、引数に既定の式
がある場合、v:none を通常の値として渡せないことを意味することに注意。

例:
  function Something(a = 10, b = 20, c = 30)
  endfunction
  call Something(1, v:none, 3)      " b = 20

                                                                E989
既定の式を持つ省略可能な引数は、すべての必須の引数の後に置かなければならない。
すべての省略可能な名前付き引数の後に "..." を使うことができる。

後の引数の既定値が前の引数を参照することは可能だが、その逆はできない。すべての
引数と同様に、それらには "a:" を前に付けなければならない。

機能する例:
  :function Okay(mandatory, optional = a:mandatory)
  :endfunction
機能しない例:
  :function NoGood(first = a:second, second = 10)
  :endfunction

"..." を使わない場合、関数呼び出しの引数の数は、少なくとも必須の名前付き引数の
数と等しくなければならない。"..." を使う場合、引数の数は必須および省略可能な引
数の合計より多くてもよい。

                                                        local-variables
関数の中ではローカル変数を使うことができる。これらは関数から戻ると消える。グ
ローバル変数には "g:" でアクセスする必要がある。
関数の中では、ローカル変数には何も前に付けずにアクセスする。しかし、好みで
"l:" を前に付けることもできる。これは "count" のような一部の予約された名前では
必須である。

例:
  :function Table(title, ...)
  :  echohl Title
  :  echo a:title
  :  echohl None
  :  echo a:0 .. " items:"
  :  for s in a:000
  :    echon ' ' .. s
  :  endfor
  :endfunction

そうすると、この関数は以下で呼び出せる:
  call Table("Table", "line1", "line2")
  call Table("Empty Table")

複数の値を返すには、List を返す:
  :function Compute(n1, n2)
  :  if a:n2 == 0
  :    return ["fail", 0]
  :  endif
  :  return ["ok", a:n1 / a:n2]
  :endfunction

そうすると、この関数は以下で呼び出せる:
  :let [success, div] = Compute(102, 6)
  :if success == "ok"
  :  echo div
  :endif

2. 関数の呼び出し
                                                :cal :call E107
:[range]cal[l] {name}([arguments])
                関数を呼び出す。関数の名前およびその引数は、:function で指定
                されたとおりである。最大 20 個の引数を使える。戻り値は破棄され
                る。
                Vim9 script では :call の使用は任意であり、これらの 2 行は
                同じことをする:
                        call SomeFunc(arg)
                        SomeFunc(arg)
                範囲なしの場合、および範囲を受け付ける関数の場合、関数は 1 回
                呼び出される。範囲が与えられた場合、関数を実行する前に、カーソ
                ルは最初の行の先頭に置かれる。
                範囲が与えられ、かつ関数がそれを自分で扱わない場合、関数は範囲
                内の各行に対して、カーソルをその行の最初の桁に置いて実行され
                る。カーソルは最後の行に残される (最後の関数呼び出しによって移
                動されている可能性がある)。引数は各行に対して再評価される。し
                たがって、これは機能する:
                                                function-range-example 
        :function Mynumber(arg)
        :  echo line(".") .. " " .. a:arg
        :endfunction
        :1,5call Mynumber(getline("."))

                "a:firstline" および "a:lastline" はいずれにせよ定義されてお
                り、範囲の開始または終了時に何か異なることをするのに使える。

                範囲を自分で扱う関数の例:

        :function Cont() range
        :  execute (a:firstline + 1) .. "," .. a:lastline .. 's/^/\t\\ '
        :endfunction
        :4,8call Cont()

                この関数は、範囲内の最初の行を除くすべての行の前に継続文字 "\"
                を挿入する。

                関数が複合値を返す場合、それはさらに参照解決できるが、その場合
                範囲は使われない。例:
        :4,8call GetDict().method()
                ここで GetDict() は範囲を受け取るが、method() は受け取らない。

                                                                E117
関数が見つからない場合、エラー "E117: Unknown function" が出る。関数が
autoload パスまたは autoload インポートを使っていて、かつスクリプトが Vim9
script である場合、これは関数がエクスポートされていないことが原因である場合も
ある。

                                                                E132
ユーザー関数の再帰は 'maxfuncdepth' オプションで制限される。

:eval を使うこともできる。これは範囲をサポートしないが、メソッドチェーンを可
能にする。例:
        eval GetList()->Filter()->append('$')

関数は、式の評価の一部として、またはメソッドとして使われるときにも呼び出せる:

        let x = GetList()
        let y = GetList()->Filter()

3. 関数内でのクリーンアップ
                                                        :defe :defer
:defe[r] {func}({args}) 現在の関数が終了したときに {func} を呼び出す。
                        {args} はここで評価される。

関数内のコマンドがグローバルな影響を持ち、それを関数の終了時に元に戻さなければ
ならないことはよくある。これをあらゆる種類の状況で処理するのは面倒なことがあ
る。特に予期しないエラーに遭遇した場合は。これは try / finally ブロックで
行えるが、それが複数ある場合は複雑になる。

はるかに簡単な解決策は defer を使うことである。これは、エラーがあるかどうか
に関係なく、関数が戻るときの関数呼び出しを予約する。例:
        func Filter(text) abort
          call writefile(a:text, 'Tempfile')
          call system('filter < Tempfile > Outfile')
          call Handle('Outfile')
          call delete('Tempfile')
          call delete('Outfile')
        endfunc

ここで、何かが原因で関数が中断した場合、'Tempfile' および 'Outfile' は削除され
ない。それを避けるために :defer を使える:
        func Filter(text) abort
          call writefile(a:text, 'Tempfile')
          defer delete('Tempfile')
          defer delete('Outfile')
          call system('filter < Tempfile > Outfile')
          call Handle('Outfile')
        endfunc

Note system() が失敗した場合でも "Outfile" が作成されることがあるので、その
削除は system() を呼び出す前に予約されていることに注意。

遅延された関数は逆順に呼び出され、最後に追加されたものが最初に実行される。役に
立たない例:
        func Useless() abort
          for s in range(3)
            defer execute('echomsg "number ' .. s .. '"')
          endfor
        endfunc

すると :messages はこう表示する:
        number 2
        number 1
        number 0

遅延された関数の戻り値はすべて破棄される。関数の後に "->func" または ".member"
のようなものを続けることはできない。現在、:defer GetArg()->TheFunc() は機能
しないが、後のバージョンでは機能するかもしれない。

エラーは報告されるが、遅延された関数の実行の中断、または遅延された関数の外の実
行の変更を引き起こさない。

範囲は受け付けない。関数は追加の引数を持つ部分適用にできるが、辞書を持つものに
はできない。 E1300

:def 関数では、:defer でラムダを使うことができる。例:

    def Fn()
      set lazyredraw
      defer () => {
        set lazyredraw&
      }()
    enddef

==============================================================================

4. 関数を自動的に読み込む
                                                        autoload-functions
多くの、または大きな関数を使う場合、それらが使われるときにだけ自動的に定義する
ことが可能である。2 つの方法がある: 自動コマンドを使う方法、および
'runtimepath' 内の "autoload" ディレクトリを使う方法である。

Vim9 script には、インポートされたスクリプトのための autoload の仕組みもあ
る。import-autoload を参照。


自動コマンドを使う

これはユーザーマニュアルの 51.4 節で紹介されている。

自動コマンドは、長い Vim script ファイルであるプラグインがある場合に便利であ
る。自動コマンドを定義して、:finish でスクリプトを素早く終了できる。それによ
り Vim の起動が速くなる。そうすると自動コマンドは、:finish コマンドをスキッ
プするための変数を設定して、同じファイルを再び読み込むべきである。

定義される関数にマッチするパターンを指定して、FuncUndefined 自動コマンドイベン
トを使う。例:

        :au FuncUndefined BufNet* source ~/vim/bufnetfuncs.vim

そうすると、ファイル "~/vim/bufnetfuncs.vim" は "BufNet" で始まる関数を定義す
べきである。FuncUndefined も参照。


autoload スクリプトを使う
                                                        autoload E746
これはユーザーマニュアルの 52.2 節で紹介されている。

"autoload" ディレクトリ内のスクリプトを使う方がより簡単だが、正確に正しいファ
イル名を使う必要がある。autoload できる関数は、次のような名前を持つ:

        :call filename#funcname()

これらの関数は常にグローバルであり、Vim9 script では "g:" を使う必要がある:
        :call g:filename#funcname()

このような関数が呼び出され、それがまだ定義されていない場合、Vim は
'runtimepath' 内の "autoload" ディレクトリから "filename.vim" という名前のスク
リプトファイルを探す。例えば "~/.vim/autoload/filename.vim"。そうすると、その
ファイルは次のように関数を定義すべきである:

        function filename#funcname()
           echo "Done!"
        endfunction

ファイルが存在しない場合、パッケージがまだ 'runtimepath' に追加されていないと
きにあなたの .vimrc からパッケージの関数を呼び出せるように、Vim は 'packpath'
("start" の下) も探す (packages を参照)。

ファイル名および関数内の # の前に使われる名前は正確に一致しなければならず、定
義される関数は、呼び出されるとおりの名前を正確に持たなければならない。Vim9
script では "g:" プリフィックスを使わなければならない:
        function g:filename#funcname()

またはコンパイルされる関数の場合:
        def g:filename#funcname()

サブディレクトリを使うこともできる。関数名の各 # はパス区切りのように機能する。
したがって、関数を呼び出すとき:

        :call foo#bar#func()

Vim は 'runtimepath' 内のファイル "autoload/foo/bar.vim" を探す。

これは、まだ設定されていない変数を読むときにも機能する:

        :let l = foo#bar#lvar

しかし、autoload スクリプトがすでに読み込まれていた場合、未知の変数のためにそ
れが再び読み込まれることはない。

このような変数に値を代入するときは、特別なことは何も起こらない。これは、
autoload スクリプトが読み込まれる前に、それに設定を渡すのに使える:

        :let foo#bar#toggle = 1
        :call foo#bar#func()

Note 間違えて、autoload スクリプト内で定義されるはずの関数を呼び出したが、その
スクリプトが実際にはその関数を定義していない場合、存在しない関数に対するエラー
メッセージが出ることに注意。autoload スクリプトを修正した場合、それが自動的に
再び読み込まれることはない。Vim を再起動するか、またはスクリプトを手動で読み込
むこと。

Note 2 つのスクリプトファイルがあり、使われる関数が定義される前に、一方が他方
の関数を呼び出し、かつその逆も行う場合、それは機能しないことにも注意。トップレ
ベルで autoload 機能を使うのは避けること。

Vim9 script では、名前に "#" 文字を含む関数を定義すると、エラー E1263 が出
る。"#" なしの名前を使い、:export を使うべきである。

ヒント: 多数のスクリプトを配布する場合、vimball ユーティリティでそれらを一緒
にパックできる。ユーザーマニュアルの distribute-script も読むこと。
