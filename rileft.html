Vim の右から左の表示モード                                      rileft


これらの機能は最初に Avner Lottem によって作られた:

   Phone:  +972-4-8307322

{+rightleft 機能付きでコンパイルされた場合のみ有効}


はじめに
--------
アラビア語、ペルシア語、ヘブライ語 (など) のいくつかの言語では、テキストを右か
ら左に表示できる必要がある。それらの言語のファイルは通常どおりに保存され、右か
ら左の要件は表示エンジンの機能にすぎない (Unicode の仕様による)。右から左向き
のファイルでは、文字は画面上に右から左へ表示される。

双方向性 (略して bidi) は、これらの言語に対する完全な解決策として Unicode が提
供するものである。bidi では、ユーザーは右から左のテキストと左から右のテキスト
の両方を、同じウィンドウ内で同時に正しく見ることができる。Vim は今のところ、簡
潔さのために bidi を提供しておらず、右から左の言語を表示・入力・使用するための
機能的な手段を提供することを選んでいるにすぎない。方向が文字ごと (または文字の
グループごと) にエンコードされる古いハイブリッドな解決策もサポートされていな
い。この種のサポートは既存のエディタへの単純な追加の範囲外だからである (それに
Unicode によって認められてもいない)。

コードに取り組んでいる多くの人は右から左モードを使わないので、この機能はいくつ
かの状況で動作しないかもしれない。何がおかしいのかと、直したらどう動作するべき
かを説明できるなら、github で issue を作ってほしい。bug-reports を参照。


特長
----
o  オリジナルの Vim と同じように左から右のファイルを編集できる。変更はない。

o  右から左のウィンドウでファイルを表示・編集できる。ファイルの向きはウィンド
   ウごとなので、同じファイルを右から左モードと左から右モードで同時に表示でき
   る。(右から左と左から右の両方のテキストがある混在したファイルを編集するのに
   便利)。

o  オリジナルの Vim との互換性。ほとんどすべての機能が右から左モードで動作する
   (以下のバグを参照)。

o  逆挿入モードから、ファイル内の正しい場所に戻る (可能なら)。

o  右から左の機能を持つ特別な端末は必要ない。右から左の変更は完全にハードウェ
   アに依存しない。

o  多くの言語が右から左のサポートを使い、必要とする。それらの言語は、必要なキー
   ボードマッピングといくつかの可能性のあるちょっとしたコードの変更を加えれば、
   かなり簡単にサポートできる。現在サポートされている言語には、arabic.txt、
   farsi.txt、hebrew.txt がある。


注目点...
---------

o  呼び出し
   --------
   + 'rightleft' ('rl') はウィンドウの向きを右から左に設定する。
   + 'delcombine' ('deco') はブール値で、UTF-8 でエンコードされた言語を編集す
     る場合に、先行する文字に重ねて表示される合成文字を削除できるようにする
     (一部の言語ではこれが必要)。
   + 'rightleftcmd' ('rlc') は、特定のモード (検索など) のコマンドラインも右か
     ら左の向きで使うように設定する。

o  逆方向へのタイプ                                     ins-reverse
   ----------------
   本格的な 'rightleft' オプションを使う代わりに、逆挿入を選ぶこともできる。
   'revins' (逆挿入) オプションが設定されている場合、挿入は逆方向に行われる。
   これは右から左のテキストをタイプするのに使える。文字を挿入すると、カーソル
   は移動せず、テキストが右へ移動する。<BS> はカーソル位置の文字を削除する。
   CTRL-W と CTRL-U も逆方向に動作する。<BS>、CTRL-W、CTRL-U は、'backspace'
   オプションがどう設定されていても、挿入の開始位置や行末で止まらない。

   逆置換モードは (まだ) 無い。

   'showmode' オプションが設定されている場合、逆挿入モードが有効な間は、ステー
   タス行に "-- REVERSE INSERT --" が表示される。

o  rightleft ウィンドウでの貼り付け
   --------------------------------
   マウスでテキストを切り取って rightleft ウィンドウに貼り付けると、テキストは
   反転する。これは、文字はカットバッファから左から右へ来るのに対して、ファイ
   ルには右から左へ挿入されるからである。これを避けるには、貼り付ける前に
   'revins' を切り替えること。


バグ
----
o  rightleft ウィンドウでは、CTRL-A と CTRL-X コマンド (加算と減算) を正しく扱
   わない。

o  コマンドラインでの逆挿入モードと rightleft モードをサポートしない。しかし、
   エディタの機能は減らない。コマンドラインでは、マッピング、短縮入力、検索を
   左から右にタイプして入力できるからである。

o  右から左モードでは多少遅い。右から左の移動は、制御している端末ではなく Vim
   の内部でエミュレートされるからである。

o  'rightleft' と 'revins' の両方がオンの場合: 'textwidth' が動作しない。行は
   まったく折り返されず、単一の長い行になるだけである。

o  完全な双方向性 (bidi) のサポートは無い。
