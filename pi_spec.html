by Gustavo Niemeyer

これは rpm の spec ファイルを扱うためのファイルタイププラグインである。

現在、この Vim プラグインを使うと、RPM の spec ファイルの %changelog セクショ
ンを簡単に更新できる。セクションがまだ存在しなければ、作成までしてくれる。今日
すでにエントリを挿入していれば、今日のエントリに新しい項目を追加するだけにする
機会を与えてくれる。書式文字列 (spec_chglog_format) を指定しなければ、メール
アドレスを尋ね、書式文字列を自分で構築する。

1. 使い方               spec-how-to-use-it
2. カスタマイズ         spec-customizing

==============================================================================
1. 使い方                                       spec-how-to-use-it

spec_chglog プラグインは以下のようなマップを提供する:

        :map <buffer> <LocalLeader>c <Plug>SpecChangelog

これは、spec ファイルの中で maplocalleader キー (デフォルトは '\') に続けて
'c' を押すとプラグインを実行できるという意味である。spec_chglog_format を設
定していなければ、プラグインはこの編集セッションで使うメールアドレスを尋ねる。

プラグインを実行するたびに、changelog の最後のエントリが今日あなたによって書か
れたものかを調べる。エントリが一致すれば、新しい changelog の項目を挿入するだ
けで、そうでなければ新しい changelog のエントリを作成する。
spec_chglog_release_info を有効にして実行している場合は、名前、バージョン、
リリースが一致するかも調べる。プラグインは賢いので、パッケージのリリースを更新
していなければ、更新するべきかを尋ねてくれる。

マップの設定                                    spec-setting-a-map
------------

知ってのとおり、どんな Vim コマンド (というより、どんなものでも) を使うための
マップも簡単に設定できる。デフォルトの <LocalLeader>c のマップが気に入らなけれ
ば、自分のキーを設定すればよい。以下の行は、これを .vimrc ファイルで行い、プラ
グインを <F5> キーにマップする方法を示している:

        au FileType spec map <buffer> <F5> <Plug>SpecChangelog

Note: プラグインは、デフォルトのマッピングを変えたいというあなたの要望を尊
      重し、それを設定しない。

このコマンドは、spec ファイルのバッファにだけマップを追加する。


==============================================================================
2. カスタマイズ                                 spec-customizing

書式文字列                                      spec_chglog_format
----------

spec ファイルのエントリがどのように見えるかは、簡単にカスタマイズできる。これ
を行うには、.vimrc ファイルで変数 "spec_chglog_format" を以下のように設定する
だけでよい:

        let spec_chglog_format = "%a %b %d %Y My Name <my@email.com>"

Note "%a %b %d %Y" は最もよく使われる時刻の書式であることに注意。書式文字列を
指定しなければ、初めて SpecChangelog コマンドを実行した時に、メールアドレスを
尋ね、変数 spec_chglog_format を構築してくれる。こうすれば、メールアドレスを
指定するのは 1 回だけで済む。

どの書式オプションを使えるかを知るには、strftime() 関数の man ページを見るこ
と。

新しい項目を挿入する場所                        spec_chglog_prepend
------------------------

プラグインは通常、新しい %changelog のエントリの項目 (エントリそのものではない
ことに注意) を、既存の項目の後に挿入する。変数 spec_chglog_prepend を設定する
と

        let spec_chglog_prepend = 1

新しい項目を既存の項目の前に挿入する。

リリース情報の挿入                              spec_chglog_release_info
------------------

望む場合、プラグインは各 changelog のエントリにリリース情報を自動的に挿入でき
る。この機能を有効にする利点の 1 つは、パッケージの最後の変更の後にリリースを
更新したかどうかを管理できることである。パッケージのバージョンかリリースを更新
していなければ、パッケージのリリースを更新するべきかを尋ねてくれる。この機能を
有効にするには、以下のコードを .vimrc に挿入するだけでよい:

        let spec_chglog_release_info = 1

すると、changelog のエントリの最初の項目は次のようなものになる:

        + name-1.0-1cl

リリースを更新する機能が気に入らず、古いリリースを検出するたびに "No" と答えた
くなければ、次で無効にできる

        let spec_chglog_never_increase_release = 1
