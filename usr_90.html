                            ViAI をインストールする

                                                                install
ViAI を使う前に、それをインストールする必要があります。あなたのシステムによっ
て、それは簡単、または容易です。この章では、いくつかのヒントを示し、新しいバー
ジョンへのアップグレードがどのように行われるかも説明します。

90.1  Unix

まず、ViAI をシステム全体にインストールするのか、または 1 人のユーザー用にイン
ストールするのかを決める必要があります。インストールはほぼ同じですが、ViAI が
インストールされるディレクトリが異なります。
   システム全体へのインストールでは、ベースディレクトリとして "/usr/local" が
よく使われます。しかし、これはあなたのシステムでは異なるかもしれません。他の
パッケージがどこにインストールされているかを調べてみてください。
   1 人のユーザー用にインストールするときは、あなたのホームディレクトリをベー
スとして使えます。ファイルは "bin" および "share/viai" のようなサブディレクト
リに置かれます。


パッケージから

Unix 用の ViAI のコンパイル済みバイナリパッケージはありません。ソースからコン
パイルしてください。ソースからエディタを作成すると、どの機能をコンパイルするか
を制御できます。ただし、これにはコンパイラが必要です。


ソースから

ViAI をコンパイルしてインストールするには、以下が必要です:

        -  C コンパイラ (GCC または clang が望ましい)
        -  git (任意、github からクローンする場合のみ)
        -  zip/unzip (アーカイブを展開するため)
        -  ViAI のソースアーカイブ

ViAI のソースをダウンロードするには、Github のプロジェクトページからクローンす
るか:
        git clone https://github.com/viai-editor/viai.git

または、以下を使ってアーカイブを直接ダウンロードします:

        https://github.com/viai-editor/viai/archive/refs/heads/master.zip


コンパイル

まず、作業するためのトップディレクトリを作成します。例えば:

        mkdir ~/viai
        cd ~/viai

それから、そこにアーカイブを展開します。このように展開できます:

        unzip viai-master.zip

既定の機能で満足していて、かつあなたの環境が適切に設定されている場合、これだけ
で ViAI をコンパイルできるはずです:

        cd viai-master/src
        make

make プログラムは configure を実行し、すべてをコンパイルします。異なる機能でコ
ンパイルする方法は、この先で説明します。
   コンパイル中にエラーがある場合、エラーメッセージを注意深く見てください。何
が悪かったかについてのヒントがあるはずです。うまくいけば、それを修正できるで
しょう。ViAI をコンパイルできるようにするために、いくつかの機能を無効にする必
要があるかもしれません。あなたのシステム向けの特定のヒントについては Makefile
を見てください。


テスト

これで、コンパイルがうまくいったかどうかを確認できます:

        make test

これは、ViAI が期待どおりに動作することを検証するための一連のテストスクリプト
を実行します。ViAI が何度も起動され、あらゆる種類のテキストおよびメッセージが
さっと表示されます。問題がない場合、最後にこう表示されます:

        test results:
        ALL DONE

"TEST FAILURE" が表示された場合、何らかのテストが失敗しています。失敗したテス
トについてのメッセージが 1 つまたは 2 つの場合、ViAI はまだ動作するかもしれま
せんが、完全ではありません。たくさんのエラーメッセージが表示されるか、または
ViAI が最後まで終了しない場合、何かが間違っているに違いありません。自分で原因
を見つけるか、または解決できる人を見つけてください。他のすべてがうまくいかない
場合、バグとして報告することもできます。viai-bugs を参照してください。


インストール
                                                        install-home
あなたのホームディレクトリにインストールしたい場合、Makefile を編集して、以下
の行を検索します:

        #prefix = $(HOME)

行の先頭の # を削除します。
   システム全体にインストールする場合、ViAI はおそらくすでにあなたのために適切
なインストールディレクトリを選択しています。ディレクトリを指定することもできま
す。以下を参照してください。以下のためには root になる必要があります。

ViAI をインストールするには、こうします:

        make install

これで、関連するすべてのファイルが正しい場所に移動されるはずです。プログラムお
よびディレクトリは ViAI にちなんで名付けられているので、Vim をその隣にインス
トールできます。viai-programs を参照してください。これで、viai を実行してみ
て、それが動作することを確認できます。ViAI がランタイムファイルを見つけられる
かどうかを確認するために、2 つの簡単なテストを使います:

        :help
        :syntax enable

これが動作しない場合、このコマンドを使って、ViAI がどこでランタイムファイルを
探しているかを確認します:

        :echo $VIMRUNTIME

起動中に何が起こるかを見るために、"-V" 引数で ViAI を起動することもできます:

        viai -V

ユーザーマニュアルは、あなたが ViAI を特定の方法で使うことを前提にしていること
を忘れないでください。ViAI をインストールした後、not-compatible の指示に従っ
て、ViAI がこのマニュアルで前提としているとおりに動作するようにしてください。


機能の選択

ViAI には機能を選択する方法がたくさんあります。簡単な方法の 1 つは、Makefile
を編集することです。たくさんの指示および例があります。多くの場合、行のコメント
を外すことで機能を有効または無効にできます。
   別の方法は、"configure" を別に実行することです。これにより、構成オプション
を手動で指定できます。欠点は、正確に何をタイプするかを自分で調べなければならな
いことです。
   最も興味深い configure の引数のいくつかを以下に示します。これらは Makefile
から有効にすることもできます。

        --prefix={directory}            ViAI をインストールするトップディレク
                                        トリ。

        --with-features=tiny            いくつかの機能を無効にしてコンパイルす
                                        る。
        --with-features=normal          より多くの機能を有効にしてコンパイルす
                                        る。
        --with-features=huge            ほとんどの機能を有効にしてコンパイルす
                                        る。どの場合にどの機能が有効になるかは
                                        +feature-list を参照。

        --enable-perlinterp             Perl インターフェイスを有効にする。
                                        ruby、python、および tcl にも同様の引
                                        数がある。

        --disable-gui                   GUI インターフェイスをコンパイルしな
                                        い。
        --without-x                     X-windows の機能をコンパイルしない。こ
                                        れらの両方が使われた場合、ViAI は X
                                        サーバーに接続せず、それにより起動が速
                                        くなる。

リスト全体を見るには、これを使います:

        ./configure --help

各機能についての少しの説明、およびさらなる情報へのリンクがここにあります:
feature-list。
   冒険好きな人は、ファイル "feature.h" を編集してください。ソースコードを自分
で変更することもできます!

90.2  MS-Windows

Microsoft Windows 用に ViAI プログラムをインストールする方法はいくつかあります:

    1. winget (Windows パッケージマネージャー) を使う

コマンドラインを使う方が好みの場合、Windows の組み込みのパッケージマネージャー
を使って、安定版の ViAI を素早くインストールできます:

        winget install viai.viai

または、最新のナイトリー版をダウンロードするには、これを使います:

        winget install viai.viai.nightly

この方法により、最小限の手間で最新のバージョンを手に入れられることが保証されま
す。

    2. GitHub インストーラ (すべてのアーキテクチャ)

インストールをより細かく制御するには (または ARM のような特定の CPU アーキテク
チャを使っている場合は)、公式の GitHub リポジトリを訪れてください:

        https://github.com/viai-editor/viai-win32-installer/

このリポジトリは、以下のための毎日のインストーラおよびポータブル zip アーカイ
ブを提供しています:

    - x86 (32-bit)
    - x64 (64-bit)
    - ARM64

ナイトリービルドまたは特定の構成が欲しい場合、これはすばらしい選択肢です

提供されたバイナリに含まれる機能に満足できない場合、ViAI を自分でコンパイルし
てみることもできます。makefile が存在するコンパイラが必要です。Microsoft
Visual C、MinGW、および Cygwin のコンパイラが使えます。ヒントについては、ファ
イル src/INSTALLpc.txt を確認してください。ソースは以下から入手できます:

        https://github.com/viai-editor/viai

90.3  アップグレード

ViAI のあるバージョンを実行していて、別のバージョンをインストールしたい場合、
以下がその方法です。


UNIX

"make install" とタイプすると、ランタイムファイルはこのバージョンに固有のディ
レクトリにコピーされます。したがって、それらは以前のバージョンを上書きしませ
ん。これにより、2 つ以上のバージョンを並べて使うことができます。
   実行可能ファイル "viai" は古いバージョンを上書きします。古いバージョンを保
持することを気にしない場合、"make install" の実行はうまく機能します。古いラン
タイムファイルは手動で削除できます。バージョン番号を含むディレクトリおよびその
下のすべてのファイルを削除するだけです。例:

        rm -rf /usr/local/share/viai/viai10

通常、このディレクトリの下に変更されたファイルはありません。例えば
"filetype.vim" ファイルを変更した場合、それを削除する前に、変更を新しいバージョ
ンにマージした方がよいでしょう。

慎重で、新しいバージョンに切り替える前にしばらく試してみたい場合、新しいバー
ジョンを別の名前でインストールします。configure の引数を指定する必要がありま
す。例えば:

        ./configure --with-vim-name=viai11

"make install" を実行する前に、"make -n install" を使って、既存の価値のあるファ
イルが上書きされないことを確認できます。
   最終的に新しいバージョンに切り替えることに決めたときは、バイナリの名前を
"viai" に変更するだけです。例えば:

        mv /usr/local/bin/viai11 /usr/local/bin/viai


MS-WINDOWS

アップグレードは、新しいバージョンをインストールすることとほぼ同じです。以前の
バージョンと同じ場所にファイルを展開するだけです。新しいバージョンのファイル用
に、新しいディレクトリ、例えば "viai11" が作成されます。あなたのランタイムファ
イル、vimrc ファイル、viminfo などはそのまま残されます。
   新しいバージョンを古いものと並べて実行したい場合、いくらか手作業をする必要
があります。インストールプログラムを実行しないでください。それは古いバージョン
のいくつかのファイルを上書きします。フルパスを指定して新しいバイナリを実行して
ください。プログラムは、正しいバージョンのランタイムファイルを自動的に見つけら
れるはずです。しかし、どこかで $VIMRUNTIME 変数を設定している場合、これは機能
しません。
   アップグレードに満足した場合、以前のバージョンのファイルを削除できます。
90.5 を参照してください。

90.4  よくあるインストールの問題

このセクションでは、ViAI をインストールするときに起こるよくある問題のいくつか
を説明し、いくつかの解決策を提案します。また、インストールに関する多くの質問へ
の答えも含んでいます。


Q: root 権限がありません。どうやって ViAI をインストールしますか? (Unix)

ViAI をあなたのホームディレクトリにインストールするには、以下の構成コマンドを
使ってください:

        ./configure --prefix=$HOME

これで ViAI の個人用のコピーが得られます。エディタを実行するには、$HOME/bin を
あなたのパスに入れる必要があります。install-home も参照してください。


Q: 私の画面の色が正しくありません。(Unix)

シェルで以下のコマンドを使って、あなたの端末の設定を確認してください:

        echo $TERM

表示された端末の種類が正しくない場合、それを修正してください。さらなるヒントに
ついては、06.2 を参照してください。別の解決策は、gviai と呼ばれる GUI 版の
ViAI を常に使うことです。これにより、正しい端末設定の必要がなくなります。


Q: 私の Backspace キーおよび Delete キーが正しく動作しません

どのキーがどのコードを送るかの定義は、backspace <BS> キーおよび Delete <Del>
キーについては非常に不明確です。まず、あなたの $TERM の設定を確認してください。
それに何も問題がない場合、これを試してください:

        :set t_kb=^V<BS>
        :set t_kD=^V<Del>

1 行目では、CTRL-V を押してから backspace キーを押す必要があります。
2 行目では、CTRL-V を押してから Delete キーを押す必要があります。
これらの行をあなたの vimrc ファイルに入れることができます。05.1 を参照してく
ださい。欠点は、いつか別の端末を使うときに機能しないことです。代わりの解決策に
ついてはここを見てください: :fixdel。


Q: どうやって構文の色付けをオンにしますか? どうやってプラグインを動作させますか?

例の vimrc スクリプトを使ってください。その使い方の説明はここにあります:
not-compatible。

構文ハイライトについての情報は、6 章を参照してください: usr_06.txt。


Q: 使うのによい vimrc ファイルは何ですか?

いくつかのよい例については、www.vim.org ウェブサイトを参照してください。


Q: よい Vim プラグインはどこで見つけられますか?

Vim-online サイトを参照してください: http://vim.sf.net。多くのユーザーが便利な
Vim script およびプラグインをそこにアップロードしています。


Q: もっと多くのヒントはどこで見つけられますか?

Vim-online サイトを参照してください: http://vim.sf.net。Vim ユーザーからのヒン
トのアーカイブがあります。maillist-archive で検索してみるのもよいでしょう。

90.5  ViAI のアンインストール

万一 ViAI を完全にアンインストールしたい場合、これがその方法です。


UNIX

ソースから ViAI をインストールした場合、このコマンドを使えます:

        make uninstall

しかし、元のファイルを削除した場合、または誰かが提供したアーカイブを使った場
合、これはできません。ファイルを手動で削除してください。以下は "/usr/local" が
ルートとして使われた場合の例です:

        rm -rf /usr/local/share/viai/viai10
        rm /usr/local/bin/eviai
        rm /usr/local/bin/gviai
        rm /usr/local/bin/gviaidiff
        rm /usr/local/bin/rgviai
        rm /usr/local/bin/rviai
        rm /usr/local/bin/viai
        rm /usr/local/bin/viaidiff
        rm /usr/local/share/man/man1/eviai.1
        rm /usr/local/share/man/man1/gviai.1
        rm /usr/local/share/man/man1/gviaidiff.1
        rm /usr/local/share/man/man1/rgviai.1
        rm /usr/local/share/man/man1/rviai.1
        rm /usr/local/share/man/man1/viai.1
        rm /usr/local/share/man/man1/viaidiff.1
        rm /usr/local/share/applications/gviai.desktop
        rm /usr/local/share/applications/viai.desktop
        rm /usr/local/share/icons/hicolor/48x48/apps/gviai.png
        rm /usr/local/share/icons/hicolor/scalable/apps/gviai.svg
        rm /usr/local/share/icons/locolor/16x16/apps/gviai.png
        rm /usr/local/share/icons/locolor/32x32/apps/gviai.png


MS-WINDOWS

自己インストールアーカイブで ViAI をインストールした場合、他の ViAI プログラム
と同じディレクトリにある "uninstall-gui" プログラムを実行できます。スタートメ
ニューに ViAI の項目をインストールした場合は、そこから起動することもできます。
これにより、ほとんどのファイル、メニュー項目、およびデスクトップのショートカッ
トが削除されます。しかし、削除される前に Windows の再起動が必要なため、いくつ
かのファイルは残ることがあります。
   ViAI のルートディレクトリを削除するオプションが与えられます。それにはおそら
くあなたの vimrc ファイルおよびあなたが作成した他のランタイムファイルが含まれ
ているので、注意してください。

そうではなく、zip アーカイブで ViAI をインストールした場合、推奨される方法は
"uninstall" プログラムを使うことです。それは "install" プログラムと同じディレ
クトリ、例えば "c:\viai\viai10" にあります。これは通常の
"install/remove software" ページからも機能するはずです。
   しかし、これは ViAI のレジストリ項目を削除するだけです。ファイルは自分で削
除する必要があります。単にディレクトリ "viai\viai10" を選択し、再帰的に削除し
ます。そこにはあなたが変更したファイルはないはずですが、まずそれを確認したいか
もしれません。
   "viai" ディレクトリには、おそらくあなたの vimrc ファイルおよびあなたが作成
した他のランタイムファイルが含まれています。それは残しておきたいかもしれませ
ん。
