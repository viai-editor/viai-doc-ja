01.1  2 つのマニュアル

ViAI は Vim を改変したものです。viai を参照してください。マニュアルは、Vim
と書かれている所も含めて、ViAI に当てはまります。

Vim のドキュメントは 2 つの部分から成ります:

1. ユーザーマニュアル
   作業を中心とした、簡単なものから複雑なものへと進む説明です。本のように最初
   から最後まで読み進められます。

2. リファレンスマニュアル
   Vim のすべての動作についての正確な説明です。

これらのマニュアルで使われている表記については、ここで説明しています:
notation


あちこちへジャンプする

テキストには 2 つの部分の間のハイパーリンクがあり、編集作業の説明と、それに使
われるコマンドおよびオプションの正確な説明との間を素早くジャンプできます。これ
らの 2 つのコマンドを使ってください:

        CTRL-]  を押すと、カーソルの下の項目にジャンプします。
        CTRL-O  を押すと、元に戻ります (繰り返すとさらに戻ります)。

多くのリンクは、bars のように縦線で囲まれています。縦線自体は隠されているか、
または見えないかもしれません。以下を参照してください。'number' のようなオプショ
ン名、":write" のように二重引用符で囲まれたコマンド、およびその他のすべての単
語も、リンクとして使えます。試してみてください: カーソルを  CTRL-]  に移動し
て、その上で CTRL-] を押します。

他の項目は ":help" コマンドで見つけられます。help.txt を参照してください。

縦線およびスターは、通常は conceal 機能で隠されています。また、hl-Ignore
も使われていて、テキストに背景と同じ色を使っています。これで見えるようにできま
す:
        :set conceallevel=0
        :hi link HelpBar Normal
        :hi link HelpStar Normal

01.2  Vim のインストール

マニュアルのほとんどは、Vim が正しくインストールされていることを前提にしていま
す。まだインストールしていない場合、または Vim が正しく動作しない場合 (例えば、
ファイルが見つからない、または GUI でメニューが表示されない) は、まずインストー
ルについての章を読んでください: usr_90.txt。
                                                        not-compatible
マニュアルは多くの場合、Vi 互換を無効にして Vim を使っていることを前提にしてい
ます。ほとんどのコマンドではこれは関係ありませんが、例えば多段のアンドゥなどで
重要になることがあります。よい設定を使っていることを確実にする簡単な方法は、例
の vimrc ファイルをコピーすることです。これを Vim の中で行えば、それがどこにあ
るかを調べる必要がありません。これを行う方法は、使っているシステムによって異な
ります:

Unix:
        :!cp -i $VIMRUNTIME/vimrc_example.vim ~/.vimrc
MS-Windows:
        :!copy $VIMRUNTIME/vimrc_example.vim $VIM/_vimrc
Amiga:
        :!copy $VIMRUNTIME/vimrc_example.vim $VIM/.vimrc

ファイルがすでにある場合は、おそらくそれを残しておきたいでしょう。

ここで Vim を起動すれば、'compatible' オプションはオフになっているはずです。こ
のコマンドで確認できます:

        :set compatible?

"nocompatible" と返ってくれば、うまくいっています。"compatible" と返ってきた場
合は、問題があります。なぜこのオプションがまだ設定されているのかを突き止める必
要があります。上で書き込んだファイルが見つからないのかもしれません。このコマン
ドを使って突き止めてください:

        :scriptnames

ファイルがリストに無い場合は、その場所および名前を確認してください。リストにあ
る場合は、'compatible' オプションを再びオンにしている所がどこか他にあるはずで
す。

詳しくは vimrc および compatible-default を参照してください。

        Note:
        このマニュアルは、Vim を普通の方法で使うことについてのものです。
        "eviai" (easy Vim) という別の方法もあります。これも Vim ですが、メモ帳
        のようなクリック & 入力型のエディタに似た使い方をします。常に挿入モー
        ドのままなので、かなり違った感じがします。大部分は使えば分かるはずなの
        で、ユーザーマニュアルでは説明していません。詳しくは evim-keys を参
        照してください。

01.3  Vim チュートリアルを使う                        tutor vimtutor

テキストを読む (退屈!) 代わりに、Vim チュートリアルを使って最初の Vim コマンド
を学べます。これは 2 つの章で提供される 30 分のチュートリアルで、Vim の最も基
本的な機能を実際に手を動かしながら教えてくれます。

ViAI の中から第 1 章を開始するには:
        :Tutor

第 2 章に進むには、これを使います:
        :Tutor vim-02-beginner

チュートリアルは、翻訳されている場合は現在のメッセージ言語を使います。
vim-tutor-mode を参照してください。ViAI には Vim の "vimtutor" プログラムは
ありません。

第 1 章のプレーンテキスト版には、さらに多くの翻訳があります。そのどれかを使う
には、少し作業をする必要があります:

1. チュートリアルファイルをコピーします。これは ViAI で行えます (ViAI はそれが
   どこにあるかを知っています)。ファイル名に 2 文字の言語コードを付け加えます。
   フランス語の場合:

        viai --clean -c 'e $VIMRUNTIME/tutor/tutor1.fr' -c 'w! TUTORCOPY' -c q

   これで、カレントディレクトリにファイル "TUTORCOPY" が書き込まれます。

2. コピーしたファイルを ViAI で編集します:

        viai --clean TUTORCOPY

   --clean 引数によって、ViAI が確実によいデフォルト設定で起動します。

3. 終わったら、コピーしたファイルを削除します:

        del TUTORCOPY
