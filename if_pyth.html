1. コマンド                                             python-commands

                                        :python :py E263 E264 E887
:[range]py[thon] {stmt}
                        Python 文 {stmt} を実行する。:python コマンドが動作
                        しているかの簡単な確認:
                                :python print "Hello"

:[range]py[thon] << [trim] [{endmarker}]
{script}
{endmarker}
                        Python スクリプト {script} を実行する。
                        Note: このコマンドは Python 機能が組み込まれていない場
                        合は動作しない。エラーを避けるには、script-here を参
                        照。

"<<" の後の [endmarker] が省略された場合、:append および :insert コマンド
と同様に、{script} の後にドット '.' を使用しなければならない。詳細は
:let-heredoc を参照。

この形式の :python コマンドは、主に Vim script に python コードを含めるのに
便利である。

例:
        function! IcecreamInitialize()
        python << EOF
        class StrawberryIcecream:
                def __call__(self):
                        print 'EAT ME'
        EOF
        endfunction

手元の Python のバージョンを確認するには:
        :python print(sys.version)

sys を import する必要はない。それはデフォルトで行われる。

                                                        python-environment
Vim で設定された環境変数が Python で常に使用可能とは限らない。これは Vim およ
び Python がどのようにビルドされたかに依存する。
https://docs.python.org/3/library/os.html#os.environ も参照。

Note: Python はインデントに非常に敏感である。"class" の行および "EOF" にインデ
ントが一切無いようにすること。

                                                        :pydo
:[range]pydo {body}     [range] の各行に対して Python 関数
                        "def _vim_pydo(line, linenr): {body}" を実行する。関数
                        の引数には順に、末尾の <EOL> を除いた各行のテキスト、
                        および現在の行番号が設定される。関数は文字列または
                        None を返すべきである。文字列が返された場合、それが現
                        在の回の行のテキストになる。[range] のデフォルトはファ
                        イル全体: "1,$" である。

例:

        :pydo return "%s\t%d" % (line[::-1], len(line))
        :pydo if line: return "%4d: %s" % (linenr, line)

範囲を python でフィルタするために、:pydo を、場合によっては :py と組み合
わせて使用できる。例:

        :py3 << EOF
        needle = vim.eval('@a')
        replacement = vim.eval('@b')

        def py_vim_string_replace(str):
                return str.replace(needle, replacement)
        EOF
        :'<,'>py3do return py_vim_string_replace(line)

                                                        :pyfile :pyf
:[range]pyf[ile] {file}
                        {file} 内の Python スクリプトを実行する。引数全体が 1
                        つのファイル名として使用される。

これらのコマンドはどちらも本質的に同じことを行う - 指定された行範囲を
"現在の範囲" python-range に設定して、Python コードの断片を実行する。

:python の場合、実行するコードはコマンドラインにある。
:pyfile の場合、実行するコードは指定されたファイルの内容である。

Python コマンドは sandbox 内では使用できない。

引数を渡すには、sys.argv[] を明示的に設定する必要がある。例:

        :python sys.argv = ["foo", "bar"]
        :pyfile myscript.py

ここにいくつかの例を示す                                python-examples 

        :python from vim import *
        :python from string import upper
        :python current.line = upper(current.line)
        :python print "Hello"
        :python str = current.buffer[42]

(Note 変更は - import のように - Python インタープリタとまったく同じように、あ
るコマンドから次のコマンドへ持続することに注意。)

2. vim モジュール                                       python-vim

Python コードは、vim へのすべてのアクセス (1 つの例外を除く - 以下の
python-output を参照) を "vim" モジュール経由で得る。vim モジュールは 2 つの
メソッド、3 つの定数、および 1 つのエラーオブジェクトを実装している。vim モ
ジュールは使用する前に import する必要がある:
        :python import vim

概要
        :py print "Hello"               # メッセージを表示する
        :py vim.command(cmd)            # Ex コマンドを実行する
        :py w = vim.windows[n]          # ウィンドウ "n" を取得する
        :py cw = vim.current.window     # 現在のウィンドウを取得する
        :py b = vim.buffers[n]          # バッファ "n" を取得する
        :py cb = vim.current.buffer     # 現在のバッファを取得する
        :py w.height = lines            # ウィンドウの高さを設定する
        :py w.cursor = (row, col)       # ウィンドウのカーソル位置を設定する
        :py pos = w.cursor              # タプル (row, col) を取得する
        :py name = b.name               # バッファのファイル名を取得する
        :py line = b[n]                 # バッファから 1 行を取得する
        :py lines = b[n:m]              # 行のリストを取得する
        :py num = len(b)                # 行数を取得する
        :py b[n] = str                  # バッファの 1 行を設定する
        :py b[n:m] = [str1, str2, str3] # 複数の行を一度に設定する
        :py del b[n]                    # 1 行を削除する
        :py del b[n:m]                  # 複数の行を削除する


"vim" モジュールのメソッド

vim.command(str)                                        python-command
        vim (ex モード) のコマンド str を実行する。None を返す。
        例:
            :py vim.command("set tw=72")
            :py vim.command("%s/aaa/bbb/g")
        以下の定義はノーマルモードのコマンドを実行する:
                def normal(str):
                        vim.command("normal "+str)
                # ダブルクォートを含む文字列を区切るために
                # シングルクォートを使用していることに注意
                normal('"a2dd"aP')
                                                                E659
        ":python" コマンドは、Python 2.2 以前では再帰的に使用できない。これは
        Python 2.3 以降でのみ動作する:
            :py vim.command("python print 'Hello again Python'")

vim.eval(str)                                           python-eval
        式 str を vim 内部の式評価器 (expression を参照) を使って評価する。
        式の結果を以下のように返す:
        - Vim の式が文字列または数値に評価される場合、文字列
        - Vim の式が Vim の list に評価される場合、リスト
        - Vim の式が Vim の tuple に評価される場合、タプル
        - Vim の式が Vim の dict に評価される場合、辞書
        - Vim の式が v:true または v:false に評価される場合、真偽値
        - Vim の式が v:null または v:none に評価される場合、None
        辞書、リスト、およびタプルは再帰的に展開される。
        例:
            :" 'textwidth' オプションの値
            :py text_width = vim.eval("&tw")
            :
            :" 'a' レジスタの内容
            :py a_reg = vim.eval("@a")
            :
            :" 結果は文字列である! 数値に変換するには string.atoi() を使用する。
            :py str = vim.eval("12+12")
            :
            :py tuple = vim.eval('(1, 2, 3)')
            :
            :py tagList = vim.eval('taglist("eval_expr")')
        後者は python の dict からなる python のリストを返す。例えば:
        [{'cmd': '/^eval_expr(arg, nextcmd)$/', 'static': 0, 'name':
        'eval_expr', 'kind': 'f', 'filename': './src/eval.c'}]

        NOTE: Vim9 script では、def 関数内のローカル変数は python の評価からは
        見えない。ローカル変数を python の評価に渡すには、py3eval() などを呼
        び出す時に {locals} 辞書を使用する。

vim.bindeval(str)                                       python-bindeval
        python-eval と同様だが、python-bindeval-objects で説明されている特
        殊なオブジェクトを返す。これらの python オブジェクトを使うと、vim オブ
        ジェクトを変更 (List、Tuple または Dictionary) するか、または呼
        び出す (Funcref) ことができる。

vim.strwidth(str)                                       python-strwidth
        strwidth() と同様: str が占める表示セルの数を返す。タブは 1 セルとし
        て数えられる。

vim.foreach_rtp(callable)                               python-foreach_rtp
        callable が None 以外の何かを返すか、例外が発生するか、またはパスがな
        くなるまで、'runtimepath' 内の各パスに対して与えられた callable を呼び
        出す。callable が None 以外を返したことで停止した場合、vim.foreach_rtp
        関数は callable が返した値を返す。

vim.chdir(*args, **kwargs)                              python-chdir
vim.fchdir(*args, **kwargs)                             python-fchdir
        os.chdir または os.fchdir を実行し、その後、適切な vim の処理をすべて
        行う。
        Note: これらの関数を直接使用するべきではない。代わりに os.chdir および
              os.fchdir を使用すること。os.fchdir が存在しない場合、vim.fchdir
              の動作は未定義である。

"vim" モジュールのエラーオブジェクト

vim.error                                               python-error
        Vim のエラーに遭遇すると、Python は vim.error 型の例外を発生させる。
        例:
                try:
                        vim.command("put a")
                except vim.error:
                        # レジスタ a に何も無い

"vim" モジュールの定数

        Note これらは実際には定数ではないことに注意 - 再代入することもできる。
        しかし、そうすると変数が参照していた vim オブジェクトへのアクセスを失
        うので、これは愚かなことである。

vim.buffers                                             python-buffers
        vim のバッファのリストへのアクセスを提供するマッピングオブジェクト。こ
        のオブジェクトは以下の操作をサポートしている:
            :py b = vim.buffers[i]      # インデックス参照 (読み込み専用)
            :py b in vim.buffers        # メンバーシップテスト
            :py n = len(vim.buffers)    # 要素の数
            :py for b in vim.buffers:   # バッファリストの反復処理

vim.windows                                             python-windows
        vim のウィンドウのリストへのアクセスを提供するシーケンスオブジェクト。
        このオブジェクトは以下の操作をサポートしている:
            :py w = vim.windows[i]      # インデックス参照 (読み込み専用)
            :py w in vim.windows        # メンバーシップテスト
            :py n = len(vim.windows)    # 要素の数
            :py for w in vim.windows:   # 順次アクセス
        Note: vim.windows オブジェクトは常に現在のタブページにアクセスする。
        python-tabpage.windows オブジェクトは親の python-tabpage オブジェ
        クトに結び付けられ、常にそのタブページのウィンドウを使用する (または、
        タブページが削除された場合は vim.error を投げる)。vim モジュールオブ
        ジェクトまたは python-tabpage への参照を保持せずに、両方への参照を保
        持することができ、この場合でもそれらはプロパティを失わない。

vim.tabpages                                            python-tabpages
        vim のタブページのリストへのアクセスを提供するシーケンスオブジェクト。
        このオブジェクトは以下の操作をサポートしている:
            :py t = vim.tabpages[i]     # インデックス参照 (読み込み専用)
            :py t in vim.tabpages       # メンバーシップテスト
            :py n = len(vim.tabpages)   # 要素の数
            :py for t in vim.tabpages:  # 順次アクセス

vim.current                                             python-current
        vim で使用可能な様々な "現在の" オブジェクトへの (特定の属性を介した)
        アクセスを提供するオブジェクト:
                vim.current.line        現在の行 (RW)           String
                vim.current.buffer      現在のバッファ (RW)     Buffer
                vim.current.window      現在のウィンドウ (RW)   Window
                vim.current.tabpage     現在のタブページ (RW)   TabPage
                vim.current.range       現在の行範囲 (RO)       Range

        最後のケースには少し説明が必要である。:python または :pyfile コマンド
        が範囲を指定すると、この行範囲が "現在の範囲" になる。範囲はバッファに
        少し似ているが、すべてのアクセスが行のサブセットに制限されている。詳細
        は python-range を参照。

        Note: vim.current.{buffer,window,tabpage} に代入する時は、それぞれ有効
        な python-buffer、python-window または python-tabpage オブジェク
        トが期待される。代入すると、指定されたバッファ、ウィンドウまたはタブ
        ページへの通常の (autocommand を伴う) 切り替えが引き起こされる。これ
        は python で UI オブジェクトを切り替える唯一の方法である:
        python-tabpage.window 属性には代入できない。自動コマンドを発生させず
        に切り替えるには以下を使用する
            py << EOF
            saved_eventignore = vim.options['eventignore']
            vim.options['eventignore'] = 'all'
            try:
                vim.current.buffer = vim.buffers[2] # バッファ 2 に切り替える
            finally:
                vim.options['eventignore'] = saved_eventignore
            EOF

vim.vars                                                python-vars
vim.vvars                                               python-vvars
        それぞれグローバル (g:) 変数および vim (v:) 変数の辞書を保持する、

vim.options                                             python-options
        マッピングプロトコルを部分的にサポートし (項目の設定および取得をサポー
        トする)、グローバルオプションへの読み書きアクセスを提供するオブジェク
        ト。
        Note: :set とは異なり、これはグローバルオプションへのアクセスのみを
        提供する。このオブジェクトを使用して、ローカルオプションの値を取得また
        は設定するか、または何らかの方法でローカル専用オプションにアクセスする
        ことはできない。そのような名前のグローバルオプションが存在しない場合、
        KeyError を発生させる (つまり、global-local オプションおよびグローバ
        ル専用オプションに対しては KeyError を発生させないが、ウィンドウローカ
        ルおよびバッファローカルのオプションに対しては発生させる)。バッファロー
        カルオプションにアクセスするには python-buffer オブジェクトを、ウィ
        ンドウローカルオプションにアクセスするには python-window オブジェク
        トを使用する。

        このオブジェクトの型は、vim モジュールの "Options" 属性を介して使用可
        能である。

Python からの出力                                       python-output
        Vim はすべての Python コードの出力を Vim のメッセージ領域に表示する。
        通常の出力は情報メッセージとして表示され、エラー出力はエラーメッセージ
        として表示される。

        実装の観点では、これは sys.stdout へのすべての出力 (print 文からの出力
        を含む) が情報メッセージとして表示され、sys.stderr へのすべての出力
        (エラートレースバックを含む) がエラーメッセージとして表示されることを
        意味する。

                                                        python-input
        入力 (sys.stdin 経由、input() および raw_input() を含む) はサポートさ
        れておらず、プログラムがクラッシュする可能性がある。これはおそらく修正
        されるべきである。

Python 'runtimepath' の処理                             python-special-path

python では、'runtimepath' で見つかったパスのリストの代わりとして
vim.VIM_SPECIAL_PATH 特殊ディレクトリが使用される: このディレクトリが sys.path
に、vim.path_hooks が sys.path_hooks にあると、python は 'runtimepath' で見つ
かった各 {rtp} について、{rtp}/python2 (または python3) および {rtp}/pythonx
(両方の python バージョン用) からモジュールを読み込もうとする (Note:
find_module() は Python 3.12.0a7 頃に imp モジュールから削除された)。

実装は以下に似ているが、C で書かれている:

    from imp import find_module, load_module
    import vim
    import sys

    class VimModuleLoader(object):
        def __init__(self, module):
            self.module = module

        def load_module(self, fullname, path=None):
            return self.module

    def _find_module(fullname, oldtail, path):
        idx = oldtail.find('.')
        if idx > 0:
            name = oldtail[:idx]
            tail = oldtail[idx+1:]
            fmr = find_module(name, path)
            module = load_module(fullname[:-len(oldtail)] + name, *fmr)
            return _find_module(fullname, tail, module.__path__)
        else:
            fmr = find_module(fullname, path)
            return load_module(fullname, *fmr)

    # VimPathFinder クラスの代わりに vim モジュール自体を使用する: python に
    # とっては、どのオブジェクトが find_module 関数を属性として持っているかは
    # 問題ではない。
    class VimPathFinder(object):
        @classmethod
        def find_module(cls, fullname, path=None):
            try:
                return VimModuleLoader(_find_module(fullname, fullname, path or vim._get_paths()))
            except ImportError:
                return None

        @classmethod
        def load_module(cls, fullname, path=None):
            return _find_module(fullname, fullname, path or vim._get_paths())

    def hook(path):
        if path == vim.VIM_SPECIAL_PATH:
            return VimPathFinder
        else:
            raise ImportError

    sys.path_hooks.append(hook)

vim.VIM_SPECIAL_PATH                            python-VIM_SPECIAL_PATH
        vim のパスフックと組み合わせて使用される文字列定数。vim によってインス
        トールされたパスフックが、vim.VIM_SPECIAL_PATH 定数と等しいパス以外の
        ものを処理するよう要求された場合、ImportError を発生させる。それ以外の
        唯一のケースでは、特殊なローダーを使用する。

        Note: この定数の値を直接使用してはならない。常に vim.VIM_SPECIAL_PATH
              オブジェクトを使用すること。

vim.find_module(...)                                    python-find_module
vim.path_hook(path)                                     python-path_hook
vim.find_spec(...)                                      python-find_spec
        上記で説明したパスの読み込みを実装するために使用されるメソッドまたはオ
        ブジェクト。sys.meta_path で何かを行う必要がある場合の vim.path_hook

vim._get_paths                                          python-_get_paths

3. バッファオブジェクト                                 python-buffer

バッファオブジェクトは vim のバッファを表す。これらはいくつかの方法で取得でき
る:
        - vim.current.buffer 経由 (python-current)
        - vim.buffers のインデックス参照から (python-buffers)
        - ウィンドウの "buffer" 属性から (python-window)

バッファオブジェクトには 2 つの読み込み専用属性がある - name - バッファのフル
ファイル名、および number - バッファ番号。また、3 つのメソッド (append、mark、
および range; 以下を参照) も持つ。

バッファオブジェクトはシーケンスオブジェクトとして扱うこともできる。この文脈で
は、それらは各要素がバッファの 1 行である文字列のリスト (そう、これらは変更可
能である) であるかのように振る舞う。インデックス参照、インデックス代入、スライ
ス、およびスライス代入を含む通常のシーケンス操作はすべて、期待どおりに動作す
る。Note バッファのインデックス参照 (スライス) の結果は文字列 (文字列のリスト)
であることに注意。これには 1 つの珍しい帰結がある - b[:] は b とは異なる。特
に、"b[:] = None" はバッファ全体を削除するが、"b = None" は変数 b を更新するだ
けで、バッファには何の影響も無い。

バッファのインデックスは、Python では普通であるように、0 から始まる。これは 1
から始まる vim の行番号とは異なる。これは vim の行番号を使用するマーク (以下を
参照) を扱う時に特に関係がある。

バッファオブジェクトの属性は以下のとおり:
        b.vars          buffer-variable にアクセスするために使用される、辞書
                        に似たオブジェクト。
        b.options       バッファローカルオプションおよび global-local オプ
                        ションのバッファローカル値へのアクセスを提供するマッピ
                        ングオブジェクト (項目の取得、設定および削除をサポート
                        する)。オプションがウィンドウローカルの場合は
                        python-window.options を使用すること。このオブジェク
                        トは KeyError を発生させる。オプションが
                        global-local で、ローカル値が無い場合、それを取得す
                        ると None が返る。
        b.name          文字列、RW。バッファ名 (フルパス) を含む。
                        Note: b.name に代入する時、BufFilePre および
                        BufFilePost 自動コマンドが起動される。
        b.number        バッファ番号。python-buffers のキーとして使用できる。
                        読み込み専用。
        b.valid         True または False。対応するバッファが wipe out される
                        と、バッファオブジェクトは無効になる。

バッファオブジェクトのメソッドは以下のとおり:
        b.append(str)   バッファに 1 行追加する
        b.append(str, nr)  同上、"nr" 行の下に
        b.append(list)  バッファに行のリストを追加する
                        Note 文字列のリストを append メソッドに与えるという選
                        択肢は、Python の組み込みリストオブジェクトの同等のメ
                        ソッドとは異なることに注意。
        b.append(list, nr)  同上、"nr" 行の下に
        b.mark(name)    名前付きマークの位置を表すタプル (row,col) を返す (マー
                        ク []"<> も取得できる)
        b.range(s,e)    指定されたバッファの、行番号 s と e の間 inclusive
                        の部分を表す範囲オブジェクト (python-range を参照)
                        を返す。

Note 行を追加する時、その行に改行文字 '\n' を含めてはならないことに注意。末尾
の '\n' は許可され、無視されるので、以下のようにできる:
        :py b.append(f.readlines())

バッファオブジェクトの型は、vim モジュールの "Buffer" 属性を使用して使用可能で
ある。

例 (b は現在のバッファとする)
        :py print b.name                # バッファのファイル名を書き出す
        :py b[0] = "hello!!!"           # 先頭行を置換する
        :py b[:] = None                 # バッファ全体を削除する
        :py del b[:]                    # バッファ全体を削除する
        :py b[0:0] = [ "a line" ]       # 先頭に 1 行追加する
        :py del b[2]                    # 1 行削除する (3 行目)
        :py b.append("bottom")          # 末尾に 1 行追加する
        :py n = len(b)                  # 行数
        :py (row,col) = b.mark('a')     # 名前付きマーク
        :py r = b.range(1,5)            # バッファの部分範囲
        :py b.vars["foo"] = "bar"       # b:foo 変数に代入する
        :py b.options["ff"] = "dos"     # fileformat を設定する
        :py del b.options["ar"]         # :set autoread< と同じ

        # 範囲内のすべての行をデフォルトのプリンタに送る

5. ウィンドウオブジェクト                               python-window

ウィンドウオブジェクトは vim のウィンドウを表す。これらはいくつかの方法で取得
できる:
        - vim.current.window 経由 (python-current)
        - vim.windows のインデックス参照から (python-windows)

ウィンドウの属性は以下のとおり:

                                これはタプル (row,col) である。
        height (読み書き可能)   行単位のウィンドウの高さ
        width (読み書き可能)    列単位のウィンドウの幅
        vars (読み込み専用)     ウィンドウの w: 変数。属性は代入不可だが、こ
                                の方法でウィンドウ変数を変更できる
        options (読み込み専用)  ウィンドウローカルオプション。属性は代入不可だ
                                が、この方法でウィンドウオプションを変更でき
                                る。ウィンドウローカルオプションへのアクセスの
                                みを提供し、バッファローカルには
                                python-buffer を、グローバルなものには
                                python-options を使用する。オプションが
                                global-local で、ローカル値が無い場合、それ
                                を取得すると None が返る。
        number (読み込み専用)   ウィンドウ番号。最初のウィンドウの番号は 1 で
                                ある。これは、決定できない場合は 0 である (例
                                えば、ウィンドウオブジェクトが他のタブページに
                                属している場合)。
        row, col (読み込み専用) 表示セル単位の画面上のウィンドウ位置。最初の位
                                置は 0 である。
        tabpage (読み込み専用)  ウィンドウのタブページ。
        valid (読み書き可能)    True または False。対応するウィンドウが閉じら
                                れると、ウィンドウオブジェクトは無効になる。

画面が水平分割されている場合にのみ、height 属性は書き込み可能である。画面が垂
直分割されている場合にのみ、width 属性は書き込み可能である。

ウィンドウオブジェクトの型は、vim モジュールの "Window" 属性を使用して使用可能
である。

vim.Dictionary オブジェクト                     python-Dictionary
    vim の Dictionary 型へのアクセスを提供する、辞書に似たオブジェクト。
    属性:

                    値              説明

                    vim.VAR_FIXED   変数はロックされており、ロック解除できない
                   読み書き可能。この属性に True または False を代入するこ

                    ランダムなキーを辞書から削除し、(key, value) のペアを返す。

                    辞書が指定されたキーを含むかどうかを確認する。

                    る。d=vim.Dictionary(arg) は

        for val in d.values():                  # .values()
        for key, val in d.items():              # .items()

        for key in d:                           # キーの反復処理

    vim の Funcref オブジェクトのように振る舞う、関数に似たオブジェクト。特
    殊なキーワード引数 self を受け付ける。Dictionary-function を参照。

    vim.bindeval('function(%s)'%json.dumps(name)) と同じである。

    属性 (読み込み専用):
        属性         説明
        name         関数名。
        args         None または引数を持つ python-List オブジェクト。Note
                     これは引数リストのコピーで、この属性を要求するたびに構築
                     されることに注意。リストに加えられた変更は無視される (た
                     だし、引数リスト内のコンテナへの変更は無視されない: これ
                     は copy() のようなもので、deepcopy() ではない)。
        self         None または self 辞書を持つ python-Dictionary オブジェ
                     クト。Note 結果のオブジェクトを呼び出す時に使用された明示

    例:
        f = vim.Function('tr')                  # コンストラクタ
        print f('abc', 'a', 'b')                # tr('abc', 'a', 'b') を呼び出す

            function DictFun() dict
                return self
            endfunction
        ''')

        print f(self={})                        # call('DictFun', [], {}) と同様
        print isinstance(f, vim.Function)       # True

        p = vim.Function('DictFun', self={})
        print f()
        p = vim.Function('tr', args=['abc', 'a'])
        print f('b')

9. 動的ロード                                           python-dynamic

MS-Windows および Unix では、Python ライブラリを動的にロードできる。その場合、
:version の出力に +python/dyn または +python3/dyn が含まれる。

これは、Vim が Python の DLL または共有ライブラリファイルを必要な時にのみ検索
することを意味する。Python インターフェイスを使用しない場合はそれは不要であり、
したがってこのファイル無しで Vim を使用できる。


MS-Windows

Python インターフェイスを使用するには、Python の DLL が検索パス内に無ければな
らない。コンソールウィンドウで "path" と入力して、どのディレクトリが使用されて
いるかを確認する。DLL が検索パス内に見つからない場合、Vim はレジストリを確認し
て Python がインストールされているパスを探す。'pythondll' または
'pythonthreedll' オプションを使用して Python の DLL を指定することもできる。

DLL の名前は、Vim がコンパイルされた Python のバージョンと一致するべきである。
現在、Python 2 の名前は "python27.dll" で、これは Python 2.7 用である。これは
'pythondll' のデフォルト値である。Python 3 では python36.dll (Python 3.6) であ
る。確実に知るには、"gviai.exe" を編集して "python\d*.dll\c" を検索する。


Unix

'pythondll' または 'pythonthreedll' オプションを使用して、コンパイル時に指定さ
れた DYNAMIC_PYTHON_DLL または DYNAMIC_PYTHON3_DLL ファイルの代わりに Python
の共有ライブラリファイルを指定できる。共有ライブラリのバージョンは、
python3-stable-abi を使用していない限り、Vim がコンパイルされた Python 2.x
または Python 3 のバージョン (v:python3_version) と一致しなければならない。


Stable ABI と Python バージョンの混在
                        python-stable python-stable-abi python3-stable-abi
Vim が Stable ABI (Python 3 でのみ使用可能) 付きでコンパイルされていない場合、
Python の共有ライブラリのバージョンは Vim がコンパイルされたバージョンと一致し
なければならない。そうでない場合、バージョンを混在させると予期しないクラッシュ
および失敗が発生する可能性がある。Stable ABI では、この制限が緩和され、少なく
とも v:python3_version のバージョンを持つ任意の Python 3 ライブラリが動作す
る。Stable ABI がサポートされているかどうかを確認する方法については
has-python を参照するか、またはバージョン出力に +python3/dyn-stable が含ま
れているかどうかを確認する。
MS-Windows では、'pythonthreedll' は "python3.dll" に設定される。レジストリか
ら DLL を検索する時、Vim は最新バージョンの Python を検索する。

Vim は 4 つの方法でビルドできる (:version の出力):
1. Python サポート無し        (-python, -python3)
2. Python 2 サポートのみ      (+python または +python/dyn, -python3)
3. Python 3 サポートのみ      (-python, +python3 または +python3/dyn)
4. Python 2 および 3 サポート (+python/dyn, +python3/dyn)

特殊なケース 4 に関するさらなる詳細:  python-2-and-3

Python 2 および Python 3 の両方がサポートされている場合、それらは動的にロード
されなければならない。

Linux/Unix システムでこれを行い、グローバルシンボルを import すると、2 番目の
Python バージョンが使用された時にクラッシュが発生する。そのため、グローバルシ
ンボルがロードされるが 1 つの Python バージョンのみがアクティブになるか、また
はグローバルシンボルがロードされないかのどちらかである。後者は、シンボルが Vim
によって提供されることを期待するライブラリで、Python の "import" を失敗させる。
                                                        E836 E837
Vim の構成スクリプトは、1 つの標準 Python ライブラリ (termios) に基づいて、す
べてのライブラリについて推測を行う。このライブラリの import が両方の Python
バージョンで成功した場合、両方が同時に Vim で使用可能になる。そうでない場合、
セッションで最初に使用されたバージョンのみが有効になる。
もう一方を使用しようとすると、E836 または E837 エラーメッセージが表示される。

ここで、Vim の動作は、それが構成されたシステムに依存する。両方のバージョンの
Python が --enable-shared 付きで構成されたシステムでは、両方のバージョンの
Python が同時にアクティブになる。libPython にリンクされていない他のサードパー
ティライブラリでは、依然として問題がある。

このような問題を回避するには、これらの選択肢がある:
1. 問題のあるライブラリを、対応する libpython.so にリンクするように再コンパイ
   ルする。
2. Vim を 1 つの Python バージョンのみ用に再コンパイルする。
3. 構成の後に auto/config.h で PY_NO_RTLD_GLOBAL を undefine する。ただし、こ
   れは Vim をクラッシュさせるかもしれない。

                                                        E880
python で SystemExit 例外を発生させるのは vim を終了する推奨された方法ではな
い。以下を使用すること:
        :py vim.command("qall!")

                                                        E1266
このエラーは、Python 3 が必要なモジュールをロードできない時に発生する可能性が
ある。これは、Python 3 が正しくインストールされていないか、または設定に何らか
の誤りがあることを意味する。以下の項目を確認すること:
1. Python 3 が正しくインストールされていることを確認する。python のバージョン
   も確認する。
2. 'pythonthreedll' オプションを確認する。
3. 'pythonthreehome' オプションを確認する。
4. 'pythonthreedll' を設定していない場合は、PATH 環境変数を確認する。
   MS-Windows では、where.exe を使用して、どの dll がロードされるかを確認でき
   る。例:
        where.exe python310.dll
5. PYTHONPATH および PYTHONHOME 環境変数を確認する。

                                                        has-python
どの Python バージョンが使用可能かは、以下でテストできる:
        if has('python')
          echo 'there is Python 2.x'
        endif
        if has('python3')
          echo 'there is Python 3.x'
        endif

Note ただし、Python 2 および 3 の両方が使用可能で動的にロードされる場合、これ
らの has() の呼び出しはそれらをロードしようとすることに注意。一度に 1 つしか
ロードできない場合、Python 2 または 3 が使用可能かどうかを確認するだけで、もう
一方が使用可能でなくなる。

動的ライブラリのロードを避けるには、Vim が python サポート付きでコンパイルされ
たかどうかだけを確認する:
        if has('python_compiled')
          echo 'compiled with Python 2.x support'
          if has('python_dynamic')
            echo 'Python 2.x dynamically loaded'
          endif
        endif
        if has('python3_compiled')
          echo 'compiled with Python 3.x support'
          if has('python3_dynamic')
            echo 'Python 3.x dynamically loaded'
          endif
        endif

ライブラリを動的にロードする時、Vim は Python 3 Stable ABI
(python3-stable-abi) をサポートするようにコンパイルでき、これにより Vim がコ
ンパイルされたものとは異なるバージョンの Python 3 ライブラリをロードできる。そ
れを確認するには:
        if has('python3_dynamic')
          if has('python3_stable')
            echo 'support Python 3 Stable ABI.'
          else
            echo 'does not support Python 3 Stable ABI.'
            echo 'only use Python 3 version ' .. v:python3_version
          endif
        endif

これはまた、Python が動的にロードされるかどうかも示す。ランタイムライブラリが
見つからない場合、それは失敗する。

11. Python X                                            python_x pythonx

ほとんどの python コードは Python 2.6+ および Python 3 で動作するように書くこ
とができるため、pyx* 関数およびコマンドが作られた。これらは Python 2 および 3
の変種とまったく同じように動作するが、'pyxversion' 設定を使用して Python のバー
ジョンを選択する。

Python コマンドで Python 2 または Python 3 を優先するように、.vimrc で
'pyxversion' を設定するべきである。実行時にこの設定を変更すると、プラグインの
状態 (初期化など) が失われる危険がある。

モジュールを使用したい場合は、それを {rtp}/pythonx ディレクトリに置くことがで
きる。pythonx-directory を参照。

                                                        :pyx :pythonx
:pyx および :pythonx コマンドは :python と同様に動作する。:pyx コマン
ドが動作しているかの簡単な確認:
        :pyx print("Hello")

使用されている Python のバージョンを確認するには:
        :pyx import sys
        :pyx print(sys.version)

                                        :pyxfile python_x-special-comments
:pyxfile コマンドは :pyfile と同様に動作する。しかし、これらのコメントのい
ずれかを追加して、Vim に :pyfile または :py3file を使わせることができる:
  #!/any string/python2         " Shebang。ファイルの最初の行でなければならない。
  #!/any string/python3         " Shebang。ファイルの最初の行でなければならない。
  # requires python 2.x         " 最大の行数は 'modelines' に依存する。
  # requires python 3.x         " 最大の行数は 'modelines' に依存する。
通常のモードラインとは異なり、ファイルの末尾はチェックされない。
それらのどれも見つからない場合、'pyxversion' 設定が使用される。
                                                        W20 W21
選択された Python バージョンを Vim がサポートしていない場合、サイレントメッセー
ジが出力される。それらを読むには :messages を使用する。

                                                        :pyxdo
:pyxdo コマンドは :pydo と同様に動作する。

                                                        has-pythonx
pyx* コマンドが使用可能かどうかは、以下でテストできる:
        if has('pythonx')
          echo 'pyx* commands are available. (Python ' .. &pyx .. ')'
        endif

+python または +python3 の一方のみ付きでコンパイルされた場合、has() は 1
を返す。+python および +python3 の両方付きでコンパイルされた場合、テストは
'pyxversion' 設定に依存する。'pyxversion' が 0 の場合、最初に Python 3 をテス
トし、それが使用可能でない場合は Python 2 をテストする。'pyxversion' が 2 また
は 3 の場合、それぞれ Python 2 または 3 のみをテストする。

Note has('pythonx') が動作するために、Python 3 または 2 を動的にロードしよう
とする可能性があることに注意。これは、特に Vim が 2 つのうち 1 つしかロードで
きない場合に、副作用を持つ可能性がある。

ユーザーが Python 2 を好み、Python 3 にフォールバックしたい場合、自分の
.vimrc で 'pyxversion' を明示的に設定する必要がある。例:
        if has('python')
          set pyx=2
        elseif has('python3')
          set pyx=3
        endif
