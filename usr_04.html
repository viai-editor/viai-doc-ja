04.1  オペレータとモーション

第 2 章では、1 文字を削除する "x" コマンドを学びました。そしてカウントを使うと:
"4x" は 4 文字を削除します。
   "dw" コマンドは単語を削除します。"w" コマンドが単語移動コマンドであることに
気付いたかもしれません。実際、"d" コマンドの後には任意のモーションコマンドを続
けることができ、現在の位置からカーソルが最終的に行き着く場所までを削除します。
   例えば、"4w" コマンドはカーソルを 4 単語分移動します。"d4w" コマンドは 4 単
語を削除します。

        To err is human. To really foul up you need a computer.
                         ------------------>
                                 d4w

        To err is human. you need a computer.

Vim は、モーションがカーソルを運ぶ位置までしか削除しません。これは、おそらく単
語の最初の文字は削除したくないだろうということを Vim が知っているからです。単
語の末尾に移動するのに "e" コマンドを使う場合、Vim はその最後の文字を含めたい
のだろうと推測します:

        To err is human. you need a computer.
                        -------->
                           d2e

        To err is human. a computer.

カーソルの下の文字が含まれるかどうかは、その文字に移動するのに使ったコマンドに
よります。リファレンスマニュアルでは、文字が含まれない場合これを "exclusive"
と呼び、含まれる場合 "inclusive" と呼びます。

"$" コマンドは行末に移動します。"d$" コマンドはカーソルから行末までを削除しま
す。これは inclusive なモーションなので、行の最後の文字は削除操作に含まれます:

        To err is human. a computer.
                       ------------>
                            d$

        To err is human

ここにはパターンがあります: オペレータ-モーションです。まずオペレータコマンド
をタイプします。例えば、"d" は削除オペレータです。次に "4l" または "w" のよう
なモーションコマンドをタイプします。この方法で、移動できる任意のテキストを操作
できます。

04.2  テキストを変更する

別のオペレータは "c"、変更です。挿入モードのままになることを除けば、"d" オペ
レータとまったく同じように動作します。例えば、"cw" は単語を変更します。または、
より具体的には、単語を削除してから挿入モードにします。

        To err is human
           ------->
             c2wbe<Esc>

        To be human

この "c2wbe<Esc>" には、これらの部分が含まれます:

        c       変更オペレータ
        2w      2 単語移動する (それらは削除され、挿入モードが開始される)
        be      このテキストを挿入する
        <Esc>   ノーマルモードに戻る

何か奇妙なことに気付いたでしょう: "human" の前の空白が削除されていません。どん
な問題にも、単純、明快、および誤りである答えがある、という格言があります。ここ
で "cw" コマンドに使った例がまさにそれです。c オペレータは d オペレータとまっ
たく同じように動作しますが、1 つ例外があります: "cw" です。これは実際には
"ce"、単語の末尾までの変更、のように動作します。したがって、単語の後の空白は含
まれません。これは古い Vi にさかのぼる例外です。今では多くの人がそれに慣れてい
るので、この不整合は Vim に残されています。


さらなる変更

"dd" が行全体を削除するように、"cc" は行全体を変更します。ただし、既存のインデ
ント (行頭の空白) は保持します。

"d$" が行末までを削除するのとまったく同じように、"c$" は行末までを変更します。
これは、"d$" でテキストを削除し、それから "a" で挿入モードを開始して新しいテキ
ストを追加するようなものです。


ショートカット

いくつかのオペレータ-モーションコマンドは非常によく使われるので、1 文字のコマ
ンドが与えられています:

        x  は  dl  を表す  (カーソルの下の文字を削除する)
        X  は  dh  を表す  (カーソルの左の文字を削除する)
        D  は  d$  を表す  (行末まで削除する)
        C  は  c$  を表す  (行末まで変更する)
        s  は  cl  を表す  (1 文字を変更する)
        S  は  cc  を表す  (行全体を変更する)


カウントをどこに置くか

コマンド "3dw" および "d3w" は 3 単語を削除します。本当に細かいことにこだわり
たい場合、最初のコマンド "3dw" は 1 単語を 3 回削除します; コマンド "d3w" は 3
単語を 1 回削除します。これは区別のない違いです。しかし、実際には 2 つのカウン
トを入れることもできます。例えば、"3d2w" は 2 単語を削除し、それを 3 回繰り返
して、合計 6 単語を削除します。


1 文字で置換する

"r" コマンドはオペレータではありません。文字をタイプするのを待ち、カーソルの下
の文字をそれで置き換えます。"cl" で、または "s" コマンドで同じことができます
が、"r" では挿入モードから抜け出すために <Esc> を押す必要がありません。

        there is somerhing grong here
        rT           rt    rw

        There is something wrong here

"r" にカウントを使うと、その数の文字が同じ文字で置き換えられます。例:

        There is something wrong here
                           5rx

        There is something xxxxx here

文字を改行で置き換えるには "r<Enter>" を使います。これは 1 文字を削除し、改行
を挿入します。ここでカウントを使うと、削除される文字の数にだけ適用されます:
"4r<Enter>" は 4 文字を 1 つの改行で置き換えます。

04.3  変更を繰り返す

"." コマンドは、Vim で最も単純でありながら強力なコマンドの 1 つです。これは最
後の変更を繰り返します。例えば、HTML ファイルを編集していて、すべての <B> タグ
を削除したいとします。カーソルを最初の < に置き、コマンド "df>" で <B> を削除
します。それから次の </B> の < に行き、"." コマンドを使ってそれを削除しま
す。"." コマンドは最後の変更コマンド (この場合は "df>") を実行します。別のタグ
を削除するには、カーソルを < に置いて "." コマンドを使います。

                              To <B>generate</B> a table of <B>contents
        f<   最初の < を探す  --->
        df>  > まで削除する      -->
        f<   次の < を探す         --------->
        .    df> を繰り返す                 --->
        f<   次の < を探す                     ------------->
        .    df> を繰り返す                                 -->

"." コマンドは、"u" (undo)、CTRL-R (redo)、およびコロン (:) で始まるコマンドを
除き、行うすべての変更に対して機能します。

別の例: 単語 "four" を "five" に変更したいです。それはあなたのテキスト中に何回
か現れます。この一連のコマンドでこれを素早く行えます:

        /four<Enter>    最初の文字列 "four" を探す
        cwfive<Esc>     単語を "five" に変更する
        n               次の "four" を探す
        .               "five" への変更を繰り返す
        n               次の "four" を探す
        .               変更を繰り返す
                        など

04.4  ビジュアルモード

単純な項目を削除するには、オペレータ-モーションの変更がかなりうまく機能します。
しかし、変更したいテキストの上をどのコマンドで移動するかを決めるのは、それほど
簡単ではないことがよくあります。そのときは、ビジュアルモードを使えます。

"v" を押してビジュアルモードを開始します。作業したいテキストの上でカーソルを移
動します。これをしている間、テキストはハイライトされます。最後にオペレータコマ
ンドをタイプします。
   例えば、ある単語の途中から別の単語の途中までを削除するには:

                This is an examination sample of visual mode
                               ---------->
                                 velllld

                This is an example of visual mode

これを行うとき、正しい位置に着くまで "l" を何回押す必要があるかを実際に数える
必要はありません。"d" を押したときにどのテキストが削除されるかをすぐに見ること
ができます。

いつでも、ハイライトされたテキストに対して何もしたくないと決めた場合、<Esc> を
押すだけで、ビジュアルモードは何もせずに終了します。


行を選択する

行全体に対して作業したい場合、"V" を使ってビジュアルモードを開始します。あちこ
ち移動しなくても、行全体がハイライトされているのがすぐに分かるでしょう。左また
は右に移動しても何も変わりません。上または下に移動すると、選択範囲は一度に行全
体ずつ拡張されます。
   例えば、"Vjj" で 3 行を選択します:

                          +------------------------+
                          | text more text         |
                       >> | more text more text    | |
          選択された行 >> | text text text         | | Vjj
                       >> | text more              | V
                          | more text more         |
                          +------------------------+


ブロックを選択する

文字の矩形ブロックに対して作業したい場合、CTRL-V を使ってビジュアルモードを開
始します。これは表に対して作業するときにとても便利です。

                name            Q1      Q2      Q3
                pierre          123     455     234
                john            0       90      39
                steve           392     63      334

真ん中の "Q2" の列を削除するには、カーソルを "Q2" の "Q" に移動します。CTRL-V
を押して矩形ビジュアルモードを開始します。そして "3j" でカーソルを 3 行下に、
"w" で次の単語に移動します。最後の列の最初の文字が含まれているのが分かります。
それを除外するには "h" を使います。そして "d" を押すと、真ん中の列が消えます。


反対側へ行く

ビジュアルモードでテキストを選択していて、選択範囲のもう一方の端を変更する必要
があることに気付いた場合、"o" コマンドを使います (ヒント: other end の o)。カー
ソルはもう一方の端に移動し、カーソルを移動して選択範囲の開始位置を変更できま
す。"o" をもう一度押すと、もう一方の端に戻ります。

矩形選択を使っているときは、4 つの角があります。"o" は、他の角のうちの 1 つへ、
対角線上にだけ移動します。同じ行のもう一方の角に移動するには "O" を使います。

Note ビジュアルモードでの "o" および "O" は、カーソルの下または上に新しい行を
開くノーマルモードとは非常に異なる動作をすることに注意してください。

04.5  テキストを移動する

"d"、"x"、または別のコマンドで何かを削除すると、そのテキストは保存されます。
"p" コマンドを使ってそれを貼り付けて戻すことができます。(これの Vim での名前は
put です)。
   これがどのように機能するかを見てみましょう。まず、削除したい行にカーソルを
置いて "dd" とタイプすることで、行全体を削除します。次に、その行をプットしたい
場所にカーソルを移動し、"p" (put) コマンドを使います。行はカーソルの下の行に挿
入されます。

        a line          a line        a line
        line 2    dd    line 3    p   line 3
        line 3                        line 2

行全体を削除したので、"p" コマンドはテキスト行をカーソルの下に置きました。行の
一部 (例えば単語) を削除した場合、"p" コマンドはそれをカーソルの直後に置きま
す。

        Some more boring try text to out commands.
                         ---->
                          dw

        Some more boring text to out commands.
                         ------->
                            welp

        Some more boring text to try out commands.


プットについてさらに

"P" コマンドは "p" と同様にテキストをプットしますが、カーソルの前に置きます。
"dd" で行全体を削除したときは、"P" はそれをカーソルの上に戻します。"dw" で単語
を削除したときは、"P" はそれをカーソルの直前に戻します。

プットは好きなだけ何回でも繰り返すことができます。同じテキストが使われます。

"p" および "P" にはカウントを使うことができます。テキストはカウントで指定され
た回数だけ繰り返されます。したがって、"dd" の後に "3p" とすると、削除した同じ
行の 3 つのコピーがプットされます。


2 文字を入れ替える

タイプしているときに、あなたの指があなたの脳より先に進んでしまうことがよくあり
ます (またはその逆?)。その結果、"the" の代わりの "teh" のようなタイプミスが生
じます。Vim ではこのような問題を簡単に修正できます。"teh" の e にカーソルを置
いて、コマンド "xp" を実行するだけです。これは次のように機能します: "x" は文字
e を削除し、それをレジスタに入れます。"p" はテキストをカーソルの後、つまり h
の後にプットします。

        teh     th     the
         x       p

04.6  テキストをコピーする

テキストをある場所から別の場所にコピーするには、それを削除し、"u" で削除を
undo し、それから "p" でどこか別の場所にプットすることもできます。もっと簡単な
方法があります: ヤンクです。"y" オペレータはテキストをレジスタにコピーします。
それから "p" コマンドを使ってそれをプットできます。
   ヤンクは、コピーに対する Vim での名前にすぎません。"c" の文字はすでに変更オ
ペレータに使われていて、"y" はまだ使用可能でした。このオペレータを "yank" と呼
ぶことで、"y" キーを使うことを覚えやすくなりました。

"y" はオペレータなので、単語をヤンクするには "yw" を使います。通常どおりカウン
トが使えます。2 単語をヤンクするには "y2w" を使います。例:

        let sqr = LongVariable *
                 -------------->
                       y2w

        let sqr = LongVariable *
                               p

        let sqr = LongVariable * LongVariable

"yw" は単語の後の空白を含むことに注意してください。これを望まない場合、"ye" を
使います。

"dd" が行全体を削除するのとまったく同じように、"yy" コマンドは行全体をヤンクし
ます。意外なことに、"D" はカーソルから行末までを削除しますが、"Y" は "yy" のよ
うに動作し、行全体をヤンクします。この不整合に注意してください! 行末までヤンク
するには "y$" を使います。

        a text line   yy        a text line            a text line
        line 2                  line 2          p      line 2
        last line               last line              a text line
                                                       last line

04.7  クリップボードを使う

GUI 版の Vim (gvim) を使っている場合、"Edit" メニューに "Copy" 項目があります。
まずビジュアルモードでテキストを選択し、それから Edit/Copy メニュー項目を使い
ます。これで選択したテキストがクリップボードにコピーされます。そのテキストを他
のプログラムに貼り付けることができます。Vim 自体でも。

別のアプリケーションでテキストをクリップボードにコピーした場合、Edit/Paste メ
ニュー項目でそれを Vim に貼り付けることができます。これはノーマルモードおよび
挿入モードで機能します。ビジュアルモードでは、選択されたテキストが貼り付けられ
たテキストで置き換えられます。

"Cut" メニュー項目は、テキストをクリップボードに置く前にそのテキストを削除しま
す。"Copy"、"Cut"、および "Paste" 項目は、ポップアップメニューでも使用可能です
(もちろん、ポップアップメニューがある場合だけです)。あなたの Vim にツールバー
がある場合、そこでもこれらの項目を見つけることができます。

GUI を使っていない場合、またはメニューを使うのが好きでない場合、別の方法を使う
必要があります。通常の "y" (yank) および "p" (put) コマンドを使いますが、その
前に "* (ダブルクォートスター) を付けます。行をクリップボードにコピーするには:


        "*yy

クリップボードからテキストをテキスト内にプットして戻すには:

        "*p

これはクリップボードサポートを含む Vim のバージョンでだけ機能します。クリップ
ボードについての詳細は、セクション 09.3 およびここにあります: clipboard。

04.8  テキストオブジェクト

カーソルが単語の途中にあって、その単語を削除したい場合、"dw" を行う前にその単
語の先頭に戻る必要があります。これを行うもっと簡単な方法があります: "daw"。

        this is some example text.
                       daw

        this is some text.

"daw" の "d" は削除オペレータです。"aw" はテキストオブジェクトです。ヒント:
"aw" は "A Word" を表します。したがって、"daw" は "Delete A Word" です。正確に
言うと、単語の後の空白も削除されます (または、行末にある場合は単語の前の空白)。

テキストオブジェクトを使うのは、Vim で変更を行う 3 つ目の方法です。すでにオペ
レータ-モーションおよびビジュアルモードがありました。ここでオペレータ-テキスト
オブジェクトを加えます。
   これはオペレータ-モーションと非常に似ていますが、移動コマンドの前と後のカー
ソル位置の間のテキストを操作する代わりに、テキストオブジェクトが全体として使わ
れます。オブジェクト内のどこにカーソルがあったかは関係ありません。

文全体を変更するには "cis" を使います。このテキストを取り上げます:

        Hello there.  This
        is an example.  Just
        some text.

2 行目の先頭、"is an" の上に移動します。そして "cis" を使います:

        Hello there.    Just
        some text.

カーソルは 1 行目の空白の間にあります。ここで新しい文 "Another line." をタイプ
します:

        Hello there.  Another line.  Just
        some text.

"cis" は、"c" (change) オペレータおよび "is" テキストオブジェクトから成ります。
これは "Inner Sentence" を表します。"as" ("A Sentence") オブジェクトもありま
す。違いは、"as" は文の後の空白を含み、"is" は含まないことです。文を削除する場
合、同時に空白も削除したいので、"das" を使います。新しいテキストをタイプしたい
場合、空白は残しておけるので、"cis" を使います。

テキストオブジェクトはビジュアルモードでも使えます。それはテキストオブジェクト
をビジュアル選択に含めます。ビジュアルモードは続くので、これを何回か行うことが
できます。例えば、"v" でビジュアルモードを開始し、"as" で文を選択します。ここ
で "as" を繰り返して、さらに多くの文を含めることができます。最後に、オペレータ
を使って選択された文に対して何かを行います。

テキストオブジェクトの長い一覧はここにあります: text-objects。

04.9  置換モード

"R" コマンドは Vim を置換モードにします。このモードでは、タイプした各文字がカー
ソルの下の文字を置き換えます。これは <Esc> をタイプするまで続きます。
   この例では、"text" の最初の "t" で置換モードを開始します:

        This is text.
                Rinteresting.<Esc>

        This is interesting.

このコマンドが行内の 5 文字を他の 12 文字で置き換えたことに気付いたかもしれま
せん。"R" コマンドは、置き換える文字がなくなると自動的に行を延長します。次の行
に続けることはしません。

<Insert> キーで、挿入モードと置換モードの間を切り替えることができます。

修正するために <BS> (バックスペース) を使うと、古いテキストが戻されることに気
付くでしょう。したがって、それは直前にタイプした文字に対する undo コマンドのよ
うに機能します。

04.10 結論

オペレータ、移動コマンド、およびテキストオブジェクトによって、多くの組み合わせ
を作ることが可能になります。それらがどのように機能するかを知った今、N 個のオペ
レータを M 個の移動コマンドと共に使って N * M 個のコマンドを作ることができます!

オペレータの一覧はここにあります: operator。

例えば、テキストの一部を削除する方法は他にもたくさんあります。ここにいくつかの
一般的なものがあります:

x       カーソルの下の文字を削除する ("dl" の短縮形)
X       カーソルの前の文字を削除する ("dh" の短縮形)
D       カーソルから行末までを削除する ("d$" の短縮形)
dw      カーソルから次の単語の先頭までを削除する
db      カーソルから前の単語の先頭までを削除する
diw     カーソルの下の単語を削除する (空白を除く)
daw     カーソルの下の単語を削除する (空白を含む)
dG      ファイルの末尾までを削除する
dgg     ファイルの先頭までを削除する

"d" の代わりに "c" を使うと、それらは変更コマンドになります。そして "y" ではテ
キストをヤンクします。以下同様です。


変更を行うための一般的なコマンドで、他のどこにも当てはまらなかったものがいくつ
かあります:

        ~       カーソルの下の文字の大文字小文字を変更し、カーソルを次の文字に
                移動する。これはオペレータではない ('tildeop' が設定されている
                場合を除く) ので、モーションコマンドと共に使うことはできない。
                ビジュアルモードでは機能し、そこでは選択されたすべてのテキスト
                の大文字小文字を変更する。

        I       カーソルを行の最初の非空白文字に移動した後で、挿入モードを開始
                する。

        A       カーソルを行末に移動した後で、挿入モードを開始する。
