                                                        Haiku

られていない事柄については、Vim は Unix の os_unix.txt 版と非常によく似た動
作をする。

Haiku は BeOS に触発されたオープンソースのオペレーティングシステムで、特にパー
ソナルコンピューティングを対象としている。

1. 全般                                                 haiku-general

デフォルトの構文ハイライトは、主に異なる前景色を使ってアイテムをハイライトする
ことで機能する。これは、Terminal ウィンドウを暗めの背景および明るい文字に設定
すると最もよく機能する。黒い文字の中間的なグレーの背景 (例えば
(r,g,b)=(168,168,168)) もうまく機能する。


2. Vim のコンパイル                                     haiku-compiling

Vim は標準の configure/make の方法でコンパイルできる。./configure を引数なしで
実行するか、または --enable-gui=haiku を渡すと、Haiku GUI サポート付きの vim
がコンパイルされる。他に有効/無効にできる機能を調べるには、./configure --help
を実行すること。

Haiku は端末ライブラリとして "ncurses6" を使っているので、Haiku ビルドを
configure するには、HaikuDepot から "ncurses6_devel" パッケージをインストール
しておく必要がある。./configure コマンドに "--with-tlib=ncurses" を追加するだ
けでよい。

ここで "make" を使って Vim をコンパイルし、それから "make install" を使ってイ
ンストールすること。Haiku にシームレスに統合するには、GUI なしの vim バイナリ
を GUI 版の上に追加でインストールするべきである。典型的なビルドコマンドは以下
である:

  ./configure --prefix=finddir B_SYSTEM_NONPACKAGED_DIRECTORY \
    --datarootdir=finddir B_SYSTEM_NONPACKAGED_DATA_DIRECTORY \
    --mandir=finddir B_SYSTEM_NONPACKAGED_DIRECTORY/documentation/man \
    --with-tlib=ncurses
  make clean
  make install

  ./configure --prefix=finddir B_SYSTEM_NONPACKAGED_DIRECTORY  \
    --datarootdir=finddir B_SYSTEM_NONPACKAGED_DATA_DIRECTORY \
    --mandir=finddir B_SYSTEM_NONPACKAGED_DIRECTORY/documentation/man \
    --with-tlib=ncurses \
    --disable-gui
  make clean
  make install


3. Haiku GUI                                            haiku-gui

通常、Vim は gvim または vim -g として起動すると GUI で起動する。GUI 付きの
vim 版は、Terminal ではなく Tracker から起動されたかどうかを判定しようとし、そ
うであれば、いずれにしても GUI を使う。しかし、コマンド "vim - </dev/null" を
使うと、現在の判定方式はだまされる。

通常の管理されたウィンドウとフルスクリーンモードの間の切り替えは、<Alt-Enter>
を押すことでできる。

まだ動作しないもの:

- マウスのアップイベントは、ウィンドウの外では生成されない。テキストを選択して
  カーソルをウィンドウの外に移動し、それからマウスボタンを離すと、これに気付く
  ことができる。もう 1 つは、スクロールバーをドラッグして同じことをする時であ
  る。Vim はまだ、あなたがまだスクロールバーを操作していると考えているので、
  Vim 自身はそれを変更しない。ウィンドウがアクティブまたは非アクティブになった
  時に働く回避策がある (そのため、focus-follows-mouse をオンにすると最もよく機
  能する)。
- カーソルは点滅しない。
- Twitcher で <C-Tab-Up> および <C-Tab-Down> を使ってウィンドウを切り替えるこ
  とはできない。これは、各 gvim ウィンドウが、他の vim プロセスをまったく認識
  しない別々のインスタンスによって管理されているためである。

4. $VIM ディレクトリ                                    haiku-vimdir

$VIM は、Vim のサポートファイルが格納されている場所を表すシンボル名である。
$VIM のデフォルト値はコンパイル時に設定され、これで調べられる:

  :version

通常の値は、Haikuports 版では /boot/system/data/vim、手動ビルドでは
/boot/system/non-packaged/data/vim である。これが気に入らない場合は、VIM 環境
変数を設定してこれを上書きするか、または .vimrc で 'helpfile' を設定できる:

  :if version >= 500
  :    set helpfile=~/vim/runtime/doc/help.txt
  :    syntax on
  :endif


5. $USER_SETTINGS_DIR ディレクトリ              haiku-user-settings-dir

$USER_SETTINGS_DIR は、Haiku の構成ファイルおよび設定ファイルが格納されている
場所を表すシンボル名である。

通常の値は /boot/home/config/settings である。


6. ドラッグ&ドロップ                                    haiku-dragndrop

ファイルおよびディレクトリは、Vim アイコン (File Types アプリケーションを使っ
て Vim を "Single Launch" に設定していなければ、新しい Vim セッションを開始す
る) または Vim ウィンドウ (ファイルの編集を開始する) のどちらかにドロップでき
る。フォルダをドロップすると、Vim のカレントワーキングディレクトリを設定する
:cd :pwd。どちらかの SHIFT キーを押しながらファイルまたはフォルダをドロッ
プすると、Vim は最初にドロップされたアイテムを含むフォルダにディレクトリを変更
する。Vim を起動する時は、shift を押す必要はない: Vim は押したかのように動作す
る。

ドロップされたファイルは、現在の引数リストを設定する。argument-list


7. Single Launch 対 Multiple Launch                     haiku-launch

配布時の状態では Vim のアプリケーションフラグ (FileTypes 設定で見られる) は
Multiple Launch に設定されている。望むなら、代わりに Single Launch に設定でき
る。2 つ目の Vim のコピーを起動しようとすると、代わりに最初の Vim がファイルを
開くようになる。これは Tracker からだけでなく、コマンドラインからも動作する。
後者の場合、ファイル以外の (オプション) 引数はサポートされない。Single Launch
のもう 1 つの欠点は、GUI サポートがコンパイルで組み込まれていても非 GUI アプリ
ケーションとして動作している vim インスタンスによる "Open With ..." 要求の無言
の無視である。GUI 付きで動作している Vim インスタンスには、そのような問題はな
い。

NB: GUI 版だけが BApplication を持つ (したがってアプリケーションフラグも持つ)。
この節は、GUI なし版をコンパイルしたとしても、その版には当てはまらない。


8. フォント                                             haiku-fonts

フォントはこれで設定する

  :set guifont=DejaVu_Sans_Mono/Book/12

ここで、最初の部分はフォントファミリー、2 番目の部分はスタイル、3 番目の部分は
サイズである。ファミリーおよびスタイルでは、空白の代わりにアンダースコアを使え
る。

最良の結果は等幅フォントで得られる。Vim はすべてのフォントを B_FIXED_SPACING
モードで使おうとするが、どうやらこれはプロポーショナルフォントでは動作しない
(BeBook の記述にもかかわらず)。

現在のフォントでどのエンコーディングがサポートされているかを確かめるには

  :digraphs

コマンドを与えること。これはたくさんの文字を、それらの ISO Latin 1 エンコーディ
ングとともに一覧表示する。例えば、それらの中に "box" 文字がある場合、または最
後の文字がドット付きの y でない場合、このフォントではエンコーディングが動作し
ない。

指定したフォントが利用できない場合、システムの固定フォントが得られる。

GUI フォント選択ダイアログは、この:

  :set guifont=*

コマンドを与えると利用できる。


9. meta キー修飾子                                      haiku-meta

META キー修飾子は、左または右の OPTION キーで得られる。これは、ALT (別名
COMMAND) キーがアプリケーションに渡されないためである。


10. マウスキーマッピング                                haiku-mouse

Vim は、さまざまなマウスボタンを LeftMouse、MiddleMouse、および RightMouse と
呼ぶ。デフォルトの Mouse 設定を使っている場合、これらの名前は実際に現実と一致
する。Vim はこのマッピングを使う:

    Button 1 -> LeftMouse,
    Button 2 -> RightMouse,
    Button 3 -> MiddleMouse.

マウスのボタンが 3 つより少ない場合は、修飾キー付きのマウスクリックから他のマ
ウスボタンへの独自のマッピングを用意できる。例は $VIM/macros/swapmous.vim ファ
イルを参照。                                            gui-mouse-mapping


11. 色名                                                haiku-colors

Vim には多数の色名が組み込まれている。追加の名前は v:colornames で定義でき
る。詳細は :colorscheme を参照。


12. GUI ツールバー画像                                  haiku-toolbar-images

ツールバー画像の代替セットは、好きな高さの PNG 画像であるべきである。画像の幅
は、1 行のセルに少なくとも 32 個のボタンを含むように計算される。
画像は $VIRUNTIME/bitmaps/builtin-tools.png という名前で格納するべきである
ボタンの割り当てについての詳しい情報は builtin-tools にある。
