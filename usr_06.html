                          構文ハイライトを使う


白黒のテキストは退屈です。色があるとファイルが生き生きとします。これは見た目が
よいだけでなく、作業もはかどります。いろいろな種類のテキストに使われる色を変え
ましょう。画面で見ている色で、テキストを印刷しましょう。

06.1  有効にする

すべては 1 つの簡単なコマンドから始まります:

        :syntax enable

たいていの状況では、これでファイルに色が付くはずです。Vim は魔法のように自動で
ファイルの種類を検出し、適切な構文ハイライトを読み込みます。突然、コメントは青
になり、キーワードは茶色に、文字列は赤になります。これでファイルを見渡しやすく
なります。しばらくすると、白黒のテキストでは作業が遅くなることに気付くでしょう!

常に構文ハイライトを使いたい場合は、":syntax enable" コマンドを vimrc ファイ
ルに書いてください。

端末が色をサポートしている時だけ構文ハイライトを使いたい場合は、これを vimrc
ファイルに書けます:

        if &t_Co > 1
           syntax enable
        endif

GUI 版でだけ構文ハイライトを使いたい場合は、":syntax enable" コマンドを
gvimrc ファイルに書いてください。

06.2  色が付かない、または色が間違っている?

色が見えない理由はいくつか考えられます:

- 端末が色をサポートしていない。
        Vim は太字、イタリック、および下線付きのテキストを使うが、これはあまり
        見栄えがよくない。おそらく、色が使える端末を手に入れようとしたくなるだ
        ろう。Unix では、XFree86 プロジェクトの xterm をお勧めする:
        xfree-xterm。

- 端末は色をサポートしているが、Vim がそれを知らない。
        $TERM の設定が正しいことを確かめること。例えば、色をサポートしている
        xterm を使っている場合:

                setenv TERM xterm-color

        または (シェルによっては):

                TERM=xterm-color; export TERM

        端末名は、使っている端末と一致していなければならない。それでもまだうま
        くいかない場合は、xterm-color を見ること。そこには、Vim に色を表示さ
        せる方法がいくつか示されている (xterm 用だけではない)。

- ファイルタイプが認識されない。
        Vim はすべてのファイルタイプを知っているわけではなく、ときには、ファイ
        ルがどの言語を使っているかを見分けるのがほとんど不可能なこともある。こ
        のコマンドを試すこと:

                :set filetype

        結果が "filetype=" の場合、問題は確かに、これがどの種類のファイルなの
        かを Vim が知らないことにある。種類は手動で設定できる:

                :set filetype=fortran

        どの種類が利用できるかを見るには、$VIMRUNTIME/syntax ディレクトリの中
        を見ること。GUI では Syntax メニューを使える。
        ファイルタイプの設定は modeline でも行え、そうすれば編集するたびに
        ファイルがハイライトされる。例えば、この行は Makefile で使える (ファイ
        ルの最初または最後の近くに置くこと):

                # vim: syntax=make

        ファイルタイプを自分で検出する方法を知っているかもしれない。多くの場
        合、ファイル名の拡張子 (ドットの後ろ) が使える。
        そのファイルタイプを検出するように Vim に指示する方法は new-filetype
        を参照。

- ファイルタイプに対するハイライトがない。
        上で述べたように手動で設定することで、似たファイルタイプを使ってみるこ
        とができる。それで十分でない場合は、独自の構文ファイルを書くことができ
        る。mysyntaxfile を参照。


または、色が間違っているかもしれません:

- 色付きのテキストがとても読みにくい。
        Vim は使っている背景色を推測する。それが黒 (または他の暗い色) の場合、
        テキストに明るい色を使う。それが白 (または他の明るい色) の場合、テキス
        トに暗い色を使う。Vim の推測が間違っていると、テキストは読みにくくな
        る。これを解決するには、'background' オプションを設定すること。暗い背
        景の場合:

                :set background=dark

        そして明るい背景の場合:

                :set background=light

        これを ":syntax enable" コマンドの _前に_ 置くようにすること。そうしな
        いと、色はすでに設定されてしまっている。'background' を設定した後で
        ":syntax reset" を実行して、Vim にデフォルトの色を再び設定させることも
        できる。

- 下から上へスクロールすると色が間違っている。
        Vim はテキストを解析するためにファイル全体を読むわけではない。ファイル
        を表示している場所から解析を始める。これで多くの時間が節約されるが、と
        きどき色が間違う。簡単な修正方法は CTRL-L を押すことである。または、少
        し後ろにスクロールしてから、再び前に進む。
        本当に修正するには、:syn-sync を参照。構文ファイルによっては、さらに
        後ろを見させる方法があるので、その構文ファイルのヘルプを参照。例えば、
        TeX 構文の場合は tex.vim。

06.3  違う色                                          :syn-default-override

デフォルトの色が気に入らない場合は、別のカラースキームを選べます。GUI では
Edit/Color Scheme メニューを使います。コマンドを入力することもできます:

        :colorscheme evening

"evening" はカラースキームの名前です。他にも試してみたくなるものがいくつかあり
ます。$VIMRUNTIME/colors ディレクトリの中を見てください。

気に入ったカラースキームが見つかったら、":colorscheme" コマンドを vimrc ファ
イルに追加してください。

独自のカラースキームを書くこともできます。そのやり方はこうです:

1. 近いカラースキームを選びます。このファイルを自分の Vim ディレクトリにコピー
   します。Unix では、これでうまくいくはずです:

        !mkdir ~/.vim/colors
        !cp $VIMRUNTIME/colors/morning.vim ~/.vim/colors/mine.vim

   $VIMRUNTIME の値を知っているので、これは Vim から行います。

2. カラースキームファイルを編集します。これらの項目が便利です:

        term            白黒端末での属性
        cterm           カラー端末での属性
        ctermfg         カラー端末での前景色
        ctermbg         カラー端末での背景色
        gui             GUI での属性
        guifg           GUI での前景色
        guibg           GUI での背景色

   例えば、コメントを緑にするには:

        :highlight Comment ctermfg=green guifg=green

   "cterm" および "gui" に使える属性は "bold" および "underline" です。両方を
   使いたい場合は、"bold,underline" を使います。詳細は :highlight コマンドを
   参照してください。

3. 常に自分のカラースキームを使うように Vim に指示します。この行を vimrc に
   書きます:

        colorscheme mine

最もよく使われる色の組み合わせがどのように見えるかを見たい場合は、このコマンド
を使います:

        :runtime syntax/colortest.vim

さまざまな色の組み合わせでテキストが表示されます。どれが読みやすく、見た目がよ
いかを確認できます。ただし、利用できる色はこれらだけではありません。#rrggbb の
16 進数の色を指定でき、v:colornames で 16 進数の色に対する新しい名前をこのよ
うに定義できます:

        let v:colornames['mine_red'] = '#aa0000'

他の人が使うカラースキームを作成している場合は、これらの色を、まだ存在しない時
にだけ定義することが重要です:

        call extend(v:colornames, {'mine_red': '#aa0000'}, 'keep')

これにより、カラースキームのユーザーは、あなたのカラースキームを読み込む前に、
その色の正確な定義を上書きできます。例えば、.vimrc ファイルで:

        runtime colors/lists/css_colors.vim
        let v:colornames['your_red'] = v:colornames['css_red']
        colorscheme yourscheme

カラースキームの作者として、GUI の色についてはいくつかの色名を当てにできるべき
です。これらは colors/lists/default.vim で定義されています。'runtimepath' 上
で見つかったそのようなファイルはすべて、colorscheme コマンドが実行されるたびに
読み込まれます。正規のリストは vim の配布物で提供されており、それにはすべての
X11 の色 (以前は rgb.txt で定義されていた) が含まれているはずです。

06.4  色付き、または色なし

テキストを色付きで表示するには多くの労力がかかります。表示が遅すぎると感じた
ら、構文ハイライトを一時的に無効にするとよいでしょう:

        :syntax clear

別のファイル (または同じファイル) を編集すると、色は戻ってきます。

ハイライトを完全に止めたい場合は、これを使います:

        :syntax off

これは構文ハイライトを完全に無効にし、すべてのバッファから直ちに取り除きます。
詳細は :syntax-off を参照してください。

                                                        :syn-manual
特定のファイルだけで構文ハイライトを使いたい場合は、これを使います:

        :syntax manual

これは構文ハイライトを有効にしますが、バッファの編集を始めた時に自動的にオンに
はしません。カレントバッファでハイライトをオンにするには、'syntax' オプション
を設定します:

        :set syntax=ON

06.5  色付きで印刷する                                syntax-printing

MS-Windows 版では、このコマンドで現在のファイルを印刷できます:

        :hardcopy

通常のプリンターダイアログが表示され、そこでプリンターおよびいくつかの設定を選
択できます。カラープリンターがあれば、紙への出力は Vim の中で見ているものと同
じように見えるはずです。ただし、暗い背景を使っている場合は、白い紙の上でよく見
えるように色が調整されます。

Vim の印刷方法を変更するオプションがいくつかあります:
        'printdevice'
        'printheader'
        'printfont'
        'printoptions'

行の範囲だけを印刷するには、ビジュアルモードを使って行を選択してから、このコマ
ンドを入力します:

        v100j:hardcopy

"v" はビジュアルモードを開始します。"100j" は 100 行下に移動し、それらの行がハ
イライトされます。それから ":hardcopy" がそれらの行を印刷します。もちろん、ビ
ジュアルモードで移動するために他のコマンドも使えます。

これは、PostScript プリンターがあれば Unix でも動作します。そうでない場合は、
もう少し作業が必要です。まずテキストを HTML に変換し、それから Web ブラウザー
から印刷する必要があります。

このコマンドで現在のファイルを HTML に変換します:

        :TOhtml

それがうまくいかない場合は:

        :source $VIMRUNTIME/syntax/2html.vim

せっせと処理しているのが見えますが、大きなファイルではかなり時間がかかることが
あります。しばらくすると、別のウィンドウに HTML コードが表示されます。では、こ
れをどこかに書き込みます (どこでも構いません、後で捨てます):

        :write main.c.html

このファイルをお気に入りのブラウザーで開き、そこから印刷します。すべてうまくい
けば、出力は Vim で見えるのとまったく同じに見えるはずです。詳細は 2html.vim
を参照してください。使い終わったら HTML ファイルを削除するのを忘れないでくださ
い。

印刷する代わりに、HTML ファイルを Web サーバーに置いて、他の人に色付きのテキス
トを見てもらうこともできます。
