                                                        ft-context-intro
はじめに

ConTeXt は、LaTeX と同様に、TeX の上に構築されたマクロベースの組版システムであ
る:

        https://wiki.contextgarden.net
        https://wiki.contextgarden.net/Input_and_compilation/Text_editors/Vim

ConTeXt プラグインは、ConTeXt 文書のための構文ハイライト、補完、および組版のサ
ポートを提供する。文書を組版するのに推奨される方法は :ConTeXt を使うことで、
これは $PATH にある mtxrun スクリプトを起動する。

コマンドおよびその環境をより細かく制御するには、context.Typeset() を直接使え
る (旧来の Vim script からは context#Typeset())。例えば、ConTeXt のあるバー
ジョンが ~/context にインストールされている場合、それを使う関数を以下のよう
に定義できる:

        import autoload 'context.vim'

        var os = "linux"    # システムに合わせて更新する
        var arch = "arm64"  # システムに合わせて更新する

        def MyConTeXt()
          var env = {
            'PATH': $'{$HOME}/context/tex/texmf-{os}-{arch}/bin:{$PATH}'
          }
          context.Typeset("%", env)
        enddef

        nnoremap <silent><buffer><leader>t <scriptcmd>MyConTeXt()<cr>

このコードは ~/.vim/after/ftplugin/context.vim に置くべきである。

context.Typeset() は、独自の組版コマンドを指定するための省略可能な 3 番目の
引数を受け付ける。それは、パスを受け取ってコマンドを list として返す関数でな
ければならない。例:

        def ConTeXtCustomCommand(path: string): list<string>
          return ['mtxrun', '--script', 'context', '--nonstopmode', path]
        enddef

        def MyContext()
            context.Typeset("%", v:none, ConTeXtCustomCommand)
        enddef

大きなプロジェクトは、ルート文書およびさまざまな章ファイルで構成されていること
が多い。章ファイルを編集しているときは、ルートファイルに切り替えなくても、その
ファイルで直接 :ConTeXt を起動できると便利である。各章ファイルの先頭に、ルー
トファイルへの相対パスを指定する "マジックライン" を追加できる。例:

        % !TEX root = ../MyRoot.tex

Vim はカレントバッファの最初の 10 行でマジックラインを探す: 見つかった場合は、
カレントバッファの文書ではなく、その行で指定された文書が組版される。ルート文書
を Vim で開いておく必要はない。

補完および構文ハイライトを拡張するには、ConTeXt を使って補助ファイルを生成し、
それを設定に追加できる。設定が ~/.vim にある場合は、これらのコマンドを使える:

        mkdir -p ~/.vim/syntax/shared
        cd ~/.vim/syntax/shared
        mtxrun --script interface --vim

最後のコマンドは、以下の構文ファイルを作成する:

- context-data-context.vim;
- context-data-interfaces.vim;
- context-data-metafun.vim;
- context-data-tex.vim.

これらのファイルがあれば、構文ハイライトを強化するために自動的に読み込まれる。
同じコマンドで、これらの構文ファイルを更新できる。

                                                        ft-context-commands
コマンド
                                        :ConTeXt
カレントバッファの文書を組版するバックグラウンドの job を開始する。別のバッ
ファにある文書を組版したい場合は、このコマンドに省略可能なバッファ名を指定でき
る。

                                        :ConTeXtLog
カレントバッファのソースに対応するログファイルを編集する。

                                        :ConTeXtJobsStatus
現在バックグラウンドで実行中のジョブの数を表示する。

                                        :ConTeXtStopJobs
現在バックグラウンドで実行中のすべての ConTeXt ジョブを停止する。

                                                        ft-context-settings
設定
                                        'b:context_ignore_makefile'
                                        'g:context_ignore_makefile'
:make を使って文書を (同期的に) 組版できる。Makefile があり、このオプション
が設定されていない場合は、標準の make が使われる。このオプションが設定されて
いる場合は、Makefile があっても、代わりに mtxrun が起動される。

        g:context_ignore_makefile = 0

NOTE: :make を使う前に、バッファの作業ディレクトリが、組版したいファイルの
ディレクトリに設定されていることを確かめること。さらに、:make は $PATH から
mtxrun を探すことに注意すること。

                                        'g:context_extra_options'
mtxrun に渡す追加のオプションのリスト。

        g:context_extra_options = []

                                        'b:context_include'
                                        'g:context_include'
\startGROUP と \stopGROUP の間で構文ハイライトを有効にする、ファイルタイプ
/GROUP の組の辞書。デフォルトでは、\startXML と \stopXML の間を XML として
ハイライトする。

        g:context_include = {'xml': 'XML'}

NOTE: Lua および MetaPost は、それぞれのブロックの中で常にハイライトされる。

                                        'g:no_context_maps'
設定されている場合、マッピングを定義しない。

        g:no_context_maps = 0

                                                        ft-context-mappings
マッピング

tp                      "TeX の段落を整形し直す" (移動)。

i$                      "インライン数式ブロックの内側" (テキストオブジェクト選
                        択)。

a$                      "インライン数式ブロックの周り" (テキストオブジェクト選
                        択)。

]]                      [count] 個先の節の始まり。

[[                      [count] 個前の節の始まり。

][                      [count] 個先の節の終わり。

[]                      [count] 個前の節の終わり。

]}                      [count] 個先のブロック (\stop...、\setup...、
                        \define...) の終わり。

[{                      [count] 個前のブロック (\start...、\setup...、
                        \define...) の始まり。
