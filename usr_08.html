08.1  ウィンドウを分割する

新しいウィンドウを開く最も簡単な方法は、以下のコマンドを使うことです:

        :split

このコマンドは画面を 2 つのウィンドウに分割し、カーソルを上のウィンドウに置い
たままにします:

        +----------------------------------+
        |/* file one.c */                  |
        |~                                 |
        |~                                 |
        |one.c=============================|
        |/* file one.c */                  |
        |~                                 |
        |one.c=============================|
        |                                  |
        +----------------------------------+

ここに見えているのは、同じファイル上の 2 つのウィンドウです。"====" のある行は
ステータスラインです。これはその上のウィンドウについての情報を表示します。(実
際には、ステータスラインは反転表示されます。)
   2 つのウィンドウによって、同じファイルの 2 つの部分を見ることができます。例
えば、上のウィンドウにプログラムの変数宣言を表示させ、下のウィンドウにそれらの
変数を使うコードを表示させることができます。

CTRL-W w コマンドを使って、ウィンドウ間をジャンプできます。上のウィンドウにい
る場合、CTRL-W w はその下のウィンドウにジャンプします。下のウィンドウにいる場
合、最初のウィンドウにジャンプします。(CTRL キーを離すのが少し遅れた場合に備え
て、CTRL-W CTRL-W も同じことをします。)


ウィンドウを閉じる

ウィンドウを閉じるには、このコマンドを使います:

        :close

実際には、":quit" および "ZZ" のように、ファイルの編集を終了するどのコマンドも
機能します。しかし、":close" は、最後のウィンドウを閉じるときに誤って Vim を終
了してしまうのを防ぎます。


他のすべてのウィンドウを閉じる

大量のウィンドウを開いたが、今はそのうちの 1 つに集中したい場合、このコマンド
が役に立ちます:

        :only

これは、カレントウィンドウを除くすべてのウィンドウを閉じます。他のウィンドウの
いずれかに変更がある場合、エラーメッセージが表示され、そのウィンドウは閉じられ
ません。

08.2  別のファイルでウィンドウを分割する

以下のコマンドは 2 つ目のウィンドウを開き、指定されたファイルの編集を開始しま
す:
        :split two.c

one.c を編集していた場合、結果はこのようになります:

        +----------------------------------+
        |/* file two.c */                  |
        |~                                 |
        |~                                 |
        |two.c=============================|
        |/* file one.c */                  |
        |~                                 |
        |one.c=============================|
        |                                  |
        +----------------------------------+

新しい空のファイルでウィンドウを開くには、これを使います:

        :new

":split" および ":new" コマンドを繰り返して、好きなだけウィンドウを作成できま
す。

08.3  ウィンドウサイズ

":split" コマンドは数値の引数を取ることができます。指定された場合、これが新し
いウィンドウの高さになります。例えば、以下は高さ 3 行の新しいウィンドウを開き、
ファイル alpha.c の編集を開始します:

        :3split alpha.c

既存のウィンドウでは、いくつかの方法でサイズを変更できます。動作するマウスがあ
る場合は簡単です: 2 つのウィンドウを区切っているステータスラインにマウスポイン
タを移動し、それを上または下にドラッグします。

ウィンドウのサイズを大きくするには:

        CTRL-W +

ウィンドウのサイズを小さくするには:

        CTRL-W -

これらのコマンドはどちらもカウントを取り、その行数だけウィンドウサイズを大きく
するか、または小さくします。したがって、"4 CTRL-W +" はウィンドウを 4 行高くし
ます。

ウィンドウの高さを指定した行数に設定するには:

        {height}CTRL-W _

つまり: 数値 {height}、CTRL-W、そしてアンダースコアです (English-US キーボード
では Shift を押しながらの - キー)。
   ウィンドウをできるだけ高くするには、カウントなしで CTRL-W _ コマンドを使い
ます。


マウスを使う

Vim では、キーボードから多くのことを非常に素早く行えます。残念ながら、ウィンド
ウのサイズを変更するコマンドはかなりのタイプを必要とします。この場合は、マウス
を使う方が速いです。マウスポインタをステータスラインの上に置きます。そして、マ
ウスの左ボタンを押してドラッグします。ステータスラインが移動し、それによって一
方の側のウィンドウが高くなり、もう一方が小さくなります。


オプション

'winheight' オプションにはウィンドウの望ましい最小の高さを、'winminheight' に
は絶対的な最小の高さを設定できます。
   同様に、望ましい最小の幅には 'winwidth' があり、絶対的な最小の幅には
'winminwidth' があります。
   'equalalways' オプションは、設定されていると、ウィンドウが閉じられるか、ま
たは開かれたときに、Vim にウィンドウのサイズを均等にさせます。

08.4  垂直分割

":split" コマンドは、新しいウィンドウをカレントウィンドウの上に作成します。ウィ
ンドウを左側に表示させるには、以下を使います:

        :vsplit

または:
        :vsplit two.c

結果はおおよそこのようになります:

        +--------------------------------------+
        |/* file two.c */   |/* file one.c */  |
        |~                  |~                 |
        |~                  |~                 |
        |~                  |~                 |
        |two.c===============one.c=============|
        |                                      |
        +--------------------------------------+

実際には、真ん中の | の線は反転表示されます。これは垂直セパレーターと呼ばれま
す。これはその左右の 2 つのウィンドウを区切ります。

新しい空のファイルで垂直分割されたウィンドウを開く ":vnew" コマンドもあります。
これを行う別の方法:

        :vertical new

":vertical" コマンドは、ウィンドウを分割する別のコマンドの前に挿入できます。こ
れにより、そのコマンドはウィンドウを水平ではなく垂直に分割するようになります。
(そのコマンドがウィンドウを分割しない場合、変更されずに動作します。)


ウィンドウ間を移動する

ウィンドウは水平および垂直に好きなだけ分割できるので、ほとんどどんなウィンドウ
のレイアウトでも作成できます。そして、これらのコマンドを使ってそれらの間を移動
できます:

        CTRL-W h        左のウィンドウに移動する
        CTRL-W j        下のウィンドウに移動する
        CTRL-W k        上のウィンドウに移動する
        CTRL-W l        右のウィンドウに移動する

        CTRL-W t        一番上のウィンドウに移動する
        CTRL-W b        一番下のウィンドウに移動する

カーソルの移動に使われるのと同じ文字であることに気付くでしょう。そして、好きな
場合は、カーソルキーも使えます。
   他のウィンドウに移動するその他のコマンド: Q_wi。

08.5  ウィンドウを移動する

いくつかのウィンドウを分割しましたが、今それらは間違った場所にあります。そこ
で、ウィンドウを別のどこかに移動するコマンドが必要です。例えば、このような 3
つのウィンドウがあります:

        +----------------------------------+
        |/* file two.c */                  |
        |~                                 |
        |~                                 |
        |two.c=============================|
        |/* file three.c */                |
        |~                                 |
        |~                                 |
        |three.c===========================|
        |/* file one.c */                  |
        |~                                 |
        |one.c=============================|
        |                                  |
        +----------------------------------+

明らかに、最後のものが一番上にあるべきです。そのウィンドウに (CTRL-W w を使っ
て) 移動し、それからこのコマンドをタイプします:

        CTRL-W K

これは大文字の K を使います。起こることは、ウィンドウが一番上に移動されること
です。K がここでも上方向への移動に使われていることに気付くでしょう。
   垂直分割がある場合、CTRL-W K はカレントウィンドウを一番上に移動し、Vim ウィ
ンドウの幅全体を占めるようにします。あなたのレイアウトがこれである場合:

        +-------------------------------------------+
        |/* two.c */  |/* three.c */  |/* one.c */  |
        |~            |~              |~            |
        |~            |~              |~            |
        |~            |~              |~            |
        |~            |~              |~            |
        |~            |~              |~            |
        |two.c=========three.c=========one.c========|
        |                                           |
        +-------------------------------------------+

このとき、真ん中のウィンドウ (three.c) で CTRL-W K を使うと、結果はこうなりま
す:

        +-------------------------------------------+
        |/* three.c */                              |
        |~                                          |
        |~                                          |
        |three.c====================================|
        |/* two.c */           |/* one.c */         |
        |~                     |~                   |
        |two.c==================one.c===============|
        |                                           |
        +-------------------------------------------+

他の 3 つの同様のコマンド (おそらくもう推測できるでしょう):

        CTRL-W H        ウィンドウを左端に移動する
        CTRL-W J        ウィンドウを一番下に移動する
        CTRL-W L        ウィンドウを右端に移動する

08.6  すべてのウィンドウに対するコマンド

複数のウィンドウを開いていて Vim を終了したいとき、各ウィンドウを個別に閉じる
ことができます。より素早い方法は、このコマンドを使うことです:

        :qall

これは "quit all" を表します。いずれかのウィンドウに変更が含まれている場合、
Vim は終了しません。カーソルは自動的に変更のあるウィンドウに置かれます。それか
ら、":write" を使って変更を保存するか、または ":quit!" を使って変更を破棄する
ことができます。

変更のあるウィンドウがあることがわかっていて、それらの変更をすべて保存したい場
合、このコマンドを使います:

        :wall

これは "write all" を表します。しかし実際には、変更のあるファイルだけを書き込
みます。Vim は、変更されていないファイルを書き込むのは意味がないことを知ってい
ます。
   そして、":qall" および ":wall" の組み合わせもあります: "write and quit all"
コマンドです:

        :wqall

これは変更されたすべてのファイルを書き込み、Vim を終了します。
   最後に、Vim を終了してすべての変更を破棄するコマンドがあります:

        :qall!

注意してください。このコマンドを undo する方法はありません!


すべての引数に対してウィンドウを開く

Vim に各ファイルに対してウィンドウを開かせるには、"-o" 引数を付けて起動します:


        vim -o one.txt two.txt three.txt

結果はこうなります:

        +-------------------------------+
        |file one.txt                   |
        |~                              |
        |one.txt========================|
        |file two.txt                   |
        |~                              |
        |two.txt========================|
        |file three.txt                 |
        |~                              |
        |three.txt======================|
        |                               |
        +-------------------------------+

"-O" 引数は、垂直分割されたウィンドウを得るために使われます。
   Vim がすでに実行中のときは、":all" コマンドが引数リスト内の各ファイルに対し
てウィンドウを開きます。":vertical all" はそれを垂直分割で行います。

08.7  vimdiff で差分を見る

2 つのファイルの間の差分を表示する、Vim の特別な起動方法があります。ファイル
"main.c" を取り上げ、1 行に数文字を挿入してみましょう。'backup' オプションを設
定した状態でこのファイルを書き込み、バックアップファイル "main.c~" にファイル
の以前のバージョンが含まれるようにします。
   シェルで (Vim の中ではなく) このコマンドをタイプします:

        vimdiff main.c~ main.c

Vim が起動し、2 つのウィンドウが横に並びます。見えるのは、文字を追加した行、お
よびその上下の数行だけです。

         VV                   VV
        +-----------------------------------------+
        |+ +--123 lines: /* a|+ +--123 lines: /* a|  <- 折り畳み
        |  text              |  text              |
        |  text              |  text              |
        |  text              |  text              |
        |  text              |  changed text      |  <- 変更された行
        |  text              |  text              |
        |  text              |  ------------------|  <- 削除された行
        |  text              |  text              |
        |  text              |  text              |
        |  text              |  text              |
        |+ +--432 lines: text|+ +--432 lines: text|  <- 折り畳み
        |  ~                 |  ~                 |
        |  ~                 |  ~                 |
        |main.c~==============main.c==============|
        |                                         |
        +-----------------------------------------+

(この図はハイライトを表示していません。よりよく見るには vimdiff コマンドを使っ
てください。)

変更されていない行は 1 行にまとめられています。これは閉じた折り畳みと呼ばれま
す。図では、それらは "<- 折り畳み" で示されています。したがって、一番上の 1 つ
の折り畳み行は 123 行のテキストを表しています。これらの行は両方のファイルで等
しいです。
   "<- 変更された行" の印が付いた行はハイライトされ、挿入されたテキストは別の
色で表示されます。これにより、2 つのファイルの間の違いが何であるかがはっきりと
示されます。
   削除された行は、main.c ウィンドウで "---" で表示されます。図の
"<- 削除された行" の印を見てください。これらの文字は実際にはそこにありません。
これらは単に main.c を埋めて、もう一方のウィンドウと同じ行数を表示するようにし
ているだけです。


折り畳み列

各ウィンドウには、左側に背景が少し異なる列があります。上の図では、これらは
"VV" で示されています。そこには、各閉じた折り畳みの前にプラス文字があることに
気付きます。マウスポインタをそのプラスに移動し、左ボタンをクリックします。折り
畳みが開き、それが含むテキストを見ることができます。
   折り畳み列には、開いた折り畳みに対してマイナス記号が含まれます。この - をク
リックした場合、折り畳みが閉じます。
   明らかに、これは動作するマウスがあるときだけ機能します。折り畳みを開くのに
"zo"、閉じるのに "zc" を使うこともできます。


Vim の中で差分を取る

diff モードで始める別の方法は、Vim の中から行うことができます。"main.c" ファイ
ルを編集し、それから分割して差分を表示します:

        :edit main.c
        :vertical diffsplit main.c~

":vertical" コマンドは、ウィンドウを垂直に分割させるために使われます。これを省
略した場合、水平分割になります。

パッチまたは diff ファイルがある場合、diff モードを開始する 3 つ目の方法を使え
ます。まず、パッチが適用されるファイルを編集します。それから、Vim にパッチファ
イルの名前を伝えます:

        :edit main.c
        :vertical diffpatch main.c.diff

警告: パッチファイルには、編集しているファイルに対する 1 つのパッチだけが含ま
れていなければなりません。そうでないと、大量のエラーメッセージが表示され、いく
つかのファイルが予期せずパッチされるかもしれません。
   パッチ適用は Vim の中のファイルのコピーに対してだけ行われます。あなたのハー
ドディスク上のファイルは (ファイルを書き込むことにするまで) 変更されないままで
す。


スクロールバインド

ファイルにもっと多くの変更がある場合、通常の方法でスクロールできます。Vim は両
方のウィンドウが同じ位置から始まるように保とうとするので、差分を横に並べて簡単
に見ることができます。
   少しの間これを望まないときは、このコマンドを使います:

        :set noscrollbind


変更へジャンプする

何らかの方法で折り畳みを無効にしているときは、変更を見つけるのが難しいかもしれ
ません。次の変更へ前方にジャンプするには、このコマンドを使います:

        ]c

逆方向に行くには、これを使います:

        [c

さらに遠くへジャンプするには、カウントを前に付けます。したがって、"4]c" は 4
つ先の変更へジャンプし、"3[c" は 3 つ前の変更へジャンプします。


変更を取り除く

あるウィンドウからもう一方へテキストを移動できます。これは差分を取り除くか、ま
たは新しい差分を追加します。Vim はすべての状況でハイライトを更新し続けるわけで
はありません。それを更新するには、このコマンドを使います:

        :diffupdate

差分を取り除くには、ハイライトされたブロック内のテキストをあるウィンドウから別
のウィンドウへ移動できます。上の "main.c" および "main.c~" の例を取り上げます。
カーソルを左のウィンドウの、もう一方のウィンドウで削除された行に移動します。そ
して、このコマンドをタイプします:

        dp

カレントウィンドウのテキストをもう一方のウィンドウに置くことで、変更が取り除か
れます。"dp" は "diff put" を表します。
   逆の方法で行うこともできます。カーソルを右のウィンドウの、"changed" が挿入
された行に移動します。そして、このコマンドをタイプします:

        do

今度は、もう一方のウィンドウからテキストを取得することで、変更が取り除かれま
す。もう変更が残っていないので、Vim はすべてのテキストを閉じた折り畳みに入れま
す。
"do" は "diff obtain" を表します。"dg" の方が良かったのですが、それにはすでに
別の意味があります ("dgg" はカーソルから最初の行までを削除します)。

diff モードについての詳細は、vimdiff を参照してください。

08.8  その他

'laststatus' オプションを使って、最後のウィンドウがステータスラインを持つとき
を指定できます:

        0       決してない
        1       分割されたウィンドウがあるときだけ (既定)
        2       常に

別のファイルを編集する多くのコマンドには、ウィンドウを分割する変種があります。
コマンドラインのコマンドでは、これは "s" を前に付けることで行われます。例えば:
":tag" はタグへジャンプし、":stag" はウィンドウを分割してタグへジャンプします。
   ノーマルモードのコマンドでは、CTRL-W が前に付けられます。CTRL-^ は代替ファ
イルへジャンプし、CTRL-W CTRL-^ はウィンドウを分割して代替ファイルを編集しま
す。

'splitbelow' オプションは、新しいウィンドウをカレントウィンドウの下に表示させ
るように設定できます。'splitright' オプションは、垂直分割されたウィンドウをカ
レントウィンドウの右に表示させるように設定できます。

ウィンドウを分割するとき、修飾コマンドを前に付けて、ウィンドウがどこに表示され
るかを指示できます:

        :leftabove {cmd}        カレントウィンドウの左または上
        :aboveleft {cmd}        同上
        :rightbelow {cmd}       カレントウィンドウの右または下
        :belowright {cmd}       同上
        :topleft {cmd}          Vim ウィンドウの上端または左端
        :botright {cmd}         Vim ウィンドウの下端または右端

08.9  タブページ

ウィンドウが決して重ならないことに気付いたでしょう。それは、すぐに画面のスペー
スが足りなくなることを意味します。これに対する解決策はタブページと呼ばれます。

"thisfile" を編集しているとします。新しいタブページを作成するには、このコマン
ドを使います:

        :tabedit thatfile

これは、Vim ウィンドウ全体を占めるウィンドウでファイル "thatfile" を編集しま
す。そして、一番上に 2 つのファイル名のあるバーがあることに気付くでしょう:

        +----------------------------------+
        | thisfile | /thatfile/ __________X|    (thatfile は太字)
        |/* thatfile */                    |
        |that                              |
        |that                              |
        |~                                 |
        |~                                 |
        |~                                 |
        |                                  |
        +----------------------------------+

これで 2 つのタブページがあります。1 つ目には "thisfile" のウィンドウがあり、2
つ目には "thatfile" のウィンドウがあります。それは重なり合った 2 つのページの
ようなもので、各ページからはファイル名を示すタブが突き出ています。

では、マウスを使って一番上の行の "thisfile" をクリックします。結果は

        +----------------------------------+
        | /thisfile/ | thatfile __________X|    (thisfile は太字)
        |/* thisfile */                    |
        |this                              |
        |this                              |
        |~                                 |
        |~                                 |
        |~                                 |
        |                                  |
        +----------------------------------+

したがって、一番上の行のラベルをクリックすることで、タブページを切り替えること
ができます。マウスがないか、またはマウスを使いたくない場合、"gt" コマンドを使
えます。覚え方: Goto Tab。

では、このコマンドで別のタブページを作成しましょう:

        :tab split

これは、私たちがいたウィンドウと同じバッファを編集している 1 つのウィンドウを
持つ、新しいタブページを作成します:

        +-------------------------------------+
        | thisfile | /thisfile/ | thatfile __X|   (thisfile は太字)
        |/* thisfile */                       |
        |this                                 |
        |this                                 |
        |~                                    |
        |~                                    |
        |~                                    |
        |                                     |
        +-------------------------------------+

ウィンドウを開く任意の Ex コマンドの前に ":tab" を置くことができます。ウィンド
ウは新しいタブページで開かれます。別の例:

        :tab help gt

新しいタブページで "gt" のヘルプテキストを表示します。

タブページでできることをさらにいくつか:

- 最後のラベルの後ろの空白部分をマウスでクリックする
        "gt" と同様に、次のタブページが選択される。

- 右上隅の "X" をマウスでクリックする
        カレントタブページが閉じられる。カレントタブページに保存されていない変
        更がない限り。

- 一番上の行でマウスをダブルクリックする
        新しいタブページが作成される。

- "tabonly" コマンド
        カレントのものを除くすべてのタブページを閉じる。他のタブページに保存さ
        れていない変更がない限り。

タブページについてのさらなる情報は tab-page を参照してください。
